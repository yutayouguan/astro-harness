# Astro 设置中心设计稿

## 交付物

- `Astro Settings Prototype.html`：完整设置中心高保真交互原型，覆盖侧栏中的 13 个设置页面。
- `Wallpaper Settings Prototype.html`：上一版壁纸设置专项原型，作为外观页的设计来源保留。

## 设计目标

- 壁纸是全局 Shell 底层，不是聊天页的局部装饰。
- 背景来源与界面强调色分离，继续复用 Astro 现有 tone 与玻璃体系。
- 上传或 AI 生成的图片仅在成功校验后应用，失败不替换当前壁纸。
- AI 生成使用已配置的独立图片 Provider，默认生成横向画面。
- 设置侧边栏按“通用 / 智能体 / 扩展 / 系统”分组，子项使用清晰的能力名称，不与分组重名。

## 原型交互

- 搜索和切换全部设置页，URL hash 保留当前页面。
- 跨页保留设置草稿，统一提供“撤销 / 保存设置”操作。
- 偏好、对话、终端、自动压缩、记忆和浏览器页的表单状态可交互。
- 模型服务支持选择服务、连接测试和凭据状态演示。
- 工具与技能支持分类、搜索和启用状态切换。
- 模型市场支持搜索、能力筛选、选中模型和应用到对话。
- 数据洞察支持周期切换，图表和指标同步变化。
- 诊断页支持级别筛选、日志搜索、摘要复制与导出反馈。
- 切换“氛围配色 / 图片壁纸”。
- 上传本地图片并立即预览。
- 调整填充、内容保护与柔化。
- 打开 AI 生成对话框，体验生成中状态和成功后自动应用。
- 从最近使用列表切换壁纸。

## 与现有功能的对齐

- 终端使用真实的 `system / project` 执行模式，并覆盖字体、行高、光标和回滚设置。
- 自动压缩展示 soft / medium / hard 三阶段以及工具结果与尾部气泡保护。
- 工具页对齐内置工具与审批两个主页签，包含浏览器授权和命令允许列表。
- 记忆页对齐日记 / 入梦 / 长期记忆 / 待审四个真实视图。
- 模型市场包含目录 / 排行、三种布局、全部模型类型与能力筛选。
- 数据洞察对齐概览 / 模型 / 工具 / Tracing 以及月 / 季 / 年周期。
- 应用图标预览直接复用 Tauri 端内置的 5 套图标资源。
