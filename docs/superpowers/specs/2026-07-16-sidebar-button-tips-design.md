# 侧栏按钮动态提示设计

## 目标

两个侧栏图标按钮的提示文案根据当前状态显示点击后将执行的动作：

- 导航栏显示时：`收起导航栏` / `Collapse sidebar`
- 导航栏隐藏时：`显示导航栏` / `Show sidebar`
- 文字显示时：`收起文字` / `Collapse text`
- 文字隐藏时：`显示文字` / `Show text`

## 实现

保留 `App.tsx` 中已有的状态判断和动态翻译键，仅调整 `messages.ts` 内对应的中英文翻译值。`title` 与 `aria-label` 使用一致的动作语义，不新增状态或组件逻辑。

## 验证

分别点击两个按钮，确认提示会随导航栏和文字状态即时切换；切换中英文后，四种动作提示均与当前状态相反并准确描述下一次点击行为。
