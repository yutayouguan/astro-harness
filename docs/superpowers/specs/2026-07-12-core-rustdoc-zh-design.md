# 核心业务中文注释设计

**日期:** 2026-07-12  
**状态:** 已批准  
**范围:** `agent` / `memory` / `providers` / `tools`

## 目标

为上述四个 crate 的 Rust 源码补充完整中文文档注释，覆盖模块、结构体、枚举、trait、函数、宏与重要常量，便于阅读与维护。不改业务逻辑。

## 规范

- 文件顶：`//!` 模块职责与在系统中的位置
- 项注释：`///`（含私有项；私有可更短）
- 内容写「做什么 / 为何 / 约束」，不复述字面代码
- 复杂 API 可用 `# 参数` / `# 返回` / `# 错误`
- 已有准确注释保留并统一风格；测试文件可只写模块级说明

## 执行顺序

1. `agent`
2. `memory`
3. `providers`
4. `tools`

## 非目标

- 不注释 `frontend` / `backend` / `mcp` 等
- 不重构、不改命名、不改行为
- 不自动 `git commit`（除非用户另行要求）
