# 上下文用量界面玻璃化美化设计

## 目标

保持对话侧栏现有浅色玻璃风格，增强上下文用量页面的信息层级、图标语义和空状态表现，不改变数据计算与交互逻辑。

## 界面设计

### 顶部指标

将会话上下文、上下文窗口和已用 tokens 改为三张紧凑的半透明指标卡：

- 会话上下文使用 `MessageSquare` 图标。
- 上下文窗口使用 `Database` 图标。
- 已用 tokens 使用 `Coins` 图标。
- 卡片保留窄侧栏下的三列布局，数值继续使用等宽数字样式。

### 用量环图

- 将环图放入独立玻璃容器，增加柔和高光、边框和背景层次。
- 保留现有分层弧线、百分比计算和无数据圆环。
- 在百分比下方增加“已用”短标签，明确数字含义。

### 分层占用

- 标题加入 `Layers3` 图标。
- 每个分层条目根据类型显示对应 Lucide 线性图标，同时保留颜色圆点。
- 展开、收起、token 数量和提示文案行为保持不变。

### 空状态

- 使用带图标的虚线玻璃容器替代单行文本。
- 继续显示“发送对话后可查看分层占用”，不新增文案。

## 技术范围

- 修改 `frontend/src/components/chat/ContextExplorer.tsx`，引入并渲染 Lucide 图标。
- 修改 `frontend/src/styles/features/chat/right-panel.css`，完成卡片、环图、列表和空状态样式。
- 不修改上下文数据结构、计算函数、国际化文案或其他侧栏 Tab。

## 验证

- 无上下文数据时，指标、环图和空状态布局完整。
- 有上下文数据时，分层图标、色点、数值和展开交互正常。
- 浅色与深色主题下文字、边框和背景保持可读。
- 运行前端构建与相关上下文用量测试。
