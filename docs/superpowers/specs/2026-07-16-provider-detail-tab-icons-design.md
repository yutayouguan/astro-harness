# 模型提供商详情 Tab 图标设计

## 目标

为模型提供商详情页的“聊天”和“媒体”两个 Tab 增加易识别的线性图标，同时保持现有布局、交互与选中态不变。

## 设计

- “聊天”使用 `lucide-react` 的 `MessageCircle`。
- “媒体”使用 `lucide-react` 的 `Image`。
- 图标位于文字左侧，尺寸为 14px，描边宽度为 2。
- Tab 使用行内 Flex 布局，图标与文字间距为 6px，并保持垂直居中。
- 图标颜色继承 Tab 当前文字颜色，因此未选中态和选中态会自动保持现有视觉层级。
- 图标设置 `aria-hidden`；Tab 的可访问名称继续由现有文字提供。

## 范围

仅修改 `ProvidersPanel` 的图标引用与两个 Tab 的内容，并补充对应的对齐样式。不改变 Tab 状态、点击逻辑、文案、下划线、面板内容或响应式行为。

## 验证

- 支持媒体模型的提供商详情页显示两个带图标的 Tab。
- 图标与文字垂直居中，间距一致。
- 切换 Tab 后图标随文字继承选中颜色。
- TypeScript 检查和前端构建通过。
