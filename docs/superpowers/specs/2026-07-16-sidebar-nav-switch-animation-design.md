# 左侧导航切换动画

日期：2026-07-16  
状态：已批准，待实施

## 目标

用户切换左侧导航项时，让选中高亮块在菜单项之间平滑滑动，明确展示当前位置变化。保留现有页面内容切换动画、导航行为和主题配色。

## 方案

在导航按钮外增加一个定位容器，并在容器内放置唯一的共享高亮块。高亮块根据当前导航项索引通过 `transform: translateY(...)` 移动；按钮本身继续负责图标、标签、徽标、点击和无障碍名称。

所有导航行使用一致的高度和间距，使图标模式与文字模式共用同一套纵向定位。高亮块的宽度、圆角和横向位置随侧栏模式变化：

- 仅图标模式：保持当前方形选中态。
- 显示文字模式：保持当前横向胶囊选中态。
- 主题色：继承当前导航项对应的 tone，延续现有明暗主题样式。

现有 `.nav-item.active` 的背景、边框和阴影视觉迁移到共享高亮块；活动按钮继续控制文字和图标颜色，避免出现双层高亮。

## 动画

- 时长约 `220ms`。
- 使用减速缓动 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 只动画 `transform`，避免布局抖动。
- 快速连续点击时，CSS transition 从当前位置追随最新导航项，不阻塞交互。
- `prefers-reduced-motion: reduce` 时取消位移动画，高亮块立即到位。

首次渲染不播放从顶部滑入的动画，避免启动时产生无意义运动。

## 范围

预计修改：

- `frontend/src/App.tsx`：增加导航定位容器、高亮块和当前索引变量。
- `frontend/src/styles/layout.css`：迁移选中态视觉并加入高亮块定位和动画。

不引入动画库，不修改页面内容的 `AnimatedSwitch`，不改变侧栏展开/收起逻辑，也不在本次改动中拆分 `App.tsx`。

## 验收与验证

1. 在仅图标和显示文字两种模式下，高亮块均准确覆盖当前项。
2. 向上、向下及快速连续切换时，高亮移动连续且不闪烁。
3. 明暗主题及各导航 tone 的颜色、边框和阴影正确。
4. 徽标、tooltip、键盘焦点和点击区域保持可用。
5. 减少动态效果系统设置下不播放位移动画。
6. `cd frontend && npm run build` 通过。
