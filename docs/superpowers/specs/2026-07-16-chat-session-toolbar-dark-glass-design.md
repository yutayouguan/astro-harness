# 会话工具栏按钮暗色毛玻璃适配

## 目标

让对话侧栏会话工具栏中的“新建会话”和 Agent 选择按钮在暗色主题下使用深色毛玻璃表面，避免沿用亮色变量后出现大面积灰白填充，同时保持现有布局、蓝色强调色和交互行为。

## 方案

在 `apps/desktop/src/styles/features/chat/right-panel.css` 中为暗色主题下的 `.chat-session-toolbar` 覆盖现有五个局部玻璃变量：

- 默认填充改为深紫黑半透明底，并保留低强度顶部高光。
- 悬停填充仅小幅提亮，避免变成亮色按钮。
- 边框使用低透明白色与当前 tone 混合。
- 阴影改为黑色柔影和低强度内高光。

现有按钮选择器继续消费这些变量，因此“新建会话”和 Agent 选择按钮会同步适配，搜索按钮的同组视觉也保持一致。亮色主题变量、组件结构、尺寸与事件处理不变。

## 状态

- 默认：深色半透明表面，与侧栏背景拉开轻微层级。
- Hover / Agent 菜单打开：表面略微提亮，边框增加当前蓝色 tone 的可见度。
- Active：沿用现有轻微缩放反馈。
- Disabled：继续由通用 AgentPicker 样式处理。

## 验证

- 暗色主题下检查“新建会话”和 Agent 选择按钮的默认、悬停与菜单打开状态。
- 亮色主题下确认现有玻璃效果未变化。
- 确认搜索按钮与同组按钮仍保持一致高度、圆角和间距。
- 运行前端现有静态检查或构建命令，确认 CSS 修改未引入错误。
