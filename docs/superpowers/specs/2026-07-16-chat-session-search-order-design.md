# 会话工具栏搜索按钮顺序设计

## 目标

将对话侧栏会话工具栏中的搜索按钮移到最后，使控件顺序变为“新建会话 → Agent → 搜索”。

## 实现

仅调整 `apps/desktop/src/components/chat/ChatSessionList.tsx` 中三个工具栏控件的 JSX 顺序：

- 新建会话按钮保持第一位。
- Agent 选择器保持第二位。
- 可展开搜索按钮移动到最右侧。
- 不修改控件样式、尺寸、搜索逻辑和响应式行为。

直接调整 DOM 顺序，确保视觉顺序与键盘 Tab 导航顺序一致。

## 验证

- 打开对话侧栏，确认工具栏顺序正确。
- 点击并展开搜索，确认会话过滤功能正常。
- 使用键盘 Tab，确认焦点依次经过新建会话、Agent 和搜索。
- 运行前端构建检查。
