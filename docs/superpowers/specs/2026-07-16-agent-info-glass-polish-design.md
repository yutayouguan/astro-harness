# Agent 信息界面玻璃化美化设计

## 目标

保持 Agent 信息页现有内容和交互不变，使其与上下文用量页的浅色玻璃仪表盘风格统一，并通过语义图标提升信息识别效率。

## 界面设计

### Agent Hero

- 为头像和身份信息增加独立玻璃背景、柔和高光和边框。
- 强化头像光晕，并将默认 Agent 信息显示为轻量状态徽标。
- 不修改 Agent 名称、ID 与默认状态逻辑。

### 信息卡片

- 用量参考使用 `Gauge` 图标。
- 记忆使用 `Brain` 图标。
- 日记使用 `NotebookText` 图标。
- 技能使用 `Sparkles` 图标。
- 卡片标题统一为“图标 + 标题”结构，使用与上下文页一致的图标底座。

### 操作按钮

- 查看上下文加入 `ArrowUpRight`。
- 编辑加入 `Pencil`。
- 复制诊断加入 `Copy`。
- 查看全部技能加入 `ArrowUpRight`。
- 保留所有按钮现有回调、文案和可访问名称。

### 内容与状态

- 记忆和日记预览优化行距、滚动条和内容背景，长内容继续滚动。
- 技能标签改为带边框和柔和高光的玻璃胶囊。
- 加载状态使用 `LoaderCircle`，不可用状态使用 `BotOff`，两者均置于轻量空状态卡片内。

## 技术范围

- 修改 `frontend/src/components/chat/ChatAgentInfo.tsx`，加入 Lucide 图标和展示钩子。
- 修改 `frontend/src/styles/features/chat/right-panel.css` 中 Agent 信息相关样式。
- 不修改数据加载、Tauri 调用、国际化文案、业务逻辑或其他侧栏 Tab。

## 验证

- 正常、加载、不可用状态均布局完整。
- 查看上下文、编辑记忆、复制诊断和查看技能行为不变。
- 长记忆与日记内容可正常滚动。
- 浅色、深色和窄侧栏下均无溢出。
- 前端构建通过。
