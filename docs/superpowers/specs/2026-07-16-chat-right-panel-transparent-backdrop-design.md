# 对话右侧栏透明点击层设计

## 目标

移除右侧栏打开时覆盖对话区域的视觉遮罩，同时保留点击侧栏外部关闭的交互。

## 实现

仅调整 `apps/desktop/src/styles/features/chat/right-panel.css`：

- 保留 `.chat-right-backdrop` 按钮及其层级，继续接收侧栏外部点击。
- 将遮罩背景改为 `transparent`。
- 移除遮罩淡入动画及不再使用的关键帧。
- 保留关闭按钮和 `Esc` 关闭行为。

## 验证

- 打开右侧栏后，对话区域不再变暗。
- 点击侧栏外部仍会关闭侧栏。
- 关闭按钮和 `Esc` 仍可关闭侧栏。
- 运行前端构建检查。
