# 记忆视图步骤条导航

日期：2026-07-15  
状态：已实现

## 背景

记忆面板四个视图原为平级 Tab。实际语义为递进流水线：

`日记 → 做梦 → 长期记忆`（采集 → 提炼 → 沉淀）；**审批**为写权限旁路闸门，不是第 4 步。

## 目标

一眼看出主流程顺序；审批与主流程视觉分离。

## 设计（方案 A）

```
[ 日记 ] › [ 做梦 ] › [ 长期记忆 ]  |  [ 审批 ]
```

- 主流程三项之间插入不可点的 `›` 箭头
- 审批前加竖向分割线，作旁路
- 小圆点动效仅覆盖主流程三段之间
- 移除旧的 Tab 边沿伪元素连接点

## 非目标

- 不加 1/2/3 序号
- 不做成大号 stepper / breadcrumb
- 不改各视图业务逻辑
