# 顶部栏与会话工具栏视觉统一设计

## 目标

- 顶部状态、模型选择器和操作按钮组统一为 40px 外部高度。
- 会话侧栏的搜索、新建会话和 Agent 选择器统一采用现有 Agent 选择器的玻璃拟态风格。
- 保留“新建会话”的蓝色文字与图标，继续表达主操作层级。

## 实现范围

仅调整以下样式文件，不修改组件结构、状态逻辑或交互行为：

- `apps/desktop/src/styles/features/shell/header.css`
- `apps/desktop/src/styles/features/chat/right-panel.css`

## 样式设计

顶部栏以 40px 为统一外高。状态芯片和模型选择器通过固定高度与 `box-sizing` 对齐；操作按钮组保持内部按钮热区不变，并使容器总高度与另外两项一致。

会话工具栏以现有 `.agent-picker-chip` 为视觉基准。搜索按钮和新建会话按钮复用相同的半透明渐变、白色边缘高光、柔和阴影、模糊效果和 12px 圆角。三项继续保持当前 36px 高度，避免改变右栏的信息密度。

## 兼容性与验证

- 保留搜索展开时隐藏其余两项的现有布局行为。
- 保留按钮的 hover、active 和 Agent 菜单交互。
- 检查明暗主题下的边框、文字对比度与玻璃背景。
- 运行前端现有静态检查，并通过实际界面截图确认高度与样式一致。
