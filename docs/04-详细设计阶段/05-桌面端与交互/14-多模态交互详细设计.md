# 多模态交互详细设计

> **Harness 边界（2026-08-29）**：多模态附件是 turn input/output 的结构化内容，由 Harness 负责持久化、Provider 转换、上下文预算和 artifact 注册。媒体生成/理解工具是 Deferred 执行能力，不应绕过 ToolRouter 或安全边界直接从 UI 调用。

> 阶段：详细设计 | 状态：草稿 | 说明：多模态内容从用户输入到 Provider 处理到 UI 渲染的完整交互层设计

Provider trait 层（`TextClient`、`ImageClient`、`TtsClient`、`AsrClient`、`VideoClient`、`MusicClient`）已在 agent-providers 详细设计中定义。本文档聚焦其上层交互：用户如何输入多模态内容、系统如何在消息模型中存储、前端如何渲染、异步媒体任务如何集成。

---

## 1. 多模态架构概述

### 1.1 ContentPart 统一内容模型

所有消息内容以 `ContentPart` 数组表示，支持文本与多媒体混排。用户消息可包含 Text、Image、Audio、File；Assistant 消息可包含 Text、Image（生成结果）、Audio（TTS）、Video（生成结果）。

### 1.2 多模态消息流

```text
用户输入（文本 / 图片粘贴 / 语音录制 / 文件拖拽）
    ▼
前端 InputBar → 构建 ContentPart[] 数组
    ▼
Tauri Command: send_multimodal_message
    ▼  MediaData::LocalPath → 读取文件 → Base64/上传
agent-runtime AgentExecutor
    ▼  按 Provider 要求格式化（Anthropic content blocks / OpenAI image_url / Google inlineData）
agent-providers → 调用 API，流式返回
    ▼
AgentEvent 推送前端（token_chunk / tts_chunk / media_task_update）
    ▼
前端 MessageBubble 多模态渲染
```

### 1.3 各 Provider 支持的模态

| Provider | 文本 | 图片输入 | 音频输入 | 视频输入 | 图片生成 | TTS | ASR | 视频生成 | 音乐生成 |
| -------- | :--: | :------: | :------: | :------: | :------: | :-: | :-: | :------: | :------: |
| Anthropic | ✓ | ✓ | ✓ | -- | -- | -- | -- | -- | -- |
| OpenAI | ✓ | ✓ | ✓ | -- | △ | △ | △ | -- | -- |
| Google | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| DeepSeek | ✓ | ✓ | -- | -- | -- | -- | -- | -- | -- |
| MiniMax | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

> △ = 降级备选。多媒体能力主力：Google + MiniMax。

## 2. 图片交互

### 2.1 图片输入

支持四种方式，统一转换为 `ContentPart::Image`：

- **粘贴**：监听 `paste` 事件，检测 `clipboardData.items` 中 `image/*` 类型，阻止默认行为后提取 `File` 对象作为附件
- **拖拽**：InputBar 注册 `dragover`/`drop`，过滤 `image/*` MIME。拖入时蓝色虚线 overlay 提示
- **文件选择器**：附件按钮弹出系统对话框，`accept="image/png,image/jpeg,image/gif,image/webp"`
- **截图/OCR**：调用 `tauri-plugin-screenshot` 截取区域，OCR 通过 Gemini 视觉理解实现

```typescript
// apps/desktop/src/components/input/ImagePasteHandler.tsx
export function useImagePasteHandler(onImageAttach: (file: File) => void) {
  useEffect(() => {
    const handler = (e: ClipboardEvent) => {
      for (const item of e.clipboardData?.items ?? []) {
        if (item.type.startsWith('image/')) {
          e.preventDefault();
          const file = item.getAsFile();
          if (file) onImageAttach(file);
        }
      }
    };
    document.addEventListener('paste', handler);
    return () => document.removeEventListener('paste', handler);
  }, [onImageAttach]);
}
```

### 2.2 图片显示

消息内联渲染：缩略图最大宽度 320px，多张以 2 列网格排列。3 张以上时前 4 张 2x2 网格，右下角 "+N" 徽章。点击打开 Lightbox（缩放/平移/左右切换/Esc 关闭）。

## 3. 语音交互

### 3.1 语音输入（麦克风 → ASR → 文本）

点击麦克风按钮或长按空格触发录音。使用 `MediaRecorder`（`audio/webm;codecs=opus`）+ `AnalyserNode` 实时波形采样：

```typescript
// apps/desktop/src/components/input/AudioRecorder.tsx
interface AudioRecorderState {
  status: 'idle' | 'recording' | 'transcribing';
  duration: number;
  waveform: number[];   // 最近 30 帧归一化音量
}

export function useAudioRecorder() {
  const [state, setState] = useState<AudioRecorderState>({ status: 'idle', duration: 0, waveform: [] });
  const recorderRef = useRef<MediaRecorder | null>(null);
  const chunksRef = useRef<Blob[]>([]);

  const start = useCallback(async () => {
    const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
    const recorder = new MediaRecorder(stream, { mimeType: 'audio/webm;codecs=opus' });
    chunksRef.current = [];
    recorder.ondataavailable = (e) => chunksRef.current.push(e.data);
    recorder.start(100);
    recorderRef.current = recorder;
    // AnalyserNode 每 4 帧采样一次波形，写入 waveform（省略 AudioContext 初始化）
    setState(s => ({ ...s, status: 'recording' }));
  }, []);

  const stop = useCallback(async (): Promise<Blob> => {
    return new Promise(resolve => {
      const r = recorderRef.current!;
      r.onstop = () => resolve(new Blob(chunksRef.current, { type: 'audio/webm' }));
      r.stop();
      r.stream.getTracks().forEach(t => t.stop());
    });
  }, []);

  return { state, start, stop };
}
```

录音结束后调用 `stop_voice_recording` Command，后端发送给 `AsrClient::transcribe()`，识别文本回填输入框供用户编辑。

### 3.2 语音输出（TTS → 流式播放）

用户启用"自动朗读回复"后，assistant 消息完成时自动触发 TTS；也可手动点击播放按钮。TTS 流式播放基于 `AudioContext`，接收 `tts_chunk` 事件的 PCM 数据块，依次拼接到播放时间线：

```typescript
export function useStreamingAudioPlayer() {
  const ctxRef = useRef<AudioContext | null>(null);
  const nextTimeRef = useRef(0);

  const playChunk = useCallback((pcm: ArrayBuffer, sampleRate: number) => {
    const ctx = ctxRef.current ??= new AudioContext({ sampleRate });
    const buf = ctx.createBuffer(1, pcm.byteLength / 4, sampleRate);
    buf.copyToChannel(new Float32Array(pcm), 0);
    const src = ctx.createBufferSource();
    src.buffer = buf;
    src.connect(ctx.destination);
    const t = Math.max(ctx.currentTime, nextTimeRef.current);
    src.start(t);
    nextTimeRef.current = t + buf.duration;
  }, []);

  return { playChunk, stop: () => { ctxRef.current?.close(); ctxRef.current = null; } };
}
```

首帧延迟目标 < 100ms。播放中消息气泡显示动态波形图标。

### 3.3 语音对话模式

连续对话循环：listening → transcribing → processing → speaking → listening。VAD 用 `AnalyserNode` 检测音量，连续 1.5s 低于阈值判定为语音结束。朗读中用户说话触发打断，立即回到 listening。

```typescript
interface VoiceConversationState {
  mode: 'idle' | 'listening' | 'transcribing' | 'processing' | 'speaking';
  isEnabled: boolean;
  silenceThreshold: number;   // 默认 0.05
  silenceTimeoutMs: number;   // 默认 1500
}
```

## 4. 视频交互

### 4.1 视频输入

支持 MP4、WebM、MOV，大小上限 100MB。支持视频输入的 Provider（Google Gemini、MiniMax M3）以 `ContentPart::Video` 传入；不支持的自动降级为提取首帧图片。

### 4.2 视频生成

异步任务通过 `VideoClient::submit()` 提交，`run_media_poller` 每 3s 轮询。生成中显示进度卡片（进度条 + 提示词 + 取消按钮），完成后替换为内嵌播放器。

## 6. ContentPart 统一消息模型

### 6.1 Rust 类型定义

```rust
// crates/agent-types/src/content.rs

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum ContentPart {
    Text { text: String },
    Image { data: MediaData, mime_type: String, alt: Option<String>, width: Option<u32>, height: Option<u32> },
    Audio { data: MediaData, mime_type: String, duration_secs: Option<f32>, transcript: Option<String> },
    Video { data: MediaData, mime_type: String, duration_secs: Option<f32>, poster: Option<MediaData> },
    File { path: String, file_name: String, mime_type: String, size_bytes: u64 },
    ToolCall(ToolCallContent),
    ToolResult(ToolResultContent),
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum MediaData {
    Url { url: String },
    Base64 { data: String },
    LocalPath { path: String },       // 延迟读取，调用 Provider 时才加载
}

impl ContentPart {
    pub fn as_text(&self) -> Option<&str> {
        match self {
            Self::Text { text } => Some(text),
            Self::Audio { transcript: Some(t), .. } => Some(t),
            _ => None,
        }
    }

    pub fn estimate_tokens(&self) -> u32 {
        match self {
            Self::Text { text } => (text.len() as u32) / 4,
            Self::Image { width, height, .. } => estimate_image_tokens(width.unwrap_or(1024), height.unwrap_or(1024)),
            Self::Audio { duration_secs, .. } => (duration_secs.unwrap_or(10.0) * 32.0) as u32,
            Self::Video { duration_secs, .. } => (duration_secs.unwrap_or(8.0) * 258.0) as u32,
            _ => 0,
        }
    }
}
```

### 6.2 数据库存储

`messages.content` 字段：纯文本消息存储字符串（向后兼容），多模态消息存储 JSON 数组：

```sql
-- 纯文本
INSERT INTO messages (id, conversation_id, role, content)
VALUES ('msg-001', 'conv-001', 'user', '请分析这张图片');

-- 多模态（JSON 数组）
INSERT INTO messages (id, conversation_id, role, content)
VALUES ('msg-002', 'conv-001', 'user', '[
  {"type":"text","text":"请分析这张图片"},
  {"type":"image","data":{"kind":"local_path","path":"attachments/msg-002/photo.jpg"},"mime_type":"image/jpeg","width":1920,"height":1080}
]');
```

解析逻辑：先尝试 `serde_json::from_str::<Vec<ContentPart>>`，失败则降级为单个 `Text`。序列化时，若仅含单个 `Text` 则直接存储字符串。

### 6.3 TypeScript 接口

```typescript
// apps/desktop/src/types/content.ts
type ContentPart =
  | { type: 'text'; text: string }
  | { type: 'image'; data: MediaData; mimeType: string; alt?: string; width?: number; height?: number }
  | { type: 'audio'; data: MediaData; mimeType: string; durationSecs?: number; transcript?: string }
  | { type: 'video'; data: MediaData; mimeType: string; durationSecs?: number; poster?: MediaData }
  | { type: 'file'; path: string; fileName: string; mimeType: string; sizeBytes: number }
  | { type: 'tool_call'; id: string; name: string; arguments: string }
  | { type: 'tool_result'; toolCallId: string; content: string; isError: boolean };

type MediaData =
  | { kind: 'url'; url: string }
  | { kind: 'base64'; data: string }
  | { kind: 'local_path'; path: string };

function contentToPreview(parts: ContentPart[], maxLen = 80): string {
  const texts = parts.map(p =>
    p.type === 'text' ? p.text : p.type === 'image' ? '[图片]' :
    p.type === 'audio' ? '[语音]' : p.type === 'video' ? '[视频]' :
    p.type === 'file' ? `[${p.fileName}]` : ''
  );
  const full = texts.join(' ');
  return full.length > maxLen ? full.slice(0, maxLen) + '...' : full;
}
```

## 7. 多模态上下文管理

### 7.1 图片 Token 估算

对齐 OpenAI GPT-4o 的 tile 规则：缩放到 2048 内 → 短边缩到 768 → 按 512x512 tile 切分，每 tile 85 tokens + 基础 170：

```rust
pub fn estimate_image_tokens(width: u32, height: u32) -> u32 {
    let (w, h) = fit_within(width, height, 2048);
    let (w, h) = scale_shortest(w, h, 768);
    let tiles = ((w as f32 / 512.0).ceil() as u32) * ((h as f32 / 512.0).ceil() as u32);
    170 + tiles * 85
}
```

### 7.2 上下文窗口预算分配

```text
总上下文窗口（如 200K tokens）
  ├─ 系统提示 + 记忆注入（固定）
  ├─ 工具定义（固定）
  ├─ 多模态内容预算（动态，上限 40%）
  │   ├─ 图片（estimate_image_tokens）
  │   ├─ 音频（时长 * 32 tokens/s）
  │   └─ 视频（时长 * 258 tokens/s）
  └─ 文本消息历史（剩余空间）
```

超过 40% 时触发自动压缩：从最新消息向历史遍历，优先保留近期多模态。超出预算的图片替换为 `[图片已省略]`，历史音频替换为转写文本，历史视频始终替换为占位符。

```rust
pub struct MultimodalBudget {
    pub max_ratio: f32,              // 0.4
    pub max_images_in_history: usize, // 10
}
```

### 7.3 图片自动压缩

发送前使用 `image` crate 对超出 Provider 限制的图片执行 Lanczos3 缩放 + JPEG 85 质量压缩：

| Provider | 图片最大尺寸 | 最大 Base64 大小 |
| -------- | ------------ | ---------------- |
| Anthropic | 8192x8192 | 20MB |
| OpenAI | 2048x2048 | 20MB |
| Google Gemini | 3072x3072 | 20MB |
| MiniMax M3 | 4096x4096 | 10MB |

## 8. 异步媒体任务集成

### 8.1 任务类型

| 工具名称 | Trait | 模式 | 典型耗时 |
| -------- | ----- | ---- | -------- |
| `generate_image` | ImageClient | 同步等待 | 3-15s |
| `generate_video` | VideoClient | 异步轮询 | 30s-5min |
| `generate_music` | MusicClient | 异步轮询 | 20s-3min |
| `text_to_speech` | TtsClient | 流式实时 | < 1s 首帧 |
| `speech_to_text` | AsrClient | 同步等待 | 2-10s |

### 8.2 任务提交与进度

同步任务（图片）直接等待结果并注入 `ContentPart::Image`。异步任务（视频、音乐）写入 `media_tasks` 表后立即返回 `task_id`，由 `run_media_poller` 每 3s 轮询状态并通过 `media_task_update` 事件推送前端：

```rust
// 异步任务提交示例（视频）
let task_id = client.submit(req).await?;
MediaTaskRepo::new(&state.db_pool).create(&NewMediaTask {
    task_id: task_id.clone(),
    workspace_id, modality: "video".into(),
    provider: client.provider_id().into(), model: "veo-3.1".into(),
}).await?;
state.media_tasks.write().await.insert(task_id.clone(), MediaTaskStatus::Pending);
app.emit("media_task_update", MediaTaskEvent { task_id, status: "pending".into(), progress_pct: 0, file_paths: vec![] }).ok();
```

### 8.3 结果注入对话

异步任务完成后，`run_media_poller` 下载媒体文件到本地，创建 assistant 消息追加到对话：

```rust
async fn handle_task_done(state: &AppState, app: &AppHandle, task: &MediaTask, result: &MediaPollResult) -> anyhow::Result<()> {
    let local_paths = download_media_files(&result.output_urls, &task.workspace_id).await?;
    MediaTaskRepo::new(&state.db_pool).set_file_paths(&task.task_id, &local_paths).await?;

    if let Some(conv_id) = &task.conversation_id {
        let part = match task.modality.as_str() {
            "video" => ContentPart::Video { data: MediaData::LocalPath { path: local_paths[0].clone() }, mime_type: "video/mp4".into(), duration_secs: result.duration_secs, poster: None },
            "music" => ContentPart::Audio { data: MediaData::LocalPath { path: local_paths[0].clone() }, mime_type: "audio/mp3".into(), duration_secs: result.duration_secs, transcript: None },
            _ => return Ok(()),
        };
        let content = Message::serialize_content(&[
            ContentPart::Text { text: format!("{}生成完成。", task.modality_display()) }, part,
        ]);
        MessageRepo::new(&state.db_pool).insert(&uuid(), conv_id, "assistant", &content).await?;
        app.emit("message_done", conv_id).ok();
    }
    Ok(())
}
```

## 9. Tauri Commands

### 9.1 多模态消息发送

```rust
#[tauri::command]
pub async fn send_multimodal_message(
    app: AppHandle, state: State<'_, AppState>,
    conversation_id: String, parts: Vec<ContentPart>,
) -> Result<String, AppError> {
    for part in &parts { validate_content_part(part)?; }
    let msg_id = uuid::Uuid::new_v4().to_string();
    MessageRepo::new(&state.db_pool)
        .insert(&msg_id, &conversation_id, "user", &Message::serialize_content(&parts))
        .await.map_err(AppError::Db)?;
    // 启动 Agent 执行循环（tokio::spawn + AgentExecutor + event relay）
    let sm = state.session_manager.clone();
    tokio::spawn(async move {
        let handle = sm.get_or_create(&conversation_id).await;
        let (tx, mut rx) = tokio::sync::mpsc::channel(128);
        tokio::spawn(AgentExecutor::new(handle, tx).round_loop_multimodal(parts));
        while let Some(ev) = rx.recv().await { emit_agent_event(&app, &conversation_id, ev); }
    });
    Ok(msg_id)
}
```

### 9.2 文件上传

```rust
#[tauri::command]
pub async fn upload_attachment(
    state: State<'_, AppState>, workspace_id: String, message_id: String, file_path: String,
) -> Result<AttachmentInfo, AppError> {
    let src = std::path::Path::new(&file_path);
    if !src.exists() { return Err(AppError::NotFound("文件不存在".into())); }
    let meta = std::fs::metadata(src).map_err(|e| AppError::Tool(e.to_string()))?;
    let mime = mime_guess::from_path(src).first_or_octet_stream().to_string();
    if meta.len() > max_file_size_for_mime(&mime) {
        return Err(AppError::Validation("文件超过大小限制".into()));
    }
    let dest_dir = attachment_dir(&workspace_id, &message_id);
    std::fs::create_dir_all(&dest_dir).ok();
    let name = src.file_name().unwrap().to_string_lossy().to_string();
    std::fs::copy(src, dest_dir.join(&name)).map_err(|e| AppError::Tool(e.to_string()))?;
    Ok(AttachmentInfo { local_path: dest_dir.join(&name).to_string_lossy().into(), file_name: name, mime_type: mime, size_bytes: meta.len() })
}
```

### 10.1 MessageBubble 多模态渲染

遍历 `ContentPart[]`，按类型分发到 `ImageContent`、`AudioContent`、`VideoContent`、`FileContent` 子组件：

```typescript
// apps/desktop/src/components/message/MessageBubble.tsx
export function MessageBubble({ message, onLightbox }: MessageBubbleProps) {
  const parts = parseContentParts(message.content);
  return (
    <div className={`message-bubble message-bubble--${message.role}`}>
      {parts.map((part, i) => {
        switch (part.type) {
          case 'text': return <MarkdownContent key={i} text={part.text} />;
          case 'image': return <ImageContent key={i} images={collectImages(parts)} onLightbox={onLightbox} />;
          case 'audio': return <AudioContent key={i} src={resolveMediaUrl(part.data)} duration={part.durationSecs} transcript={part.transcript} />;
          case 'video': return <VideoContent key={i} src={resolveMediaUrl(part.data)} poster={part.poster ? resolveMediaUrl(part.poster) : undefined} />;
          case 'file':  return <FileContent key={i} fileName={part.fileName} fileSize={part.sizeBytes} mimeType={part.mimeType} localPath={part.path} />;
          case 'tool_call': return <ToolCallCard key={i} toolCall={part} />;
          case 'tool_result': return <ToolResultCard key={i} toolResult={part} />;
          default: return null;
        }
      })}
    </div>
  );
}

function parseContentParts(content: string): ContentPart[] {
  try { const p = JSON.parse(content); if (Array.isArray(p)) return p; } catch {}
  return [{ type: 'text', text: content }];
}

function resolveMediaUrl(data: MediaData): string {
  return data.kind === 'url' ? data.url : data.kind === 'base64' ? `data:application/octet-stream;base64,${data.data}` : convertFileSrc(data.path);
}
```

### 10.3 InputBar 多模态扩展

`AttachmentBar` 展示待发送附件列表（缩略图/图标 + 文件名 + 移除按钮）。`VoiceButton` 集成到 InputBar 右侧，按下录音松开触发 ASR。完整 InputBar 组合：

```typescript
export function InputBar({ conversationId }: { conversationId: string }) {
  const [text, setText] = useState('');
  const [attachments, setAttachments] = useState<Attachment[]>([]);

  useImagePasteHandler(async (file) => {
    const info = await invoke<AttachmentInfo>('upload_attachment', { workspaceId: currentWorkspaceId(), messageId: 'pending', filePath: file.path });
    setAttachments(prev => [...prev, fileToAttachment(file, info)]);
  });

  const { isDragging, dropRef } = useFileDrop(async (files) => {
    for (const f of files) {
      const info = await invoke<AttachmentInfo>('upload_attachment', { workspaceId: currentWorkspaceId(), messageId: 'pending', filePath: f.path });
      setAttachments(prev => [...prev, fileToAttachment(f, info)]);
    }
  });

  const handleSend = async () => {
    if (!text.trim() && attachments.length === 0) return;
    const parts: ContentPart[] = [];
    if (text.trim()) parts.push({ type: 'text', text: text.trim() });
    for (const att of attachments) parts.push(attachmentToContentPart(att));
    await invoke('send_multimodal_message', { conversationId, parts });
    setText(''); setAttachments([]);
  };

  return (
    <div ref={dropRef} className={`input-bar ${isDragging ? 'input-bar--drag-over' : ''}`}>
      {isDragging && <div className="input-bar__drop-overlay">放开以添加附件</div>}
      <AttachmentBar attachments={attachments} onRemove={id => setAttachments(prev => prev.filter(a => a.id !== id))} />
      <div className="input-bar__row">
        <button className="input-bar__attach" onClick={openFilePicker}><PaperclipIcon /></button>
        <textarea value={text} onChange={e => setText(e.target.value)}
          onKeyDown={e => { if (e.key === 'Enter' && !e.shiftKey) { e.preventDefault(); handleSend(); }}}
          placeholder="输入消息，或粘贴图片..." rows={1} />
        <VoiceButton onTranscript={t => setText(prev => prev + t)} />
        <button className="input-bar__send" onClick={handleSend} disabled={!text.trim() && !attachments.length}><SendIcon /></button>
      </div>
    </div>
  );
}
```
