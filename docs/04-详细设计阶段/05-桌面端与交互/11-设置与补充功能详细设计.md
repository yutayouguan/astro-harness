## Part 1: 设置界面

### 1. 设置架构 — SettingsManager

#### 1.1 层级配置模型

设置采用三级覆盖：**系统默认值 → 全局用户配置 → 工作区覆盖**。读取时自底向上合并，写入时只写入对应层级的差异。

```rust
// crates/agent-core/src/settings/manager.rs

use serde::{Deserialize, Serialize};
use std::path::PathBuf;

/// 设置层级，优先级从低到高
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SettingsLayer {
    /// 编译期硬编码的默认值，不可修改
    SystemDefault,
    /// ~/.astro/settings.json，全局用户配置
    GlobalUser,
    /// ~/.astro/workspaces/<id>/settings.json，工作区级覆盖
    WorkspaceOverride,
}

pub struct SettingsManager {
    /// 合并后的最终视图（只读快照）
    merged: RwLock<AppSettings>,
    /// 各层级的原始值
    layers: RwLock<SettingsLayers>,
    /// 文件监听句柄，外部编辑时自动重载
    watcher: Option<notify::RecommendedWatcher>,
}

struct SettingsLayers {
    system_default: AppSettings,
    global_user: PartialSettings,
    workspace_overrides: HashMap<String, PartialSettings>,
}
```

合并算法：对 `PartialSettings` 的每个字段执行 `Option::or` 链式覆盖。工作区级只允许覆盖 `model`、`temperature`、`budget`、`privacy` 等子集，不允许覆盖 `language`、`theme` 等全局属性。

```rust
impl SettingsManager {
    /// 读取指定工作区的最终合并设置
    pub async fn get_merged(&self, workspace_id: Option<&str>) -> AppSettings {
        let layers = self.layers.read().await;
        let mut result = layers.system_default.clone();
        result.apply_partial(&layers.global_user);
        if let Some(ws_id) = workspace_id {
            if let Some(ws_partial) = layers.workspace_overrides.get(ws_id) {
                result.apply_partial(ws_partial);
            }
        }
        result
    }

    /// 写入指定层级，返回合并后的新快照
    pub async fn update(
        &self,
        layer: SettingsLayer,
        workspace_id: Option<&str>,
        patch: PartialSettings,
    ) -> anyhow::Result<AppSettings> {
        {
            let mut layers = self.layers.write().await;
            match layer {
                SettingsLayer::GlobalUser => layers.global_user.merge(patch),
                SettingsLayer::WorkspaceOverride => {
                    let ws_id = workspace_id
                        .ok_or_else(|| anyhow::anyhow!("workspace_id required"))?;
                    layers
                        .workspace_overrides
                        .entry(ws_id.to_string())
                        .or_default()
                        .merge(patch);
                }
                SettingsLayer::SystemDefault => {
                    anyhow::bail!("cannot modify system defaults");
                }
            }
        }
        // 持久化 + 重新合并
        self.persist(layer, workspace_id).await?;
        let merged = self.get_merged(workspace_id).await;
        *self.merged.write().await = merged.clone();
        Ok(merged)
    }
}
```

#### 1.2 设置 Schema 版本控制

`settings.json` 顶层携带 `schema_version` 字段。应用启动时检测版本号，若低于当前版本则执行迁移函数链：

```rust
/// settings.json 文件格式
#[derive(Debug, Serialize, Deserialize)]
pub struct SettingsFile {
    /// 当前 schema 版本，每次结构变更 +1
    pub schema_version: u32,
    #[serde(flatten)]
    pub settings: PartialSettings,
}

const CURRENT_SCHEMA_VERSION: u32 = 3;

/// 迁移注册表：(from_version, to_version, migration_fn)
static MIGRATIONS: &[(u32, u32, fn(&mut serde_json::Value))] = &[
    (1, 2, migrate_v1_to_v2),  // theme 字段从 string 改为 ThemeConfig 对象
    (2, 3, migrate_v2_to_v3),  // privacy.pii_filter 拆分为 pii_filter + pii_patterns
];

fn run_migrations(raw: &mut serde_json::Value) -> anyhow::Result<()> {
    let version = raw.get("schema_version")
        .and_then(|v| v.as_u64())
        .unwrap_or(1) as u32;
    for &(from, to, migrate) in MIGRATIONS {
        if version == from {
            migrate(raw);
            raw["schema_version"] = serde_json::Value::from(to);
        }
    }
    Ok(())
}
```

### 2. 设置面板布局

#### 2.1 导航结构

左侧平铺 icon 列表 + 右内容区双栏布局。Tab 按 4 个分组排列（由 `settingsTabs.ts` 中的 `SettingsTabId` 类型定义），`preferences:xxx` 前缀路由到 `PreferencesPanel` 的对应 section。另有 `evolution` 作为 jump-only 入口（不在导航列表中显示）。

| 分组 | Tab 标签 | Tab ID | 核心内容 |
| ---- | -------- | ------ | -------- |
| 基础 basics | 通用 | `general` | 语言、启动行为、通知偏好 |
| | 外观 | `appearance` | 主题、强调色、字号、代码块 |
| | 对话 | `chat` | 对话行为、发送模式 |
| | 终端 | `terminal` | 终端集成配置 |

| | Provider 配置 | `providers` | API Key、端点、协议模式 |
| | 工具 | `tools` | 工具启用/禁用、审批策略 |
| | 记忆 | `memory` | MEMORY.md/USER.md 快照、审批队列 |
| 扩展 extensions | 浏览器 | `browser` | 浏览器集成配置 |
| | 模型市场 | `model_market` | OpenRouter 模型目录、模型元数据 |
| | 洞察 | `insights` | 用量统计、trace 分析 |
| 系统 system | 环境依赖 | `dependencies` | 运行时依赖检测 |
| | 诊断 | `diagnostics` | 日志级别、诊断信息、实验性功能 |

#### 3.2 API Key 输入

API Key 字段默认以掩码显示（`sk-ant-***...***`），点击眼睛图标切换明文。输入后立即触发 `save_provider_key` Tauri Command（写入系统 Keychain / 加密文件），前端不存储明文。

```typescript
// apps/desktop/src/components/settings/ApiKeyInput.tsx

export function ApiKeyInput({ providerId, hasKey }: { providerId: string; hasKey: boolean }) {
  const [value, setValue] = useState("");
  const [masked, setMasked] = useState(true);
  const [saving, setSaving] = useState(false);

  const handleSave = async () => {
    if (!value.trim()) return;
    setSaving(true);
    try {
      await invoke("save_provider_key", { provider: providerId, key: value });
      setValue("");
      toast.success("API Key 已保存");
    } catch (e) {
      toast.error(`保存失败: ${(e as AppError).message}`);
    } finally {
      setSaving(false);
    }
  };

  return (
    <div className="flex items-center gap-2">
      <Input
        type={masked ? "password" : "text"}
        placeholder={hasKey ? "sk-***已配置***" : "输入 API Key"}
        value={value}
        onChange={(e) => setValue(e.target.value)}
        className="font-mono flex-1"
      />
      <Button variant="ghost" size="icon" onClick={() => setMasked(!masked)}>
        {masked ? <EyeOffIcon /> : <EyeIcon />}
      </Button>
      <Button onClick={handleSave} disabled={saving || !value.trim()}>
        {saving ? <Spinner /> : "保存"}
      </Button>
    </div>
  );
}
```

#### 3.4 模型列表刷新

每个 Provider 卡片的模型 Tab 提供手动刷新按钮。点击后调用 `refresh_provider_models`，该 Command 向 Provider API 拉取模型列表并更新缓存。

```rust
// apps/desktop/src-tauri/src/commands/settings.rs

#[tauri::command]
pub async fn refresh_provider_models(
    provider_id: String,
    state: State<'_, AppState>,
) -> Result<Vec<ProviderModel>, AppError> {
    let registry = state.provider_registry.read().await;
    let client = registry.get(&provider_id)
        .ok_or_else(|| AppError::NotFound(format!("provider {}", provider_id)))?;

    let models = client.list_models().await
        .map_err(|e| AppError::Provider(e.to_string()))?;

    // 更新本地缓存
    ProviderRepo::new(&state.db_pool)
        .upsert_models(&provider_id, &models)
        .await
        .map_err(AppError::Db)?;

    Ok(models)
}
```

#### 3.6 Key 验证流程

输入 API Key 后的完整验证链路：输入 -> 保存到 Keychain -> 测试连接 -> 加载模型列表 / 展示错误。

```typescript
// apps/desktop/src/components/settings/ProviderCard.tsx（验证流程片段）

type KeyValidationStatus =
  | { state: "idle" }
  | { state: "saving" }
  | { state: "testing" }
  | { state: "loading_models" }
  | { state: "success"; models: ProviderModel[] }
  | { state: "error"; errorType: KeyErrorType; message: string };

type KeyErrorType = "invalid_key" | "network_error" | "quota_exhausted" | "unknown";

function classifyKeyError(error: AppError): { errorType: KeyErrorType; message: string } {
  const msg = error.message ?? "";
  if (msg.includes("401") || msg.includes("invalid") || msg.includes("Incorrect API key")) {
    return { errorType: "invalid_key", message: "API Key 无效，请检查是否复制完整" };
  }
  if (msg.includes("429") || msg.includes("quota") || msg.includes("exceeded")) {
    return { errorType: "quota_exhausted", message: "账户额度已用尽，请前往 Provider 官网充值" };
  }
  if (msg.includes("timeout") || msg.includes("network") || msg.includes("ECONNREFUSED")) {
    return { errorType: "network_error", message: "网络连接失败，请检查网络或代理设置" };
  }
  return { errorType: "unknown", message: msg };
}
```

验证成功时自动拉取可用模型列表并展示：

```typescript
const handleSaveAndValidate = async (key: string) => {
  setStatus({ state: "saving" });
  try {
    await invoke("save_provider_key", { provider: providerId, key });
  } catch (e) {
    setStatus({ state: "error", ...classifyKeyError(e as AppError) });
    return;
  }

  setStatus({ state: "testing" });
  try {
    const conn = await invoke<ConnectionStatus>("test_provider_connection", { providerId });
    if (!conn.ok) {
      setStatus({ state: "error", ...classifyKeyError({ message: conn.error_message } as AppError) });
      return;
    }
  } catch (e) {
    setStatus({ state: "error", ...classifyKeyError(e as AppError) });
    return;
  }

  setStatus({ state: "loading_models" });
  try {
    const models = await invoke<ProviderModel[]>("refresh_provider_models", { providerId });
    setStatus({ state: "success", models });
  } catch (e) {
    // 连接正常但模型拉取失败，不阻塞使用
    setStatus({ state: "success", models: [] });
    toast.warning("模型列表加载失败，可稍后手动刷新");
  }
};
```

Rust 侧对 Provider API 错误的分类：

```rust
// crates/agent-providers/src/error.rs（片段）

#[derive(Debug, thiserror::Error, Serialize)]
#[serde(tag = "error_type", rename_all = "snake_case")]
pub enum ProviderApiError {
    #[error("invalid API key")]
    InvalidKey,
    #[error("quota exhausted")]
    QuotaExhausted,
    #[error("network error: {message}")]
    Network { message: String },
    #[error("rate limited, retry after {retry_after_secs}s")]
    RateLimited { retry_after_secs: u64 },
    #[error("{message}")]
    Other { message: String },
}

impl ProviderApiError {
    pub fn from_status(status: u16, body: &str) -> Self {
        match status {
            401 | 403 => Self::InvalidKey,
            429 => {
                // 区分限流和额度用尽
                if body.contains("quota") || body.contains("exceeded") || body.contains("billing") {
                    Self::QuotaExhausted
                } else {
                    Self::RateLimited { retry_after_secs: 60 }
                }
            }
            _ => Self::Other { message: body.to_string() },
        }
    }
}
```

```rust
    let tmp_path = path.with_extension("json.tmp");
```

```rust
impl SettingsManager {
    fn start_file_watcher(&mut self, settings_path: PathBuf) -> anyhow::Result<()> {
        let layers = self.layers.clone();
        let merged = self.merged.clone();

        let mut watcher = notify::recommended_watcher(move |res: Result<Event, _>| {
            if let Ok(event) = res {
                if matches!(event.kind, EventKind::Modify(_)) {
                    // 重新读取并合并
                    if let Ok(content) = fs::read_to_string(&settings_path) {
                        if let Ok(file) = serde_json::from_str::<SettingsFile>(&content) {
                            let mut l = layers.blocking_write();
                            l.global_user = file.settings;
                            // 重新计算合并结果
                            let mut new_merged = l.system_default.clone();
                            new_merged.apply_partial(&l.global_user);
                            *merged.blocking_write() = new_merged;
                        }
                    }
                }
            }
        })?;

        watcher.watch(
            &self.global_settings_path().parent().unwrap(),
            RecursiveMode::NonRecursive,
        )?;
        self.watcher = Some(watcher);
        Ok(())
    }
```

#### 7.3 同步流程

```rust
impl OpenRouterCatalog {
    /// 全量同步。分页拉取，每页 500 条，直至 links.next 为 null
    pub async fn sync(&self) -> anyhow::Result<SyncResult> {
        let mut offset = 0u32;
        let limit = 500u32;
        let mut total_fetched = 0usize;
        let mut all_models: Vec<CatalogModel> = Vec::new();

        loop {
            let url = format!(
                "{}/models?output_modalities=all&offset={}&limit={}",
                self.base_url, offset, limit
            );
            let resp: OpenRouterModelsResponse = self.http
                .get(&url)
                .header("Authorization", format!("Bearer {}", self.api_key.as_deref().unwrap_or("")))
                .send()
                .await?
                .json()
                .await?;

            let batch_len = resp.data.len();
            for model in resp.data {
                all_models.push(CatalogModel::from_api(model));
            }
            total_fetched += batch_len;

            if resp.links.next.is_none() || batch_len == 0 {
                break;
            }
            offset += limit;
        }

        // 事务写入 SQLite
        self.upsert_batch(&all_models).await?;

        // 清理已过期模型（expiration_date < now）
        let removed = self.remove_expired().await?;

        Ok(SyncResult {
            total_models: total_fetched,
            new_models: all_models.len(),
            removed_expired: removed,
            synced_at: chrono::Utc::now(),
        })
    }

    /// 批量 upsert，单事务完成
    async fn upsert_batch(&self, models: &[CatalogModel]) -> anyhow::Result<()> {
        let mut tx = self.pool.begin().await?;
        for model in models {
            sqlx::query(
                "INSERT INTO model_catalog (
                    id, canonical_slug, name, description, context_length,
                    input_modalities, output_modalities,
                    pricing_prompt, pricing_completion, pricing_image,
                    supported_params, provider_name, created_at,
                    expiration_date, last_synced_at
                ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, datetime('now'))
                ON CONFLICT(id) DO UPDATE SET
                    name = excluded.name,
                    description = excluded.description,
                    context_length = excluded.context_length,
                    pricing_prompt = excluded.pricing_prompt,
                    pricing_completion = excluded.pricing_completion,
                    supported_params = excluded.supported_params,
                    expiration_date = excluded.expiration_date,
                    last_synced_at = datetime('now')"
            )
            .bind(&model.id)
            .bind(&model.canonical_slug)
            .bind(&model.name)
            .bind(&model.description)
            .bind(model.context_length)
            .bind(serde_json::to_string(&model.input_modalities)?)
            .bind(serde_json::to_string(&model.output_modalities)?)
            .bind(model.pricing_prompt)
            .bind(model.pricing_completion)
            .bind(model.pricing_image)
            .bind(serde_json::to_string(&model.supported_parameters)?)
            .bind(&model.provider_name)
            .bind(model.created_at)
            .bind(&model.expiration_date)
            .execute(&mut *tx)
            .await?;
        }
        tx.commit().await?;
        Ok(())
    }
}
```

#### 7.4 定时刷新

后台任务在应用启动时创建，每 24 小时同步一次。首次启动或缓存为空时立即同步：

```rust
// apps/desktop/src-tauri/src/background/catalog_sync.rs

pub async fn run_catalog_sync(
    catalog: Arc<OpenRouterCatalog>,
    app: AppHandle,
) {
    // 检查缓存是否为空或过期
    let needs_immediate = catalog.is_cache_empty_or_stale().await.unwrap_or(true);
    if needs_immediate {
        match catalog.sync().await {
            Ok(result) => {
                tracing::info!("catalog sync: {} models fetched", result.total_models);
                app.emit("catalog_synced", &result).ok();
            }
            Err(e) => tracing::warn!("catalog sync failed: {}", e),
        }
    }

    // 24 小时周期刷新
    let mut interval = tokio::time::interval(Duration::from_secs(24 * 3600));
    interval.tick().await; // 跳过首次立即触发
    loop {
        interval.tick().await;
        match catalog.sync().await {
            Ok(result) => {
                app.emit("catalog_synced", &result).ok();
            }
            Err(e) => tracing::warn!("catalog periodic sync failed: {}", e),
        }
    }
}
```

```rust
impl OpenRouterCatalog {
    /// 查询本地缓存的模型列表
    pub async fn list_cached(
        &self,
        filter: &CatalogFilter,
    ) -> anyhow::Result<Vec<CatalogModel>> {
        let mut query = String::from(
            "SELECT * FROM model_catalog WHERE expiration_date IS NULL OR expiration_date > datetime('now')"
        );
        if let Some(provider) = &filter.provider {
            query.push_str(&format!(" AND provider_name = '{}'", provider));
        }
        if let Some(modality) = &filter.output_modality {
            query.push_str(&format!(" AND output_modalities LIKE '%\"{}\"'", modality));
        }
        if let Some(param) = &filter.supported_param {
            query.push_str(&format!(" AND supported_params LIKE '%\"{}\"'", param));
        }
        query.push_str(" ORDER BY provider_name, name");

        let rows = sqlx::query_as::<_, CatalogModel>(&query)
            .fetch_all(&self.pool)
            .await?;
        Ok(rows)
    }

    /// 检查本地缓存是否为空或超过刷新间隔
    pub async fn is_cache_empty_or_stale(&self) -> anyhow::Result<bool> {
        let row: (i64, Option<String>) = sqlx::query_as(
            "SELECT COUNT(*), MIN(last_synced_at) FROM model_catalog"
        )
        .fetch_one(&self.pool)
        .await?;

        if row.0 == 0 { return Ok(true); }
        if let Some(oldest) = row.1 {
            let synced = chrono::NaiveDateTime::parse_from_str(&oldest, "%Y-%m-%d %H:%M:%S")?;
            let age = chrono::Utc::now().naive_utc() - synced;
            Ok(age > chrono::Duration::hours(24))
        } else {
            Ok(true)
        }
    }
}
```

#### 9.1 双引擎架构

采用平台原生引擎优先、Tesseract 降级的双引擎策略：

| 平台 | 主引擎 | 降级引擎 | 说明 |
| ---- | ------ | -------- | ---- |
| macOS | Apple Vision 框架（`objc2-vision`） | Tesseract（`tesseract-rs`） | Vision 准确率高、零依赖 |
| Windows | Windows.Media.Ocr（`windows` crate） | Tesseract | 系统内置，Win10+ 可用 |
| Linux | Tesseract（`tesseract-rs`） | -- | 唯一可用引擎 |

在线模式（调用多模态 LLM Vision API）作为用户可选的高精度引擎，适合复杂版式和表格。

```rust
// crates/agent-tools/src/ocr/engine.rs

use std::time::Instant;

pub struct OcrEngineSelector {
    native_available: bool,
    tesseract_available: bool,
}

impl OcrEngineSelector {
    pub fn new() -> Self {
        Self {
            native_available: Self::check_native(),
            tesseract_available: Self::check_tesseract(),
        }
    }

    /// Auto 模式的引擎选择优先级
    pub fn select(&self, requested: OcrEngine) -> OcrEngine {
        match requested {
            OcrEngine::Auto => {
                if self.native_available { OcrEngine::Native }
                else if self.tesseract_available { OcrEngine::Tesseract }
                else { OcrEngine::Online }
            }
            OcrEngine::Native if !self.native_available => {
                tracing::warn!("native OCR not available, falling back to Tesseract");
                if self.tesseract_available { OcrEngine::Tesseract }
                else { OcrEngine::Online }
            }
            other => other,
        }
    }

    #[cfg(target_os = "macos")]
    fn check_native() -> bool {
        // macOS Vision framework 在 10.15+ 始终可用
        true
    }

    #[cfg(target_os = "windows")]
    fn check_native() -> bool {
        // 检查 Windows.Media.Ocr 是否可用（Win10+）
        windows::Media::Ocr::OcrEngine::is_available().unwrap_or(false)
    }

    #[cfg(target_os = "linux")]
    fn check_native() -> bool {
        false
    }

    fn check_tesseract() -> bool {
        std::process::Command::new("tesseract")
            .arg("--version")
            .output()
            .map(|o| o.status.success())
            .unwrap_or(false)
    }
}
```

```rust
// crates/agent-tools/src/ocr/engine/macos_vision.rs

#[cfg(target_os = "macos")]
pub async fn recognize_with_vision(image_data: &[u8]) -> anyhow::Result<OcrResult> {
    use objc2_foundation::{NSData, NSArray};
    use objc2_vision::{VNRecognizeTextRequest, VNImageRequestHandler, VNRecognizedTextObservation};

    let start = Instant::now();

    // 在阻塞线程中执行 ObjC 调用
    let result = tokio::task::spawn_blocking(move || -> anyhow::Result<OcrResult> {
        let ns_data = unsafe { NSData::with_bytes(image_data) };
        let handler = unsafe {
            VNImageRequestHandler::initWithData_options(&NSData::alloc(), &ns_data, None)
        }?;

        let request = unsafe { VNRecognizeTextRequest::new() };
        unsafe {
            // 支持中英文
            request.setRecognitionLanguages(&NSArray::from_vec(vec![
                "zh-Hans", "zh-Hant", "en-US",
            ]));
            request.setRecognitionLevel(VNRequestTextRecognitionLevelAccurate);
        }

        unsafe { handler.performRequests(&NSArray::from_vec(vec![&request])) }?;

        let observations = unsafe { request.results() };
        let mut full_text = String::new();
        let mut regions = Vec::new();

        for obs in observations.iter() {
            let candidate = unsafe { obs.topCandidates(1) };
            if let Some(top) = candidate.first() {
                let text = unsafe { top.string().to_string() };
                let confidence = unsafe { top.confidence() } as f32;
                let bbox = unsafe { obs.boundingBox() };

                full_text.push_str(&text);
                full_text.push('\n');

                regions.push(TextRegion {
                    bbox: (bbox.origin.x as f32, bbox.origin.y as f32,
                           bbox.size.width as f32, bbox.size.height as f32),
                    text,
                    confidence,
                });
            }
        }

        Ok(OcrResult {
            text: full_text.trim().to_string(),
            confidence: if regions.is_empty() { None } else {
                Some(regions.iter().map(|r| r.confidence).sum::<f32>() / regions.len() as f32)
            },
            regions,
            engine_used: OcrEngine::Native,
            elapsed_ms: start.elapsed().as_millis() as u64,
        })
    }).await??;

    Ok(result)
}
```

```rust
// crates/agent-tools/src/ocr/engine/tesseract.rs

pub async fn recognize_with_tesseract(image_data: &[u8]) -> anyhow::Result<OcrResult> {
    let start = Instant::now();

    let result = tokio::task::spawn_blocking(move || -> anyhow::Result<OcrResult> {
        let tess = tesseract::Tesseract::new(None, Some("chi_sim+eng"))?
            .set_image_from_mem(image_data)?
            .recognize()?;

        let text = tess.get_text()?;
        let confidence = tess.mean_text_conf() as f32 / 100.0;

        // 提取文字区域坐标
        let mut regions = Vec::new();
        let boxes = tess.get_component_images(tesseract::PageIteratorLevel::TextLine)?;
        for (i, bbox) in boxes.iter().enumerate() {
            let line_text = tess.get_text_at(i, tesseract::PageIteratorLevel::TextLine)
                .unwrap_or_default();
            regions.push(TextRegion {
                bbox: (bbox.x as f32, bbox.y as f32, bbox.w as f32, bbox.h as f32),
                text: line_text,
                confidence,
            });
        }

        Ok(OcrResult {
            text: text.trim().to_string(),
            confidence: Some(confidence),
            regions,
            engine_used: OcrEngine::Tesseract,
            elapsed_ms: start.elapsed().as_millis() as u64,
        })
    }).await??;

    Ok(result)
}
```

```rust
use std::path::PathBuf;

pub async fn capture_screenshot() -> anyhow::Result<Vec<u8>> {
    let tmp = NamedTempFile::new()?.into_temp_path();
    let tmp_path = tmp.to_path_buf();

    #[cfg(target_os = "macos")]

            .args(["-i", "-t", "png", tmp_path.to_str().unwrap()])

            anyhow::bail!("screencapture cancelled or failed");

    #[cfg(target_os = "windows")]
    {
        // 使用 PowerShell 调用 Snipping Tool API
        let script = format!(
            r#"Add-Type -AssemblyName System.Windows.Forms;
            $screen = [System.Windows.Forms.Screen]::PrimaryScreen;
            $bitmap = New-Object System.Drawing.Bitmap($screen.Bounds.Width, $screen.Bounds.Height);
            $graphics = [System.Drawing.Graphics]::FromImage($bitmap);
            $graphics.CopyFromScreen($screen.Bounds.Location, [System.Drawing.Point]::Empty, $screen.Bounds.Size);
            $bitmap.Save('{}');
            $bitmap.Dispose();"#,
            tmp_path.display()
        );
        tokio::process::Command::new("powershell")
            .args(["-Command", &script])
            .status()
            .await?;
    }

    #[cfg(target_os = "linux")]
    {
        // 尝试 gnome-screenshot，回退到 scrot
        let status = tokio::process::Command::new("gnome-screenshot")
            .args(["-a", "-f", tmp_path.to_str().unwrap()])
            .status()
            .await;
        if status.is_err() || !status.unwrap().success() {
            tokio::process::Command::new("scrot")
                .args(["-s", tmp_path.to_str().unwrap()])
                .status()
                .await?;
        }
    }

    let data = tokio::fs::read(&tmp_path).await?;
    if data.is_empty() {
        anyhow::bail!("screenshot capture returned empty data");
    }
    Ok(data)
```

#### 9.7 文字提取管道

完整的截屏 OCR 流程：截图 -> 引擎选择 -> 识别 -> 返回结果到前端输入框。

```rust
// crates/agent-tools/src/ocr/pipeline.rs

pub struct OcrPipeline {
    engine_selector: OcrEngineSelector,
    online_client: Option<Arc<dyn TextClient>>,
}

impl OcrPipeline {
    pub async fn process_image(
        &self,
        image_data: &[u8],
        engine_pref: OcrEngine,
    ) -> anyhow::Result<OcrResult> {
        let engine = self.engine_selector.select(engine_pref);

        match engine {
            OcrEngine::Native => {
                #[cfg(target_os = "macos")]
                return engine::macos_vision::recognize_with_vision(image_data).await;
                #[cfg(target_os = "windows")]
                return engine::windows_ocr::recognize_with_windows(image_data).await;
                #[cfg(target_os = "linux")]
                anyhow::bail!("native OCR not available on Linux");
            }
            OcrEngine::Tesseract => {
                engine::tesseract::recognize_with_tesseract(image_data).await
            }
            OcrEngine::Online => {
                let client = self.online_client.as_ref()
                    .ok_or_else(|| anyhow::anyhow!("no online provider configured"))?;
                engine::online::recognize_with_vision_api(image_data, client.as_ref()).await
            }
            OcrEngine::Auto => unreachable!("Auto resolved by engine_selector"),
        }
    }

    pub async fn screenshot_and_recognize(
        &self,
        engine_pref: OcrEngine,
    ) -> anyhow::Result<OcrResult> {
        let image_data = screenshot::capture_screenshot().await?;
        self.process_image(&image_data, engine_pref).await
    }
}
```

```typescript
// apps/desktop/src/hooks/useOnboardingCheck.ts

export function useOnboardingCheck() {
  const [needsOnboarding, setNeedsOnboarding] = useState(false);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    invoke<boolean>("check_needs_onboarding")
      .then((needs) => setNeedsOnboarding(needs))
      .catch(() => setNeedsOnboarding(false)) // 检测失败则跳过引导
      .finally(() => setLoading(false));
  }, []);

  return { needsOnboarding, loading };
}
```

#### 11.2 引导步骤（3 步向导）

**Step 1: 欢迎页**

- 产品 Logo + 一句话介绍
- 语言选择（中文 / English）
- \[开始设置\] 按钮

**Step 2: Provider 配置**

- 推荐 Provider 列表（Anthropic / OpenAI / DeepSeek），按推荐度排序
- 每个 Provider 卡片：Logo + 名称 + "免费额度" / "需付费" 标签
- 点击展开 → API Key 输入框 + \[测试连接\] 按钮
- 至少配置 1 个 Provider 才能继续
- 底部"跳过，稍后配置"链接（灰色，进入后功能受限提示）
- 测试成功 → 绿色对勾 + 可用模型列表自动加载
- 测试失败 → 红色错误信息 + 常见问题链接

**Step 3: 快速体验**

- 自动创建"默认工作区"
- 预填一条示例消息："你好！请介绍一下你能做什么？"
- \[开始对话\] 按钮 → 发送示例消息 → 进入主界面

### 12. 自定义指令

#### 概念
类似 ChatGPT "Custom Instructions"，用户设置全局或工作区级的常驻指令，每次对话自动注入。与 SOUL.md（Agent 身份）和工作区 Prompt（工作区行为）并列，但更面向用户偏好。

#### 设置界面
设置 → 个性化 → 自定义指令

两个文本框：
1. **关于我**（≤500 字符）
   placeholder: "比如：我是一名 Rust 后端开发者，偏好函数式编程风格"
   注入位置：Slot[5] 记忆注入的 <user_profile> 部分

2. **回复偏好**（≤500 字符）
   placeholder: "比如：回答简洁直接，代码优先用 Rust，注释用中文"
   注入位置：Slot[3] 会话级覆盖的补充段

#### 作用域
| 级别 | 存储位置 | 优先级 |
|------|---------|--------|
| 全局 | ~/.astro/custom_instructions.json | 基础层 |
| 工作区 | ~/.astro/workspaces/{ws}/custom_instructions.json | 覆盖全局 |

#### 数据模型
```typescript
interface CustomInstructions {
  about_user: string;      // ≤500 chars
  response_style: string;  // ≤500 chars
  updated_at: number;
}
```

#### 与现有 Persona 系统的关系
- SOUL.md = Agent 的持久身份（Slot[1]）
- 工作区 Prompt = 工作区行为覆盖（Slot[2]）
- 自定义指令 = 用户个人偏好（注入 Slot[3] 和 Slot[5]）
- /personality = 临时会话覆盖（Slot[3] 主体部分）
四者叠加，不互相覆盖
