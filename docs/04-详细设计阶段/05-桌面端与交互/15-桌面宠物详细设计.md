# 桌面宠物详细设计

## 目标与范围

桌面宠物是 Astro 的本地透明悬浮窗口。它同时支持：

- 单张 PNG/JPEG/WebP 静态桌宠，作为快速生成和降级路径。
- Codex-compatible v2 动画桌宠，使用 `8x11` atlas 与 `spriteVersionNumber: 2`。

自动生成完整 v2 atlas 属于后续的后台孵化流水线；当前运行时提供严格导入、播放和 Agent 状态投影。

## 持久化协议

`~/.astro/ui/desktop-pet/state.json` 是桌宠当前状态的唯一事实源，由 `agent-types::DesktopPetState` 定义。Agent Tool 和 Tauri 命令必须通过共享文件锁读写，不得维护独立副本。

动画宠物包从用户显式选择的 `pet.json` 导入，再复制到：

```text
~/.astro/ui/desktop-pet/pets/<id>-<nonce>/
├── pet.json
└── spritesheet.png | spritesheet.webp
```

Astro 不自动扫描 `.codex/pets` 作为配置输入；用户可通过设置页显式导入兼容包。

## V2 Atlas 契约

| 项目 | 值 |
| --- | --- |
| 图集尺寸 | `1536x2288` |
| 单元格 | `192x208` |
| 网格 | `8` 列 x `11` 行 |
| 标准动作 | 行 `0-8` |
| 16 向注视 | 行 `9-10` |
| 透明度 | 所有未使用单元格必须全透明 |

导入时必须校验 manifest 版本、路径越界、图片真实格式、图集尺寸、已用格非空和未用格全透明。失败时不替换当前桌宠。

## 动画与状态投影

Canvas 播放器按 v2 的逐帧时长播放，切换动作时复用已解码的 atlas，不重新加载图片。

| Astro 运行状态 | 动画行 |
| --- | --- |
| 无活动 | `idle` |
| Turn / Tool 执行 | `running` |
| 审批或等待用户输入 | `waiting` |
| review / inspect / audit 工具 | `review` |
| 首次显示或更换动画宠物 | `waving` |
| Turn 成功 | `jumping` 短暂播放后回到聚合状态 |
| Turn 失败 | `failed` 短暂播放后回到聚合状态 |
| 向左/右拖动 | `running-left` / `running-right` |
| 空闲时鼠标靠近 | 行 `9-10` 的 16 向注视 |

`session_status_changed` 是运行/等待/完成/失败的权威来源；`desktop_pet_activity_changed` 只补充 review 类工具语义。多会话同时存在时，等待用户的状态优先于普通运行。

## 可访问性与性能

- `prefers-reduced-motion` 下每个状态只显示首帧，禁用注视跟随和拖动动作切换。
- atlas 每次路径变化只解码一次，动作切换仅重置时间轴。
- Canvas 按设备像素比绘制，但最高使用 `2x`，防止高 DPI 窗口过度消耗。
- 动作切换不锁定指针输入；窗口拖动仍由 Tauri 原生机制接管。

## 信任边界

- 仅导入用户显式选择的 manifest。
- `spritesheetPath` 必须是包内相对路径，canonicalize 后不得越出 manifest 父目录。
- 只接受 PNG/WebP，atlas 最大 50 MB，manifest 最大 64 KiB。
- 导入、校验或状态写入失败时，保留当前桌宠并清理未完成的临时包。
