# 对话公开分享系统设计

> 版本：v1.0 | 日期：2026-08-07 | 状态：草稿
> 对应需求：F-25 对话公开分享、M-27 对话公开分享模块

本文档描述**分享流程**：范围选择 → 媒体感知打包 → 系统原生分享框。与 [07-导出与分享.md](../../03-系统设计阶段/06-桌面端/07-导出与分享.md) 的区别：导出是用户主动保存到本地文件；分享是生成可交付包并直接投递给他人（通过 AirDrop / 微信 / 邮件等 OS 原生渠道，或 P2 云端链接）。

---

## 1. 打包策略（媒体感知）

根据所选消息的媒体附件情况，自动选择打包策略：

| 对话媒体内容 | 策略 | 输出物 | 接收方操作 |
| ------------ | ---- | ------ | ---------- |
| 无媒体 / 仅图片 | **A：单文件 HTML** | `.html`（图片 base64 内嵌） | 直接双击打开 |
| 含音频 < 10 MB | **A：单文件 HTML** | `.html`（音频 base64 内嵌） | 直接双击打开 |
| 含音频 ≥ 10 MB 或任意视频 | **B：ZIP 包** | `.zip`（HTML + `media/` + `README.txt`） | 解压后打开 index.html |
| 云端分享（P2） | **C：云端链接** | 在线 URL | 浏览器直接访问 |

策略判断在 `SharePackager::detect_strategy()` 中完成，无需用户手动选择。

## 2. 整体数据流

```text
用户点击对话操作菜单「分享」
    │
    ▼
前端展示 ShareRangeSelector 弹窗
    │  ○ 全部消息 / 最近 N 条 / 手动勾选
    │  ☐ 包含工具调用详情（默认关闭）
    │  ☐ 脱敏处理（默认开启）
    │  [生成分享包]
    ▼
invoke("share_conversation", { conversationId, messageIds, includeTools, redact })
    │
    ▼
SharePackager::pack()
    ├─ 1. 检测媒体附件 → 选择策略 A / B
    ├─ 2. 生成 HTML（脱敏 + Tool 调用卡片渲染）
    ├─ 3. 策略 A → 媒体 base64 内嵌到 HTML
    │    策略 B → 生成 index.html + 复制 media/ + 生成 README.txt + ZIP 打包
    ├─ 4. 写入临时目录（AppData/temp/share/）
    └─ 5. emit "share_ready" { file_path, strategy }
    │
    ▼
前端收到事件 → 三按钮操作面板
    ├─ [系统分享]  → @tauri-apps/plugin-share → macOS Share Sheet / Windows 分享菜单
    ├─ [浏览器预览] → shell::open(file_path)
    └─ [另存为]   → tauri-plugin-dialog 文件保存对话框
```

## 3. SharePackager Rust 实现

```rust
// crates/agent-core/src/share/packager.rs

pub struct SharePackager {
    filter: SensitiveFilter,   // 复用 07-导出与分享.md 中的脱敏实现
    temp_dir: PathBuf,         // AppData/temp/share/
}

pub enum ShareStrategy { Html, Zip }

pub struct ShareOptions {
    pub message_ids: Vec<String>,
    pub include_tools: bool,
    pub redact: bool,
}

impl SharePackager {
    pub async fn pack(
        &self,
        conversation: &Conversation,
        messages: Vec<Message>,
        options: ShareOptions,
    ) -> anyhow::Result<(PathBuf, ShareStrategy)> {
        // 1. 检测媒体附件
        let strategy = self.detect_strategy(&messages).await;

        // 2. 生成 HTML 内容
        let html = self.render_html(&conversation, &messages, &options).await?;

        // 3. 按策略打包
        let file_path = match strategy {
            ShareStrategy::Html => self.pack_html(conversation, html).await?,
            ShareStrategy::Zip  => self.pack_zip(conversation, html, &messages).await?,
        };

        Ok((file_path, strategy))
    }

    /// 媒体感知：扫描附件决定策略
    async fn detect_strategy(&self, messages: &[Message]) -> ShareStrategy {
        let mut total_audio_bytes: u64 = 0;
        let mut has_video = false;

        for msg in messages {
            for attachment in msg.attachments.iter() {
                match attachment.mime.as_str() {
                    m if m.starts_with("video/") => has_video = true,
                    m if m.starts_with("audio/") => {
                        total_audio_bytes += attachment.size_bytes;
                    }
                    _ => {}
                }
            }
        }

        const AUDIO_INLINE_LIMIT: u64 = 10 * 1024 * 1024; // 10 MB
        if has_video || total_audio_bytes >= AUDIO_INLINE_LIMIT {
            ShareStrategy::Zip
        } else {
            ShareStrategy::Html
        }
    }

    /// 策略 A：生成自包含单文件 HTML（媒体 base64 内嵌）
    async fn pack_html(
        &self,
        conv: &Conversation,
        html_body: String,
    ) -> anyhow::Result<PathBuf> {
        let filename = sanitize_filename(&format!(
            "chat-{}-{}.html",
            chrono::Local::now().format("%Y%m%d"),
            &conv.title[..conv.title.len().min(20)]
        ));
        let path = self.temp_dir.join(&filename);
        tokio::fs::write(&path, html_body.as_bytes()).await?;
        Ok(path)
    }

    /// 策略 B：生成 ZIP 包（index.html + media/ + README.txt）
    async fn pack_zip(
        &self,
        conv: &Conversation,
        html_body: String,
        messages: &[Message],
    ) -> anyhow::Result<PathBuf> {
        let zip_name = sanitize_filename(&format!(
            "chat-{}-{}.zip",
            chrono::Local::now().format("%Y%m%d"),
            &conv.title[..conv.title.len().min(20)]
        ));
        let zip_path = self.temp_dir.join(&zip_name);

        // ZIP 打包在 blocking 线程执行，避免阻塞 tokio 运行时
        let html_bytes = html_body.into_bytes();
        let media_files = self.collect_media_files(messages).await;
        let zip_path2 = zip_path.clone();

        tokio::task::spawn_blocking(move || {
            let file = std::fs::File::create(&zip_path2)?;
            let mut zip = zip::ZipWriter::new(file);
            let opts = zip::write::FileOptions::default()
                .compression_method(zip::CompressionMethod::Deflated);

            // index.html
            zip.start_file("index.html", opts)?;
            std::io::Write::write_all(&mut zip, &html_bytes)?;

            // media/ 目录中的各媒体文件
            for (rel_path, abs_path) in &media_files {
                zip.start_file(format!("media/{}", rel_path), opts)?;
                let mut f = std::fs::File::open(abs_path)?;
                std::io::copy(&mut f, &mut zip)?;
            }

            // README.txt 解压说明
            zip.start_file("README.txt", opts)?;
            std::io::Write::write_all(&mut zip,
                b"1. Unzip this archive\n2. Open index.html in your browser\n")?;

            zip.finish()?;
            anyhow::Ok(())
        })
        .await??;

        Ok(zip_path)
    }

    /// 生成 HTML 正文（Tool 调用卡片 + 脱敏处理）
    async fn render_html(
        &self,
        conv: &Conversation,
        messages: &[Message],
        opts: &ShareOptions,
    ) -> anyhow::Result<String> {
        // HTML 模板内联 CSS，支持深色模式，无外部依赖
        let mut body = String::new();
        for msg in messages {
            let content = if opts.redact {
                self.filter.filter(&msg.content)
            } else {
                msg.content.clone()
            };
            body.push_str(&render_message_html(&msg.role, &content));

            if opts.include_tools {
                for call in &msg.tool_calls {
                    body.push_str(&render_tool_call_html(call));
                }
            }
        }
        Ok(wrap_html_template(&conv.title, &body))
    }
}
```

## 4. HTML 模板规范

生成的 HTML 必须满足：

- **自包含**：CSS/JS 全部内联，无 CDN 依赖，离线可访问
- **深色模式**：`@media (prefers-color-scheme: dark)` 自适应
- **代码高亮**：使用内联 `<style>` 实现基础语法着色（不依赖 shiki）
- **Tool 调用卡片**：`<details>/<summary>` 实现可折叠展示
- **媒体引用**：
  - 策略 A：`<img src="data:image/…;base64,…">`、`<audio src="data:audio/…;base64,…">`
  - 策略 B：`<img src="media/xxx.jpg">`、`<video src="media/xxx.mp4">`

## 5. 前端 ShareRangeSelector 组件

```typescript
// apps/desktop/src/components/share/ShareRangeSelector.tsx

interface ShareRangeSelectorProps {
  open: boolean;
  onClose: () => void;
  conversationId: string;
  messages: Message[];
}

export function ShareRangeSelector({
  open, onClose, conversationId, messages
}: ShareRangeSelectorProps) {
  const [rangeMode, setRangeMode] = useState<"all" | "recent" | "select">("all");
  const [recentCount, setRecentCount] = useState(20);
  const [selected, setSelected] = useState<Set<string>>(new Set());
  const [includeTools, setIncludeTools] = useState(false);
  const [redact, setRedact] = useState(true);
  const [packing, setPacking] = useState(false);
  const [shareReady, setShareReady] = useState<ShareReadyPayload | null>(null);

  const selectedIds = useMemo(() => {
    if (rangeMode === "all")    return messages.map(m => m.id);
    if (rangeMode === "recent") return messages.slice(-recentCount).map(m => m.id);
    return [...selected];
  }, [rangeMode, recentCount, selected, messages]);

  const handlePack = async () => {
    setPacking(true);
    // 监听 share_ready 事件，一次性
    const unlisten = await listen<ShareReadyPayload>("share_ready", (e) => {
      setShareReady(e.payload);
      unlisten();
    });
    await invoke("share_conversation", {
      conversationId,
      messageIds: selectedIds,
      includeTools,
      redact,
    });
    setPacking(false);
  };

  if (shareReady) {
    return <ShareActionPanel payload={shareReady} onClose={onClose} />;
  }

  return (
    <Dialog open={open} onOpenChange={onClose}>
      <DialogContent>
        <DialogHeader><DialogTitle>分享对话</DialogTitle></DialogHeader>

        {/* 范围选择 */}
        <RadioGroup value={rangeMode} onValueChange={v => setRangeMode(v as any)}>
          <RadioGroupItem value="all">全部消息（{messages.length} 条）</RadioGroupItem>
          <RadioGroupItem value="recent">
            最近
            <input type="number" min={1} max={messages.length}
              value={recentCount} onChange={e => setRecentCount(+e.target.value)}
              className="w-16 mx-2 border rounded px-1" />
            条
          </RadioGroupItem>
          <RadioGroupItem value="select">手动勾选</RadioGroupItem>
        </RadioGroup>

        {rangeMode === "select" && (
          <MessageCheckList messages={messages} selected={selected} onToggle={id => {
            setSelected(prev => { const s = new Set(prev); s.has(id) ? s.delete(id) : s.add(id); return s; });
          }} />
        )}

        {/* 选项 */}
        <div className="flex flex-col gap-3 mt-4">
          <OptionRow label="包含工具调用详情"
            desc="展示每个 Tool 调用的参数和结果" checked={includeTools} onChange={setIncludeTools} />
          <OptionRow label="脱敏处理"
            desc="自动隐藏 API Key、本地路径等敏感信息" checked={redact} onChange={setRedact} />
        </div>

        <DialogFooter>
          <Button variant="outline" onClick={onClose}>取消</Button>
          <Button onClick={handlePack} disabled={packing || selectedIds.length === 0}>
            {packing ? "打包中…" : "生成分享包"}
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}
```

## 6. 分享操作面板（打包完成后）

```typescript
// apps/desktop/src/components/share/ShareActionPanel.tsx

interface ShareReadyPayload {
  filePath: string;
  strategy: "html" | "zip";
  fileSizeBytes: number;
}

export function ShareActionPanel({ payload, onClose }: {
  payload: ShareReadyPayload;
  onClose: () => void;
}) {
  const sizeLabel = payload.fileSizeBytes > 1024 * 1024
    ? `${(payload.fileSizeBytes / 1024 / 1024).toFixed(1)} MB`
    : `${Math.round(payload.fileSizeBytes / 1024)} KB`;

  return (
    <div className="share-action-panel">
      <p className="text-sm text-muted-foreground">
        已生成 {payload.strategy === "zip" ? "ZIP 压缩包" : "HTML 文件"}（{sizeLabel}）
      </p>

      <div className="flex gap-3 mt-4">
        {/* 系统原生分享 */}
        <Button onClick={async () => {
          const { share } = await import("@tauri-apps/plugin-share");
          await share({ files: [payload.filePath] });
        }}>
          系统分享
        </Button>

        {/* 浏览器预览 */}
        <Button variant="outline" onClick={() =>
          invoke("shell_open", { path: payload.filePath })
        }>
          在浏览器中预览
        </Button>

        {/* 另存为 */}
        <Button variant="outline" onClick={async () => {
          const { save } = await import("@tauri-apps/plugin-dialog");
          const dest = await save({
            defaultPath: payload.filePath.split(/[\\/]/).pop(),
            filters: payload.strategy === "zip"
              ? [{ name: "ZIP", extensions: ["zip"] }]
              : [{ name: "HTML", extensions: ["html"] }],
          });
          if (dest) await invoke("copy_share_file", {
            src: payload.filePath, dest
          });
        }}>
          另存为
        </Button>
      </div>
    </div>
  );
}
```

## 7. Tauri Command

```rust
// apps/desktop/src-tauri/src/commands/share.rs

#[tauri::command]
pub async fn share_conversation(
    conversation_id: String,
    message_ids: Vec<String>,
    include_tools: bool,
    redact: bool,
    app: AppHandle,
    state: State<'_, AppState>,
) -> Result<(), String> {
    let conversation = ConversationRepo::new(&state.db_pool)
        .get(&conversation_id).await.map_err(|e| e.to_string())?;

    let messages = MessageRepo::new(&state.db_pool)
        .get_by_ids(&message_ids).await.map_err(|e| e.to_string())?;

    let temp_dir = app.path().app_cache_dir()
        .map_err(|e| e.to_string())?.join("share");
    tokio::fs::create_dir_all(&temp_dir).await.map_err(|e| e.to_string())?;

    let packager = SharePackager::new(temp_dir);
    let (file_path, strategy) = packager.pack(
        &conversation,
        messages,
        ShareOptions { include_tools, redact, message_ids },
    ).await.map_err(|e| e.to_string())?;

    let size = tokio::fs::metadata(&file_path).await
        .map(|m| m.len()).unwrap_or(0);

    app.emit("share_ready", ShareReadyEvent {
        file_path: file_path.to_string_lossy().to_string(),
        strategy: match strategy {
            ShareStrategy::Html => "html",
            ShareStrategy::Zip  => "zip",
        },
        file_size_bytes: size,
    }).ok();

    Ok(())
}
```

## 8. 临时文件管理

- **位置**：`{AppCacheDir}/share/`（Tauri 应用缓存目录，每平台自动解析）
- **清理策略**：应用启动时删除 `share/` 目录下超过 24 小时的文件，避免累积占用磁盘
- **文件名安全**：`sanitize_filename()` 剔除路径分隔符和不合法字符，防止路径穿越

## 9. P2：云端分享（策略 C）

P2 功能，需用户自部署后端服务（或 Astro 官方可选服务）：

```text
用户点击「生成分享链接」（P2 选项）
    │
    ▼
invoke("cloud_share_conversation", { conversation_id, ... })
    │
    ▼
SharePackager::pack() → HTML（同策略 A）
    │
    ▼
HTTP POST 到 share_endpoint（workspace.yaml 中配置）
    │  Content-Type: multipart/form-data
    │  文件 + 密码（可选）+ 过期时间
    ▼
后端返回 { url: "https://share.example.com/c/abc123" }
    │
    ▼
前端显示分享链接 + 一键复制
```

云端后端只是静态文件托管服务，无需账号，接收方直接打开链接查看。本客户端不实现后端，只约定 HTTP 协议接口。

## 10. 设计约束

- **脱敏默认开启**：`SensitiveFilter` 在 `render_html()` 中强制执行，用户须主动关闭
- **临时文件不含原始媒体路径**：策略 B 中媒体文件以匿名文件名复制到 `media/` 目录，避免本地路径泄露
- **ZIP 同步限制**：ZIP 打包在 `spawn_blocking` 执行，最大 5 分钟超时；超时后返回错误，用户可改用"另存为"导出
- **Tool 调用默认不包含**：`include_tools` 默认 `false`，避免暴露 Agent 内部执行细节
- **云端分享（P2）不强依赖**：客户端离线仍可完整使用策略 A/B，云端为可选增强
