# 多工作区管理详细设计

> 版本：v1.0 | 日期：2026-08-09 | 状态：草稿
> 对应需求：F-01 多工作区管理

> **当前 Harness 基线（2026-08-29）**：Workspace 是配置、文件和项目上下文边界；Agent 运行控制仍归 Thread/Session/Task。本文出现的 Supervisor、远程 Agent 或跨工作区统一 `state.db` 仅按目标设计理解，不能覆盖当前 rollout 与职责数据库契约。

多工作区管理为用户提供完整的配置与数据隔离能力：每个工作区拥有独立的 Provider/模型配置、Persona、Skill 集合、MCP Server 连接、记忆空间和对话历史。用户可在工作区间即时切换，无需重启应用；工作区配置可导出为模板供复用或分享。

本文档在 [05-多工作区隔离](../../03-系统设计阶段/06-桌面端/05-多工作区隔离.md) 系统设计基础上，给出完整的数据模型、Repository 实现、生命周期管理、隔离策略、模板系统、Tauri Commands 和前端组件的实现级设计。

## 1. 工作区数据模型

### 1.1 workspaces 表

```sql
-- migrations/0006_workspaces.sql

CREATE TABLE IF NOT EXISTS workspaces (
    id          TEXT    PRIMARY KEY,                          -- UUID v4
    name        TEXT    NOT NULL,                             -- 工作区名称，1~64 字符
    icon        TEXT    NOT NULL DEFAULT '🤖',                -- emoji 或图标标识
    description TEXT,                                        -- 可选描述，上限 256 字符
    is_default  INTEGER NOT NULL DEFAULT 0,                  -- 1=默认工作区（有且仅一个）
    is_archived INTEGER NOT NULL DEFAULT 0,                  -- 1=已归档，不在侧边栏显示
    sort_order  INTEGER NOT NULL DEFAULT 0,                  -- 拖拽排序权重，值越小越靠前
    created_at  INTEGER NOT NULL DEFAULT (CAST(unixepoch('now','subsec') * 1000 AS INTEGER)),
    updated_at  INTEGER NOT NULL DEFAULT (CAST(unixepoch('now','subsec') * 1000 AS INTEGER))
);

-- 保证有且仅有一个默认工作区
CREATE UNIQUE INDEX IF NOT EXISTS idx_workspaces_default
    ON workspaces(is_default) WHERE is_default = 1;

CREATE INDEX IF NOT EXISTS idx_workspaces_sort
    ON workspaces(is_archived, sort_order);
```

### 1.2 workspace_configs 表

工作区的配置项以结构化列存储，避免 JSON 大字段的部分更新问题：

```sql
-- migrations/0006_workspaces.sql（续）

CREATE TABLE IF NOT EXISTS workspace_configs (
    workspace_id          TEXT    PRIMARY KEY REFERENCES workspaces(id) ON DELETE CASCADE,

    -- Provider / 模型配置（NULL = 继承全局默认）
    default_text_model    TEXT,                               -- 如 "claude-sonnet-4-5"
    default_embedding_model TEXT,                             -- 如 "text-embedding-3-small"
    default_image_model   TEXT,                               -- 如 "gpt-image-1"

    -- Persona
    system_prompt         TEXT,                               -- 工作区级 system prompt（Slot [2]）
    agent_name            TEXT    DEFAULT 'Astro',            -- Agent 显示名称
    agent_avatar          TEXT    DEFAULT '🤖',               -- Agent 头像

    -- 安全配置
    max_agent_depth       INTEGER DEFAULT 3,                  -- 子 Agent 最大递归深度
    require_approval_json TEXT    DEFAULT '[]',               -- JSON: GuardRule[]

    -- 进化配置
    evolution_enabled     INTEGER NOT NULL DEFAULT 1,         -- Skill 自进化开关
    auto_approve_evolutions INTEGER NOT NULL DEFAULT 0,       -- 自动批准进化

    -- 记忆
    memory_namespace      TEXT    NOT NULL DEFAULT '',        -- 向量存储命名空间前缀

    -- 工具白名单（NULL=不限制，使用全局可用工具集）
    tool_whitelist_json   TEXT,                               -- JSON: string[] | null

    -- 自定义人格列表
    personalities_json    TEXT    DEFAULT '{}',               -- JSON: Record<string, PersonalityDef>

    updated_at            INTEGER NOT NULL DEFAULT (CAST(unixepoch('now','subsec') * 1000 AS INTEGER))
);
```

### 1.3 workspace_skills 表


### 1.4 workspace_mcp_servers 表

```sql
-- 工作区级 MCP server 配置
CREATE TABLE IF NOT EXISTS workspace_mcp_servers (
    workspace_id TEXT NOT NULL REFERENCES workspaces(id) ON DELETE CASCADE,
    server_name  TEXT NOT NULL,
    config       TEXT NOT NULL DEFAULT '{}',   -- JSON: MCP server 连接参数
```

### 1.7 WorkspaceRepository

```rust
// crates/agent-core/src/storage/workspace_repo.rs

pub struct WorkspaceRepo(SqlitePool);

impl WorkspaceRepo {
    pub fn new(pool: &SqlitePool) -> Self {
        Self(pool.clone())
    }

    /// 查询所有未归档工作区（侧边栏列表）
    pub async fn list_active(&self) -> anyhow::Result<Vec<Workspace>> {
        Ok(sqlx::query_as!(
            Workspace,
            "SELECT id, name, icon, description,
                    is_default AS \"is_default: bool\",
                    is_archived AS \"is_archived: bool\",
                    sort_order, created_at, updated_at
             FROM workspaces
             WHERE is_archived = 0
             ORDER BY is_default DESC, sort_order ASC, created_at ASC"
        )
        .fetch_all(&self.0)
        .await?)
    }

    /// 查询所有工作区（含归档，设置面板使用）
    pub async fn list_all(&self) -> anyhow::Result<Vec<Workspace>> {
        Ok(sqlx::query_as!(
            Workspace,
            "SELECT id, name, icon, description,
                    is_default AS \"is_default: bool\",
                    is_archived AS \"is_archived: bool\",
                    sort_order, created_at, updated_at
             FROM workspaces
             ORDER BY is_default DESC, sort_order ASC, created_at ASC"
        )
        .fetch_all(&self.0)
        .await?)
    }

    /// 按 ID 查询单个工作区
    pub async fn get(&self, id: &str) -> anyhow::Result<Workspace> {
        sqlx::query_as!(
            Workspace,
            "SELECT id, name, icon, description,
                    is_default AS \"is_default: bool\",
                    is_archived AS \"is_archived: bool\",
                    sort_order, created_at, updated_at
             FROM workspaces WHERE id = ?",
            id
        )
        .fetch_optional(&self.0)
        .await?
        .ok_or_else(|| anyhow::anyhow!("工作区不存在: {}", id))
    }

    /// 创建工作区（含配置行）
    pub async fn create(&self, ws: &Workspace, config: &WorkspaceConfig) -> anyhow::Result<()> {
        let mut tx = self.0.begin().await?;

        sqlx::query!(
            "INSERT INTO workspaces (id, name, icon, description, is_default, sort_order, created_at, updated_at)
             VALUES (?, ?, ?, ?, 0, ?, ?, ?)",
            ws.id, ws.name, ws.icon, ws.description, ws.sort_order, ws.created_at, ws.updated_at
        )
        .execute(&mut *tx)
        .await?;

        let approval_json = serde_json::to_string(&config.require_approval)?;
        let tool_wl_json = config.tool_whitelist.as_ref()
            .map(|v| serde_json::to_string(v))
            .transpose()?;
        let personalities_json = serde_json::to_string(&config.personalities)?;

        sqlx::query!(
            "INSERT INTO workspace_configs
             (workspace_id, default_text_model, default_embedding_model, default_image_model,
              system_prompt, agent_name, agent_avatar, max_agent_depth, require_approval_json,
              evolution_enabled, auto_approve_evolutions, memory_namespace,
              tool_whitelist_json, personalities_json)
             VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)",
            config.workspace_id, config.default_text_model, config.default_embedding_model,
            config.default_image_model, config.system_prompt, config.agent_name,
            config.agent_avatar, config.max_agent_depth, approval_json,
            config.evolution_enabled, config.auto_approve_evolutions,
            config.memory_namespace, tool_wl_json, personalities_json
        )
        .execute(&mut *tx)
        .await?;

        tx.commit().await?;
        Ok(())
    }

    /// 更新工作区基本信息（名称、图标、描述）
    pub async fn update_info(
        &self,
        id: &str,
        name: &str,
        icon: &str,
        description: Option<&str>,
    ) -> anyhow::Result<()> {
        let now = now_ms();
        sqlx::query!(
            "UPDATE workspaces SET name = ?, icon = ?, description = ?, updated_at = ? WHERE id = ?",
            name, icon, description, now, id
        )
        .execute(&self.0)
        .await?;
        Ok(())
    }

    /// 更新工作区配置
    pub async fn update_config(&self, config: &WorkspaceConfig) -> anyhow::Result<()> {
        let approval_json = serde_json::to_string(&config.require_approval)?;
        let tool_wl_json = config.tool_whitelist.as_ref()
            .map(|v| serde_json::to_string(v))
            .transpose()?;
        let personalities_json = serde_json::to_string(&config.personalities)?;
        let now = now_ms();

        sqlx::query!(
            "UPDATE workspace_configs
             SET default_text_model = ?, default_embedding_model = ?, default_image_model = ?,
                 system_prompt = ?, agent_name = ?, agent_avatar = ?,
                 max_agent_depth = ?, require_approval_json = ?,
                 evolution_enabled = ?, auto_approve_evolutions = ?,
                 memory_namespace = ?, tool_whitelist_json = ?,
                 personalities_json = ?, updated_at = ?
             WHERE workspace_id = ?",
            config.default_text_model, config.default_embedding_model, config.default_image_model,
            config.system_prompt, config.agent_name, config.agent_avatar,
            config.max_agent_depth, approval_json,
            config.evolution_enabled, config.auto_approve_evolutions,
            config.memory_namespace, tool_wl_json,
            personalities_json, now, config.workspace_id
        )
        .execute(&self.0)
        .await?;
        Ok(())
    }

    /// 获取工作区配置
    pub async fn get_config(&self, workspace_id: &str) -> anyhow::Result<WorkspaceConfig> {
        let row = sqlx::query!(
            "SELECT * FROM workspace_configs WHERE workspace_id = ?",
            workspace_id
        )
        .fetch_optional(&self.0)
        .await?
        .ok_or_else(|| anyhow::anyhow!("工作区配置不存在: {}", workspace_id))?;

        Ok(WorkspaceConfig {
            workspace_id: row.workspace_id,
            default_text_model: row.default_text_model,
            default_embedding_model: row.default_embedding_model,
            default_image_model: row.default_image_model,
            system_prompt: row.system_prompt,
            agent_name: row.agent_name.unwrap_or_else(|| "Astro".into()),
            agent_avatar: row.agent_avatar.unwrap_or_else(|| "🤖".into()),
            max_agent_depth: row.max_agent_depth.unwrap_or(3) as u8,
            require_approval: serde_json::from_str(
                row.require_approval_json.as_deref().unwrap_or("[]")
            )?,
            evolution_enabled: row.evolution_enabled != 0,
            auto_approve_evolutions: row.auto_approve_evolutions != 0,
            memory_namespace: row.memory_namespace,
            tool_whitelist: row.tool_whitelist_json
                .as_deref()
                .map(serde_json::from_str)
                .transpose()?,
            personalities: serde_json::from_str(
                row.personalities_json.as_deref().unwrap_or("{}")
            )?,
        })
    }

    /// 归档工作区
    pub async fn archive(&self, id: &str) -> anyhow::Result<()> {
        self.ensure_not_default(id).await?;
        sqlx::query!(
            "UPDATE workspaces SET is_archived = 1, updated_at = ? WHERE id = ?",
            now_ms(), id
        )
        .execute(&self.0)
        .await?;
        Ok(())
    }

    /// 取消归档
    pub async fn unarchive(&self, id: &str) -> anyhow::Result<()> {
        sqlx::query!(
            "UPDATE workspaces SET is_archived = 0, updated_at = ? WHERE id = ?",
            now_ms(), id
        )
        .execute(&self.0)
        .await?;
        Ok(())
    }

    /// 删除工作区（级联删除所有关联数据）
    pub async fn delete(&self, id: &str) -> anyhow::Result<()> {
        self.ensure_not_default(id).await?;
        // ON DELETE CASCADE 自动清理 workspace_configs、workspace_skills、
        // workspace_mcp_servers、conversations（及其 messages）、
        // memory_entries、media_tasks、audit_logs 等
        sqlx::query!("DELETE FROM workspaces WHERE id = ?", id)
            .execute(&self.0)
            .await?;
        Ok(())
    }

    /// 更新排序
    pub async fn update_sort_order(&self, orders: &[(String, i32)]) -> anyhow::Result<()> {
        let mut tx = self.0.begin().await?;
        for (id, order) in orders {
            sqlx::query!(
                "UPDATE workspaces SET sort_order = ? WHERE id = ?",
                order, id
            )
            .execute(&mut *tx)
            .await?;
        }
        tx.commit().await?;
        Ok(())
    }

    /// 获取工作区数量（用于上限检查）
    pub async fn count(&self) -> anyhow::Result<i64> {
        let row = sqlx::query!("SELECT COUNT(*) as cnt FROM workspaces")
            .fetch_one(&self.0)
            .await?;
        Ok(row.cnt)
    }

    /// 内部：确保操作目标不是默认工作区
    async fn ensure_not_default(&self, id: &str) -> anyhow::Result<()> {
        let ws = self.get(id).await?;
        if ws.is_default {
            anyhow::bail!("默认工作区不可执行此操作");
        }
        Ok(())
    }
}
```

## 2. 工作区生命周期

### 2.1 生命周期状态图

```text
             ┌──────────┐
     创建 ──→│  active   │←── 取消归档
             └────┬──┬──┘
                  │  │
          归档 ───┘  └─── 删除 ──→ (级联删除，不可恢复)
                  │
             ┌────▼─────┐
             │ archived  │
             └────┬──────┘
                  │
           删除 ──┘──→ (级联删除，不可恢复)
```

默认工作区（`is_default = 1`）不可归档、不可删除，只能重命名和修改配置。

### 2.2 创建工作区

创建支持三种模式：空白创建、从模板创建、克隆现有工作区。

```rust
// crates/agent-core/src/workspace/manager.rs

pub struct WorkspaceManager {
    pool: SqlitePool,
    active: Arc<RwLock<String>>,  // 当前活跃工作区 ID
    /// 已加载的工作区 AgentContext 缓存，避免重复构建
    contexts: Arc<Mutex<HashMap<String, Arc<AgentContext>>>>,
    /// 内置模板注册表
    template_registry: Arc<TemplateRegistry>,
}

impl WorkspaceManager {
    pub fn new(
        pool: SqlitePool,
        template_registry: Arc<TemplateRegistry>,
    ) -> Self {
        Self {
            pool,
            active: Arc::new(RwLock::new("default".into())),
            contexts: Arc::new(Mutex::new(HashMap::new())),
            template_registry,
        }
    }

    /// 创建新工作区
    pub async fn create(&self, input: NewWorkspace) -> anyhow::Result<WorkspaceWithConfig> {
        let repo = WorkspaceRepo::new(&self.pool);

        // 上限检查
        let count = repo.count().await?;
        if count >= MAX_WORKSPACES as i64 {
            anyhow::bail!("工作区数量已达上限 ({MAX_WORKSPACES})");
        }

        // 名称校验
        validate_workspace_name(&input.name)?;

        let id = Uuid::new_v4().to_string();
        let now = now_ms();

        // 基于模板或空白创建配置
        let config = if let Some(template_id) = &input.template_id {
            let tpl = self.template_registry.get(template_id)
                .ok_or_else(|| anyhow::anyhow!("模板不存在: {}", template_id))?;
            tpl.to_config(&id)
        } else {
            WorkspaceConfig::default_for(&id)
        };

        let workspace = Workspace {
            id: id.clone(),
            name: input.name,
            icon: input.icon,
            description: input.description,
            is_default: false,
            is_archived: false,
            sort_order: count as i32,  // 追加到末尾
            created_at: now,
            updated_at: now,
        };

        repo.create(&workspace, &config).await?;

        Ok(WorkspaceWithConfig { workspace, config })
    }

    /// 克隆现有工作区（复制配置，不复制对话和记忆）
    pub async fn clone_workspace(
        &self,
        source_id: &str,
        new_name: &str,
    ) -> anyhow::Result<WorkspaceWithConfig> {
        let repo = WorkspaceRepo::new(&self.pool);

        let count = repo.count().await?;
        if count >= MAX_WORKSPACES as i64 {
            anyhow::bail!("工作区数量已达上限 ({MAX_WORKSPACES})");
        }

        validate_workspace_name(new_name)?;

        let source = repo.get(source_id).await?;
        let source_config = repo.get_config(source_id).await?;

        let new_id = Uuid::new_v4().to_string();
        let now = now_ms();

        let new_workspace = Workspace {
            id: new_id.clone(),
            name: new_name.to_string(),
            icon: source.icon,
            description: source.description.map(|d| format!("（克隆自 {}）{}", source.name, d)),
            is_default: false,
            is_archived: false,
            sort_order: count as i32,
            created_at: now,
            updated_at: now,
        };

        let new_config = WorkspaceConfig {
            workspace_id: new_id.clone(),
            memory_namespace: new_id.clone(),  // 新的命名空间，不共享记忆
            ..source_config
        };

        repo.create(&new_workspace, &new_config).await?;

        // 复制 Skill 激活状态
        self.clone_workspace_skills(source_id, &new_id).await?;
        // 复制 MCP Server 配置
        self.clone_workspace_mcp_servers(source_id, &new_id).await?;

        Ok(WorkspaceWithConfig {
            workspace: new_workspace,
            config: new_config,
        })
    }

    async fn clone_workspace_skills(&self, from: &str, to: &str) -> anyhow::Result<()> {
        sqlx::query!(
            "INSERT INTO workspace_skills (workspace_id, skill_name, enabled)
             SELECT ?, skill_name, enabled FROM workspace_skills WHERE workspace_id = ?",
            to, from
        )
        .execute(&self.pool)
        .await?;
        Ok(())
    }

    async fn clone_workspace_mcp_servers(&self, from: &str, to: &str) -> anyhow::Result<()> {
        sqlx::query!(
            "INSERT INTO workspace_mcp_servers (workspace_id, server_name, config, enabled)
             SELECT ?, server_name, config, enabled
             FROM workspace_mcp_servers WHERE workspace_id = ?",
            to, from
        )
        .execute(&self.pool)
        .await?;
        Ok(())
    }

    /// 重命名工作区
    pub async fn rename(
        &self,
        id: &str,
        name: &str,
        icon: &str,
        description: Option<&str>,
    ) -> anyhow::Result<()> {
        validate_workspace_name(name)?;
        WorkspaceRepo::new(&self.pool)
            .update_info(id, name, icon, description)
            .await
    }

    /// 归档工作区
    pub async fn archive(&self, id: &str) -> anyhow::Result<()> {
        // 归档前如果是当前活跃工作区，自动切换到默认
        let active = self.active.read().await.clone();
        if active == id {
            self.switch("default").await?;
        }
        WorkspaceRepo::new(&self.pool).archive(id).await
    }

    /// 删除工作区（不可恢复）
    pub async fn delete(&self, id: &str) -> anyhow::Result<()> {
        let active = self.active.read().await.clone();
        if active == id {
            self.switch("default").await?;
        }

        // 清理已缓存的 AgentContext
        self.contexts.lock().await.remove(id);

        // 级联删除（外键 ON DELETE CASCADE）
        WorkspaceRepo::new(&self.pool).delete(id).await?;

        // 清理向量存储中该 namespace 的数据
        self.cleanup_vector_namespace(id).await?;

        Ok(())
    }

    /// 清理向量命名空间中的嵌入数据
    async fn cleanup_vector_namespace(&self, workspace_id: &str) -> anyhow::Result<()> {
        sqlx::query!(
            "DELETE FROM embeddings WHERE workspace_id = ?",
            workspace_id
        )
        .execute(&self.pool)
        .await?;
        Ok(())
    }
}

/// 工作区名称校验
fn validate_workspace_name(name: &str) -> anyhow::Result<()> {
    let trimmed = name.trim();
    if trimmed.is_empty() {
        anyhow::bail!("工作区名称不能为空");
    }
    if trimmed.len() > 64 {
        anyhow::bail!("工作区名称不能超过 64 个字符");
    }
    Ok(())
}

const MAX_WORKSPACES: usize = 20;
```

### 3.1 workspace_id 外键约束

```sql

-- memory_entries 表
ALTER TABLE memory_entries ADD COLUMN workspace_id TEXT
    NOT NULL DEFAULT 'default'
    REFERENCES workspaces(id) ON DELETE CASCADE;

    NOT NULL DEFAULT 'default'
    REFERENCES workspaces(id) ON DELETE CASCADE;

    NOT NULL DEFAULT 'default'
```

### 3.2 查询作用域强制绑定

所有 Repository 查询方法必须接受 `workspace_id` 参数，并在 WHERE 条件中绑定。以下是隔离规则在各 Repository 中的应用：

```rust
// 约定：所有面向用户的查询都必须绑定 workspace_id

// ConversationRepo — 对话列表始终按工作区过滤
pub async fn list(

// MemoryRepo — 记忆检索始终按工作区过滤
pub async fn search_active(
    &self,
    workspace_id: &str,  // 必须参数
    category: Option<&str>,
    limit: i64,
) -> anyhow::Result<Vec<MemoryEntry>> {
    if let Some(cat) = category {
        Ok(sqlx::query_as!(
            MemoryEntry,
            "SELECT * FROM memory_entries
             WHERE workspace_id = ? AND category = ? AND valid_to IS NULL
             ORDER BY importance DESC, created_at DESC LIMIT ?",
            workspace_id, cat, limit
        )
        .fetch_all(&self.0)
        .await?)
    } else {
        Ok(sqlx::query_as!(
            MemoryEntry,
            "SELECT * FROM memory_entries
             WHERE workspace_id = ? AND valid_to IS NULL
             ORDER BY importance DESC, created_at DESC LIMIT ?",
            workspace_id, limit
        )
        .fetch_all(&self.0)
        .await?)
    }

// KNN 向量检索 — workspace_id 过滤
pub async fn knn_search(
    pool: &SqlitePool,
    workspace_id: &str,  // 必须参数
    query_embedding: &[f32],
    top_k: usize,
) -> anyhow::Result<Vec<KnnResult>> {
    let embedding_json = serde_json::to_string(query_embedding)?;
    let rows = sqlx::query!(
        "SELECT e.source_id, e.source_type, e.distance
         FROM embeddings e
         WHERE e.embedding MATCH ?
           AND e.workspace_id = ?
           AND k = ?",
        embedding_json, workspace_id, top_k as i64
    )
    .fetch_all(pool)
    .await?;

    Ok(rows.into_iter().map(|r| KnnResult {
        source_id: r.source_id,
        source_type: r.source_type,
        distance: r.distance,
    }).collect())
}
```

```rust
        workspace_id: &str,
        config: WorkspaceConfig,

    }
```

```rust
/// 根据工作区白名单过滤可用工具
pub fn filter_tools(
    all_tools: &[ToolDefinition],
    whitelist: Option<&[String]>,
) -> Vec<ToolDefinition> {
    match whitelist {
        // None = 不限制，返回全部工具
        None => all_tools.to_vec(),
        // Some([]) = 空白名单，禁用所有工具
        Some(allowed) if allowed.is_empty() => vec![],
        // Some([...]) = 只保留白名单中的工具
        Some(allowed) => {
            let set: HashSet<&str> = allowed.iter().map(|s| s.as_str()).collect();
            all_tools
                .iter()
                .filter(|t| set.contains(t.name.as_str()))
                .cloned()
                .collect()
        }
    }
}
```

```rust
impl WorkspaceTemplate {
    /// 从现有工作区生成模板
    pub async fn export_from(
        pool: &SqlitePool,

    ) -> anyhow::Result<Self> {

            config: sanitize_mcp_config(

            ),
            enabled: r.enabled != 0,
        })
        .collect();

        Ok(Self {
            meta: TemplateMeta {
                name: ws.name,
                icon: ws.icon,
                description: ws.description,
                version: "1.0.0".into(),
                author: None,
                tags: vec![],
            },
            config: TemplateConfig {
                default_text_model: config.default_text_model,
                default_embedding_model: config.default_embedding_model,
                default_image_model: config.default_image_model,

                agent_name: Some(config.agent_name),
                agent_avatar: Some(config.agent_avatar),
                max_agent_depth: Some(config.max_agent_depth),
                evolution_enabled: Some(config.evolution_enabled),
                tool_whitelist: config.tool_whitelist,
                personalities: Some(config.personalities),
            },
            skills,
            mcp_servers,
        })
    }
}

/// 从 MCP Server 配置中移除敏感字段
fn sanitize_mcp_config(config: &serde_json::Value) -> serde_json::Value {
    if let serde_json::Value::Object(map) = config {
        let mut sanitized = map.clone();
        // 移除可能含有密钥的字段
        for key in &["api_key", "apiKey", "token", "secret", "password", "auth"] {
            sanitized.remove(*key);
        }
        serde_json::Value::Object(sanitized)
    } else {
        config.clone()
    }
```

### 5.3 模板导入

```rust
// crates/agent-core/src/workspace/manager.rs（续）

impl WorkspaceManager {
    /// 从模板文件创建工作区
    pub async fn import_template(
        &self,
        template_json: &str,
        name_override: Option<&str>,
    ) -> anyhow::Result<WorkspaceWithConfig> {
        let template: WorkspaceTemplate = serde_json::from_str(template_json)
            .map_err(|e| anyhow::anyhow!("模板格式无效: {}", e))?;

        let repo = WorkspaceRepo::new(&self.pool);
        let count = repo.count().await?;
        if count >= MAX_WORKSPACES as i64 {
            anyhow::bail!("工作区数量已达上限 ({MAX_WORKSPACES})");
        }

        let name = name_override
            .unwrap_or(&template.meta.name)
            .to_string();
        validate_workspace_name(&name)?;

        let id = Uuid::new_v4().to_string();
        let now = now_ms();
        let config = template.to_config(&id);

        let workspace = Workspace {
            id: id.clone(),
            name,
            icon: template.meta.icon.clone(),
            description: template.meta.description.clone(),
            is_default: false,
            is_archived: false,
            sort_order: count as i32,
            created_at: now,
            updated_at: now,
        };

        // 在事务内创建工作区 + 配置 + Skills + MCP Servers
        let mut tx = self.pool.begin().await?;

        // 创建工作区和配置
        repo.create(&workspace, &config).await?;

        // 写入 Skill 激活状态
        for skill in &template.skills {
            sqlx::query!(
                "INSERT INTO workspace_skills (workspace_id, skill_name, enabled)
                 VALUES (?, ?, ?)",
                id, skill.skill_name, skill.enabled
            )
            .execute(&mut *tx)
            .await?;
        }

        // 写入 MCP Server 配置
        for mcp in &template.mcp_servers {
            let config_str = serde_json::to_string(&mcp.config)?;
            sqlx::query!(
                "INSERT INTO workspace_mcp_servers (workspace_id, server_name, config, enabled)
                 VALUES (?, ?, ?, ?)",
                id, mcp.server_name, config_str, mcp.enabled
            )
            .execute(&mut *tx)
            .await?;
        }

        tx.commit().await?;

        Ok(WorkspaceWithConfig { workspace, config })
    }

    /// 导出工作区为模板 JSON
    pub async fn export_template(&self, workspace_id: &str) -> anyhow::Result<String> {
        let template = WorkspaceTemplate::export_from(&self.pool, workspace_id).await?;
        serde_json::to_string_pretty(&template)
            .map_err(|e| anyhow::anyhow!("序列化模板失败: {}", e))
    }
}
```

## 6. 工作区切换

### 6.1 切换流程

```text
用户点击工作区
    │
    ▼
WorkspaceSwitcher → invoke("switch_workspace", { id })
    │
    ▼
WorkspaceManager::switch(id)
    │
    ├─ 1. 校验目标工作区存在且未归档
    │
    ├─ 2. 检查 contexts 缓存中是否已有该工作区的 AgentContext
    │     ├─ 命中 → 直接复用
    │     └─ 未命中 → 构建新的 AgentContext（加载配置、合并全局默认、连接 MCP）
    │
    ├─ 3. 更新 active 为新工作区 ID
    │
    ├─ 4. emit("workspace_switched", WorkspaceSwitchedEvent)
    │
    └─ 5. 前端接收事件 → 刷新侧边栏对话列表 + 重置聊天面板
```

### 6.2 WorkspaceManager.switch 实现

```rust
// crates/agent-core/src/workspace/manager.rs（续）

impl WorkspaceManager {
    /// 切换到指定工作区（不影响其他工作区的正在运行任务）
    pub async fn switch(&self, workspace_id: &str) -> anyhow::Result<SwitchResult> {
        let repo = WorkspaceRepo::new(&self.pool);
        let workspace = repo.get(workspace_id).await?;

        if workspace.is_archived {
            anyhow::bail!("不能切换到已归档的工作区: {}", workspace.name);
        }

        // 复用已有 AgentContext，或构建新的
        let ctx = {
            let mut contexts = self.contexts.lock().await;
            if let Some(existing) = contexts.get(workspace_id) {
                existing.clone()
            } else {
                let config = repo.get_config(workspace_id).await?;
                let new_ctx = Arc::new(
                    AgentContext::build_for_workspace(&workspace, &config).await?
                );
                contexts.insert(workspace_id.to_string(), new_ctx.clone());
                new_ctx
            }
        };

        // 更新活跃工作区
        *self.active.write().await = workspace_id.to_string();

        Ok(SwitchResult {
            workspace,
            context: ctx,
        })
    }

    /// 获取当前活跃工作区 ID
    pub async fn active_id(&self) -> String {
        self.active.read().await.clone()
    }

    /// 获取当前活跃工作区的 AgentContext
    pub async fn active_context(&self) -> anyhow::Result<Arc<AgentContext>> {
        let id = self.active.read().await.clone();
        self.contexts
            .lock()
            .await
            .get(&id)
            .cloned()
            .ok_or_else(|| anyhow::anyhow!("活跃工作区上下文未加载"))
    }
}

pub struct SwitchResult {
    pub workspace: Workspace,
    pub context: Arc<AgentContext>,
}
```

### 6.4 前端状态同步

前端通过 Zustand store 管理工作区状态，监听 Tauri 事件自动同步：

```typescript
// apps/desktop/src/store/workspace.ts

import { create } from "zustand";
import { invoke } from "@tauri-apps/api/core";
import { listen } from "@tauri-apps/api/event";

interface Workspace {
  id: string;
  name: string;
  icon: string;
  description: string | null;
  isDefault: boolean;
  isArchived: boolean;
  sortOrder: number;
}

interface WorkspaceConfig {
  workspaceId: string;
  defaultTextModel: string | null;
  defaultEmbeddingModel: string | null;
  defaultImageModel: string | null;
  systemPrompt: string | null;
  agentName: string;
  agentAvatar: string;
  maxAgentDepth: number;
  evolutionEnabled: boolean;
  toolWhitelist: string[] | null;
  personalities: Record<string, { displayName: string; prompt: string }>;
}

interface WorkspaceState {
  workspaces: Workspace[];
  activeId: string;
  activeConfig: WorkspaceConfig | null;
  loading: boolean;

  // Actions
  fetchWorkspaces: () => Promise<void>;
  switchWorkspace: (id: string) => Promise<void>;
  createWorkspace: (input: {
    name: string;
    icon: string;
    description?: string;
    templateId?: string;
  }) => Promise<Workspace>;
  deleteWorkspace: (id: string) => Promise<void>;
  updateConfig: (config: WorkspaceConfig) => Promise<void>;

  // 初始化事件监听
  initListeners: () => () => void;
}

export const useWorkspaceStore = create<WorkspaceState>((set, get) => ({
  workspaces: [],
  activeId: "default",
  activeConfig: null,
  loading: false,

  fetchWorkspaces: async () => {
    set({ loading: true });
    try {
      const workspaces = await invoke<Workspace[]>("list_workspaces");
      set({ workspaces, loading: false });
    } catch (e) {
      console.error("加载工作区失败:", e);
      set({ loading: false });
    }
  },

  switchWorkspace: async (id: string) => {
    try {
      await invoke("switch_workspace", { workspaceId: id });
      // 事件监听器会处理后续状态更新
    } catch (e) {
      console.error("切换工作区失败:", e);
      throw e;
    }
  },

  createWorkspace: async (input) => {
    const ws = await invoke<Workspace>("create_workspace", input);
    // workspace_list_changed 事件会触发列表刷新
    return ws;
  },

  deleteWorkspace: async (id: string) => {
    await invoke("delete_workspace", { workspaceId: id });
  },

  updateConfig: async (config: WorkspaceConfig) => {
    await invoke("update_workspace_config", { config });
    set({ activeConfig: config });
  },

  initListeners: () => {
    const unlisteners: Array<() => void> = [];

    // 监听工作区切换事件
    listen<{ workspaceId: string; workspaceName: string; workspaceIcon: string }>(
      "workspace_switched",
      async (event) => {
        const { workspaceId } = event.payload;
        set({ activeId: workspaceId });

        // 加载新工作区的配置
        const config = await invoke<WorkspaceConfig>("get_workspace_config", {
          workspaceId,
        });
        set({ activeConfig: config });
      }
    ).then((u) => unlisteners.push(u));

    // 监听工作区列表变更事件
    listen("workspace_list_changed", () => {
      get().fetchWorkspaces();
    }).then((u) => unlisteners.push(u));

    // 返回清理函数
    return () => unlisteners.forEach((u) => u());
  },
}));
```

```typescript
import { Dialog, DialogContent, DialogHeader, DialogTitle } from "@/components/ui/dialog";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Textarea } from "@/components/ui/textarea";
import { invoke } from "@tauri-apps/api/core";
import { useWorkspaceStore } from "@/store/workspace";

interface TemplateMetaView {
  id: string;
  name: string;
  icon: string;
  description: string | null;
  tags: string[];
}

interface Props {
  open: boolean;
  onOpenChange: (open: boolean) => void;
}

export function NewWorkspaceDialog({ open, onOpenChange }: Props) {
  const { switchWorkspace } = useWorkspaceStore();
  const [name, setName] = useState("");
  const [icon, setIcon] = useState("🤖");
  const [description, setDescription] = useState("");
  const [selectedTemplate, setSelectedTemplate] = useState<string | null>(null);
  const [templates, setTemplates] = useState<TemplateMetaView[]>([]);

          description: description.trim() || null,
```

```typescript
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";

interface WorkspaceConfig {

  defaultTextModel: string | null;
  defaultEmbeddingModel: string | null;
  defaultImageModel: string | null;
  systemPrompt: string | null;
  agentName: string;

  toolWhitelist: string[] | null;

      setConfig({ ...activeConfig });
      setDirty(false);

    setSaving(true);

      await updateConfig(config);
      setDirty(false);

      setSaving(false);
    }

      await writeTextFile(path, json);

    value: WorkspaceConfig[K]

  return (

        </h1>
        <div className="flex gap-2">
          <Button variant="outline" size="sm" onClick={handleExport}>
            导出模板
          </Button>
          <Button size="sm" onClick={handleSave} disabled={!dirty || saving}>
            {saving ? "保存中..." : "保存"}
          </Button>
        </div>
      </div>

      <Tabs defaultValue="model">
        <TabsList>
          <TabsTrigger value="model">模型</TabsTrigger>
          <TabsTrigger value="persona">人格</TabsTrigger>
          <TabsTrigger value="safety">安全</TabsTrigger>
          <TabsTrigger value="advanced">高级</TabsTrigger>
        </TabsList>

        {/* 模型配置 Tab */}
        <TabsContent value="model" className="space-y-4 mt-4">
          <div>
            <label className="text-sm font-medium">默认文本模型</label>
            <p className="text-xs text-muted-foreground mb-1">
              留空则使用全局默认模型
            </p>
            <Input
              value={config.defaultTextModel ?? ""}
              onChange={(e) =>
                updateField("defaultTextModel", e.target.value || null)
              }
              placeholder="如 claude-sonnet-5（留空继承全局）"
            />
          </div>

          <div>
            <label className="text-sm font-medium">默认 Embedding 模型</label>
            <Input
              value={config.defaultEmbeddingModel ?? ""}
              onChange={(e) =>
                updateField("defaultEmbeddingModel", e.target.value || null)
              }
              placeholder="如 text-embedding-3-small（留空继承全局）"
            />
          </div>

          <div>
            <label className="text-sm font-medium">默认图像模型</label>
            <Input
              value={config.defaultImageModel ?? ""}
              onChange={(e) =>
                updateField("defaultImageModel", e.target.value || null)
              }
              placeholder="如 gpt-image-1（留空继承全局）"
            />
          </div>
        </TabsContent>

        {/* 人格配置 Tab */}
        <TabsContent value="persona" className="space-y-4 mt-4">

            <div className="w-20">
              <label className="text-sm font-medium">头像</label>
```

## 9. 设计约束

### 9.1 工作区数量上限

系统限制最多 **20 个工作区**（含默认工作区）。此上限基于以下考虑：

- 每个工作区可能缓存独立的 `AgentContext`，包含 MCP 连接、工具注册表等，20 个以内内存开销可控
- 侧边栏下拉列表超过 20 个条目时体验显著下降
- 用户可通过归档不活跃的工作区来释放配额

创建工作区时由 `WorkspaceManager::create` 检查 `WorkspaceRepo::count()` 是否达到上限，超限时返回 `AppError::Validation` 错误。

### 9.2 默认工作区

- 系统有且仅有一个默认工作区，由数据库唯一索引 `idx_workspaces_default` 保证
- 默认工作区不可删除、不可归档
- 首次启动时自动创建，ID 固定为 `"default"`
- 删除或归档当前活跃的非默认工作区时，自动切换回默认工作区

### 9.3 删除时的数据清理

工作区删除采用级联删除策略，通过 SQLite 外键 `ON DELETE CASCADE` 自动清理：

```text
DELETE workspaces(id)
  │
  ├── CASCADE → workspace_configs
  ├── CASCADE → workspace_skills
  ├── CASCADE → workspace_mcp_servers
  ├── CASCADE → conversations
  │                └── CASCADE → messages
  ├── CASCADE → memory_entries
  ├── CASCADE → media_tasks
  ├── CASCADE → audit_logs
  ├── CASCADE → embeddings
  └── CASCADE → task_traces
```

额外清理（非外键关联数据）：
- 向量存储中该 `workspace_id` 对应的嵌入数据（通过 `WorkspaceManager::cleanup_vector_namespace` 显式删除）
- 已缓存的 `AgentContext` 实例（从 `contexts` HashMap 中移除）

### 9.4 并发安全

- `WorkspaceManager.active` 使用 `RwLock<String>`，切换工作区时写锁，读取当前工作区时读锁
- `WorkspaceManager.contexts` 使用 `Mutex<HashMap>`，保护 AgentContext 缓存的并发安全
- 工作区切换不中断其他工作区中正在运行的 Agent 任务——任务绑定的是 `AgentContext`（通过 `Arc` 引用），切换只更新 `active` 指针

### 9.5 命名约束

| 约束项 | 规则 |
| ------ | ---- |
| 工作区名称 | 1~64 字符，不能全为空白字符 |
| 工作区描述 | 0~256 字符 |
| 工作区图标 | 1~2 字符（emoji） |
| System Prompt | 上限 2 000 tokens（注入时截断） |
| 模板文件 | `.workspace.json` 扩展名，JSON 格式 |

### 9.6 性能考量

| 场景 | 策略 |
| ---- | ---- |
| 工作区列表查询 | 索引 `(is_archived, sort_order)`，毫秒级返回 |
| 工作区切换 | AgentContext 缓存复用，首次加载后不重建 |
| 配置热更新 | 仅重建目标工作区的 AgentContext，不影响其他工作区 |
| 级联删除 | SQLite 外键 CASCADE，单事务内完成，大工作区（万级对话）可能耗时数百毫秒 |
| 模板导出 | 仅导出配置数据（不含对话/记忆），文件体积通常 < 5KB |
