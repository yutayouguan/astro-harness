# 工作流编辑器详细设计

> **Harness 边界（2026-09-05）**：`agent-workflow` 是 Harness 之上的 DAG 调度器，当前实现 43 种节点/6 类能力，持久化到 `~/.astro/workflows/workflows.json`。已启用工作流可通过 `agent_tool` 契约投影为 Responses API 原生 `workflow` namespace 工具，但 workflow DAG 状态仍不等于 regular Agent turn 状态。

### 1.4 Agent 工具投影

Workflow 级配置包含 `exposure=disabled|deferred|direct`、工具名、输入 JSON Schema、
输出说明、调用示例与 `confirmation=auto|always`。新建工作流的工具暴露默认为
Deferred，但只有 Workflow 本身启用且 per-Agent `workflow` toolset 开启时才能发现或调用。

Agent 传入的参数按 JSON Schema 校验后原样映射到 `trigger_input`。超过 30 秒的任务返回
`run_id` 并继续在独立 current-thread runtime 中执行；Agent 使用 `workflow.get_run` /
`workflow.cancel_run` 继续管理。含 AI、媒体、Action 或 HumanApproval 节点的流程先进入
Agent 审批链，审批通过后 HumanApproval 节点不会再次停住同一调用。

后台 run 按 Agent Session 隔离，其他 Session 不能查询或取消。子工作流与根工作流一起
冻结到 Step runtime，不在执行期间重读可变磁盘定义。含 `Code` 节点（包括子工作流）
的流程在完成 Agent sandbox 适配前 fail closed。

### 1.2 与已有 DAG 引擎的关系

前端编辑器负责构建和可视化 `WorkflowGraph`（JSON），通过 Tauri Command 提交给后端。后端的 `WorkflowExecutor`（见 05-工作流DAG执行引擎设计 第 4 节）接收 JSON、执行拓扑排序调度、管理并发和错误策略，并通过 Tauri Event 将节点状态变更实时推送回前端。前端仅负责渲染状态覆盖层，不参与调度逻辑。

```text
前端 Canvas ──(invoke: run_workflow)──► 后端 WorkflowExecutor
                                              │
                                        Tauri Event（异步推送）
                                              │
前端 RunOverlay ◄── workflow_node_running / workflow_node_done / workflow_node_failed
```

### 2.2 节点端口类型定义

每个端口声明其数据类型，连线时进行类型兼容性校验：

```typescript
// apps/desktop/src/components/workflow-editor/types.ts

/** 端口数据类型 */
export type PortDataType =
  | "text"      // 文本字符串
  | "number"    // 数值
  | "boolean"   // 布尔
  | "list"      // 数组
  | "object"    // JSON 对象
  | "any"       // 通配符，兼容所有类型
  | "file";     // 文件路径

/** 节点端口定义 */
export interface PortDefinition {
  id: string;              // 端口标识，如 "output", "true_branch"
  label: string;           // 显示名称
  dataType: PortDataType;  // 数据类型
  required: boolean;       // 是否必须连接
}

/** 节点类型定义 */
export interface NodeTypeDefinition {
  type: string;            // 类型标识，如 "llm_call"
  category: NodeCategory;  // 分类
  label: string;           // 显示名称
  description: string;     // 描述
  icon: string;            // lucide 图标名
  color: string;           // 节点主色（Tailwind class）
  inputs: PortDefinition[];   // 输入端口列表
  outputs: PortDefinition[];  // 输出端口列表
  configSchema: JSONSchema;   // 配置表单的 JSON Schema
  defaultConfig: Record<string, unknown>; // 默认配置值
}

export type NodeCategory =
  | "trigger"        // 触发节点 (5)
  | "ai"             // AI 节点 (8)
  | "media"          // 媒体节点 (9)
  | "flow_control"   // 流程控制 (6)
  | "data_processing" // 数据处理 (7)
  | "action"         // 动作节点 (7)
  | "custom";        // 自定义 (1)
```

### 3.2 连线验证（类型安全边）

连线时校验源端口与目标端口的数据类型兼容性：

```typescript
// apps/desktop/src/components/workflow-editor/connectionValidator.ts

const TYPE_COMPATIBILITY: Record<PortDataType, PortDataType[]> = {
  text:    ["text", "any"],
  number:  ["number", "any"],
  boolean: ["boolean", "any"],
  list:    ["list", "any"],
  object:  ["object", "any"],
  file:    ["file", "text", "any"],  // file 路径可视为 text
  any:     ["text", "number", "boolean", "list", "object", "file", "any"],
};

export function isValidConnection(connection: Connection, nodes: Node[]): boolean {
  const sourceNode = nodes.find(n => n.id === connection.source);
  const targetNode = nodes.find(n => n.id === connection.target);
  if (!sourceNode || !targetNode) return false;

  const sourceDef = getNodeDefinition(sourceNode.type!);
  const targetDef = getNodeDefinition(targetNode.type!);

  const sourcePort = sourceDef.outputs.find(p => p.id === connection.sourceHandle);
  const targetPort = targetDef.inputs.find(p => p.id === connection.targetHandle);

  if (!sourcePort || !targetPort) return false;

  // 类型兼容性检查
  return TYPE_COMPATIBILITY[sourcePort.dataType]?.includes(targetPort.dataType) ?? false;
}
```

```typescript
import dagre from "@dagrejs/dagre";

export function applyAutoLayout(
  nodes: Node[],
  edges: Edge[],
  direction: "TB" | "LR" = "LR",
): { nodes: Node[]; edges: Edge[] } {
  const g = new dagre.graphlib.Graph();
  g.setDefaultEdgeLabel(() => ({}));
  g.setGraph({ rankdir: direction, nodesep: 60, ranksep: 120, marginx: 40, marginy: 40 });

  nodes.forEach(node => {
    const def = getNodeDefinition(node.type!);
    // 节点尺寸根据类型动态计算
    const width = def.category === "control" ? 180 : 200;
    const height = def.category === "control" ? 80 : 100;
    g.setNode(node.id, { width, height });
  });

  edges.forEach(edge => {
    g.setEdge(edge.source, edge.target);
  });

  dagre.layout(g);

  const layoutedNodes = nodes.map(node => {
    const pos = g.node(node.id);
    return { ...node, position: { x: pos.x - pos.width / 2, y: pos.y - pos.height / 2 } };
  });

  return { nodes: layoutedNodes, edges };
}
```

```typescript
// apps/desktop/src/components/workflow-editor/undoRedo.ts

export interface UndoableAction {
  type: string;
  apply: (state: WorkflowState) => WorkflowState;
  revert: (state: WorkflowState) => WorkflowState;
  description: string;  // 用于显示操作历史
}

// 在 Zustand store 中集成
interface WorkflowStoreState {
  // ...
  undoStack: UndoableAction[];
  redoStack: UndoableAction[];
  executeAction: (action: UndoableAction) => void;
  undo: () => void;
  redo: () => void;
}

// 示例：添加节点
function createAddNodeAction(node: Node): UndoableAction {
  return {
    type: "ADD_NODE",
    apply: (state) => ({ ...state, nodes: [...state.nodes, node] }),
    revert: (state) => ({ ...state, nodes: state.nodes.filter(n => n.id !== node.id) }),
    description: `添加 ${node.data.label}`,
  };
}

// 示例：删除节点（同时删除关联边）
function createDeleteNodeAction(nodeId: string, nodes: Node[], edges: Edge[]): UndoableAction {
  const node = nodes.find(n => n.id === nodeId)!;
  const connectedEdges = edges.filter(e => e.source === nodeId || e.target === nodeId);

  return {
    type: "DELETE_NODE",
    apply: (state) => ({
      ...state,
      nodes: state.nodes.filter(n => n.id !== nodeId),
      edges: state.edges.filter(e => e.source !== nodeId && e.target !== nodeId),
    }),
    revert: (state) => ({
      ...state,
      nodes: [...state.nodes, node],
      edges: [...state.edges, ...connectedEdges],
    }),
    description: `删除 ${node.data.label}`,
  };
}
```

```typescript
function copySelectedNodes(selectedIds: Set<string>, nodes: Node[], edges: Edge[]): ClipboardData {
  const selectedNodes = nodes.filter(n => selectedIds.has(n.id));
  const internalEdges = edges.filter(
    e => selectedIds.has(e.source) && selectedIds.has(e.target)

  const center = computeBoundingCenter(selectedNodes);

function pasteFromClipboard(clipboard: ClipboardData, cursorPosition: XYPosition): { nodes: Node[]; edges: Edge[] } {
  const idMap = new Map<string, string>();
  const newNodes = clipboard.nodes.map(n => {

    idMap.set(n.id, newId);

      id: newId,

        x: cursorPosition.x + n.relativePosition.x,
        y: cursorPosition.y + n.relativePosition.y,

    id: `edge_${nanoid(8)}`,

    target: idMap.get(e.target)!,
```

```typescript
export function PromptEditor({
  value,
  onChange,
  variableContext,
}: {
  value: string;
  onChange: (v: string) => void;
  variableContext: VariableContext;
}) {
  const editorRef = useRef<monaco.editor.IStandaloneCodeEditor | null>(null);

  useEffect(() => {
    // 注册自定义 token 规则：高亮 {{...}} 和 ${...}
    monaco.languages.setMonarchTokensProvider("prompt-template", {
      tokenizer: {
        root: [
          [/\{\{[^}]+\}\}/, "variable.template"],  // {{node.output}} 样式
          [/\$\{[^}]+\}/, "variable.reference"],    // ${node.output} 样式
        ],
      },
    });

    // 注册自动补全（输入 {{ 或 ${ 时触发变量列表）
    monaco.languages.registerCompletionItemProvider("prompt-template", {
      triggerCharacters: ["{", "."],
      provideCompletionItems: (model, position) => {
        const textBefore = model.getValueInRange({
          startLineNumber: position.lineNumber,
          startColumn: 1,
          endLineNumber: position.lineNumber,
          endColumn: position.column,
        });

        if (textBefore.endsWith("{{") || textBefore.endsWith("${")) {
          return {
            suggestions: variableContext.allVariables.map(v => ({
              label: v.ref,
              kind: monaco.languages.CompletionItemKind.Variable,
              insertText: v.ref.replace(/^\$?\{?\{?/, ""),
              detail: `${v.label} (${v.type})`,
            })),
          };
        }
        return { suggestions: [] };
      },
    });
  }, [variableContext]);

  return (
    <MonacoEditor
      height="200px"
      language="prompt-template"
      value={value}
      onChange={v => onChange(v ?? "")}
      options={{
        minimap: { enabled: false },
        lineNumbers: "off",
        wordWrap: "on",
        fontSize: 13,
        scrollBeyondLastLine: false,
      }}
      onMount={editor => { editorRef.current = editor; }}
    />
  );
```

```typescript
// apps/desktop/src/components/workflow-editor/RunOverlay.tsx

export function useRunOverlay(runId: string | null) {
  const [nodeStatuses, setNodeStatuses] = useState<Record<string, NodeRunStatus>>({});
  const [overallProgress, setOverallProgress] = useState(0);

  useEffect(() => {
    if (!runId) return;

    const unlisteners = [
      listen<WorkflowNodeEvent>("workflow_node_running", e => {
        if (e.payload.run_id !== runId) return;
        setNodeStatuses(prev => ({
          ...prev,
          [e.payload.node_id]: {
            status: "running",
            startedAt: Date.now(),
          },
        }));
      }),

      listen<WorkflowNodeDoneEvent>("workflow_node_done", e => {
        if (e.payload.run_id !== runId) return;
        setNodeStatuses(prev => ({
          ...prev,
          [e.payload.node_id]: {
            status: "done",
            output: e.payload.output,
            duration: Date.now() - (prev[e.payload.node_id]?.startedAt ?? Date.now()),
          },
        }));
        recalculateProgress();
      }),

      listen<WorkflowNodeFailedEvent>("workflow_node_failed", e => {
        if (e.payload.run_id !== runId) return;
        setNodeStatuses(prev => ({
          ...prev,
          [e.payload.node_id]: {
            status: "failed",
            error: e.payload.error,
            duration: Date.now() - (prev[e.payload.node_id]?.startedAt ?? Date.now()),
          },
        }));
      }),

      listen<WorkflowNodeSkippedEvent>("workflow_node_skipped", e => {
        if (e.payload.run_id !== runId) return;
        setNodeStatuses(prev => ({
          ...prev,
          [e.payload.node_id]: { status: "skipped" },
        }));
      }),
    ];

    return () => { unlisteners.forEach(p => p.then(f => f())); };
  }, [runId]);

  return { nodeStatuses, overallProgress };
}

interface NodeRunStatus {
  status: "pending" | "running" | "done" | "failed" | "skipped";
  startedAt?: number;
  duration?: number;
  output?: unknown;
  error?: string;
}
```

```text
│                   ${now}                       当前 ISO 时间戳
```

### 7.2 模板语法

工作流模板引擎使用 `${}` 作为变量引用语法（与 05 号文档的 `{{}}` 兼容，后端同时解析两种语法）：

```text
简单引用：     ${nodeId.output}
嵌套路径：     ${nodeId.output.results[0].title}
管道过滤：     ${nodeId.output | uppercase}
默认值：       ${nodeId.output ?? "默认文本"}
条件三元：     ${nodeId.output.count > 0 ? "有结果" : "无结果"}
```

### 7.3 后端模板解析器

```rust
// crates/agent-workflow/src/template.rs

use regex::Regex;
use lazy_static::lazy_static;

lazy_static! {
    // 匹配 ${...} 和 {{...}} 两种语法
    static ref TEMPLATE_RE: Regex = Regex::new(
        r"(?:\$\{([^}]+)\}|\{\{([^}]+)\}\})"
    ).unwrap();
}

/// 解析模板字符串，替换变量引用为实际值
pub fn resolve_template_str(
    template: &str,
    ctx: &ExecutionContext,
) -> anyhow::Result<String> {
    let result = TEMPLATE_RE.replace_all(template, |caps: &regex::Captures| {
        let path = caps.get(1).or(caps.get(2)).map(|m| m.as_str()).unwrap_or("");

        // 解析管道过滤器
        let (var_path, filters) = parse_filters(path);

        // 解析默认值
        let (var_path, default_val) = parse_default(var_path);

        // 从上下文中解析变量值
        let value = ctx.resolve_path(var_path.trim())
            .unwrap_or_else(|| {
                default_val.map(|d| Value::String(d.to_string()))
                    .unwrap_or(Value::Null)
            });

        // 应用过滤器
        let filtered = apply_filters(value, &filters);
        value_to_string(&filtered)
    });

    Ok(result.into())
}

/// 解析管道过滤器，如 "nodeId.output | uppercase | trim"
fn parse_filters(expr: &str) -> (&str, Vec<&str>) {
    let parts: Vec<&str> = expr.splitn(2, '|').collect();
    if parts.len() == 1 {
        (parts[0], vec![])
    } else {
        let filters = parts[1].split('|').map(str::trim).collect();
        (parts[0], filters)
    }
}

/// 支持的过滤器
fn apply_filters(value: Value, filters: &[&str]) -> Value {
    let mut result = value;
    for filter in filters {
        result = match *filter {
            "uppercase" => Value::String(result.as_str().unwrap_or("").to_uppercase()),
            "lowercase" => Value::String(result.as_str().unwrap_or("").to_lowercase()),
            "trim" => Value::String(result.as_str().unwrap_or("").trim().to_string()),
            "length" => match &result {
                Value::String(s) => json!(s.len()),
                Value::Array(a) => json!(a.len()),
                _ => Value::Null,
            },
            "json" => Value::String(serde_json::to_string(&result).unwrap_or_default()),
            "pretty_json" => Value::String(serde_json::to_string_pretty(&result).unwrap_or_default()),
            _ => result, // 未知过滤器，透传
        };
    }
    result
}
```

```rust
pub struct WorkflowRepository {

impl WorkflowRepository {
    /// 创建新工作流
    pub async fn create(&self, workflow: &WorkflowGraph, workspace_id: &str) -> anyhow::Result<String> {
        let id = format!("wf-{}", uuid::Uuid::new_v4());
        let graph_json = serde_json::to_string(workflow)?;

        sqlx::query!(
            "INSERT INTO workflows (id, workspace_id, name, description, version, status, graph_json, tags)
             VALUES (?, ?, ?, ?, ?, 'draft', ?, ?)",
            id, workspace_id, workflow.name, workflow.description,
            workflow.version, graph_json, "[]"
        ).execute(&self.pool).await?;

        Ok(id)
    }

    /// 保存（更新）工作流
    pub async fn save(&self, id: &str, workflow: &WorkflowGraph) -> anyhow::Result<()> {
        let graph_json = serde_json::to_string(workflow)?;
        let now = now_ms();

        sqlx::query!(
            "UPDATE workflows SET name=?, description=?, version=?, graph_json=?, updated_at=? WHERE id=?",
            workflow.name, workflow.description, workflow.version, graph_json, now, id
        ).execute(&self.pool).await?;

        Ok(())
    }

    /// 列出工作区内所有工作流
    pub async fn list(&self, workspace_id: &str) -> anyhow::Result<Vec<WorkflowSummary>> {
        let rows = sqlx::query_as!(
            WorkflowSummary,
            "SELECT id, name, description, status, tags, updated_at, run_count
             FROM workflows WHERE workspace_id=? AND status != 'archived'
             ORDER BY updated_at DESC",
            workspace_id
        ).fetch_all(&self.pool).await?;

        Ok(rows)
    }

    /// 加载单个工作流（完整 graph）
    pub async fn load(&self, id: &str) -> anyhow::Result<WorkflowGraph> {
        let row = sqlx::query!("SELECT graph_json FROM workflows WHERE id=?", id)
            .fetch_one(&self.pool).await?;

        let graph: WorkflowGraph = serde_json::from_str(&row.graph_json)?;
        Ok(graph)
    }

    /// 删除工作流（标记为 archived）
    pub async fn delete(&self, id: &str) -> anyhow::Result<()> {
        sqlx::query!("UPDATE workflows SET status='archived', updated_at=? WHERE id=?", now_ms(), id)
            .execute(&self.pool).await?;
        Ok(())
    }

    /// 复制工作流
    pub async fn duplicate(&self, id: &str, new_name: &str) -> anyhow::Result<String> {
        let graph = self.load(id).await?;
        let row = sqlx::query!("SELECT workspace_id FROM workflows WHERE id=?", id)
            .fetch_one(&self.pool).await?;

        let mut new_graph = graph;
        new_graph.name = new_name.to_string();
        self.create(&new_graph, &row.workspace_id).await
    }
```

## 9. 工作流 → Skill 编译

### 9.1 SkillCompiler

将可视化 DAG 编译为 `SKILL.md` 文件，使工作流可以作为 Skill 被 Agent 召回和执行：

```rust
// crates/agent-workflow/src/skill_compiler.rs

pub struct SkillCompiler {
    pool: SqlitePool,
}

impl SkillCompiler {
    /// 将工作流图编译为 SKILL.md 内容
    pub fn compile(&self, graph: &WorkflowGraph) -> anyhow::Result<String> {
        // 1. 生成 frontmatter
        let frontmatter = self.generate_frontmatter(graph)?;
        // 2. 生成步骤描述
        let steps = self.generate_steps(graph)?;
        // 3. 组装 SKILL.md
        Ok(format!("{}\n\n{}", frontmatter, steps))
    }

    fn generate_frontmatter(&self, graph: &WorkflowGraph) -> anyhow::Result<String> {
        let trigger_patterns = graph.metadata.as_ref()
            .and_then(|m| m.trigger_patterns.as_ref())
            .map(|ps| ps.iter().map(|p| format!("  - \"{}\"", p)).collect::<Vec<_>>().join("\n"))
            .unwrap_or_default();

        let params = self.extract_input_params(graph);
        let required_tools = self.extract_required_tools(graph);
        let risk_level = self.infer_risk_level(graph);

        Ok(format!(r#"---
name: {name}
version: {version}
description: {description}
origin: synthesized
status: draft
trigger_patterns:
{trigger_patterns}
parameters:
{params}
risk_level: {risk_level}
requires_tools: [{tools}]
source_workflow_id: {workflow_id}
---"#,
            name = slugify(&graph.name),
            version = graph.version,
            description = graph.description,
            trigger_patterns = trigger_patterns,
            params = params,
            risk_level = risk_level,
            tools = required_tools.join(", "),
            workflow_id = graph.id,
        ))
    }

    fn generate_steps(&self, graph: &WorkflowGraph) -> anyhow::Result<String> {
        let order = topological_sort(&graph.nodes, &graph.edges)?;
        let mut steps = format!("# {}\n\n## 执行步骤\n\n", graph.name);

        for (i, node_id) in order.iter().enumerate() {
            let node = graph.node(node_id)?;
            let step_desc = self.describe_node_as_step(node, i + 1);
            steps.push_str(&step_desc);
            steps.push('\n');
        }

        Ok(steps)
    }

    fn describe_node_as_step(&self, node: &WorkflowNode, step_num: usize) -> String {
        match &node.kind {
            NodeKind::Start => format!("{}. **接收输入**：获取用户提供的参数\n", step_num),
            NodeKind::End => format!("{}. **输出结果**：返回最终处理结果\n", step_num),
            NodeKind::Llm { model, prompt, .. } => {
                format!("{}. **LLM 处理**（模型：{}）：\n   {}\n", step_num, model, truncate(prompt, 200))
            }
            NodeKind::Tool { tool, params } => {
                format!("{}. **调用工具** `{}`：参数 = {}\n", step_num, tool, serde_json::to_string(params).unwrap_or_default())
            }
            NodeKind::Condition { expr } => {
                format!("{}. **条件判断**：如果 {} 成立，走分支 A；否则走分支 B\n", step_num, expr)
            }
            NodeKind::Loop { items_expr, .. } => {
                format!("{}. **循环处理**：遍历 {}，对每个元素执行以下操作\n", step_num, items_expr)
            }
            _ => format!("{}. 执行 {:?}\n", step_num, node.kind),
        }
    }

    /// 推断工作流的风险等级（取所有工具节点中最高的风险等级）
    fn infer_risk_level(&self, graph: &WorkflowGraph) -> &'static str {
        let has_shell = graph.nodes.iter().any(|n| matches!(&n.kind, NodeKind::Tool { tool, .. } if tool == "shell_exec"));
        let has_file_write = graph.nodes.iter().any(|n| matches!(&n.kind, NodeKind::Tool { tool, .. } if tool == "file_write"));

        if has_shell { "L2" }
        else if has_file_write { "L1" }
        else { "L0" }
    }

    /// 提取工作流中使用的所有工具名称
    fn extract_required_tools(&self, graph: &WorkflowGraph) -> Vec<String> {
        graph.nodes.iter()
            .filter_map(|n| match &n.kind {
                NodeKind::Tool { tool, .. } => Some(tool.clone()),
                _ => None,
            })
            .collect::<std::collections::HashSet<_>>()
            .into_iter()
            .collect()
    }

    /// 从 Start 节点提取输入参数，生成 YAML 格式
    fn extract_input_params(&self, graph: &WorkflowGraph) -> String {
        // 查找 Start 节点的 inputParams 配置
        let start = graph.nodes.iter().find(|n| matches!(n.kind, NodeKind::Start));
        if let Some(start) = start {
            if let Some(params) = start.config.get("inputParams").and_then(|v| v.as_array()) {
                return params.iter().map(|p| {
                    let name = p.get("name").and_then(|v| v.as_str()).unwrap_or("param");
                    let dtype = p.get("dataType").and_then(|v| v.as_str()).unwrap_or("string");
                    let desc = p.get("description").and_then(|v| v.as_str()).unwrap_or("");
                    let required = p.get("required").and_then(|v| v.as_bool()).unwrap_or(false);
                    format!("  {}:\n    type: {}\n    description: {}\n    required: {}", name, dtype, desc, required)
                }).collect::<Vec<_>>().join("\n");
            }
        }
        String::new()
    }
}
```

```typescript
    toast.error("导入失败", { description: errors.join(", ") });
    return;
  }
  const newId = await invoke<string>("create_workflow", {
    workspaceId,
    graph: JSON.stringify(graph),
  });
  navigate(`/workflows/${newId}`);
}
```

### 12.3 Zustand Store 结构

```typescript
// apps/desktop/src/components/workflow-editor/hooks/useWorkflowStore.ts

import { create } from "zustand";
import { immer } from "zustand/middleware/immer";

interface WorkflowState {
  // 工作流元数据
  workflowId: string | null;
  workflowName: string;
  workflowDescription: string;

  // React Flow 数据
  nodes: Node[];
  edges: Edge[];
  selectedNodeId: string | null;

  // 编辑状态
  dirty: boolean;
  validationErrors: ValidationError[];

  // 撤销/重做
  undoStack: UndoableAction[];
  redoStack: UndoableAction[];

  // 运行状态
  runState: {
    runId: string | null;
    status: "idle" | "running" | "paused" | "done" | "failed";
    nodeStatuses: Record<string, NodeRunStatus>;
    logs: RunLogEntry[];
    progress: number;
  };

  // 画布视口
  viewport: { x: number; y: number; zoom: number };

  // AI 助手状态
  assistantOpen: boolean;
}

interface WorkflowActions {
  // 节点操作
  addNode: (node: Node) => void;
  updateNodeData: (nodeId: string, data: any) => void;
  deleteNode: (nodeId: string) => void;
  selectNode: (nodeId: string | null) => void;

  // 边操作
  addEdge: (edge: Edge) => void;
  deleteEdge: (edgeId: string) => void;

  // 编辑操作
  executeAction: (action: UndoableAction) => void;
  undo: () => void;
  redo: () => void;
  copySelected: () => void;
  pasteNodes: () => void;
  selectAll: () => void;
  deleteSelected: () => void;
  autoLayout: () => void;

  // 持久化
  load: (id: string) => Promise<void>;
  save: () => Promise<void>;
  createNew: (template?: WorkflowTemplate) => void;

  // 运行
  runWorkflow: (input?: Value) => Promise<void>;
  pauseWorkflow: () => Promise<void>;
  cancelWorkflow: () => Promise<void>;

  // AI 助手
  openAssistant: () => void;
  closeAssistant: () => void;
  applyGeneratedGraph: (graph: WorkflowGraph) => void;
}

export const useWorkflowStore = create<WorkflowState & WorkflowActions>()(
  immer((set, get) => ({
    // 初始状态
    workflowId: null,
    workflowName: "未命名工作流",
    workflowDescription: "",
    nodes: [],
    edges: [],
    selectedNodeId: null,
    dirty: false,
    validationErrors: [],
    undoStack: [],
    redoStack: [],
    runState: {
      runId: null,
      status: "idle",
      nodeStatuses: {},
      logs: [],
      progress: 0,
    },
    viewport: { x: 0, y: 0, zoom: 1 },
    assistantOpen: false,

    // Actions 实现
    addNode: (node) => set(state => {
      state.nodes.push(node);
      state.dirty = true;
    }),

    executeAction: (action) => set(state => {
      const newState = action.apply({ nodes: state.nodes, edges: state.edges });
      state.nodes = newState.nodes;
      state.edges = newState.edges;
      state.undoStack.push(action);
      state.redoStack = [];
      state.dirty = true;
      state.validationErrors = validateCurrentGraph(newState.nodes, newState.edges);
    }),

    undo: () => set(state => {
      const action = state.undoStack.pop();
      if (!action) return;
      const newState = action.revert({ nodes: state.nodes, edges: state.edges });
      state.nodes = newState.nodes;
      state.edges = newState.edges;
      state.redoStack.push(action);
      state.dirty = true;
    }),

    redo: () => set(state => {
      const action = state.redoStack.pop();
      if (!action) return;
      const newState = action.apply({ nodes: state.nodes, edges: state.edges });
      state.nodes = newState.nodes;
      state.edges = newState.edges;
      state.undoStack.push(action);
      state.dirty = true;
    }),

    save: async () => {
      const { workflowId, nodes, edges, workflowName, workflowDescription } = get();
      const graph: WorkflowGraph = {
        id: workflowId ?? "",
        name: workflowName,
        description: workflowDescription,
        version: "1.0.0",
        nodes,
        edges,
      };
      const graphJson = JSON.stringify(graph);

      if (workflowId) {
        await invoke("save_workflow", { id: workflowId, graph: graphJson });
      } else {
        const id = await invoke<string>("create_workflow", {
          workspaceId: getCurrentWorkspaceId(),
          graph: graphJson,
        });
        set({ workflowId: id });
      }
      set({ dirty: false });
    },

    runWorkflow: async (input) => {
      const { workflowId } = get();
      if (!workflowId) return;

      // 先保存
      await get().save();

      const runId = await invoke<string>("run_workflow", {
        id: workflowId,
        input: input ?? {},
      });

      set(state => {
        state.runState = {
          runId,
          status: "running",
          nodeStatuses: {},
          logs: [],
          progress: 0,
        };
      });
    },

    // ... 其他 action 实现
  }))
);
```
