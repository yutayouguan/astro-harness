# 快捷键与命令面板详细设计

> 版本：v1.0 | 日期：2026-08-09 | 状态：草稿
> 对应需求：F-21 快捷键与命令面板

Astro Agent 的键盘交互分为三层：**Rust 侧 ShortcutManager**（通过 Tauri global_shortcut plugin 注册系统级热键，窗口最小化或失焦时仍可响应）、**React 侧 useHotkeys Hook**（监听应用内局部快捷键）、以及 **CommandPalette 命令面板**（`Cmd+K` 唤起，提供 fuse.js 模糊搜索所有已注册命令的能力）。用户可通过 `~/.astro/keybindings.json` 自定义绑定，系统自动检测冲突并支持一键恢复默认值。

---

## 1. 快捷键系统架构

### 1.1 整体分层

```text
┌────────────────────────────────────────────────────┐
│  OS 层（系统级热键）                                 │
│  tauri-plugin-global-shortcut                      │
│  ShortcutManager (Rust)                            │
│    ├─ toggle_window: Cmd+Shift+Space               │
│    └─ quick_capture: Cmd+Shift+A                   │
├────────────────────────────────────────────────────┤
│  App 层（应用内快捷键）                              │
│  useHotkeys (React Hook)                           │
│    ├─ 全局级：Cmd+K / Cmd+N / Cmd+, / Cmd+W        │
│    ├─ 上下文级：Enter(输入框) / Escape(面板)         │
│    └─ 工作区级：Cmd+1~9 切换                        │
├────────────────────────────────────────────────────┤
│  Command 层（命令面板）                              │
│  CommandRegistry + CommandPalette                  │
│    ├─ fuzzy search (fuse.js)                       │
│    ├─ 分组展示 + 最近命令                            │
│    └─ Skill 动态注册                                │
└────────────────────────────────────────────────────┘
```

### 1.2 Rust 侧 ShortcutManager

ShortcutManager 在应用启动阶段向操作系统注册全局热键。热键在应用失焦甚至最小化到托盘时依然有效。注册失败（如被其他应用占用）时回退到备选键位并通过系统通知告知用户。

```rust
// src-tauri/src/shortcuts.rs

use std::collections::HashMap;
use tauri::{AppHandle, Manager};
use tauri_plugin_global_shortcut::{
    Code, GlobalShortcutExt, Modifiers, Shortcut, ShortcutEvent, ShortcutState,
};
use anyhow::Result;

/// 全局快捷键管理器，持有已注册热键及其动作映射
pub struct ShortcutManager {
    shortcuts: HashMap<String, Shortcut>,
}

impl ShortcutManager {
    pub fn new() -> Self {
        Self {
            shortcuts: HashMap::new(),
        }
    }

    /// 在应用启动时注册所有全局快捷键
    pub fn register_all(&mut self, app: &AppHandle) -> Result<()> {
        // 唤起 / 隐藏主窗口
        let toggle = Shortcut::new(
            Some(Modifiers::SUPER | Modifiers::SHIFT),
            Code::Space,
        );

        app.global_shortcut().on_shortcut(
            toggle,
            |app_handle, _shortcut, event| {
                if event.state == ShortcutState::Pressed {
                    toggle_main_window(app_handle);
                }
            },
        )?;
        self.shortcuts.insert("toggle_window".into(), toggle);

        // 快速捕获（从任意应用发起新对话）
        let quick_capture = Shortcut::new(
            Some(Modifiers::SUPER | Modifiers::SHIFT),
            Code::KeyA,
        );

        app.global_shortcut().on_shortcut(
            quick_capture,
            |app_handle, _shortcut, event| {
                if event.state == ShortcutState::Pressed {
                    show_quick_capture(app_handle);
                }
            },
        )?;
        self.shortcuts.insert("quick_capture".into(), quick_capture);

        Ok(())
    }

    /// 注销所有全局快捷键（应用退出时调用）
    pub fn unregister_all(&self, app: &AppHandle) -> Result<()> {
        for shortcut in self.shortcuts.values() {
            let _ = app.global_shortcut().unregister(*shortcut);
        }
        Ok(())
    }
}

fn toggle_main_window(app: &AppHandle) {
    if let Some(window) = app.get_webview_window("main") {
        if window.is_visible().unwrap_or(false) {
            let _ = window.hide();
        } else {
            let _ = window.show();
            let _ = window.set_focus();
        }
    }
}

fn show_quick_capture(app: &AppHandle) {
    if let Some(window) = app.get_webview_window("main") {
        let _ = window.show();
        let _ = window.set_focus();
        let _ = window.emit("quick-capture", ());
    }
}
```

### 1.3 React 侧 useHotkeys Hook

应用内快捷键通过 `keydown` 事件在 React 层处理。Hook 自动区分 macOS（`metaKey`）和 Windows/Linux（`ctrlKey`），并根据当前上下文栈决定是否拦截。

```typescript
// src/hooks/useHotkeys.ts

import { useEffect, useRef } from "react";
import { useKeybindingStore } from "@/stores/keybinding-store";
import { useContextStack } from "@/hooks/useContextStack";

export interface HotkeyBinding {
  /** 绑定标识符，与 keybindings.json 中的 key 对应 */
  id: string;
  /** 仅在指定上下文激活时触发 */
  context?: string;
  /** 回调 */
  handler: (e: KeyboardEvent) => void;
}

export function useHotkeys(bindings: HotkeyBinding[]) {
  const { resolveKey } = useKeybindingStore();
  const { activeContext } = useContextStack();
  const bindingsRef = useRef(bindings);
  bindingsRef.current = bindings;

  useEffect(() => {
    const onKeyDown = (e: KeyboardEvent) => {
      const isMac = navigator.platform.includes("Mac");
      const pressed = buildKeyString(e, isMac);

      for (const binding of bindingsRef.current) {
        // 上下文过滤：若指定了 context 则仅在匹配时触发
        if (binding.context && binding.context !== activeContext) continue;

        const expected = resolveKey(binding.id);
        if (normalizeKey(pressed) === normalizeKey(expected)) {
          e.preventDefault();
          e.stopPropagation();
          binding.handler(e);
          return;
        }
      }
    };

    window.addEventListener("keydown", onKeyDown, { capture: true });
    return () => window.removeEventListener("keydown", onKeyDown, { capture: true });
  }, [activeContext, resolveKey]);
}

/** 将 KeyboardEvent 转换为统一字符串，例如 "Cmd+Shift+K" */
function buildKeyString(e: KeyboardEvent, isMac: boolean): string {
  const parts: string[] = [];
  if (isMac ? e.metaKey : e.ctrlKey) parts.push("Cmd");
  if (e.shiftKey) parts.push("Shift");
  if (e.altKey) parts.push("Alt");
  parts.push(e.key.length === 1 ? e.key.toUpperCase() : e.key);
  return parts.join("+");
}

function normalizeKey(key: string): string {
  return key
    .toLowerCase()
    .replace("ctrl", "cmd")
    .replace("meta", "cmd")
    .replace("comma", ",")
    .replace(" ", "");
}
```

## 3. 命令面板设计

### 3.1 CommandPalette 组件

命令面板基于 `cmdk`（shadcn/ui Command）封装，支持键盘导航、分组展示、最近命令追踪和模糊搜索。

```tsx
// src/components/CommandPalette.tsx

import { useEffect, useState, useCallback, useMemo } from "react";
import {
  CommandDialog,
  CommandEmpty,
  CommandGroup,
  CommandInput,
  CommandItem,
  CommandList,
  CommandSeparator,
} from "@/components/ui/command";
import { commandRegistry, type CommandDef } from "@/lib/command-registry";
import { useRecentCommands } from "@/hooks/useRecentCommands";
import Fuse from "fuse.js";
import * as Icons from "lucide-react";

interface CommandPaletteProps {
  open: boolean;
  onClose: () => void;
}

const GROUP_LABELS: Record<string, string> = {
  recent: "最近使用",
  conversation: "对话操作",
  workspace: "工作区",
  skill: "技能",
  history: "历史搜索",
  settings: "设置",
  action: "操作",
};

const GROUP_ORDER = ["recent", "conversation", "workspace", "skill", "settings", "action"];

export function CommandPalette({ open, onClose }: CommandPaletteProps) {
  const [query, setQuery] = useState("");
  const [commands, setCommands] = useState<CommandDef[]>([]);
  const { recentIds, recordUsage } = useRecentCommands();

  // 构建 fuse.js 实例
  const fuse = useMemo(() => {
    const allCommands = commandRegistry.getAll();
    return new Fuse(allCommands, {
      keys: [
        { name: "label", weight: 0.5 },
        { name: "keywords", weight: 0.3 },
        { name: "group", weight: 0.2 },
      ],
      threshold: 0.4,
      includeScore: true,
    });
  }, [commands.length]);

  useEffect(() => {
    const update = () => {
      if (!query) {
        setCommands(commandRegistry.getAll());
      } else {
        const results = fuse.search(query);
        setCommands(results.map((r) => r.item));
      }
    };
    update();
    return commandRegistry.subscribe(update);
  }, [query, fuse]);

  const handleSelect = useCallback(
    async (cmd: CommandDef) => {
      onClose();
      setQuery("");
      recordUsage(cmd.id);
      await cmd.execute();
    },
    [onClose, recordUsage],
  );

  // 按 group 分组并排序；无查询时在顶部插入最近使用
  const grouped = useMemo(() => {
    const groups: Record<string, CommandDef[]> = {};

    if (!query && recentIds.length > 0) {
      const recentCmds = recentIds
        .map((id) => commandRegistry.get(id))
        .filter(Boolean) as CommandDef[];
      if (recentCmds.length > 0) groups["recent"] = recentCmds;
    }

    for (const cmd of commands) {
      (groups[cmd.group] ??= []).push(cmd);
    }

    return GROUP_ORDER
      .filter((g) => groups[g]?.length)
      .map((g) => ({ group: g, items: groups[g] }));
  }, [commands, query, recentIds]);

  return (
    <CommandDialog open={open} onOpenChange={onClose}>
      <CommandInput
        placeholder="输入命令或搜索..."
        value={query}
        onValueChange={setQuery}
        aria-label="命令面板搜索"
      />
      <CommandList aria-label="命令列表">
        <CommandEmpty>未找到相关命令</CommandEmpty>
        {grouped.map(({ group, items }, idx) => (
          <div key={group}>
            {idx > 0 && <CommandSeparator />}
            <CommandGroup heading={GROUP_LABELS[group] ?? group}>
              {items.map((cmd) => {
                const IconComp = cmd.icon
                  ? (Icons as Record<string, React.ComponentType<{ size?: number }>>)[cmd.icon]
                  : null;
                return (
                  <CommandItem
                    key={cmd.id}
                    value={cmd.id}
                    onSelect={() => handleSelect(cmd)}
                    className="flex items-center gap-2"
                  >
                    {IconComp && <IconComp size={16} />}
                    <span className="flex-1">{cmd.label}</span>
                    {cmd.shortcut && (
                      <kbd className="text-xs bg-muted px-1.5 py-0.5 rounded font-mono">
                        {cmd.shortcut}
                      </kbd>
                    )}
                  </CommandItem>
                );
              })}
            </CommandGroup>
          </div>
        ))}
      </CommandList>
    </CommandDialog>
  );
}
```

### 3.2 Command 注册模式

命令注册系统采用发布-订阅模式，支持动态增删命令（如 Skill 安装/卸载时自动注册/注销）。

```typescript
// src/lib/command-registry.ts

export interface CommandDef {
  id: string;
  label: string;
  group: "conversation" | "workspace" | "skill" | "history" | "settings" | "action";
  shortcut?: string;
  keywords?: string[];
  execute: () => void | Promise<void>;
  icon?: string;
  visible?: boolean;
  /** 权重，用于默认排序（值越大越靠前） */
  weight?: number;
}

class CommandRegistry {
  private commands = new Map<string, CommandDef>();
  private listeners = new Set<() => void>();

  register(command: CommandDef): () => void {
    this.commands.set(command.id, { visible: true, weight: 0, ...command });
    this.notify();
    return () => {
      this.commands.delete(command.id);
      this.notify();
    };
  }

  registerMany(commands: CommandDef[]): () => void {
    const fns = commands.map((c) => this.register(c));
    return () => fns.forEach((fn) => fn());
  }

  get(id: string): CommandDef | undefined {
    return this.commands.get(id);
  }

  getAll(): CommandDef[] {
    return Array.from(this.commands.values())
      .filter((c) => c.visible !== false)
      .sort((a, b) => (b.weight ?? 0) - (a.weight ?? 0));
  }

  subscribe(listener: () => void): () => void {
    this.listeners.add(listener);
    return () => { this.listeners.delete(listener); };
  }

  private notify() {
    this.listeners.forEach((l) => l());
  }
}

export const commandRegistry = new CommandRegistry();
```

### 3.3 最近命令追踪

```typescript
// src/hooks/useRecentCommands.ts

import { useState, useCallback } from "react";

const STORAGE_KEY = "astro:recent-commands";
const MAX_RECENT = 5;

export function useRecentCommands() {
  const [recentIds, setRecentIds] = useState<string[]>(() => {
    try {
      return JSON.parse(localStorage.getItem(STORAGE_KEY) ?? "[]");
    } catch {
      return [];
    }
  });

  const recordUsage = useCallback((id: string) => {
    setRecentIds((prev) => {
      const next = [id, ...prev.filter((x) => x !== id)].slice(0, MAX_RECENT);
      localStorage.setItem(STORAGE_KEY, JSON.stringify(next));
      return next;
    });
  }, []);

  return { recentIds, recordUsage };
}
```

### 4.2 Rust 侧加载与冲突检测

```rust
// crates/agent-core/src/config/keybindings.rs

use serde::{Deserialize, Serialize};
use std::collections::HashMap;

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct KeybindingConfig {
    pub version: u32,
    pub bindings: HashMap<String, String>,
}

/// 默认快捷键（编译期内嵌）
fn default_bindings() -> HashMap<String, String> {
    let pairs = [
        ("command_palette",     "Cmd+K"),
        ("new_conversation",    "Cmd+N"),
        ("open_settings",       "Cmd+,"),
        ("toggle_sidebar",      "Cmd+/"),
        ("global_search",       "Cmd+Shift+F"),
        ("close_conversation",  "Cmd+W"),
        ("send_message",        "Enter"),
        ("newline_in_input",    "Shift+Enter"),
        ("regenerate_reply",    "Cmd+Shift+R"),
        ("stop_generation",     "Escape"),
        ("next_workspace",      "Ctrl+Tab"),
        ("prev_workspace",      "Ctrl+Shift+Tab"),
    ];
    pairs.into_iter().map(|(k, v)| (k.into(), v.into())).collect()
}

impl KeybindingConfig {
    /// 加载用户自定义绑定并合并默认值
    pub fn load(config_dir: &std::path::Path) -> Self {
        let path = config_dir.join("keybindings.json");
        let user_cfg: Option<KeybindingConfig> = std::fs::read_to_string(&path)
            .ok()
            .and_then(|s| serde_json::from_str(&s).ok());

        let mut merged = default_bindings();
        if let Some(cfg) = user_cfg {
            for (k, v) in cfg.bindings {
                merged.insert(k, v);
            }
        }
        Self { version: 1, bindings: merged }
    }

    /// 检测冲突：同一键位被多个操作绑定
    pub fn detect_conflicts(&self) -> Vec<KeyConflict> {
        let mut key_to_ids: HashMap<String, Vec<String>> = HashMap::new();
        for (id, key) in &self.bindings {
            let normalized = normalize_key(key);
            key_to_ids.entry(normalized).or_default().push(id.clone());
        }
        key_to_ids
            .into_iter()
            .filter(|(_, ids)| ids.len() > 1)
            .map(|(key, ids)| KeyConflict { key, binding_ids: ids })
            .collect()
    }

    /// 保存用户自定义绑定（仅写入与默认值不同的条目）
    pub fn save(&self, config_dir: &std::path::Path) -> anyhow::Result<()> {
        let defaults = default_bindings();
        let diff: HashMap<String, String> = self.bindings.iter()
            .filter(|(k, v)| defaults.get(*k).map(|d| d != *v).unwrap_or(true))
            .map(|(k, v)| (k.clone(), v.clone()))
            .collect();

        let cfg = serde_json::json!({ "version": 1, "bindings": diff });
        let path = config_dir.join("keybindings.json");
        std::fs::write(path, serde_json::to_string_pretty(&cfg)?)?;
        Ok(())
    }

    /// 恢复默认值
    pub fn reset_to_defaults(&mut self) {
        self.bindings = default_bindings();
    }
}

#[derive(Debug, Serialize)]
pub struct KeyConflict {
    pub key: String,
    pub binding_ids: Vec<String>,
}

fn normalize_key(key: &str) -> String {
    key.to_lowercase()
        .replace("ctrl", "cmd")
        .replace("meta", "cmd")
        .replace(" ", "")
}
```

### 4.3 KeybindingEditor UI

前端提供可视化的快捷键编辑器，用户可点击某一行后按下新键位来重新绑定。

```tsx
// src/pages/settings/KeybindingEditor.tsx

import { useState, useEffect } from "react";
import { invoke } from "@tauri-apps/api/core";
import { Button } from "@/components/ui/button";

interface Binding {
  id: string;
  label: string;
  key: string;
  isDefault: boolean;
}

interface Conflict {
  key: string;
  binding_ids: string[];
}

export function KeybindingEditor() {
  const [bindings, setBindings] = useState<Binding[]>([]);
  const [conflicts, setConflicts] = useState<Conflict[]>([]);
  const [recording, setRecording] = useState<string | null>(null);

  useEffect(() => {
    invoke<Binding[]>("get_keybindings").then(setBindings);
  }, []);

  const startRecording = (id: string) => setRecording(id);

  const handleKeyDown = async (e: KeyboardEvent) => {
    if (!recording) return;
    e.preventDefault();

    const isMac = navigator.platform.includes("Mac");
    const parts: string[] = [];
    if (isMac ? e.metaKey : e.ctrlKey) parts.push("Cmd");
    if (e.shiftKey) parts.push("Shift");
    if (e.altKey) parts.push("Alt");
    if (!["Meta", "Control", "Shift", "Alt"].includes(e.key)) {
      parts.push(e.key.length === 1 ? e.key.toUpperCase() : e.key);
    } else {
      return; // 仅按下修饰键时不提交
    }

    const newKey = parts.join("+");
    const result = await invoke<{ conflicts: Conflict[] }>(
      "update_keybinding",
      { bindingId: recording, newKey },
    );

    setConflicts(result.conflicts);
    setRecording(null);
    invoke<Binding[]>("get_keybindings").then(setBindings);
  };

  useEffect(() => {
    if (recording) {
      window.addEventListener("keydown", handleKeyDown);
      return () => window.removeEventListener("keydown", handleKeyDown);
    }
  }, [recording]);

  const resetAll = async () => {
    await invoke("reset_keybindings");
    invoke<Binding[]>("get_keybindings").then(setBindings);
    setConflicts([]);
  };

  return (
    <div className="space-y-4">
      <div className="flex justify-between items-center">
        <h2 className="text-lg font-semibold">快捷键设置</h2>
        <Button variant="outline" size="sm" onClick={resetAll}>
          恢复默认
        </Button>
      </div>

      {conflicts.length > 0 && (
        <div className="p-3 bg-destructive/10 rounded text-sm" role="alert">
          存在冲突：{conflicts.map((c) => `"${c.key}" 被 ${c.binding_ids.join("、")} 同时使用`).join("；")}
        </div>
      )}

      <table className="w-full text-sm">
        <thead>
          <tr className="border-b text-left">
            <th className="py-2">操作</th>
            <th className="py-2">快捷键</th>
            <th className="py-2 w-24"></th>
          </tr>
        </thead>
        <tbody>
          {bindings.map((b) => (
            <tr key={b.id} className="border-b">
              <td className="py-2">{b.label}</td>
              <td className="py-2">
                {recording === b.id ? (
                  <span className="text-primary animate-pulse">请按下新快捷键...</span>
                ) : (
                  <kbd className="bg-muted px-2 py-0.5 rounded font-mono text-xs">
                    {b.key}
                  </kbd>
                )}
              </td>
              <td className="py-2 text-right">
                <Button
                  variant="ghost"
                  size="sm"
                  onClick={() => startRecording(b.id)}
                >
                  {recording === b.id ? "录入中" : "修改"}
                </Button>
              </td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
```

## 5. 上下文感知

不同视图下激活不同的快捷键集合，通过上下文栈（context stack）管理优先级。栈顶上下文拥有最高拦截优先级，`Escape` 始终弹出栈顶。

### 5.1 上下文定义

| 上下文 ID | 激活条件 | 专属快捷键 |
| --- | --- | --- |
| `global` | 始终存在（栈底） | `Cmd+K`, `Cmd+N`, `Cmd+,`, `Cmd+/` |
| `chat` | 对话页面可见 | `Enter`(发送), `Shift+Enter`(换行), `Up`(编辑上条) |
| `command-palette` | 命令面板打开 | `Up/Down`(导航), `Enter`(执行), `Escape`(关闭) |
| `settings` | 设置页面可见 | `Escape`(返回) |
| `search` | 全局搜索打开 | `Up/Down`(导航), `Enter`(打开结果), `Escape`(关闭) |
| `modal` | 任意模态弹窗 | `Escape`(关闭), `Enter`(确认) |

### 5.2 上下文栈管理

```typescript
// src/hooks/useContextStack.ts

import { createContext, useContext, useState, useCallback, useMemo } from "react";

interface ContextStackValue {
  activeContext: string;
  push: (ctx: string) => void;
  pop: () => void;
  /** 检查当前上下文是否匹配 */
  is: (ctx: string) => boolean;
}

const ContextStackCtx = createContext<ContextStackValue>(null!);

export function ContextStackProvider({ children }: { children: React.ReactNode }) {
  const [stack, setStack] = useState<string[]>(["global"]);

  const push = useCallback((ctx: string) => {
    setStack((prev) => [...prev, ctx]);
  }, []);

  const pop = useCallback(() => {
    setStack((prev) => (prev.length > 1 ? prev.slice(0, -1) : prev));
  }, []);

  const value = useMemo<ContextStackValue>(() => ({
    activeContext: stack[stack.length - 1],
    push,
    pop,
    is: (ctx: string) => stack[stack.length - 1] === ctx,
  }), [stack, push, pop]);

  return (
    <ContextStackCtx.Provider value={value}>{children}</ContextStackCtx.Provider>
  );
}

export function useContextStack() {
  return useContext(ContextStackCtx);
}
```

### 5.3 上下文与快捷键联动

视图组件在挂载和卸载时自动推入/弹出上下文，`useHotkeys` 根据栈顶上下文过滤绑定：

```tsx
// 示例：命令面板打开时推入上下文
function ChatPage() {
  const { push, pop } = useContextStack();
  const [paletteOpen, setPaletteOpen] = useState(false);

  useEffect(() => {
    push("chat");
    return () => pop();
  }, []);

  useEffect(() => {
    if (paletteOpen) push("command-palette");
    else pop();
  }, [paletteOpen]);

  // ...
}
```

```rust
/// 获取所有快捷键绑定（合并默认值与用户自定义）

pub async fn get_keybindings(
    state: State<'_, AppState>,
) -> Result<Vec<BindingEntry>, AppError> {
    let config = state.keybinding_config.read().await;
    let labels = binding_labels();

    Ok(config.bindings.iter().map(|(id, key)| {
        BindingEntry {
            id: id.clone(),
            label: labels.get(id.as_str()).unwrap_or(&id.as_str()).to_string(),
            key: key.clone(),
            is_default: default_key(id) == Some(key.as_str()),
        }
    }).collect())

#[derive(Serialize)]
pub struct UpdateResult {
    pub conflicts: Vec<KeyConflict>,
}

/// 更新单个快捷键绑定，返回冲突信息
#[tauri::command]
pub async fn update_keybinding(
    binding_id: String,
    new_key: String,
    state: State<'_, AppState>,
) -> Result<UpdateResult, AppError> {
    let mut config = state.keybinding_config.write().await;
    config.bindings.insert(binding_id, new_key);

    let conflicts = config.detect_conflicts();
    config.save(&state.config_dir).map_err(AppError::Config)?;

    Ok(UpdateResult { conflicts })
}

/// 恢复所有快捷键为默认值
#[tauri::command]
pub async fn reset_keybindings(
    state: State<'_, AppState>,
) -> Result<(), AppError> {
    let mut config = state.keybinding_config.write().await;
    config.reset_to_defaults();
    config.save(&state.config_dir).map_err(AppError::Config)?;
    Ok(())
}

/// 通过 ID 执行已注册命令（供系统托盘菜单等非前端入口调用）
#[tauri::command]
pub async fn execute_command(
    command_id: String,
    app: tauri::AppHandle,
) -> Result<(), AppError> {
    // 将命令执行委托给前端

        .map_err(|e| AppError::Internal(e.to_string()))?;

    }).collect())
}
```

## 7. 无障碍性

### 7.1 屏幕阅读器支持

命令面板和快捷键编辑器遵循 WAI-ARIA 规范，确保屏幕阅读器用户能够完整操作。

| 元素 | ARIA 属性 | 说明 |
| --- | --- | --- |
| 命令面板容器 | `role="dialog"`, `aria-label="命令面板"` | 标识为模态对话框 |
| 搜索输入框 | `aria-label="命令面板搜索"`, `aria-controls="command-list"` | 关联列表 |
| 命令列表 | `role="listbox"`, `id="command-list"` | 可键盘导航的列表 |
| 命令条目 | `role="option"`, `aria-selected` | 当前高亮项标记 selected |
| 分组标题 | `role="group"`, `aria-labelledby` | 语义化分组 |
| 快捷键提示 | `aria-hidden="true"` | 纯视觉提示，不朗读 |
| 冲突警告 | `role="alert"` | 冲突提示自动朗读 |

### 7.2 焦点管理

```typescript
// src/lib/focus-manager.ts

/** 命令面板打开时的焦点管理 */
export function trapFocus(container: HTMLElement) {
  const focusable = container.querySelectorAll<HTMLElement>(
    'input, button, [tabindex]:not([tabindex="-1"])',
  );
  if (focusable.length === 0) return;

  const first = focusable[0];
  const last = focusable[focusable.length - 1];

  // 打开时自动聚焦搜索框
  first.focus();

  const handler = (e: KeyboardEvent) => {
    if (e.key !== "Tab") return;

    if (e.shiftKey && document.activeElement === first) {
      e.preventDefault();
      last.focus();
    } else if (!e.shiftKey && document.activeElement === last) {
      e.preventDefault();
      first.focus();
    }
  };

  container.addEventListener("keydown", handler);
  return () => container.removeEventListener("keydown", handler);
}
```

### 7.3 操作公告

对于快捷键触发的非视觉操作（如切换工作区），通过 ARIA live region 向屏幕阅读器发送公告：

```typescript
// src/lib/announce.ts

let announcer: HTMLElement | null = null;

function getAnnouncer(): HTMLElement {
  if (!announcer) {
    announcer = document.createElement("div");
    announcer.setAttribute("role", "status");
    announcer.setAttribute("aria-live", "polite");
    announcer.setAttribute("aria-atomic", "true");
    announcer.className = "sr-only"; // Tailwind: screen-reader only
    document.body.appendChild(announcer);
  }
  return announcer;
}

/** 向屏幕阅读器发送操作公告 */
export function announce(message: string) {
  const el = getAnnouncer();
  el.textContent = "";
  // 强制 DOM 重排以触发 live region 朗读
  requestAnimationFrame(() => {
    el.textContent = message;
  });
}

// 使用示例：
// announce("已切换到工作区「代码助手」");
// announce("命令面板已打开");
```
