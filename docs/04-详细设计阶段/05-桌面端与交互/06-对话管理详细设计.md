# 对话管理详细设计

> **Harness 当前基线（2026-09-01）**：执行事实源是 rollout，SessionStore 使用 schema v22 的 `response_items` 原生索引。`get_chat_history` 向前端直接返回 `ResponseItem`，React 仅在渲染边界折叠为气泡，不再存在数据库/Tauri `Message` DTO。本文后续 `MessageRepo` 伪代码仅是历史草案。

> 版本：v1.0 | 日期：2026-08-09 | 状态：草稿
> 对应需求：F-06 对话管理、F-12 对话分支、F-18 对话置顶与标签

对话管理是连接 `agent-core` 核心数据类型与 Tauri 前端 UI 的桥梁层，负责对话的完整生命周期：创建、消息流转与持久化、会话标题自动生成、归档、删除、导入导出，以及侧边栏组件的交互逻辑。

## 2. 对话数据模型

### 2.1 conversations 表

完整 DDL 见 [数据库设计/01-Schema设计.md](../../03-系统设计阶段/04-数据库设计/01-Schema设计.md) 第 2 节。核心字段说明：

```sql
CREATE TABLE IF NOT EXISTS conversations (
    id                      TEXT PRIMARY KEY,                          -- UUID v4
    workspace_id            TEXT NOT NULL REFERENCES workspaces(id) ON DELETE CASCADE,
    title                   TEXT NOT NULL DEFAULT '新对话',
    model                   TEXT NOT NULL,                             -- 使用的模型 ID，如 "claude-sonnet-4-5"
    system_prompt           TEXT,                                      -- 会话级系统提示（NULL 使用工作区默认）
    token_input             INTEGER NOT NULL DEFAULT 0,                -- 累计输入 token
    token_output            INTEGER NOT NULL DEFAULT 0,                -- 累计输出 token
    status                  TEXT NOT NULL DEFAULT 'active'             -- active / archived / deleted
                            CHECK(status IN ('active','archived','deleted')),
    is_pinned               INTEGER NOT NULL DEFAULT 0,                -- 1=置顶
    parent_conversation_id  TEXT REFERENCES conversations(id) ON DELETE SET NULL,
    branch_point_message_id TEXT REFERENCES messages(id) ON DELETE SET NULL,
    created_at              INTEGER NOT NULL DEFAULT (unixepoch('now','subsec')*1000),
    updated_at              INTEGER NOT NULL DEFAULT (unixepoch('now','subsec')*1000)
);
```

## 3. ConversationRepository

### 3.1 基础 CRUD

```rust
// crates/agent-core/src/storage/conversation.rs

pub struct ConversationRepo(SqlitePool);

impl ConversationRepo {
    pub fn new(pool: &SqlitePool) -> Self {
        Self(pool.clone())
    }

    /// 创建新对话
    pub async fn create(&self, meta: &NewConversation) -> anyhow::Result<String> {
        let id = Uuid::new_v4().to_string();
        let title = meta.title.as_deref().unwrap_or("新对话");
        sqlx::query!(
            "INSERT INTO conversations (id, workspace_id, title, model, system_prompt)
             VALUES (?, ?, ?, ?, ?)",
            id, meta.workspace_id, title, meta.model, meta.system_prompt
        ).execute(&self.0).await?;
        Ok(id)
    }

    /// 获取对话详情
    pub async fn get_by_id(&self, id: &str) -> anyhow::Result<Option<Conversation>> {
        Ok(sqlx::query_as!(
            Conversation,
            "SELECT * FROM conversations WHERE id = ? AND status != 'deleted'",
            id
        ).fetch_optional(&self.0).await?)
    }

    /// 更新对话元信息
    pub async fn update(&self, id: &str, patch: &ConversationPatch) -> anyhow::Result<()> {
        let now = now_ms();
        if let Some(title) = &patch.title {
            sqlx::query!(
                "UPDATE conversations SET title = ?, updated_at = ? WHERE id = ?",
                title, now, id
            ).execute(&self.0).await?;
        }
        if let Some(model) = &patch.model {
            sqlx::query!(
                "UPDATE conversations SET model = ?, updated_at = ? WHERE id = ?",
                model, now, id
            ).execute(&self.0).await?;
        }
        if let Some(system_prompt) = &patch.system_prompt {
            sqlx::query!(
                "UPDATE conversations SET system_prompt = ?, updated_at = ? WHERE id = ?",
                system_prompt, now, id
            ).execute(&self.0).await?;
        }
        Ok(())
    }

    /// 软删除（状态设为 deleted，不物理移除）
    pub async fn soft_delete(&self, id: &str) -> anyhow::Result<()> {
        sqlx::query!(
            "UPDATE conversations
             SET status = 'deleted', updated_at = (unixepoch('now','subsec')*1000)
             WHERE id = ?",
            id
        ).execute(&self.0).await?;
        Ok(())
    }

    /// 物理删除（定时任务清理已超过 TTL 的 deleted 对话）
    pub async fn purge_expired(&self, ttl_days: i64) -> anyhow::Result<u64> {
        let cutoff = now_ms() - ttl_days * 86_400_000;
        let result = sqlx::query!(
            "DELETE FROM conversations
             WHERE status = 'deleted' AND updated_at < ?",
            cutoff
        ).execute(&self.0).await?;
        Ok(result.rows_affected())
    }

    /// 累加 token 计数
    pub async fn update_tokens(&self, id: &str, input: i64, output: i64) -> anyhow::Result<()> {
        sqlx::query!(
            "UPDATE conversations
             SET token_input = token_input + ?,
                 token_output = token_output + ?,
                 updated_at = (unixepoch('now','subsec')*1000)
             WHERE id = ?",
            input, output, id
        ).execute(&self.0).await?;
        Ok(())
    }
}

/// 对话更新补丁（字段可选）
#[derive(Debug, Deserialize, Default)]
pub struct ConversationPatch {
    pub title: Option<String>,
    pub model: Option<String>,
    pub system_prompt: Option<String>,
}
```

### 3.2 分页列表与过滤

```rust
impl ConversationRepo {
    /// 分页列表：支持状态过滤、置顶排序、关键词搜索
    pub async fn list(
        &self,
        workspace_id: &str,
        filter: &ListConversationsFilter,
    ) -> anyhow::Result<PaginatedResult<ConversationSummary>> {
        let status_filter = filter.status.as_deref().unwrap_or("active");
        let offset = filter.offset.unwrap_or(0);
        let limit = filter.limit.unwrap_or(50).min(200);

        // 总数查询
        let total = sqlx::query_scalar!(
            "SELECT COUNT(*) FROM conversations
             WHERE workspace_id = ? AND status = ?",
            workspace_id, status_filter
        ).fetch_one(&self.0).await?.unwrap_or(0);

        // 列表查询：置顶在前，再按 updated_at DESC
        let rows = sqlx::query!(
            r#"SELECT
                 c.id, c.title, c.model, c.status, c.is_pinned,
                 c.token_input, c.token_output,
                 c.created_at, c.updated_at,
                 COUNT(m.id) AS "message_count!: i64",
                 (SELECT content FROM messages
                  WHERE conversation_id = c.id
                  ORDER BY created_at DESC LIMIT 1) AS last_message_preview
               FROM conversations c
               LEFT JOIN messages m ON m.conversation_id = c.id
               WHERE c.workspace_id = ? AND c.status = ?
               GROUP BY c.id
               ORDER BY c.is_pinned DESC, c.updated_at DESC
               LIMIT ? OFFSET ?"#,
            workspace_id, status_filter, limit, offset
        ).fetch_all(&self.0).await?;

        let items: Vec<ConversationSummary> = rows.into_iter().map(|r| {
            ConversationSummary {
                id: r.id,
                title: r.title,
                model: r.model,
                status: ConversationStatus::from_str(&r.status),
                is_pinned: r.is_pinned != 0,
                token_input: r.token_input,
                token_output: r.token_output,
                message_count: r.message_count,
                last_message_preview: r.last_message_preview
                    .map(|s| s.chars().take(80).collect()),
                created_at: r.created_at,
                updated_at: r.updated_at,
            }
        }).collect();

        Ok(PaginatedResult { items, total, offset, limit })
    }

    /// 按关键词搜索对话标题
    pub async fn search_by_title(
        &self,
        workspace_id: &str,
        keyword: &str,
        limit: i64,
    ) -> anyhow::Result<Vec<ConversationSummary>> {
        let pattern = format!("%{}%", keyword);
        let rows = sqlx::query!(
            r#"SELECT
                 c.id, c.title, c.model, c.status, c.is_pinned,
                 c.token_input, c.token_output,
                 c.created_at, c.updated_at,
                 COUNT(m.id) AS "message_count!: i64",
                 NULL AS last_message_preview
               FROM conversations c
               LEFT JOIN messages m ON m.conversation_id = c.id
               WHERE c.workspace_id = ? AND c.status = 'active'
                 AND c.title LIKE ?
               GROUP BY c.id
               ORDER BY c.updated_at DESC
               LIMIT ?"#,
            workspace_id, pattern, limit
        ).fetch_all(&self.0).await?;

        Ok(rows.into_iter().map(ConversationSummary::from).collect())
    }
}

#[derive(Debug, Deserialize, Default)]
pub struct ListConversationsFilter {
    pub status: Option<String>,     // "active" | "archived"，默认 "active"
    pub offset: Option<i64>,
    pub limit: Option<i64>,
}

#[derive(Debug, Serialize)]
pub struct PaginatedResult<T> {
    pub items: Vec<T>,
    pub total: i64,
    pub offset: i64,
    pub limit: i64,
}
```

### 3.3 归档 / 置顶 / 批量操作

```rust
impl ConversationRepo {
    /// 归档对话
    pub async fn archive(&self, id: &str) -> anyhow::Result<()> {
        sqlx::query!(
            "UPDATE conversations
             SET status = 'archived', is_pinned = 0,
                 updated_at = (unixepoch('now','subsec')*1000)
             WHERE id = ? AND status = 'active'",
            id
        ).execute(&self.0).await?;
        Ok(())
    }

    /// 取消归档（恢复为 active）
    pub async fn unarchive(&self, id: &str) -> anyhow::Result<()> {
        sqlx::query!(
            "UPDATE conversations
             SET status = 'active', updated_at = (unixepoch('now','subsec')*1000)
             WHERE id = ? AND status = 'archived'",
            id
        ).execute(&self.0).await?;
        Ok(())
    }

    /// 置顶 / 取消置顶
    pub async fn set_pinned(&self, id: &str, pinned: bool) -> anyhow::Result<()> {
        let val = if pinned { 1 } else { 0 };
        sqlx::query!(
            "UPDATE conversations
             SET is_pinned = ?, updated_at = (unixepoch('now','subsec')*1000)
             WHERE id = ?",
            val, id
        ).execute(&self.0).await?;
        Ok(())
    }

    /// 批量软删除
    pub async fn bulk_delete(&self, ids: &[String]) -> anyhow::Result<u64> {
        if ids.is_empty() { return Ok(0); }
        let mut tx = self.0.begin().await?;
        let mut affected = 0u64;
        for id in ids {
            let r = sqlx::query!(
                "UPDATE conversations
                 SET status = 'deleted', updated_at = (unixepoch('now','subsec')*1000)
                 WHERE id = ? AND status != 'deleted'",
                id
            ).execute(&mut *tx).await?;
            affected += r.rows_affected();
        }
        tx.commit().await?;
        Ok(affected)
    }

    /// 批量归档
    pub async fn bulk_archive(&self, ids: &[String]) -> anyhow::Result<u64> {
        if ids.is_empty() { return Ok(0); }
        let mut tx = self.0.begin().await?;
        let mut affected = 0u64;
        for id in ids {
            let r = sqlx::query!(
                "UPDATE conversations
                 SET status = 'archived', is_pinned = 0,
                     updated_at = (unixepoch('now','subsec')*1000)
                 WHERE id = ? AND status = 'active'",
                id
            ).execute(&mut *tx).await?;
            affected += r.rows_affected();
        }
        tx.commit().await?;
        Ok(affected)
    }
}
```

## 4. 对话生命周期状态机

### 4.1 状态转换图

```text
                  create_conversation
                         │
                         ▼
                    ┌──────────┐
             ┌────►│  Active   │◄───── unarchive()
             │     └────┬──┬───┘
             │          │  │
             │  archive()  │ soft_delete()
             │          │  │
             │          ▼  │
             │     ┌──────────┐
             │     │ Archived │
             │     └────┬─────┘
             │          │
             │          │ soft_delete()
             │          │
             │          ▼
             │     ┌──────────┐     purge_expired()      ┌───────────┐
             │     │ Deleted  │ ──── (30 天 TTL) ─────► │ 物理删除   │
             │     └──────────┘                          └───────────┘
             │
             └── restore()（管理员恢复，仅在 TTL 内有效）
```

### 4.2 状态转换规则

| 当前状态 | 允许的目标状态 | 触发操作 | 约束 |
| -------- | -------------- | -------- | ---- |
| Active | Archived | `archive()` | 归档时自动取消置顶 |
| Active | Deleted | `soft_delete()` | 级联标记子分支为 deleted |
| Archived | Active | `unarchive()` | 恢复为 active，不恢复置顶 |
| Archived | Deleted | `soft_delete()` | - |
| Deleted | Active | `restore()`（管理员） | 仅在 30 天 TTL 内有效 |
| Deleted | (物理删除) | `purge_expired()` | 后台定时任务，30 天后自动清理 |

### 4.3 TTL 清理定时任务

```rust
// apps/desktop/src-tauri/src/tasks/cleanup.rs

/// 每 6 小时执行一次，清理超过 TTL 的 deleted 对话
pub async fn spawn_cleanup_task(pool: SqlitePool) {
    tokio::spawn(async move {
        let repo = ConversationRepo::new(&pool);
        let mut interval = tokio::time::interval(Duration::from_secs(6 * 3600));
        loop {
            interval.tick().await;
            match repo.purge_expired(30).await {
                Ok(count) if count > 0 => {
                    tracing::info!("已清理 {} 个过期对话", count);
                }
                Err(e) => tracing::warn!("清理过期对话失败: {}", e),
                _ => {}
            }
        }
    });
}
```

## 5. 会话标题自动生成

### 5.1 触发时机

- 对话创建时使用默认标题 "新对话"
- 当收到**第一条 assistant 回复完成**（`finish_reason = "stop"`）后，异步触发标题生成
- 用户手动重命名后，不再自动覆盖（设置 `title_manual = true` 标记）

### 5.2 标题生成策略

```rust
// crates/agent-core/src/conversation/title_gen.rs

use crate::types::Message;

/// 从对话前几轮消息中生成简洁标题
pub async fn generate_title(
    messages: &[Message],
    provider: &dyn TextClient,
    model: &str,
) -> anyhow::Result<String> {
    // 只取前 4 条消息（user + assistant 各 2 轮），控制 token 成本
    let context: Vec<&Message> = messages.iter().take(4).collect();

    let prompt = format!(
        "请为以下对话生成一个简洁的中文标题（不超过 20 个字，不加引号和标点）：\n\n{}",
        context.iter()
            .map(|m| format!("{}: {}", m.role.as_str(), truncate(&m.content_text(), 200)))
            .collect::<Vec<_>>()
            .join("\n")
    );

    let response = provider.complete(&ChatRequest {
        model: model.to_string(),
        messages: vec![Message::user(&prompt)],
        max_tokens: Some(30),
        temperature: Some(0.3),
        ..Default::default()
    }).await?;

    let title = response.text
        .unwrap_or_default()
        .trim()
        .trim_matches(|c: char| c == '"' || c == '「' || c == '」')
        .to_string();

    Ok(if title.is_empty() { "新对话".to_string() } else { title })
}

fn truncate(s: &str, max_chars: usize) -> String {
    s.chars().take(max_chars).collect()
}
```

### 5.3 调用位置

```rust
// apps/desktop/src-tauri/src/commands/conversation.rs

/// 在 send_message 流式完成后异步触发标题生成
async fn maybe_generate_title(
    conv_id: &str,
    pool: &SqlitePool,
    provider: &dyn TextClient,
    model: &str,
    app: &AppHandle,
) {
    let conv_repo = ConversationRepo::new(pool);
    let msg_repo = MessageRepo::new(pool);

    // 仅在默认标题 "新对话" 时触发
    let conv = match conv_repo.get_by_id(conv_id).await {
        Ok(Some(c)) if c.title == "新对话" => c,
        _ => return,
    };

    let messages = msg_repo.list_by_conversation(conv_id).await.unwrap_or_default();
    if messages.len() < 2 { return; }  // 至少有 user + assistant 各一条

    match generate_title(&messages, provider, model).await {
        Ok(title) => {
            conv_repo.update(conv_id, &ConversationPatch {
                title: Some(title.clone()),
                ..Default::default()
            }).await.ok();
            // 通知前端刷新侧边栏
            app.emit("astro://conversation/updated", serde_json::json!({
                "id": conv_id,
                "title": title,
            })).ok();
        }
        Err(e) => tracing::warn!("标题生成失败: {}", e),
    }
}
```

### 5.4 成本控制

| 指标 | 值 |
| ---- | --- |
| 输入 token | ~100-200（前 4 条消息截断至 200 字符） |
| 输出 token | ~10-20 |

## 6. 消息流转与持久化

### 6.1 消息发送全流程

```text
用户输入
   │
   ▼
前端 InputBar ── invoke("send_message") ──► Tauri Command 层
   │                                              │
   │ 乐观更新：                                    │ 1. 验证参数
   │ 立即在 UI 显示                                │ 2. 插入 user message 到 messages 表
   │ 用户消息                                      │ 3. 调用 LLM 流式推理
   │                                              │ 4. 逐 chunk emit("astro://chat/token")
   │                                              │ 5. 流结束后插入 assistant message
   │◄────── listen("astro://chat/token") ─────────│ 6. 更新 conversation.updated_at
   │                                              │ 7. 触发标题生成（首次）
   ▼                                              │ 8. 记录 cost_records
前端逐 chunk                                       │
拼接渲染                                           ▼
```

### 6.2 用户消息持久化

用户消息在 LLM 调用之前**同步写入**数据库，确保即使流式推理崩溃也不丢失用户输入：

```rust
// apps/desktop/src-tauri/src/commands/conversation.rs

#[tauri::command]
pub async fn send_message(
    payload: SendMessagePayload,
    app: AppHandle,
    state: State<'_, AppState>,
) -> Result<String, AppError> {
    let msg_repo = MessageRepo::new(&state.pool);
    let conv_repo = ConversationRepo::new(&state.pool);

    // 1. 持久化用户消息
    let user_msg_id = Uuid::new_v4().to_string();
    msg_repo.insert(&NewMessage {
        id: user_msg_id.clone(),
        conversation_id: payload.conversation_id.clone(),
        role: "user",
        content: payload.content.clone(),
        ..Default::default()
    }).await.map_err(AppError::internal)?;

    // 2. 更新对话 updated_at
    conv_repo.touch(&payload.conversation_id).await.ok();

    // 3. 启动流式推理（异步）
    let conv_id = payload.conversation_id.clone();
    let pool = state.pool.clone();
    let provider = state.ctx.providers.text_client(&payload.model_override
        .unwrap_or_else(|| get_conversation_model(&pool, &conv_id))
    ).map_err(AppError::internal)?;

    tokio::spawn(async move {
        stream_llm_response(&conv_id, &pool, provider.as_ref(), &app).await;
    });

    Ok(user_msg_id)
}
```

### 6.3 流式 Assistant 消息持久化

Assistant 消息采用**流结束后一次性写入**策略，而非逐 chunk 写入，避免高频小写入对 SQLite WAL 造成压力：

```rust
async fn stream_llm_response(
    conv_id: &str,
    pool: &SqlitePool,
    provider: &dyn TextClient,
    app: &AppHandle,
) {
    let msg_repo = MessageRepo::new(pool);
    let conv_repo = ConversationRepo::new(pool);
    let messages = msg_repo.list_by_conversation(conv_id).await.unwrap_or_default();

    let mut stream = provider.stream_chat(&build_request(&messages)).await;
    // 注意：streaming 阶段通过 push_str 逐 chunk 拼接纯文本。
    // 流结束写入 messages 表时，content 列存储的是序列化后的 Vec<ContentPart> JSON（非纯 String）。
    // 即 full_content 最终会被包装为 [ContentPart::Text { text: full_content }] 后 JSON 序列化写入。
    let mut full_content = String::new();
    let mut reasoning_content = String::new();
    let mut token_count = 0i64;
    let start = Instant::now();

    while let Some(chunk) = stream.next().await {
        match chunk {
            Ok(delta) => {
                if let Some(text) = &delta.text {
                    full_content.push_str(text);
                    app.emit("astro://chat/token", TokenChunkEvent {
                        conversation_id: conv_id.to_string(),
                        chunk: text.clone(),
                        thinking_chunk: delta.reasoning.clone(),
                        finish_reason: None,
                    }).ok();
                }
                if let Some(reasoning) = &delta.reasoning {
                    reasoning_content.push_str(reasoning);
                }
                if let Some(usage) = &delta.usage {
                    token_count = usage.output_tokens;
                }
            }
            Err(e) => {
                app.emit("astro://chat/error", StreamErrorEvent {
                    conversation_id: conv_id.to_string(),
                    error_code: "PROVIDER_ERROR".to_string(),
                    message: e.to_string(),
                    recoverable: false,
                }).ok();
                return;
            }
        }
    }

    let latency_ms = start.elapsed().as_millis() as i64;

    // 流结束后一次性写入 assistant 消息
    let assistant_msg_id = Uuid::new_v4().to_string();
    msg_repo.insert(&NewMessage {
        id: assistant_msg_id,
        conversation_id: conv_id.to_string(),
        role: "assistant",
        content: full_content,
        reasoning_content: if reasoning_content.is_empty() { None } else { Some(reasoning_content) },
        token_count,
        latency_ms: Some(latency_ms),
        ..Default::default()
    }).await.ok();

    // 更新对话 token 累计
    conv_repo.update_tokens(conv_id, 0, token_count).await.ok();

    // 通知流结束
    app.emit("astro://chat/token", TokenChunkEvent {
        conversation_id: conv_id.to_string(),
        chunk: String::new(),
        thinking_chunk: None,
        finish_reason: Some("stop".to_string()),
    }).ok();

    // 异步触发标题生成
    let pool_clone = pool.clone();
    let app_clone = app.clone();
    let conv_id_owned = conv_id.to_string();
    tokio::spawn(async move {
        maybe_generate_title(&conv_id_owned, &pool_clone, provider, model, &app_clone).await;
    });
}
```

### 6.4 消息排序保证

| 策略 | 说明 |
| ---- | ---- |
| **时间戳排序** | `messages.created_at`（Unix ms）作为排序依据 |
| **亚毫秒精度** | SQLite `unixepoch('now','subsec')` 提供亚秒级精度 |
| **同一对话串行** | 同一 `conversation_id` 的 LLM 请求串行执行（通过 per-conversation Mutex），不会出现消息交错 |
| **分支消息隔离** | 分支复制消息后各自独立写入，`conversation_id` 确保隔离 |

```typescript
interface ChatState {
  messages: Message[];
  streamingContent: string;
  isStreaming: boolean;

export const useChatStore = create<ChatState>((set, get) => ({
  messages: [],
  streamingContent: "",
  isStreaming: false,

  // 乐观添加用户消息，不等待后端确认
  sendMessage: async (conversationId: string, content: string) => {
    const tempMsg: Message = {
      id: `temp-${Date.now()}`,
      role: "user",
      content,
      createdAt: Date.now(),
    };

    set((s) => ({
      messages: [...s.messages, tempMsg],
      streamingContent: "",
      isStreaming: true,
    }));

    try {
      const realId = await invoke<string>("send_message", {
        payload: { conversationId, content },
      });
      // 替换临时 ID 为真实 ID
      set((s) => ({
        messages: s.messages.map((m) =>
          m.id === tempMsg.id ? { ...m, id: realId } : m
        ),
      }));
    } catch (err) {
      // 回滚乐观更新
      set((s) => ({
        messages: s.messages.filter((m) => m.id !== tempMsg.id),
        isStreaming: false,
      }));
      throw err;
    }
  },
}));
```

### 10.1 支持撤销的操作

| 操作 | 撤销方式 | 时间窗口 |
|------|---------|---------|
| 删除对话 | Toast "已删除" + [撤销] 按钮 | 5 秒 |
| 删除消息 | 同上 | 5 秒 |

### 10.2 实现机制

- 软删除延迟：操作触发后标记 `pending_delete = true`，5 秒后定时器执行真正删除
- 撤销 = 取消定时器 + 清除 `pending_delete` 标记
- Toast 组件：底部弹出，5 秒自动消失，包含 [撤销] 按钮
- 不使用通用 undo/redo 栈（复杂度不值得），仅支持上述 3 种高频误操作

```rust
// crates/agent-core/src/conversation/export.rs

#[derive(Debug, Serialize)]
pub struct ExportedConversation {
    pub version: String,
    pub app: String,
    pub exported_at: String,
    pub conversation: ExportedConvData,
}

#[derive(Debug, Serialize)]
pub struct ExportedConvData {
    pub id: String,
    pub title: String,
    pub model: String,
    pub created_at: i64,
    pub updated_at: i64,
    pub messages: Vec<ExportedMessage>,
}

#[derive(Debug, Serialize)]
pub struct ExportedMessage {
    pub role: String,
    pub content: String,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub reasoning_content: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub tool_name: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub token_count: Option<i64>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub latency_ms: Option<i64>,
    pub created_at: i64,
}

pub enum ExportFormat {
    Json,
    Markdown,
}

pub async fn export_conversation(
    pool: &SqlitePool,
    conversation_id: &str,
    format: ExportFormat,
) -> anyhow::Result<String> {
    let conv_repo = ConversationRepo::new(pool);
    let msg_repo = MessageRepo::new(pool);

    let conv = conv_repo.get_by_id(conversation_id).await?
        .ok_or_else(|| anyhow::anyhow!("对话不存在: {}", conversation_id))?;
    let messages = msg_repo.list_by_conversation(conversation_id).await?;

    match format {
        ExportFormat::Json => export_as_json(&conv, &messages),
        ExportFormat::Markdown => export_as_markdown(&conv, &messages),
    }
}

fn export_as_json(conv: &Conversation, messages: &[Message]) -> anyhow::Result<String> {
    let exported = ExportedConversation {
        version: "1.0".to_string(),
        app: "astro-agent".to_string(),
        exported_at: chrono::Utc::now().to_rfc3339(),
        conversation: ExportedConvData {
            id: conv.id.clone(),
            title: conv.title.clone(),
            model: conv.model.clone(),
            created_at: conv.created_at,
            updated_at: conv.updated_at,
            messages: messages.iter().map(|m| ExportedMessage {
                role: m.role.as_str().to_string(),
                content: m.content_text(),
                reasoning_content: m.reasoning_content.clone(),
                tool_name: m.tool_name.clone(),
                token_count: if m.token_count > 0 { Some(m.token_count) } else { None },
                latency_ms: m.latency_ms,
                created_at: m.created_at,
            }).collect(),
        },
    };
    Ok(serde_json::to_string_pretty(&exported)?)
}

fn export_as_markdown(conv: &Conversation, messages: &[Message]) -> anyhow::Result<String> {
    let mut md = String::new();
    md.push_str(&format!("# {}\n\n", conv.title));
    md.push_str(&format!(
        "> 模型: {} | 创建时间: {}\n\n---\n\n",
        conv.model,
        format_timestamp(conv.created_at)
    ));

    for msg in messages {
        let role_label = match msg.role.as_str() {
            "user" => "用户",
            "assistant" => "助手",
            "system" => "系统",
            "tool" => &format!("工具 ({})", msg.tool_name.as_deref().unwrap_or("unknown")),
            _ => "未知",
        };
        md.push_str(&format!(
            "**{}** ({})\n\n{}\n\n---\n\n",
            role_label,
            format_time(msg.created_at),
            msg.content_text()
        ));
    }
    Ok(md)
}
```

```rust
// crates/agent-core/src/conversation/import.rs

/// 支持的导入格式
pub enum ImportSource {
    /// 本应用导出的 JSON（version: "1.0"）
    AstroJson,
    /// ChatGPT 导出格式（conversations.json）
    ChatGptExport,
    /// Claude 导出格式
    ClaudeExport,
}

pub async fn import_conversations(
    pool: &SqlitePool,
    workspace_id: &str,
    data: &str,
    source: ImportSource,
) -> anyhow::Result<Vec<String>> {
    let parsed = match source {
        ImportSource::AstroJson => parse_astro_json(data)?,
        ImportSource::ChatGptExport => parse_chatgpt_export(data)?,
        ImportSource::ClaudeExport => parse_claude_export(data)?,
    };

    let conv_repo = ConversationRepo::new(pool);
    let msg_repo = MessageRepo::new(pool);
    let mut imported_ids = Vec::new();

    for conv_data in parsed {
        let mut tx = pool.begin().await?;
        let conv_id = Uuid::new_v4().to_string();

        // 创建对话
        sqlx::query!(
            "INSERT INTO conversations (id, workspace_id, title, model, created_at, updated_at)
             VALUES (?, ?, ?, ?, ?, ?)",
            conv_id, workspace_id, conv_data.title, conv_data.model,
            conv_data.created_at, conv_data.updated_at
        ).execute(&mut *tx).await?;

        // 导入消息
        for msg in &conv_data.messages {
            let msg_id = Uuid::new_v4().to_string();
            sqlx::query!(
                "INSERT INTO messages (id, conversation_id, role, content, created_at)
                 VALUES (?, ?, ?, ?, ?)",
                msg_id, conv_id, msg.role, msg.content, msg.created_at
            ).execute(&mut *tx).await?;
        }

        tx.commit().await?;
        imported_ids.push(conv_id);
    }

    Ok(imported_ids)
}

/// ChatGPT 导出格式映射
fn parse_chatgpt_export(data: &str) -> anyhow::Result<Vec<ParsedConversation>> {
    let raw: Vec<ChatGptConversation> = serde_json::from_str(data)?;

    Ok(raw.into_iter().map(|c| {
        let messages: Vec<ParsedMessage> = c.mapping.values()
            .filter_map(|node| node.message.as_ref())
            .filter(|msg| matches!(msg.author.role.as_str(), "user" | "assistant"))
            .map(|msg| ParsedMessage {
                role: msg.author.role.clone(),
                content: msg.content.parts.join("\n"),
                created_at: (msg.create_time.unwrap_or(0.0) * 1000.0) as i64,
            })
            .collect();

        ParsedConversation {
            title: c.title,
            model: "imported".to_string(),
            created_at: (c.create_time * 1000.0) as i64,
            updated_at: (c.update_time * 1000.0) as i64,
            messages,
        }
    }).collect())
}

/// ChatGPT 导出 JSON 结构（部分字段）
#[derive(Deserialize)]
struct ChatGptConversation {
    title: String,
    create_time: f64,
    update_time: f64,
    mapping: HashMap<String, ChatGptNode>,
}

#[derive(Deserialize)]
struct ChatGptNode {
    message: Option<ChatGptMessage>,
}

#[derive(Deserialize)]
struct ChatGptMessage {
    author: ChatGptAuthor,
    content: ChatGptContent,
    create_time: Option<f64>,
}

#[derive(Deserialize)]
struct ChatGptAuthor { role: String }

#[derive(Deserialize)]
struct ChatGptContent { parts: Vec<String> }
```

### 13.2 日期分组逻辑

```typescript
// apps/desktop/src/utils/groupByDate.ts

export type DateGroup = "pinned" | "today" | "yesterday" | "thisWeek" | "thisMonth" | "earlier";

export function groupConversationsByDate(
  conversations: ConversationSummary[]
): Record<DateGroup, ConversationSummary[]> {
  const now = new Date();
  const todayStart = startOfDay(now).getTime();
  const yesterdayStart = todayStart - 86_400_000;
  const weekStart = startOfWeek(now).getTime();
  const monthStart = startOfMonth(now).getTime();

  const groups: Record<DateGroup, ConversationSummary[]> = {
    pinned: [],
    today: [],
    yesterday: [],
    thisWeek: [],
    thisMonth: [],
    earlier: [],
  };

  for (const conv of conversations) {
    if (conv.isPinned) {
      groups.pinned.push(conv);
    } else if (conv.updatedAt >= todayStart) {
      groups.today.push(conv);
    } else if (conv.updatedAt >= yesterdayStart) {
      groups.yesterday.push(conv);
    } else if (conv.updatedAt >= weekStart) {
      groups.thisWeek.push(conv);
    } else if (conv.updatedAt >= monthStart) {
      groups.thisMonth.push(conv);
    } else {
      groups.earlier.push(conv);
    }
  }

  return groups;
}

const DATE_GROUP_LABELS: Record<DateGroup, string> = {
  pinned: "📌 置顶",
  today: "今天",
  yesterday: "昨天",
  thisWeek: "本周",
  thisMonth: "本月",
  earlier: "更早",
};
```

```typescript
// apps/desktop/src/store/conversation.ts

import { create } from "zustand";
import { invoke } from "@tauri-apps/api/core";
import { listen } from "@tauri-apps/api/event";

interface ConversationState {
  // 数据
  conversations: ConversationSummary[];
  activeConversationId: string | null;
  loading: boolean;
  searchQuery: string;

  // 操作
  loadConversations: (workspaceId: string) => Promise<void>;
  createConversation: (payload: NewConversation) => Promise<string>;
  selectConversation: (id: string) => void;
  renameConversation: (id: string, title: string) => Promise<void>;
  archiveConversation: (id: string) => Promise<void>;
  deleteConversation: (id: string) => Promise<void>;
  togglePin: (id: string) => Promise<void>;
  setSearchQuery: (query: string) => void;
}

export const useConversationStore = create<ConversationState>((set, get) => ({
  conversations: [],
  activeConversationId: null,
  loading: false,
  searchQuery: "",

  loadConversations: async (workspaceId: string) => {
    set({ loading: true });
    try {
      const result = await invoke<PaginatedResult<ConversationSummary>>(
        "list_conversations",
        { payload: { workspaceId, filter: { status: "active" } } }
      );
      set({ conversations: result.items, loading: false });
    } catch {
      set({ loading: false });
    }
  },

  createConversation: async (payload: NewConversation) => {
    const id = await invoke<string>("create_conversation", { payload });
    // 乐观更新：立即插入列表头部
    set((s) => ({
      conversations: [
        {
          id,
          title: payload.title ?? "新对话",
          model: payload.model,
          status: "active" as const,
          isPinned: false,
          tokenInput: 0,
          tokenOutput: 0,
          messageCount: 0,
          createdAt: Date.now(),
          updatedAt: Date.now(),
        },
        ...s.conversations,
      ],
      activeConversationId: id,
    }));
    return id;
  },

  selectConversation: (id: string) => {
    set({ activeConversationId: id });
  },

  renameConversation: async (id: string, title: string) => {
    // 乐观更新
    set((s) => ({
      conversations: s.conversations.map((c) =>
        c.id === id ? { ...c, title } : c
      ),
    }));
    await invoke("update_conversation", { id, patch: { title } });
  },

  archiveConversation: async (id: string) => {
    // 乐观移除
    set((s) => ({
      conversations: s.conversations.filter((c) => c.id !== id),
      activeConversationId:
        s.activeConversationId === id ? null : s.activeConversationId,
    }));
    await invoke("archive_conversation", { id });
  },

  deleteConversation: async (id: string) => {
    // 乐观移除
    set((s) => ({
      conversations: s.conversations.filter((c) => c.id !== id),
      activeConversationId:
        s.activeConversationId === id ? null : s.activeConversationId,
    }));
    await invoke("delete_conversation", { id });
  },

  togglePin: async (id: string) => {
    const conv = get().conversations.find((c) => c.id === id);
    if (!conv) return;
    const newPinned = !conv.isPinned;
    // 乐观更新
    set((s) => ({
      conversations: s.conversations.map((c) =>
        c.id === id ? { ...c, isPinned: newPinned } : c
      ),
    }));
    await invoke("pin_conversation", { id, pinned: newPinned });
  },

  setSearchQuery: (query: string) => {
    set({ searchQuery: query });
  },
}));
```

```typescript
 * 在 App.tsx 挂载时调用，监听后端对话事件实现跨窗口同步
 */
export function useConversationEvents(workspaceId: string) {
  useEffect(() => {
    const unlisteners: Promise<() => void>[] = [];

    // 新建对话（其他窗口创建时同步）
    unlisteners.push(
      listen("astro://conversation/created", (e) => {
        const { id, workspaceId: wsId } = e.payload as any;
        if (wsId === workspaceId) {
          useConversationStore.getState().loadConversations(workspaceId);
        }
      })
    );

    // 对话更新（标题自动生成、重命名、置顶变更）
    unlisteners.push(
      listen("astro://conversation/updated", (e) => {
        const { id, title, isPinned } = e.payload as any;
        useConversationStore.setState((s) => ({
          conversations: s.conversations.map((c) => {
            if (c.id !== id) return c;
            return {
              ...c,
              ...(title !== undefined && { title }),
              ...(isPinned !== undefined && { isPinned }),
            };
          }),
        }));
      })
    );

    // 对话删除
    unlisteners.push(
      listen("astro://conversation/deleted", (e) => {
        const { id } = e.payload as any;
        useConversationStore.setState((s) => ({
          conversations: s.conversations.filter((c) => c.id !== id),
          activeConversationId:
            s.activeConversationId === id ? null : s.activeConversationId,
        }));
      })
    );

    // 对话归档
    unlisteners.push(
      listen("astro://conversation/archived", (e) => {
        const { id } = e.payload as any;
        useConversationStore.setState((s) => ({
          conversations: s.conversations.filter((c) => c.id !== id),
        }));
      })
    );

    // 导入完成
    unlisteners.push(
      listen("astro://conversation/imported", () => {
        useConversationStore.getState().loadConversations(workspaceId);
      })
    );

    return () => {
      unlisteners.forEach((p) => p.then((fn) => fn()));
    };
  }, [workspaceId]);
}
```

### 15.3 搜索防抖

```typescript
// apps/desktop/src/hooks/useConversationSearch.ts

export function useConversationSearch(workspaceId: string) {
  const searchQuery = useConversationStore((s) => s.searchQuery);
  const [searchResults, setSearchResults] = useState<ConversationSummary[] | null>(null);

  useEffect(() => {
    if (!searchQuery.trim()) {
      setSearchResults(null);
      return;
    }

    const timer = setTimeout(async () => {
      try {
        const results = await invoke<ConversationSummary[]>("search_conversations", {
          keyword: searchQuery,
          workspaceId,
        });
        setSearchResults(results);
      } catch {
        setSearchResults([]);
      }
    }, 300);

    return () => clearTimeout(timer);
  }, [searchQuery, workspaceId]);

  return searchResults;
}
```

## 16. 设计约束

### 16.1 容量限制

| 指标 | 上限 | 说明 |
| ---- | ---- | ---- |
| 每工作区活跃对话数 | 1,000 | 超过后提示归档旧对话（不强制阻止创建） |
| 每对话消息数 | 10,000 | LLM 上下文窗口远小于此，此为存储层上限 |
| 单条消息内容大小 | 1 MB | TEXT 字段，超长内容截断后存入 ai_artifacts |
| 对话标题长度 | 100 字符 | 自动生成限制 20 字符，手动重命名限制 100 |
| 每工作区置顶数 | 20 | 超过后提示取消部分置顶 |
| 导入单批上限 | 500 个对话 | 大文件分批导入，避免长事务阻塞 |
| 软删除 TTL | 30 天 | 超过后物理删除，无法恢复 |

### 16.2 分页策略

| 场景 | 策略 | 参数 |
| ---- | ---- | ---- |
| 侧边栏初始加载 | 首屏加载前 50 条 | `limit=50, offset=0` |
| 侧边栏滚动加载 | 触底时加载下一页 | `limit=50, offset+=50` |
| 消息列表 | 首屏加载最新 100 条 | `ORDER BY created_at DESC LIMIT 100` |
| 消息向上翻阅 | 滚动至顶部时加载更早消息 | 基于 `created_at` 游标分页 |
| 搜索结果 | 固定上限 | `limit=20` |
| 归档列表 | 按需加载 | 展开归档区时 `status="archived"` |

### 16.3 性能目标

| 操作 | 目标延迟 | 实现手段 |
| ---- | -------- | -------- |
| 列出对话（50 条） | < 10ms | 复合索引 `idx_conv_pinned(workspace_id, is_pinned, updated_at)` |
| 创建对话 | < 5ms | 单 INSERT |
| 加载消息（100 条） | < 15ms | 索引 `idx_messages_conv(conversation_id, created_at)` |
| 标题搜索 | < 20ms | LIKE 查询，数据量小无需额外索引 |
| 导出（1000 条消息） | < 500ms | 异步 + 进度事件 |
| 导入（100 个对话） | < 3s | 批量事务 |
