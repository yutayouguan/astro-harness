# 国际化详细设计

> 版本：v1.0 | 日期：2026-08-09 | 状态：草稿
> 对应需求：F-20 国际化、系统设计参考 [桌面端/02-国际化](../../03-系统设计阶段/06-桌面端/02-国际化.md)

桌面端面向多语言用户，前端采用 react-i18next，后端采用 fluent-rs，通过 Tauri 事件总线实现运行时语言切换。

---

## 1. 国际化架构

### 1.1 整体分层

```text
┌──────────────── 前端（React + WebView）────────────────┐
│  i18next ── namespace JSON ── useTranslation()         │
│  Intl.DateTimeFormat / NumberFormat ── 日期/数字格式化  │
└─────────────────────┬──────────────────────────────────┘
                      │ Tauri invoke / event
┌─────────────────────▼──────────────────────────────────┐
│               Rust 后端（src-tauri）                     │
│  fluent-rs ── .ftl 文件 ── FluentBundle（错误/通知）    │
│  PromptStore ── prompts/{locale}/ ── 多语言 Prompt      │
│  sys_locale ── 系统语言检测 → config.toml 持久化        │
└────────────────────────────────────────────────────────┘
```

### 1.2 语言检测优先级

| 优先级 | 来源 | 说明 |
| ------ | ---- | ---- |
| 1 | 用户偏好 | `~/.astro/config.toml` 中的 `locale` 字段 |
| 2 | 系统语言 | `sys_locale::get_locale()` 读取 OS 设置 |
| 3 | 默认回退 | 硬编码 `"en-US"` |

```rust
// apps/desktop/src-tauri/src/i18n/detect.rs
const SUPPORTED_LOCALES: &[&str] = &["zh-CN", "en-US", "ja-JP", "zh-TW"];

pub fn detect_locale(user_pref: Option<&str>) -> String {
    if let Some(p) = user_pref { if SUPPORTED_LOCALES.contains(&p) { return p.into(); } }
    if let Some(sys) = sys_locale::get_locale() {
        let n = normalize_locale(&sys);   // "zh-Hans-CN" → "zh-CN" 等
        if SUPPORTED_LOCALES.contains(&n.as_str()) { return n; }
    }
    "en-US".into()
}
```

支持语言路线图：v1 zh-CN + en-US → v2 ja-JP + zh-TW → v3 社区贡献。

## 2. 前端本地化

### 2.1 目录结构

```text
apps/desktop/src/i18n/
├── index.ts              # i18next 初始化
├── types.ts              # namespace 类型声明（CustomTypeOptions）
└── locales/
    ├── zh-CN/
    │   ├── common.json   # 按钮、标签、状态
    │   ├── chat.json     # 对话界面
    │   ├── settings.json # 设置面板
    │   ├── errors.json   # 错误消息
    │   ├── skills.json   # Skills 管理
    │   └── evolution.json# 进化系统
    ├── en-US/            # 同结构
    └── ja-JP/
```

### 2.2 初始化（异步获取持久化 locale）

```typescript
// apps/desktop/src/i18n/index.ts
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import resourcesToBackend from "i18next-resources-to-backend";
import { invoke } from "@tauri-apps/api/core";

i18n.use(initReactI18next).use(resourcesToBackend(
  (lang: string, ns: string) => import(`./locales/${lang}/${ns}.json`)
));

export async function initI18n() {
  const saved = await invoke<string | null>("get_saved_locale");
  const system = await invoke<string>("get_system_locale");
  await i18n.init({
    lng: saved ?? system ?? "zh-CN", fallbackLng: "en-US", defaultNS: "common",
    ns: ["common", "chat", "settings", "errors", "skills", "evolution"],
    interpolation: { escapeValue: false },
    react: { useSuspense: true },
  });
}
```

### 2.4 组件使用模式

```typescript
import { useTranslation, Trans } from "react-i18next";

// 基础 + 插值
const { t } = useTranslation("chat");
<textarea placeholder={t("inputPlaceholder")} />;
<span>{t("toolCall", { tool })}</span>;

// 复数：i18next 通过 _one/_other 后缀自动选择
<span>{t("messageCount", { count: 3 })}</span>;   // → "3 messages" / "3 条消息"

// 多 namespace 混用
const { t: te } = useTranslation("errors");
const { t: tc } = useTranslation("common");
<p>{te(error.kind, error.params)}</p>
<button>{tc("retry")}</button>

// Trans 组件处理富文本（翻译含 <link> 标签）
<Trans t={t} i18nKey="apiKeyHint" values={{ provider }}
  components={{ link: <a href={url} target="_blank" rel="noopener noreferrer" /> }} />;
```

### 2.5 TypeScript 类型安全

在 `types.ts` 中通过 `declare module "i18next"` 声明 `CustomTypeOptions`，将 zh-CN JSON 的 `typeof` 作为 `resources` 类型，使 `t("chat:inputPlaceholder")` 获得编译期检查。

### 3.2 I18nManager

依赖：`fluent = "0.16"`, `fluent-bundle = "0.15"`, `unic-langid = "0.9"`, `sys-locale = "0.3"`。

```rust
// apps/desktop/src-tauri/src/i18n/mod.rs
pub struct I18nManager {
    bundles: HashMap<String, FluentBundle<FluentResource>>,
    current_locale: Arc<RwLock<String>>,
    fallback_locale: String,
}

impl I18nManager {
    /// 启动时加载所有 locale 目录下的 .ftl → FluentBundle
    pub fn new(i18n_dir: &PathBuf, initial_locale: &str) -> anyhow::Result<Self> { /* ... */ }

    /// 查找消息：当前 locale → fallback → 返回 msg_id 原文
    pub async fn format(&self, msg_id: &str, args: Option<&FluentArgs<'_>>) -> String { /* ... */ }

    pub async fn set_locale(&self, locale: String) {
        *self.current_locale.write().await = locale;
    }
}
```

`I18nManager` 以 `Arc<I18nManager>` 挂载到 `AppState.i18n`。`AppError::localize(&i18n)` 将结构化错误转为本地化消息后返回前端。

## 4. Prompt 多语言模板

### 4.1 语言选择策略

| 场景 | 语言策略 |
| ---- | -------- |
| System / Planner / Router Prompt | 跟随用户 UI locale |
| Skill Prompt | Skill 自身定义（多为英文） |
| Persona SOUL.md | 按 locale 提供变体 |

### 4.2 PromptStore

```text
prompts/
├── zh-CN/system.md, planner.md, personas/default.md, skills/research.md
├── en-US/...
└── ja-JP/...
```

```rust
// crates/agent-core/src/prompts/mod.rs
pub struct PromptStore {
    base_dir: PathBuf,
    locale: RwLock<String>,
    fallback: String,
    cache: RwLock<HashMap<String, String>>,
}

impl PromptStore {
    /// 优先 {locale}/{name}，缺失回退 {fallback}/{name}，结果缓存
    pub async fn load(&self, name: &str) -> anyhow::Result<String> { /* ... */ }

    /// 切换 locale 并清空缓存
    pub async fn set_locale(&self, locale: String) {
        *self.locale.write().await = locale;
        self.cache.write().await.clear();
    }
}
```

Persona 按语言编写：zh-CN 版注明「技术术语保留英文并首次出现给出释义」，en-US 版注明「Explain technical terms when first appear」。

## 5. 日期与数字格式

### 5.1 前端（Intl API）

```typescript
// apps/desktop/src/utils/format.ts
import i18n from "../i18n";

export const formatConversationDate = (ts: string) =>
  new Intl.DateTimeFormat(i18n.language, { dateStyle: "medium", timeStyle: "short" }).format(new Date(ts));

export const formatRelativeTime = (ts: string) => {
  const diff = Date.now() - new Date(ts).getTime();
  const rtf = new Intl.RelativeTimeFormat(i18n.language, { numeric: "auto" });
  const m = Math.floor(diff / 60000), h = Math.floor(m / 60), d = Math.floor(h / 24);
  return d > 0 ? rtf.format(-d, "day") : h > 0 ? rtf.format(-h, "hour") : rtf.format(-m, "minute");
};

export const formatCost = (amount: number) =>
  new Intl.NumberFormat(i18n.language, { style: "currency", currency: "USD", minimumFractionDigits: 4 }).format(amount);
```

### 5.2 后端（chrono）

```rust
pub fn format_datetime_for_locale(dt: &DateTime<Utc>, locale: &str) -> String {
    let local = dt.with_timezone(&Local);
    match locale {
        "zh-CN" | "zh-TW" => local.format("%Y年%m月%d日 %H:%M").to_string(),
        "ja-JP" => local.format("%Y/%m/%d %H:%M").to_string(),
        _ => local.format("%b %d, %Y %I:%M %p").to_string(),
    }
}
```

### 5.3 效果对照

| 类型 | zh-CN | en-US | ja-JP |
| ---- | ----- | ----- | ----- |
| 日期 | 2026年8月9日 14:30 | Aug 9, 2026, 2:30 PM | 2026/08/09 14:30 |
| 相对时间 | 3 分钟前 | 3 minutes ago | 3 分前 |
| 费用 | US$0.0023 | $0.0023 | $0.0023 |

## 6. 语言切换

### 6.1 运行时切换流程（无需重启）

```text
用户选择新语言
  ├── invoke("set_locale") → 持久化 config.toml + I18nManager/PromptStore 切换 + app.emit("locale_changed")
  ├── i18n.changeLanguage() → 按需加载新 namespace JSON + React 自动重渲染
  └── locale_changed 事件 → 所有窗口 useLocaleSync() 同步切换
```

### 6.2 Tauri Command

```rust
#[command]
pub fn get_system_locale() -> String {
    sys_locale::get_locale().unwrap_or_else(|| "en-US".to_string())
}

#[command]
pub async fn set_locale(app: AppHandle, locale: String, state: State<'_, AppState>) -> Result<(), String> {
    { let mut c = state.config.write().await; c.locale = Some(locale.clone()); c.save().map_err(|e| e.to_string())?; }
    state.i18n.set_locale(locale.clone()).await;
    state.prompt_store.set_locale(locale.clone()).await;
    app.emit("locale_changed", &locale).map_err(|e| e.to_string())
}

#[command]
pub fn get_supported_locales() -> Vec<LocaleInfo> {
    vec![
        LocaleInfo { code: "zh-CN".into(), native_name: "简体中文".into() },
        LocaleInfo { code: "en-US".into(), native_name: "English".into() },
        LocaleInfo { code: "ja-JP".into(), native_name: "日本語".into() },
        LocaleInfo { code: "zh-TW".into(), native_name: "繁體中文".into() },
    ]
}
```

### 6.3 前端切换组件

```typescript
// apps/desktop/src/components/settings/LanguageSwitcher.tsx
export function LanguageSwitcher() {
  const { i18n } = useTranslation("settings");
  const [locales, setLocales] = useState<LocaleInfo[]>([]);
  useEffect(() => { invoke<LocaleInfo[]>("get_supported_locales").then(setLocales); }, []);

  // 监听其他窗口切换
  useEffect(() => {
    const u = listen<string>("locale_changed", (e) => { i18n.changeLanguage(e.payload); });
    return () => { u.then(fn => fn()); };
  }, [i18n]);

  const handleChange = async (locale: string) => {
    await invoke("set_locale", { locale });
    await i18n.changeLanguage(locale);
    document.documentElement.lang = locale;
  };

  return (
    <select value={i18n.language} onChange={e => handleChange(e.target.value)}>
      {locales.map(l => <option key={l.code} value={l.code}>{l.nativeName}</option>)}
    </select>
  );
}
```

## 7. 翻译工作流

### 7.1 源语言与流程

源语言 **zh-CN**：开发者编写中文 → 手动翻译 en-US（人工审校）→ AI 辅助翻译 ja-JP/zh-TW（人工复核）→ 社区贡献其他语言。

### 7.2 规范

- JSON key camelCase（`inputPlaceholder`），FTL ID kebab-case（`network-error`）
- 禁止拼接句子，变量使用 `{{var}}`（JSON）或 `{$var}`（FTL）
- 复数使用 `_one` / `_other` 后缀

### 7.3 CI 检测

`scripts/check-i18n.ts`：遍历非源 locale 目录，对比每个 namespace JSON key 集合，报告 missing/extra key。`scripts/check-ftl.sh`：提取 `.ftl` message ID 做同样对比。两者在 CI `i18n-check` job 中运行，失败则阻断合并。

### 7.4 社区贡献新语言

1. 在 `locales/` 和 `src-tauri/i18n/` 下创建新 locale 目录，复制源文件并翻译
2. 在 `SUPPORTED_LOCALES` 和 `get_supported_locales` 中注册
3. 运行 `check-i18n.ts` 确认无缺失 key，提交 PR
