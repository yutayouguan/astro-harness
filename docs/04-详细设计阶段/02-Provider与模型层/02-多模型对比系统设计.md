# 多模型对比系统设计

> 版本：v1.0 | 日期：2026-08-07 | 状态：草稿
> 对应需求：F-33 多模型对比、M-15 多模型对比模块（US-082）

多模型对比允许用户将同一消息并发发送给 2-4 个模型，并排查看各模型的流式回复，最终选择一个回复作为后续对话上下文（"采用此回复"），其余回复可选择归档为对话分支。

---

## 1. 核心概念

```text
┌──────────────────────────────────────────────────────────┐
│ 对比模式  [claude-sonnet-5] [gpt-4o] [gemini-2.5-pro]  │
│                           [+ 添加]                       │
├─────────────────┬─────────────────┬──────────────────────┤
│ claude-sonnet-5 │ gpt-4o          │ gemini-2.5-pro       │
│ $0.012 预估     │ $0.008 预估     │ $0.004 预估          │
├─────────────────┼─────────────────┼──────────────────────┤
│                 │                 │                      │
│ （流式输出中）  │ （流式输出中）  │ （流式输出中）       │
│                 │                 │                      │
│ [✓ 采用此回复] │ [✓ 采用此回复] │ [✓ 采用此回复]      │
└─────────────────┴─────────────────┴──────────────────────┘
│ 输入框（同一消息同步发给所有模型）                       │
└──────────────────────────────────────────────────────────┘
```

**核心约束**：
- 选模型数：2-4 个（最少 2 个才有对比意义，最多 4 个避免费用失控）
- 上下文共享：所有模型接收完全相同的历史消息 + 当前用户消息
- 并发执行：各模型请求独立并发，互不等待
- 采用唯一：同一对比轮次只能采用一个模型的回复

---

## 2. 数据流

```text
用户激活对比模式（按钮 / `/compare` 命令）
    │
    ▼
前端展示 ModelSelector → 用户勾选 2-4 个模型
    │
    ▼
用户发送消息 → invoke("compare_send", { models, content, history })
    │
    ▼
CompareSession::run_parallel()
    │  tokio::join! 并发启动各模型流式调用
    │
    ├─► Model A：流式 delta → emit("compare_delta", { model: "claude-sonnet-5", delta, done: false })
    ├─► Model B：流式 delta → emit("compare_delta", { model: "gpt-4o", delta, done: false })
    └─► Model C：流式 delta → emit("compare_delta", { model: "gemini-2.5-pro", delta, done: false })
    │
    ▼（各列独立完成，emit done=true）
用户点击 [✓ 采用此回复]
    │
    ▼
invoke("compare_adopt", { compareId, adoptedModel })
    │  1. 将采用模型的回复写入 messages 表（成为后续对话上下文）
    │  2. 其余模型的回复可选创建分支对话（见 36-对话分支系统设计.md）
    │  3. 保存对比记录到 compare_sessions 表（P2）
    ▼
对比模式结束，切回普通对话模式
```

## 3. Rust 实现

### 3.1 CompareSession

```rust
// crates/agent-core/src/compare/session.rs
// 注：对比模式绕过 Agent 工具路由，直接使用 ChatCompletionModel 进行纯文本对话。

pub struct CompareSession {
    pub id: Uuid,
    pub conversation_id: String,
    pub models: Vec<String>,   // e.g. ["claude-sonnet-5", "gpt-4o", "gemini-2.5-pro"]
    pub user_message: String,
    pub history: Vec<Message>, // 共享的历史消息快照
}

impl CompareSession {
    /// 并发向所有模型发送请求，各自流式 emit 到前端
    pub async fn run_parallel(
        &self,
        registry: Arc<Registry>,
        app: AppHandle,
    ) -> anyhow::Result<HashMap<String, String>> {
        // 各模型并发请求，结果收集到 HashMap<model_id, full_response>
        let tasks: Vec<_> = self.models.iter().map(|model_id| {
            let model_id = model_id.clone();
            let registry = registry.clone();
            let app = app.clone();
            let history = self.history.clone();
            let user_msg = self.user_message.clone();
            let compare_id = self.id.to_string();

            tokio::spawn(async move {
                let client = registry.chat_completion_model(&model_id)?;
                let mut stream = client.chat_stream(ChatCompletionRequest {
                    model: model_id.clone(),
                    messages: build_messages(&history, &user_msg),
                    ..Default::default()
                }).await?;

                let mut full_text = String::new();
                while let Some(chunk) = stream.next().await {
                    let delta = chunk?.delta;
                    full_text.push_str(&delta);
                    app.emit("compare_delta", CompareDeltaEvent {
                        compare_id: compare_id.clone(),
                        model: model_id.clone(),
                        delta,
                        done: false,
                    }).ok();
                }

                // 发送完成信号 + 实际费用
                let cost = estimate_cost(&model_id, count_tokens(&full_text));
                app.emit("compare_delta", CompareDeltaEvent {
                    compare_id: compare_id.clone(),
                    model: model_id.clone(),
                    delta: String::new(),
                    done: true,
                }).ok();
                app.emit("compare_cost", CompareCostEvent {
                    compare_id,
                    model: model_id,
                    cost_usd: cost,
                }).ok();

                anyhow::Ok((model_id.clone(), full_text))
            })
        }).collect();

        // 等待所有任务完成
        let mut results = HashMap::new();
        for task in tasks {
            if let Ok(Ok((model, text))) = task.await {
                results.insert(model, text);
            }
        }
        Ok(results)
    }
}
```

### 3.2 采用回复

```rust
// crates/agent-core/src/compare/adopt.rs

pub async fn adopt_response(
    pool: &SqlitePool,
    conversation_id: &str,
    adopted_model: &str,
    response_text: &str,
    other_responses: &HashMap<String, String>,
    create_branches: bool,
) -> anyhow::Result<()> {
    // 1. 将采用的回复写入 messages 表（作为正式 assistant 消息）
    sqlx::query!(
        "INSERT INTO messages (id, conversation_id, role, content, model, created_at)
         VALUES (?, ?, 'assistant', ?, ?, ?)",
        Uuid::new_v4().to_string(),
        conversation_id,
        response_text,
        adopted_model,
        now_ms(),
    )
    .execute(pool)
    .await?;

    // 2. 其余回复（可选）创建为对话分支
    if create_branches {
        for (model, text) in other_responses {
            if model == adopted_model { continue; }
            // 创建分支对话，branch_point 为当前用户消息
            // 详细实现见 36-对话分支系统设计.md
            create_compare_branch(pool, conversation_id, model, text).await?;
        }
    }

    Ok(())
}
```

```typescript
// 后端 → 前端事件

interface CompareDeltaEvent {
  compareId: string;
  model: string;      // 哪个模型的输出
  delta: string;      // 新增文本片段
  done: boolean;      // true = 该模型完成
}
// event: "compare_delta"

interface CompareCostEvent {
  compareId: string;
  model: string;
  costUsd: number;    // 实际费用（完成后）
}
// event: "compare_cost"
```

## 5. 前端实现

### 5.1 对比视图组件

```typescript
// apps/desktop/src/components/chat/CompareView.tsx

export function CompareView({ compareId, models }: {
  compareId: string;
  models: string[];
}) {
  // 每个模型的回复文本（流式累积）
  const [responses, setResponses] = useState<Record<string, string>>(
    Object.fromEntries(models.map(m => [m, ""]))
  );
  const [costs, setCosts] = useState<Record<string, number>>({});
  const [done, setDone] = useState<Set<string>>(new Set());
  const [adopted, setAdopted] = useState<string | null>(null);

  // 订阅流式 delta 事件
  useEffect(() => {
    const unlisten = listen<CompareDeltaEvent>("compare_delta", (e) => {
      if (e.payload.compareId !== compareId) return;
      const { model, delta, done: isDone } = e.payload;
      if (!isDone) {
        setResponses(prev => ({ ...prev, [model]: prev[model] + delta }));
      } else {
        setDone(prev => new Set([...prev, model]));
      }
    });
    const unlistenCost = listen<CompareCostEvent>("compare_cost", (e) => {
      if (e.payload.compareId !== compareId) return;
      setCosts(prev => ({ ...prev, [e.payload.model]: e.payload.costUsd }));
    });
    return () => { unlisten.then(f => f()); unlistenCost.then(f => f()); };
  }, [compareId]);

  const handleAdopt = async (model: string) => {
    setAdopted(model);
    const { createBranches } = await showAdoptDialog();
    await invoke("compare_adopt", {
      compareId,
      conversationId: useConversationStore.getState().activeConversationId,
      adoptedModel: model,
      createBranches,
    });
  };

  // 水平均分列布局，最多 4 列
  return (
    <div className="compare-view" style={{ gridTemplateColumns: `repeat(${models.length}, 1fr)` }}>
      {models.map(model => (
        <CompareColumn
          key={model}
          model={model}
          text={responses[model]}
          costUsd={costs[model]}
          isDone={done.has(model)}
          isAdopted={adopted === model}
          disabled={!!adopted}
          onAdopt={() => handleAdopt(model)}
        />
      ))}
    </div>
  );
}

function CompareColumn({ model, text, costUsd, isDone, isAdopted, disabled, onAdopt }) {
  return (
    <div className={`compare-column ${isAdopted ? "adopted" : ""}`}>
      {/* 列头：模型名 + 费用 */}
      <div className="compare-column-header">
        <span className="model-name">{modelDisplayName(model)}</span>
        {costUsd != null
          ? <span className="cost">${costUsd.toFixed(4)}</span>
          : <span className="cost estimated">{estimateCost(model)} 预估</span>
        }
        {!isDone && <span className="streaming-indicator">●</span>}
      </div>

      {/* 流式内容区 */}
      <div className="compare-column-body">
        <MarkdownRenderer content={text} />
      </div>

      {/* 底部操作 */}
      <div className="compare-column-footer">
        <Button
          onClick={onAdopt}
          disabled={disabled || !isDone}
          variant={isAdopted ? "default" : "outline"}
        >
          {isAdopted ? "✓ 已采用" : "✓ 采用此回复"}
        </Button>
      </div>
    </div>
  );
}
```

### 5.2 模型选择器

```typescript
// apps/desktop/src/components/chat/ModelSelector.tsx

export function ModelSelector({ selected, onChange }: {
  selected: string[];
  onChange: (models: string[]) => void;
}) {
  const availableModels = useProviderStore(s => s.availableModels);

  const toggle = (modelId: string) => {
    if (selected.includes(modelId)) {
      if (selected.length > 2) onChange(selected.filter(m => m !== modelId));
    } else {
      if (selected.length < 4) onChange([...selected, modelId]);
    }
  };

  return (
    <div className="model-selector">
      <p className="hint">选择 2-4 个模型进行对比</p>
      <div className="model-grid">
        {availableModels.map(model => (
          <button
            key={model.id}
            className={`model-chip ${selected.includes(model.id) ? "selected" : ""}`}
            onClick={() => toggle(model.id)}
            disabled={!selected.includes(model.id) && selected.length >= 4}
          >
            {model.provider_icon} {model.display_name}
            <span className="price">${model.price_per_1m_output}/1M</span>
          </button>
        ))}
      </div>
    </div>
  );
}
```

## 6. 费用预估

在用户选择模型后、发送前，前端根据 OpenRouter 模型目录（见 [02-OpenRouter模型目录.md](../../03-系统设计阶段/02-核心功能模块/02-OpenRouter模型目录.md)）估算费用：

```typescript
function estimateCost(modelId: string, inputTokens = 1000, outputTokens = 500): string {
  const model = modelCatalog[modelId];
  if (!model) return "未知";
  const cost = (inputTokens / 1e6) * model.pricePerMInputTokens
             + (outputTokens / 1e6) * model.pricePerMOutputTokens;
  return `$${cost.toFixed(4)}`;
}
```

对比完成后，从 `compare_cost` 事件接收实际费用并替换预估值。

```sql
    workspace_id    TEXT NOT NULL,
    user_message    TEXT NOT NULL,
    models          TEXT NOT NULL,   -- JSON 数组 ["claude-sonnet-5", "gpt-4o"]
```

## 8. 与对话分支的集成

"采用此回复"时，可将其余模型的回复保存为对话分支（用户可在弹窗中勾选）：

```text
采用 claude-sonnet-5 的回复
    │
    ▼
主线对话继续：用户 → claude-sonnet-5 回复 → 下一轮...
    │
    └─ 其余回复（可选创建分支）：
         gpt-4o 回复 → conv-branch-gpt4o（parent=主线, branch_point=用户消息）
         gemini 回复 → conv-branch-gemini
```

实现复用 [36-对话分支系统设计.md](../05-桌面端与交互/03-对话分支系统设计.md) 的 `create_branch()` 函数。

## 9. 设计约束

- **最多 4 个模型**：费用控制 + UI 可读性（4 列各 25% 宽度是可接受下限）
- **共享历史快照**：发送时对历史消息做快照，对比期间历史不变，保证各模型接收完全相同的上下文
- **取消终止所有流**：`compare_cancel` 同时终止所有并发模型的流式连接（每个 tokio task 持有 `CancellationToken`）
- **费用分别计入各模型**：`cost_records` 表按 `model` 字段区分，便于模型洞察界面的分模型费用统计
- **对比期间禁用工具调用**：对比模式只做纯文本对话，不触发 Tool 执行（注入系统提示词关闭 tool use），避免不同模型的工具调用产生副作用
