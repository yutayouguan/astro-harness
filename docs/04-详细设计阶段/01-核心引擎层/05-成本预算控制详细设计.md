## 1. 预算模型（workspace/session/daily 粒度）

### 1.1 三级预算维度

预算体系分为三个层级，由粗到细逐级管控，任一级别超限即触发对应的 `OverflowPolicy`。

| 维度 | 作用域 | 典型上限 | 重置周期 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| **全局月度预算** | 整个应用 | $100/月 | 每月 1 日 00:00 UTC | 防止账户级意外超支 |
| **全局每日预算** | 整个应用 | $10/日 | 每日 00:00 UTC | 防止单日暴涨 |
| **工作区每日预算** | 单个工作区 | $2/日 | 每日 00:00 UTC | 防止单项目耗尽全局配额 |
| **会话预算** | 单次 Agent 运行 | $0.50/次 | 会话结束 | 防止单次任务失控 |
| **进化引擎专项** | 自我进化引擎 | $5/月 | 每月 1 日 00:00 UTC | Eval + Prompt 优化独立配额 |

检查顺序：会话预算 -> 工作区每日预算 -> 全局每日预算 -> 全局月度预算。任一级别超限即短路返回。

### 1.3 BudgetManager 主结构体

```rust
// crates/agent-core/src/budget/manager.rs

use std::sync::Arc;
use std::sync::atomic::Ordering;
use anyhow::Result;
use chrono::{Datelike, Utc};
use sqlx::SqlitePool;
use tokio::sync::RwLock;

pub struct BudgetManager {
    db: SqlitePool,
    config: RwLock<BudgetConfig>,
    /// 模型单价表（运行时可更新）
    pricing: Arc<RwLock<ModelPricingTable>>,
    /// HumanGuard 引用，用于费用超限时强制关闭 YOLO
    human_guard: Option<Arc<HumanGuard>>,
    /// EventEmitter 用于广播预算事件（不直接依赖 tauri::AppHandle）
    emitter: Arc<dyn EventEmitter>,
    /// 内存缓存：当前会话累计费用（session_id → 累计 USD）
    session_costs: DashMap<String, f64>,
}

impl BudgetManager {
    pub fn new(
        db: SqlitePool,
        config: BudgetConfig,
        pricing: ModelPricingTable,
        emitter: Arc<dyn EventEmitter>,
    ) -> Self {
        Self {
            db,
            config: RwLock::new(config),
            pricing: Arc::new(RwLock::new(pricing)),
            human_guard: None,
            emitter,
            session_costs: DashMap::new(),
        }
    }

    /// 注入 HumanGuard 引用（在 AppState 初始化后调用，打破循环依赖）
    pub fn set_human_guard(&mut self, guard: Arc<HumanGuard>) {
        self.human_guard = Some(guard);
    }

    /// 从数据库重新加载预算配置（用于运行时修改后刷新）
    pub async fn reload_config(&self) -> Result<()> {
        let row = sqlx::query_as::<_, BudgetConfigRow>(
            "SELECT * FROM budget_configs WHERE id = 'global'"
        )
        .fetch_optional(&self.db)
        .await?;

        if let Some(row) = row {
            let mut config = self.config.write().await;
            config.global_daily_limit_usd = row.global_daily_usd;
            config.global_monthly_limit_usd = row.global_monthly_usd;
            config.evolution_monthly_limit_usd = row.evolution_monthly_usd;
            if let Ok(policy) = serde_json::from_str(&row.overflow_policy) {
                config.overflow_policy = policy;
            }
        }
        Ok(())
    }

    /// 注册新会话，初始化费用追踪
    pub fn register_session(&self, session_id: &str) {
        self.session_costs.insert(session_id.to_string(), 0.0);
    }

    /// 注销会话，清理费用追踪
    pub fn unregister_session(&self, session_id: &str) {
        self.session_costs.remove(session_id);
    }
}
```

### 2.1 模型单价表

单价以 **美元 / 百万 Token** 为单位，区分输入（prompt）、输出（completion）、缓存命中（cached）三种计费维度。

```rust
                best_len = prefix.len();
            }
        }
        best
```

### 2.2 费用计算公式

单次 LLM 调用的费用计算逻辑，与可观测性详细设计中 `TokenUsage::cost_usd()` 保持一致：

```rust
// crates/agent-core/src/budget/pricing.rs

/// 计算单次 LLM 调用的费用（美元）
///
/// 公式：
///   cost = (uncached_input_tokens * input_price / 1M)
///        + (cached_input_tokens * input_price * cache_discount / 1M)
///        + (output_tokens * output_price / 1M)
///
/// 其中：
///   uncached_input_tokens = prompt_tokens - cached_tokens
///   缓存命中 token 按 input_price * cache_discount 计费
pub fn calculate_cost(
    prompt_tokens: u64,
    completion_tokens: u64,
    cached_tokens: u64,
    price: &ModelPrice,
) -> f64 {
    let uncached_input = prompt_tokens.saturating_sub(cached_tokens);
    let input_cost = uncached_input as f64 * price.input / 1_000_000.0;
    let cache_cost = cached_tokens as f64 * price.input * price.cache_discount / 1_000_000.0;
    let output_cost = completion_tokens as f64 * price.output / 1_000_000.0;
    input_cost + cache_cost + output_cost
}
```

### 2.3 费用估算（调用前预估）

`check_before_call` 需要在实际调用 LLM 之前估算本次调用的费用。由于此时不知道确切 token 数，采用基于消息长度的启发式估算。

```rust
// crates/agent-core/src/budget/estimator.rs

/// Token 估算器：在实际调用前根据消息内容估算 token 数
pub struct CostEstimator;

impl CostEstimator {
    /// 估算输入 token 数
    /// 启发式规则：
    ///   - 英文：约 1 token / 4 字符
    ///   - 中文/日文/韩文：约 1 token / 1.5 字符
    ///   - 混合文本取加权平均
    ///   - 加 15% 安全边际（system prompt、格式 token 等开销）
    pub fn estimate_input_tokens(messages: &[Message]) -> u64 {
        let mut total_chars: usize = 0;
        let mut cjk_chars: usize = 0;

        for msg in messages {
            let text = msg.text_content();
            total_chars += text.len();
            cjk_chars += text.chars().filter(|c| is_cjk(*c)).count();
        }

        let ascii_chars = total_chars - cjk_chars;
        // 英文 4 字符/token，CJK 1.5 字符/token
        let estimated = (ascii_chars as f64 / 4.0) + (cjk_chars as f64 / 1.5);
        // 加 15% 安全边际
        (estimated * 1.15) as u64
    }

    /// 估算输出 token 数
    /// 经验值：输出通常为输入的 25%-50%，取 35% 作为默认估算
    /// 如果指定了 max_tokens 则取 min(估算值, max_tokens)
    pub fn estimate_output_tokens(
        estimated_input: u64,
        max_tokens: Option<u64>,
    ) -> u64 {
        let estimated = (estimated_input as f64 * 0.35) as u64;
        match max_tokens {
            Some(max) => estimated.min(max),
            None => estimated,
        }
    }

    /// 综合估算本次调用费用（美元）
    pub fn estimate_call_cost(
        messages: &[Message],
        model: &str,
        max_tokens: Option<u64>,
        pricing: &ModelPricingTable,
    ) -> f64 {
        let price = match pricing.get_price(model) {
            Some(p) => p,
            None => return 0.0, // 未知模型，不拦截
        };

        let input_tokens = Self::estimate_input_tokens(messages);
        let output_tokens = Self::estimate_output_tokens(input_tokens, max_tokens);
        // 估算时假设无缓存命中（最坏情况）
        calculate_cost(input_tokens, output_tokens, 0, price)
    }
}

fn is_cjk(c: char) -> bool {
    matches!(c,
        '\u{4E00}'..='\u{9FFF}'   |  // CJK Unified
        '\u{3400}'..='\u{4DBF}'   |  // CJK Extension A
        '\u{3040}'..='\u{309F}'   |  // Hiragana
        '\u{30A0}'..='\u{30FF}'   |  // Katakana
        '\u{AC00}'..='\u{D7AF}'      // Hangul
    )
}
```

## 3. check_before_call 拦截逻辑

### 3.1 调用时序

`check_before_call` 在 `AgentExecutor::round_loop()` 的第 3 步（LLM 调用前）被调用，是预算管控的核心拦截点。

```text
round_loop 第 N 轮
    │
    ├── ① pending 消息注入
    ├── ② 上下文构建（ContextBuilder）
    │
    ├── ③ 预算检查 ← BudgetManager::check_before_call()
    │       │
    │       ├── 估算本次调用费用（CostEstimator）
    │       ├── 查询会话累计费用（内存）
    │       ├── 查询工作区今日费用（SQLite）
    │       ├── 查询全局今日/本月费用（SQLite）
    │       │
    │       ├── 任一级别超限？
    │       │   ├── YES → apply_policy()
    │       │   │         ├── Block → 返回错误，LLM 调用不执行
    │       │   │         ├── Warn → 记录警告，继续
    │       │   │         └── Downgrade → 返回降级模型，LLM 用降级模型调用
    │       │   └── NO → PreCallDecision::Allow
    │       │
    │       └── YOLO 剩余阈值检查（不管是否超限，独立判断）
    │
    ├── ④ LLM 流式调用（使用原模型或降级模型）
    └── ...
```

### 3.2 核心实现

```rust
// crates/agent-core/src/budget/manager.rs（续）

/// 调用前预算检查决策
#[derive(Debug, Clone)]
pub enum PreCallDecision {
    /// 允许调用，无任何限制
    Allow,
    /// 允许调用，但发出预算警告
    Warn { message: String },
    /// 拒绝调用
    Block { reason: String },
    /// 允许调用，但降级到更便宜的模型
    Downgrade { model: String, reason: String },
}

impl BudgetManager {
    /// 调用前检查：评估本次 LLM 调用是否在各级预算之内
    ///
    /// 参数：
    ///   - workspace_id: 当前工作区 ID
    ///   - session_id: 当前会话 ID（用于会话级预算检查）
    ///   - estimated_cost: 预估本次调用费用（美元），由 CostEstimator 计算
    ///
    /// 返回 PreCallDecision 指示后续行为。
    /// 任何超限情况都会同时触发 YOLO 强制关闭。
    pub async fn check_before_call(
        &self,
        workspace_id: &str,
        session_id: &str,
        estimated_cost: f64,
    ) -> Result<PreCallDecision> {
        let config = self.config.read().await;
        let today = Utc::now().date_naive();
        let month_start = format!("{}-{:02}-01", today.year(), today.month());

        // ── 1. 会话级预算检查 ──
        let session_limit = config.workspace_limits
            .get(workspace_id)
            .and_then(|ws| ws.session_limit_usd)
            .unwrap_or(config.default_session_limit_usd);

        if let Some(session_spent) = self.session_costs.get(session_id) {
            if *session_spent + estimated_cost > session_limit {
                return Ok(self.apply_policy(&config.overflow_policy, "会话预算"));
            }
        }

        // ── 2. 工作区每日预算检查 ──
        if let Some(ws_config) = config.workspace_limits.get(workspace_id) {
            let daily_workspace: f64 = sqlx::query_scalar(
                "SELECT COALESCE(SUM(cost_usd), 0.0) FROM cost_records
                 WHERE workspace_id = ? AND date(recorded_at / 1000, 'unixepoch') = date('now')"
            )
            .bind(workspace_id)
            .fetch_one(&self.db)
            .await?;

            if daily_workspace + estimated_cost > ws_config.daily_limit_usd {
                return Ok(self.apply_policy(&ws_config.overflow_policy, "工作区每日预算"));
            }
        }

        // ── 3. 全局每日预算检查 ──
        let daily_global: f64 = sqlx::query_scalar(
            "SELECT COALESCE(SUM(cost_usd), 0.0) FROM cost_records
             WHERE date(recorded_at / 1000, 'unixepoch') = date('now')"
        )
        .fetch_one(&self.db)
        .await?;

        if daily_global + estimated_cost > config.global_daily_limit_usd {
            return Ok(self.apply_policy(&config.overflow_policy, "全局每日预算"));
        }

        // ── 4. 全局每月预算检查 ──
        let monthly_global: f64 = sqlx::query_scalar(
            "SELECT COALESCE(SUM(cost_usd), 0.0) FROM cost_records
             WHERE recorded_at >= ?",
        )
        .bind(&month_start)
        .fetch_one(&self.db)
        .await?;

        if monthly_global + estimated_cost > config.global_monthly_limit_usd {
            return Ok(self.apply_policy(&config.overflow_policy, "全局每月预算"));
        }

        // ── 5. YOLO 剩余阈值检查（独立于超限判断） ──
        let daily_remaining = config.global_daily_limit_usd - daily_global;
        if daily_remaining < config.yolo_shutdown_remaining_usd {
            self.enforce_yolo_shutdown("日预算剩余不足");
        }

        // ── 6. 预算告警检查（非拦截，仅通知） ──
        let daily_ratio = daily_global / config.global_daily_limit_usd;
        if daily_ratio >= config.critical_threshold {
            self.emit_budget_alert(
                "error",
                &format!("今日花费 ${:.2}，已达每日限额的 {:.0}%",
                    daily_global, daily_ratio * 100.0),
            ).await;
        } else if daily_ratio >= config.warning_threshold {
            self.emit_budget_alert(
                "warning",
                &format!("今日花费 ${:.2}，已达每日限额的 {:.0}%",
                    daily_global, daily_ratio * 100.0),
            ).await;
        }

        Ok(PreCallDecision::Allow)
    }

    /// 应用超限策略，同时强制关闭 YOLO
    fn apply_policy(&self, policy: &OverflowPolicy, budget_name: &str) -> PreCallDecision {
        // 任何超限策略触发时均强制关闭 YOLO
        self.enforce_yolo_shutdown(budget_name);

        match policy {
            OverflowPolicy::Block => PreCallDecision::Block {
                reason: format!("已超出{}上限，LLM 调用被拒绝", budget_name),
            },
            OverflowPolicy::Warn => PreCallDecision::Warn {
                message: format!("警告：已超出{}上限，继续执行", budget_name),
            },
            OverflowPolicy::Downgrade { fallback_model } => PreCallDecision::Downgrade {
                model: fallback_model.clone(),
                reason: format!("已超出{}，切换至 {}", budget_name, fallback_model),
            },
        }
    }

    /// 发送预算告警事件
    async fn emit_budget_alert(&self, level: &str, message: &str) {
        let _ = self.emitter.emit("budget_alert", serde_json::json!({
            "level": level,
            "message": message,
            "timestamp": Utc::now().to_rfc3339(),
        })).await;
    }
}
```

```rust
            }
        }
```

```rust
    async fn upsert_daily_summary(&self, record: &CostRecord) -> Result<()> {
        let date = Utc::now().format("%Y-%m-%d").to_string();
        sqlx::query(
            "INSERT INTO daily_cost_summary
                (date, workspace_id, provider, model, total_cost_usd, total_input_tokens,
                 total_output_tokens, call_count)
             VALUES (?, ?, ?, ?, ?, ?, ?, 1)
             ON CONFLICT(date, workspace_id, provider, model) DO UPDATE SET
                total_cost_usd = total_cost_usd + excluded.total_cost_usd,
                total_input_tokens = total_input_tokens + excluded.total_input_tokens,
                total_output_tokens = total_output_tokens + excluded.total_output_tokens,
                call_count = call_count + 1"
        )
        .bind(&date)
        .bind(&record.workspace_id)
        .bind(&record.provider)
        .bind(&record.model)
        .bind(record.cost_usd)
        .bind(record.input_tokens as i64)
        .bind(record.output_tokens as i64)
        .execute(&self.db)
        .await?;
        Ok(())
    }
```

## 4. 预算耗尽时的降级策略

当预算达到不同阈值时，系统采用渐进式降级策略，尽可能在控制成本的前提下保持 Agent 可用性。

### 4.1 降级层级

```text
预算使用比例

0%                    80%           90%           100%
├─────────────────────┼─────────────┼─────────────┤
│     正常执行         │  Warning    │  Critical   │ Block/Downgrade
│                     │  阶段        │   阶段       │
│ - 使用配置的模型     │ - 发出告警   │ - 模型降级   │ - 策略按 OverflowPolicy
│ - 完整工具可用       │ - 前端展示   │ - 减少输出   │   Block: 停止
│ - YOLO 可用         │   黄色提示   │ - 关闭贵工具 │   Downgrade: 降级
│                     │             │ - 关闭 YOLO  │   Warn: 继续但告警
```

### 4.2 DegradationManager

```rust
// crates/agent-core/src/budget/degradation.rs

use serde::{Serialize, Deserialize};

/// 降级动作
#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum DegradationAction {
    /// 无降级
    None,
    /// 切换到更便宜的模型
    SwitchModel { target_model: String },
    /// 减少 max_tokens 输出限制
    ReduceMaxTokens { new_max_tokens: u64 },
    /// 禁用高成本工具
    DisableExpensiveTools { disabled_tools: Vec<String> },
    /// 全部停止
    HardStop { reason: String },
}

/// 降级策略管理器
pub struct DegradationManager {
    /// 降级模型映射：原始模型 → 便宜替代
    fallback_chain: Vec<(String, String)>,
    /// 高成本工具列表（调用一次预计 > $0.01 的工具）
    expensive_tools: Vec<String>,
}

impl DegradationManager {
    pub fn new() -> Self {
        Self {
            fallback_chain: vec![
                ("claude-opus-4".into(), "claude-sonnet-4-5".into()),
                ("claude-sonnet-4-5".into(), "claude-haiku-4-5".into()),
                ("claude-sonnet-4".into(), "claude-haiku-4-5".into()),
                ("gpt-4o".into(), "gpt-4o-mini".into()),
                ("o3".into(), "o4-mini".into()),
                ("gemini-2.5-pro".into(), "gemini-2.5-flash".into()),
            ],
            expensive_tools: vec![
                "web_search".into(),         // 每次搜索消耗额外 API 费用
                "generate_image".into(),     // 图片生成 $0.04-0.12/次
                "generate_video".into(),     // 视频生成成本高
                "delegate_task".into(),      // 子 Agent 派生会产生递归费用
            ],
        }
    }

    /// 根据预算使用比例计算降级动作列表
    pub fn compute_degradations(
        &self,
        daily_ratio: f64,
        monthly_ratio: f64,
        current_model: &str,
        overflow_policy: &OverflowPolicy,
    ) -> Vec<DegradationAction> {
        let ratio = daily_ratio.max(monthly_ratio);
        let mut actions = Vec::new();

        if ratio >= 1.0 {
            // 已超限，按 overflow_policy 决定
            match overflow_policy {
                OverflowPolicy::Block => {
                    actions.push(DegradationAction::HardStop {
                        reason: "预算已耗尽".into(),
                    });
                    return actions;
                }
                OverflowPolicy::Downgrade { fallback_model } => {
                    actions.push(DegradationAction::SwitchModel {
                        target_model: fallback_model.clone(),
                    });
                }
                OverflowPolicy::Warn => {
                    // Warn 模式不降级，仅记录
                }
            }
        }

        if ratio >= 0.9 {
            // Critical 阶段：降级模型 + 减少输出 + 禁用高成本工具
            if let Some(fallback) = self.get_fallback_model(current_model) {
                actions.push(DegradationAction::SwitchModel {
                    target_model: fallback,
                });
            }
            actions.push(DegradationAction::ReduceMaxTokens {
                new_max_tokens: 2048,  // 从默认 8192 降到 2048
            });
            actions.push(DegradationAction::DisableExpensiveTools {
                disabled_tools: self.expensive_tools.clone(),
            });
        } else if ratio >= 0.8 {
            // Warning 阶段：仅减少输出上限
            actions.push(DegradationAction::ReduceMaxTokens {
                new_max_tokens: 4096,  // 从默认 8192 降到 4096
            });
        }

        actions
    }

    /// 查找降级模型
    fn get_fallback_model(&self, model: &str) -> Option<String> {
        self.fallback_chain.iter()
            .find(|(from, _)| model.starts_with(from.as_str()))
            .map(|(_, to)| to.clone())
    }
}
```

### 4.3 降级动作的应用

降级动作在 `round_loop` 中由 `AgentExecutor` 应用到 `AgentContext`：

```rust
// crates/agent-runtime/src/executor.rs

impl AgentExecutor {
    /// 应用降级动作到当前执行上下文
    fn apply_degradations(&mut self, actions: &[DegradationAction]) {
        for action in actions {
            match action {
                DegradationAction::SwitchModel { target_model } => {
                    tracing::info!(
                        "预算降级: {} → {}",
                        self.context.current_model, target_model
                    );
                    self.context.current_model = target_model.clone();
                }
                DegradationAction::ReduceMaxTokens { new_max_tokens } => {
                    if let Some(current) = self.context.max_tokens {
                        if *new_max_tokens < current {
                            tracing::info!(
                                "预算降级: max_tokens {} → {}",
                                current, new_max_tokens
                            );
                            self.context.max_tokens = Some(*new_max_tokens);
                        }
                    }
                }
                DegradationAction::DisableExpensiveTools { disabled_tools } => {
                    for tool_name in disabled_tools {
                        self.context.tools.disable(tool_name);
                        tracing::info!("预算降级: 禁用高成本工具 {}", tool_name);
                    }
                }
                DegradationAction::HardStop { reason } => {
                    tracing::warn!("预算耗尽，停止执行: {}", reason);
                    // 由 check_before_call 的 Block 分支处理
                }
                DegradationAction::None => {}
            }
        }
    }
}
```

## 5. YOLO 模式预算强制关闭

### 5.1 设计背景

YOLO 模式跳过 L2/L3 工具调用的审批弹窗，实现零打断执行（见 [agent-runtime 详细设计 Section 9.4](./02-agent-runtime详细设计.md)）。但在预算紧张时，无审批的自动执行可能导致费用不可控地快速增长。因此，BudgetManager 在检测到以下任一条件时强制关闭 YOLO：

| 触发条件 | 阈值 | 说明 |
| -------- | ---- | ---- |
| 任一预算级别超限 | 100% | `apply_policy()` 内部统一触发 |
| 全局日预算剩余不足 | 剩余 < `yolo_shutdown_remaining_usd`（默认 $1） | 即使未超限也预防性关闭 |
| 全局月预算剩余不足 | 剩余 < 日限额的 50% | 月末预算吃紧时提前关闭 |

### 5.2 实现

```rust
// crates/agent-core/src/budget/manager.rs（续）

impl BudgetManager {
    /// 费用超限 / 预算紧张时强制关闭 YOLO 开关
    ///
    /// 调用链：
    ///   check_before_call() → apply_policy() → enforce_yolo_shutdown()
    ///   check_before_call() → YOLO 剩余阈值检查 → enforce_yolo_shutdown()
    ///
    /// 关闭后推送 `yolo_force_disabled` 事件通知前端更新开关 UI。
    fn enforce_yolo_shutdown(&self, reason: &str) {
        if let Some(guard) = &self.human_guard {
            // 检查当前是否启用了 YOLO
            if guard.yolo_mode.load(Ordering::Relaxed) {
                // 原子性关闭
                guard.yolo_mode.store(false, Ordering::Release);

                tracing::warn!(
                    "YOLO 模式已被 BudgetManager 强制关闭: {}",
                    reason
                );

                // 通知前端
                let emitter = self.emitter.clone();
                let reason_owned = reason.to_string();
                tokio::spawn(async move {
                    let _ = emitter.emit("yolo_force_disabled", serde_json::json!({
                        "reason": format!("{}，YOLO 模式已自动关闭", reason_owned),
                        "timestamp": Utc::now().to_rfc3339(),
                    })).await;
                });

                // 写入审计日志
                let db = self.db.clone();
                let reason_audit = reason.to_string();
                tokio::spawn(async move {
                    let _ = sqlx::query(
                        "INSERT INTO audit_logs (id, action, details, created_at)
                         VALUES (lower(hex(randomblob(16))), 'yolo_force_disabled', ?,
                                 unixepoch('now','subsec')*1000)"
                    )
                    .bind(&reason_audit)
                    .execute(&db)
                    .await;
                });
            }
        }
    }

    /// 在 check_before_call 主流程中调用的 YOLO 主动检查
    /// 不依赖超限触发，而是在每次检查时主动评估剩余预算
    async fn check_yolo_remaining(&self, daily_spent: f64, monthly_spent: f64) {
        let config = self.config.read().await;

        let daily_remaining = config.global_daily_limit_usd - daily_spent;
        let monthly_remaining = config.global_monthly_limit_usd - monthly_spent;

        // 条件 1：日预算剩余不足
        if daily_remaining < config.yolo_shutdown_remaining_usd {
            self.enforce_yolo_shutdown(&format!(
                "日预算剩余 ${:.2}，低于安全阈值 ${:.2}",
                daily_remaining, config.yolo_shutdown_remaining_usd
            ));
            return;
        }

        // 条件 2：月预算剩余不足日限额的 50%
        if monthly_remaining < config.global_daily_limit_usd * 0.5 {
            self.enforce_yolo_shutdown(&format!(
                "月预算剩余 ${:.2}，不足日限额一半",
                monthly_remaining
            ));
        }
    }
}
```

### 6.4 CostReportBuilder

```rust
// crates/agent-core/src/budget/report.rs（续）

pub struct CostReportBuilder {
    pool: SqlitePool,
}

impl CostReportBuilder {
    pub fn new(pool: &SqlitePool) -> Self {
        Self { pool: pool.clone() }
    }

    /// 生成指定时间范围的费用报表
    pub async fn build(
        &self,
        workspace_id: Option<&str>,
        period: ReportPeriod,
        config: &BudgetConfig,
    ) -> Result<CostReport> {
        let (from_ms, to_ms) = period.to_ms_range();

        // 并发查询各维度数据
        let (total, by_model, by_provider, daily_trend) = tokio::try_join!(
            self.query_total(workspace_id, from_ms, to_ms),
            self.query_by_model(workspace_id, from_ms, to_ms),
            self.query_by_provider(workspace_id, from_ms, to_ms),
            self.query_daily_trend(workspace_id, from_ms, to_ms),
        )?;

        // 计算百分比
        let by_model = by_model.into_iter().map(|mut m| {
            m.percentage = if total.cost_usd > 0.0 {
                m.cost_usd / total.cost_usd * 100.0
            } else { 0.0 };
            m
        }).collect();

        let by_provider = by_provider.into_iter().map(|mut p| {
            p.percentage = if total.cost_usd > 0.0 {
                p.cost_usd / total.cost_usd * 100.0
            } else { 0.0 };
            p
        }).collect();

        // 当日/当月预算使用情况
        let today_cost = self.query_today_cost(workspace_id).await?;
        let month_cost = self.query_month_cost(workspace_id).await?;

        Ok(CostReport {
            period,
            total_cost_usd: total.cost_usd,
            total_input_tokens: total.input_tokens,
            total_output_tokens: total.output_tokens,
            total_cached_tokens: total.cached_tokens,
            total_calls: total.call_count,
            by_model,
            by_provider,
            daily_trend,
            budget_usage: BudgetUsage {
                daily_spent_usd: today_cost,
                daily_limit_usd: config.global_daily_limit_usd,
                daily_ratio: today_cost / config.global_daily_limit_usd,
                monthly_spent_usd: month_cost,
                monthly_limit_usd: config.global_monthly_limit_usd,
                monthly_ratio: month_cost / config.global_monthly_limit_usd,
            },
        })
    }

    async fn query_total(
        &self,
        workspace_id: Option<&str>,
        from_ms: i64,
        to_ms: i64,
    ) -> Result<TotalCost> {
        let row = sqlx::query_as::<_, TotalCostRow>(
            "SELECT
                COALESCE(SUM(cost_usd), 0.0)       AS cost_usd,
                COALESCE(SUM(input_tokens), 0)      AS input_tokens,
                COALESCE(SUM(output_tokens), 0)     AS output_tokens,
                COALESCE(SUM(cached_tokens), 0)     AS cached_tokens,
                COUNT(*)                             AS call_count
             FROM cost_records
             WHERE recorded_at BETWEEN ? AND ?
               AND (? IS NULL OR workspace_id = ?)"
        )
        .bind(from_ms)
        .bind(to_ms)
        .bind(workspace_id)
        .bind(workspace_id)
        .fetch_one(&self.pool)
        .await?;
        Ok(row.into())
    }

    async fn query_by_model(
        &self,
        workspace_id: Option<&str>,
        from_ms: i64,
        to_ms: i64,
    ) -> Result<Vec<ModelCostBreakdown>> {
        let rows = sqlx::query_as::<_, ModelCostRow>(
            "SELECT model,
                    SUM(cost_usd) AS cost_usd,
                    SUM(input_tokens) AS input_tokens,
                    SUM(output_tokens) AS output_tokens,
                    SUM(cached_tokens) AS cached_tokens,
                    COUNT(*) AS call_count
             FROM cost_records
             WHERE recorded_at BETWEEN ? AND ?
               AND (? IS NULL OR workspace_id = ?)
             GROUP BY model
             ORDER BY cost_usd DESC"
        )
        .bind(from_ms)
        .bind(to_ms)
        .bind(workspace_id)
        .bind(workspace_id)
        .fetch_all(&self.pool)
        .await?;
        Ok(rows.into_iter().map(Into::into).collect())
    }

    async fn query_by_provider(
        &self,
        workspace_id: Option<&str>,
        from_ms: i64,
        to_ms: i64,
    ) -> Result<Vec<ProviderCostBreakdown>> {
        let rows = sqlx::query_as::<_, ProviderCostRow>(
            "SELECT provider,
                    SUM(cost_usd) AS cost_usd,
                    COUNT(*) AS call_count
             FROM cost_records
             WHERE recorded_at BETWEEN ? AND ?
               AND (? IS NULL OR workspace_id = ?)
             GROUP BY provider
             ORDER BY cost_usd DESC"
        )
        .bind(from_ms)
        .bind(to_ms)
        .bind(workspace_id)
        .bind(workspace_id)
        .fetch_all(&self.pool)
        .await?;
        Ok(rows.into_iter().map(Into::into).collect())
    }

    async fn query_daily_trend(
        &self,
        workspace_id: Option<&str>,
        from_ms: i64,
        to_ms: i64,
    ) -> Result<Vec<DailyCostEntry>> {
        // 从物化视图查询，避免全表 SUM
        let rows = sqlx::query_as::<_, DailyCostRow>(
            "SELECT date,
                    SUM(total_cost_usd) AS cost_usd,
                    SUM(total_input_tokens) AS input_tokens,
                    SUM(total_output_tokens) AS output_tokens,
                    SUM(call_count) AS call_count
             FROM daily_cost_summary
             WHERE date BETWEEN date(? / 1000, 'unixepoch') AND date(? / 1000, 'unixepoch')
               AND (? IS NULL OR workspace_id = ?)
             GROUP BY date
             ORDER BY date ASC"
        )
        .bind(from_ms)
        .bind(to_ms)
        .bind(workspace_id)
        .bind(workspace_id)
        .fetch_all(&self.pool)
        .await?;
        Ok(rows.into_iter().map(Into::into).collect())
    }

    async fn query_today_cost(&self, workspace_id: Option<&str>) -> Result<f64> {
        let cost: f64 = sqlx::query_scalar(
            "SELECT COALESCE(SUM(cost_usd), 0.0) FROM cost_records
             WHERE date(recorded_at / 1000, 'unixepoch') = date('now')
               AND (? IS NULL OR workspace_id = ?)"
        )
        .bind(workspace_id)
        .bind(workspace_id)
        .fetch_one(&self.pool)
        .await?;
        Ok(cost)
    }

    async fn query_month_cost(&self, workspace_id: Option<&str>) -> Result<f64> {
        let cost: f64 = sqlx::query_scalar(
            "SELECT COALESCE(SUM(cost_usd), 0.0) FROM cost_records
             WHERE strftime('%Y-%m', recorded_at / 1000, 'unixepoch') = strftime('%Y-%m', 'now')
               AND (? IS NULL OR workspace_id = ?)"
        )
        .bind(workspace_id)
        .bind(workspace_id)
        .fetch_one(&self.pool)
        .await?;
        Ok(cost)
    }
}
```

```rust
    from_date: Option<String>,
    to_date: Option<String>,
    state: State<'_, AppState>,
) -> Result<CostReport, String> {
    let period = match period_type.as_str() {
        "daily" => ReportPeriod::Daily {
            date: Utc::now().date_naive(),
        },
        "weekly" => {
            let today = Utc::now().date_naive();
            let start = today - chrono::Duration::days(6);
            ReportPeriod::Weekly { start, end: today }
        }
        "monthly" => {
            let now = Utc::now();
            ReportPeriod::Monthly {
                year: now.year(),
                month: now.month(),
            }
        }
        "custom" => {
            let from = NaiveDate::parse_from_str(
                &from_date.ok_or("custom 模式需要 from_date")?,
                "%Y-%m-%d"
            ).map_err(|e| e.to_string())?;
            let to = NaiveDate::parse_from_str(
                &to_date.ok_or("custom 模式需要 to_date")?,
                "%Y-%m-%d"
            ).map_err(|e| e.to_string())?;
            ReportPeriod::Custom { from, to }
        }
        _ => return Err(format!("不支持的报表周期类型: {}", period_type)),
    };

    let config = state.budget_manager.config.read().await;
    let builder = CostReportBuilder::new(&state.db_pool);
    let report = builder.build(workspace_id.as_deref(), period, &config)
        .await
        .map_err(|e| e.to_string())?;

    Ok(report)
}

    workspace_id: Option<String>,

) -> Result<ResetResult, String> {

            .bind(&workspace_id)

            .await
            .map_err(|e| e.to_string())?;

            // 同步清理日汇总
            sqlx::query(
                "DELETE FROM daily_cost_summary
                 WHERE date = date('now')
                   AND (? IS NULL OR workspace_id = ?)"
            )
            .bind(&workspace_id)
            .bind(&workspace_id)
            .execute(&state.db_pool)
            .await
            .map_err(|e| e.to_string())?;

            result.rows_affected()
        }
        "month" => {
            let result = sqlx::query(
                "DELETE FROM cost_records
                 WHERE strftime('%Y-%m', recorded_at / 1000, 'unixepoch') = strftime('%Y-%m', 'now')
                   AND (? IS NULL OR workspace_id = ?)"
            )
            .bind(&workspace_id)
            .bind(&workspace_id)
            .execute(&state.db_pool)
            .await
            .map_err(|e| e.to_string())?;

            sqlx::query(
                "DELETE FROM daily_cost_summary
                 WHERE date >= date('now', 'start of month')
                   AND (? IS NULL OR workspace_id = ?)"
            )
            .bind(&workspace_id)
            .bind(&workspace_id)
            .execute(&state.db_pool)
            .await
            .map_err(|e| e.to_string())?;

            result.rows_affected()
        }
        "all" => {
            let result = sqlx::query(
                "DELETE FROM cost_records WHERE (? IS NULL OR workspace_id = ?)"
            )
            .bind(&workspace_id)
            .bind(&workspace_id)
            .execute(&state.db_pool)
            .await
            .map_err(|e| e.to_string())?;

            sqlx::query(
                "DELETE FROM daily_cost_summary WHERE (? IS NULL OR workspace_id = ?)"
            )
            .bind(&workspace_id)
            .bind(&workspace_id)
            .execute(&state.db_pool)
            .await
            .map_err(|e| e.to_string())?;

            result.rows_affected()
        }
        _ => return Err(format!("不支持的重置范围: {}", scope)),
    };

    // 写入审计日志
    sqlx::query(
        "INSERT INTO audit_logs (id, action, details, created_at)
         VALUES (lower(hex(randomblob(16))), 'budget_reset', ?,

        "scope": scope,
        "workspace_id": workspace_id,
        "deleted_records": deleted,
    })).unwrap())
    .execute(&state.db_pool)
    .await
    .map_err(|e| e.to_string())?;

    Ok(ResetResult {
        deleted_records: deleted,
        scope,
    })
}

/// 获取预算告警列表
#[tauri::command]
pub async fn get_budget_alerts(
    state: State<'_, AppState>,
) -> Result<Vec<BudgetAlert>, String> {
    let summary = state.budget_manager
        .get_summary(None)
        .await
        .map_err(|e| e.to_string())?;
    let config = state.budget_manager.config.read().await;

    let mut alerts = vec![];

    let daily_ratio = summary.today_usd / summary.daily_limit_usd;
    let monthly_ratio = summary.this_month_usd / summary.monthly_limit_usd;

    if daily_ratio >= 1.0 {
        alerts.push(BudgetAlert {
            level: "error".into(),
            scope: "daily".into(),
            message: format!(
                "今日花费 ${:.2} 已超出每日限额 ${:.2}",
                summary.today_usd, summary.daily_limit_usd
            ),
        });
    } else if daily_ratio >= config.critical_threshold {
        alerts.push(BudgetAlert {
            level: "warning".into(),
            scope: "daily".into(),
            message: format!(
                "今日花费 ${:.2}，已达每日限额的 {:.0}%",
                summary.today_usd, daily_ratio * 100.0
            ),
        });
    }

    if monthly_ratio >= 1.0 {
        alerts.push(BudgetAlert {
            level: "error".into(),
            scope: "monthly".into(),
            message: format!(
                "本月花费 ${:.2} 已超出每月限额 ${:.2}",
                summary.this_month_usd, summary.monthly_limit_usd
            ),
        });
    } else if monthly_ratio >= config.critical_threshold {
        alerts.push(BudgetAlert {
            level: "warning".into(),
            scope: "monthly".into(),
            message: format!(
                "本月花费 ${:.2}，已达每月限额的 {:.0}%",
                summary.this_month_usd, monthly_ratio * 100.0
            ),
        });
    }

    Ok(alerts)
}

    pub level: String,    // "warning" | "error"
    pub scope: String,    // "daily" | "monthly" | "workspace"
```

```rust
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```
