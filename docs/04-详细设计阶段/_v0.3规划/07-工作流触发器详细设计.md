# 工作流触发器详细设计

> v0.3 精简版 | 状态：规划中 | 原始设计已精简，保留 MVP 核心

---

## 1. 设计定位

v0.3 的触发器系统仅支持两种触发方式：

1. **手动触发** -- 用户点击"运行"按钮
2. **Cron 定时触发** -- 标准 cron 表达式 + 时区

所有触发最终调用同一入口：`ChainExecutor::run(chain, input)`。

## 2. 数据结构

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct WorkflowTrigger {
    pub id: String,
    pub workflow_id: String,
    pub workspace_id: String,
    pub trigger_type: TriggerType,       // manual | cron
    pub config: Value,                   // CronConfig 或空
    pub enabled: bool,
    pub last_fired_at: Option<i64>,
    pub fire_count: u32,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum TriggerType { Manual, Cron }

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct CronConfig {
    pub expression: String,              // "0 9 * * 1-5"
    pub timezone: String,                // "Asia/Shanghai"
}
```

## 3. Cron 定时触发

```rust
pub struct TriggerManager {
    pool: SqlitePool,
    chain_executor: Arc<ChainExecutor>,
    cron_handles: RwLock<HashMap<String, JoinHandle<()>>>,
}

impl TriggerManager {
    pub async fn start(&self) -> anyhow::Result<()> {
        for trigger in self.list_enabled_cron().await? {
            self.arm_cron(&trigger).await?;
        }
        Ok(())
    }

    async fn arm_cron(&self, trigger: &WorkflowTrigger) -> anyhow::Result<()> {
        let config: CronConfig = serde_json::from_value(trigger.config.clone())?;
        let trigger_id = trigger.id.clone();
        let workflow_id = trigger.workflow_id.clone();
        let pool = self.pool.clone();
        let executor = self.chain_executor.clone();

        let handle = tokio::spawn(async move {
            loop {
                let next = compute_next_run(&config.expression, &config.timezone);
                let delay = Duration::from_millis((next - now_ms()).max(0) as u64);
                tokio::time::sleep(delay).await;
                record_fire(&pool, &trigger_id).await.ok();
                if let Ok(chain) = load_chain(&pool, &workflow_id).await {
                    let ok = executor.run(&chain, Value::Null).await.is_ok();
                    record_result(&pool, &trigger_id, ok).await.ok();
                }
            }
        });
        self.cron_handles.write().await.insert(trigger.id.clone(), handle);
        Ok(())
    }

    pub async fn shutdown(&self) {
        for (_, h) in self.cron_handles.write().await.drain() { h.abort(); }
    }
}

fn compute_next_run(expr: &str, tz_str: &str) -> i64 {
    let tz: chrono_tz::Tz = tz_str.parse().unwrap_or(chrono_tz::Asia::Shanghai);
    let schedule = cron::Schedule::from_str(expr).expect("invalid cron");
    schedule.after(&chrono::Utc::now().with_timezone(&tz)).next()
        .map(|t| t.timestamp_millis()).unwrap_or(i64::MAX)
}
```

## 4. 触发历史记录

```sql
CREATE TABLE IF NOT EXISTS workflow_triggers (
    id            TEXT PRIMARY KEY,
    workflow_id   TEXT NOT NULL,
    workspace_id  TEXT NOT NULL,
    trigger_type  TEXT NOT NULL CHECK(trigger_type IN ('manual', 'cron')),
    config        TEXT NOT NULL DEFAULT '{}',
    enabled       INTEGER NOT NULL DEFAULT 1,
    last_fired_at INTEGER,
    fire_count    INTEGER NOT NULL DEFAULT 0,
    created_at    INTEGER NOT NULL DEFAULT (unixepoch('now','subsec')*1000)
);

CREATE TABLE IF NOT EXISTS trigger_fire_history (
    id         TEXT PRIMARY KEY,
    trigger_id TEXT NOT NULL REFERENCES workflow_triggers(id) ON DELETE CASCADE,
    fired_at   INTEGER NOT NULL,
    success    INTEGER,
    error      TEXT
);
```

## 5. Tauri Commands（3 个）

```rust
#[tauri::command]
pub async fn create_trigger(state: State<'_, AppState>,
    workflow_id: String, workspace_id: String, trigger_type: String, config: Value,
) -> Result<String, AppError> {
    let id = format!("trig-{}", uuid::Uuid::new_v4());
    sqlx::query!("INSERT INTO workflow_triggers (id, workflow_id, workspace_id, trigger_type, config) VALUES (?,?,?,?,?)",
        id, workflow_id, workspace_id, trigger_type, config
    ).execute(&state.db_pool).await?;
    if trigger_type == "cron" { state.trigger_manager.arm_cron_by_id(&id).await?; }
    Ok(id)
}

#[tauri::command]
pub async fn delete_trigger(state: State<'_, AppState>, trigger_id: String) -> Result<(), AppError> {
    state.trigger_manager.disarm(&trigger_id).await;
    sqlx::query!("DELETE FROM workflow_triggers WHERE id=?", trigger_id).execute(&state.db_pool).await?;
    Ok(())
}

#[tauri::command]
pub async fn list_triggers(state: State<'_, AppState>, workflow_id: String) -> Result<Vec<WorkflowTrigger>, AppError> {
    Ok(sqlx::query_as!(WorkflowTrigger, "SELECT * FROM workflow_triggers WHERE workflow_id=?", workflow_id)
        .fetch_all(&state.db_pool).await?)
}
```
