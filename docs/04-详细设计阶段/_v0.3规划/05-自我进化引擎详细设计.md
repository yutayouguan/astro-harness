# 自我进化引擎详细设计（EvolutionEngine）

> v0.3 精简版 | 状态：规划中 | 原始设计已精简，保留 MVP 核心

---

## 1. 设计定位

自我进化引擎负责从任务执行轨迹中提取可复用模式，辅助用户将成功的对话/任务沉淀为 Skill。v0.3 聚焦两个核心能力：

1. **任务完成后的简单反思** -- LLM 生成一段改进建议
2. **保存为 Skill** -- 用户手动触发，从成功对话中提取 SKILL.md

所有自动生成的 Skill 必须经过用户确认后才能激活（进化审批）。

---

## 2. TaskTrace 数据模型

TaskTrace 记录每次任务的完整执行轨迹，是进化引擎的数据基础。

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TaskTrace {
    pub trace_id: String,
    pub workspace_id: String,
    pub task: String,                    // 用户原始输入
    pub steps: Vec<TaskStep>,            // 执行步骤序列
    pub outcome: TaskOutcome,            // 最终结果
    pub metrics: TaskMetrics,            // 执行指标
    pub created_at: i64,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TaskStep {
    pub action: StepAction,
    pub result: StepResult,
    pub duration_ms: u64,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum StepAction {
    ToolCall { name: String, params: Value },
    LlmCall { model: String },
    SkillInvocation { skill_name: String },
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum TaskOutcome {
    Success { summary: String },
    Failure { error: String },
    Partial { summary: String, issues: Vec<String> },
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TaskMetrics {
    pub total_duration_ms: u64,
    pub token_cost: u64,
    pub tools_used: Vec<String>,
    pub quality_score: Option<f32>,
}
```

```sql
CREATE TABLE IF NOT EXISTS task_traces (
    id            TEXT PRIMARY KEY,
    workspace_id  TEXT NOT NULL REFERENCES workspaces(id) ON DELETE CASCADE,
    task          TEXT NOT NULL,
    steps_json    TEXT NOT NULL,
    outcome       TEXT NOT NULL,
    metrics_json  TEXT NOT NULL,
    created_at    INTEGER NOT NULL DEFAULT (unixepoch('now','subsec')*1000)
);
CREATE INDEX IF NOT EXISTS idx_traces_ws ON task_traces(workspace_id, created_at DESC);
```

## 3. 简单反思：任务完成后生成改进建议

每次任务完成后，LLM 生成一段简短的改进建议（2-4 句话），存入 `evolution_log` 表。不做自动优化，仅供用户参考。

```rust
pub struct TaskReflector {
    provider: Arc<dyn TextClient>,
}

impl TaskReflector {
    pub async fn reflect(&self, trace: &TaskTrace) -> anyhow::Result<String> {
        let prompt = format!(
            "分析以下任务执行记录，给出一段简短改进建议（2-4 句话）。\n\n\
             任务: {}\n步骤: {:?}\n结果: {:?}\n耗时: {}ms",
            trace.task, trace.steps, trace.outcome, trace.metrics.total_duration_ms,
        );
        self.provider.generate(&prompt).await
    }
}
```

```sql
CREATE TABLE IF NOT EXISTS evolution_log (
    id            TEXT PRIMARY KEY,
    workspace_id  TEXT NOT NULL,
    action_type   TEXT NOT NULL,       -- 'reflect' | 'create_skill'
    payload       TEXT NOT NULL,       -- JSON
    status        TEXT NOT NULL,       -- 'applied' | 'pending_approval' | 'rejected'
    approved_by   TEXT,
    created_at    INTEGER NOT NULL DEFAULT (unixepoch('now','subsec')*1000)
);
```

## 4. 保存为 Skill：从成功对话提取 SKILL.md

用户在任务完成后可点击"保存为 Skill"按钮，触发 SkillSynthesizer 从轨迹中提取 SKILL.md。

```rust
pub struct SkillSynthesizer {
    provider: Arc<dyn TextClient>,
}

pub struct SynthesizedSkill {
    pub name: String,
    pub content: String,           // 完整 SKILL.md
    pub source_trace_id: String,
}

impl SkillSynthesizer {
    pub async fn synthesize_from_trace(
        &self,
        trace: &TaskTrace,
    ) -> anyhow::Result<SynthesizedSkill> {
        let prompt = format!(
            "根据以下成功任务的执行记录，生成可复用的 SKILL.md。\n\
             包含 YAML frontmatter（name, version, description, trigger_patterns, tags, \
             origin: user_saved, status: draft）和 Markdown 正文。\n\n\
             任务: {}\n步骤: {:?}",
            trace.task, trace.steps,
        );
        let content = self.provider.generate(&prompt).await?;
        let name = extract_skill_name(&content)?;
        Ok(SynthesizedSkill { name, content, source_trace_id: trace.trace_id.clone() })
    }
}
```

## 5. 进化审批：用户确认机制

所有自动生成的 Skill 必须经用户确认才能注册到 SkillRegistry：

```text
用户点击"保存为 Skill"
  → LLM 生成 SKILL.md 草稿
  → 写入 evolution_log（status = pending_approval）
  → 前端弹出预览面板
  → 用户"确认" → 注册 Skill（status = applied）
  → 用户"拒绝" → status = rejected
```

```rust
impl EvolutionEngine {
    pub async fn approve_skill(&self, log_id: &str, workspace_id: &str) -> anyhow::Result<String> {
        let log = self.log_repo.get(log_id).await?;
        let synthesized: SynthesizedSkill = serde_json::from_str(&log.payload)?;

        // 写入文件 + 注册
        let skill_dir = self.skill_dir(workspace_id);
        tokio::fs::create_dir_all(&skill_dir).await?;
        let file_path = skill_dir.join(format!("{}.md", synthesized.name));
        tokio::fs::write(&file_path, &synthesized.content).await?;

        let manifest = SkillManifest::from_markdown(&synthesized.content, &file_path)?;
        self.skill_repo.insert(&manifest).await?;
        self.registry.write().await.update(manifest.clone(), &synthesized.content);
        self.log_repo.update_status(log_id, "applied", Some("user")).await?;
        Ok(manifest.id)
    }

    pub async fn reject_skill(&self, log_id: &str) -> anyhow::Result<()> {
        self.log_repo.update_status(log_id, "rejected", Some("user")).await
    }
}
```

## 6. EvolutionEngine 主结构

```rust
pub struct EvolutionEngine {
    provider: Arc<dyn TextClient>,
    skill_repo: SkillRepo,
    registry: Arc<RwLock<SkillRegistry>>,
    log_repo: EvolutionLogRepo,
    reflector: TaskReflector,
    synthesizer: SkillSynthesizer,
}

impl EvolutionEngine {
    /// 任务完成后触发反思（异步，不阻塞用户）
    pub async fn on_task_completed(&self, trace: &TaskTrace) -> anyhow::Result<()> {
        let reflection = self.reflector.reflect(trace).await?;
        self.log_repo.insert(&EvolutionLogEntry {
            id: Uuid::new_v4().to_string(),
            workspace_id: trace.workspace_id.clone(),
            action_type: "reflect".to_string(),
            payload: json!({ "trace_id": trace.trace_id, "reflection": reflection }).to_string(),
            status: "applied".to_string(),
            approved_by: None,
        }).await
    }

    /// 用户触发"保存为 Skill"，返回 log_id 供前端展示预览
    pub async fn save_as_skill(&self, trace: &TaskTrace) -> anyhow::Result<String> {
        let result = self.synthesizer.synthesize_from_trace(trace).await?;
        let log_id = Uuid::new_v4().to_string();
        self.log_repo.insert(&EvolutionLogEntry {
            id: log_id.clone(),
            workspace_id: trace.workspace_id.clone(),
            action_type: "create_skill".to_string(),
            payload: serde_json::to_string(&result)?,
            status: "pending_approval".to_string(),
            approved_by: None,
        }).await?;
        Ok(log_id)
    }
}
```
