### 1.2 更新流程总览

完整的更新生命周期分为五个阶段，每个阶段均可被用户中断或跳过：

```text
┌─────────────────────────────────────────────────────────────────────┐
│                     更新生命周期（F-27）                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   ① Check（检查）                                                   │
│   │  定时 / 手动触发 → 根据 channel 选择端点                         │
│   │  GET /latest.json 或 /beta.json                                │
│   │  比较 remote.version vs local.version                           │
│   │                                                                 │
│   ▼                                                                 │
│   ② Download（下载）                                                │
│   │  获取 Content-Length → 预检磁盘空间                              │
│   │  流式下载 → 进度事件 → 断点续传                                  │
│   │                                                                 │
│   ▼                                                                 │
│   ③ Verify（验签）                                                  │
│   │  Ed25519 签名校验（Tauri pubkey）                               │
│   │  校验失败 → 删除下载文件 → 报错                                  │
│   │                                                                 │
│   ▼                                                                 │
│   ④ Stage（暂存）                                                   │
│   │  将验证通过的安装包放入暂存目录                                   │
│   │  标记 pending_update 状态                                       │
│   │                                                                 │
│   ▼                                                                 │
│   ⑤ Install + Restart（安装并重启）                                 │
│      用户主动重启 → 应用安装包 → 启动新版本                           │
│      或立即重启（用户授权时）                                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

```rust
    pub notes: String,
```

## 2. 更新检查策略

### 2.1 检查触发方式

| 触发方式 | 时机 | 行为 |
|---------|------|------|
| 启动检查 | 应用启动 30 秒后 | 静默检查，仅在发现更新时通知 |
| 定期检查 | 每 6 小时 | 后台轮询，不打扰用户工作 |
| 手动检查 | 用户点击"检查更新" | 立即检查，无论定时器状态 |
| 强制检查 | 应用从后台恢复 | 若距上次检查超过 6 小时则触发 |

### 2.2 定期检查实现

```rust
// apps/desktop/src-tauri/src/updater/scheduler.rs

use std::sync::atomic::{AtomicI64, Ordering};
use tokio::time::{interval, Duration};

/// 上次成功检查的时间戳（Unix 秒）
static LAST_CHECK: AtomicI64 = AtomicI64::new(0);

const CHECK_INTERVAL: Duration = Duration::from_secs(6 * 3600); // 6 小时

pub async fn start_periodic_check(app: AppHandle) {
    let mut ticker = interval(CHECK_INTERVAL);
    ticker.tick().await; // 首次立即触发

    loop {
        ticker.tick().await;
        if let Err(e) = do_check(&app).await {
            tracing::warn!("定期更新检查失败: {e}");
        }
    }
}

pub async fn do_check(app: &AppHandle) -> Result<Option<UpdateInfo>, anyhow::Error> {
    let updater = app.updater()?;
    let result = updater.check().await?;

    LAST_CHECK.store(chrono::Utc::now().timestamp(), Ordering::Relaxed);

    match result {
        Some(update) => {
            let info = UpdateInfo {
                version: update.version.clone(),
                notes: update.body.clone().unwrap_or_default(),
                pub_date: update.date.map(|d| d.to_string()),
                is_critical: is_critical_update(&update.body),
                is_downgrade: false,
            };
            app.emit("update-state-changed", UpdateState::Available(info.clone()))?;
            Ok(Some(info))
        }
        None => Ok(None),
    }
}

/// 解析 release notes 中的 [CRITICAL] 标记
fn is_critical_update(notes: &Option<String>) -> bool {
    notes.as_deref().map_or(false, |n| n.contains("[CRITICAL]"))
}

/// 判断是否应该立即检查（从后台恢复时调用）
pub fn should_check_now() -> bool {
    let last = LAST_CHECK.load(Ordering::Relaxed);
    let now = chrono::Utc::now().timestamp();
    now - last > CHECK_INTERVAL.as_secs() as i64
}
```

### 2.3 通道感知端点选择

应用根据用户配置的更新通道，动态选择检查端点。通道配置存储于 `agent.toml`，运行时通过环境变量或配置 API 读取：

```rust
// apps/desktop/src-tauri/src/updater/channel.rs

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum UpdateChannel {
    Stable,
    Beta,
    Nightly,
}

impl UpdateChannel {
    /// 返回该通道对应的 latest.json 端点 URL
    pub fn endpoint_url(&self) -> &'static str {
        match self {
            Self::Stable  => "https://releases.astro-agent.dev/latest.json",
            Self::Beta    => "https://releases.astro-agent.dev/beta.json",
            Self::Nightly => "https://releases.astro-agent.dev/nightly.json",
        }
    }

    /// 从用户配置加载通道设置
    pub fn from_config(config: &AgentConfig) -> Self {
        match config.updater.channel.as_str() {
            "beta"    => Self::Beta,
            "nightly" => Self::Nightly,
            _         => Self::Stable,
        }
    }
}
```

## 3. 增量下载

### 3.1 下载策略

Tauri Updater v2 默认执行全量替换下载（完整安装包）。为优化用户体验，在 Tauri 原生下载流程之上增加预检和断点续传逻辑：

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 全量下载 | 下载完整安装包（.dmg / .exe / .AppImage） | 默认方式，所有平台 |
| 预检 Content-Length | 下载前检查文件大小，预估时间 | 带宽敏感场景 |
| 断点续传 | 网络中断后从上次位置继续 | 不稳定网络 |

### 3.2 预检与带宽友好下载

```rust
// apps/desktop/src-tauri/src/updater/download.rs

use reqwest::header::{CONTENT_LENGTH, RANGE};
use std::path::PathBuf;
use tokio::io::AsyncWriteExt;

/// 下载预检：获取文件大小并检查磁盘空间
pub async fn preflight_check(url: &str) -> Result<DownloadPreflight, anyhow::Error> {
    let resp = reqwest::Client::new()
        .head(url)
        .send()
        .await?;

    let content_length = resp
        .headers()
        .get(CONTENT_LENGTH)
        .and_then(|v| v.to_str().ok())
        .and_then(|v| v.parse::<u64>().ok())
        .unwrap_or(0);

    let download_dir = download_staging_dir()?;
    let available_space = fs2::available_space(&download_dir)?;

    Ok(DownloadPreflight {
        file_size: content_length,
        available_space,
        has_enough_space: available_space > content_length * 2, // 保留 2 倍空间
        supports_resume: resp.headers().contains_key("accept-ranges"),
    })
}

#[derive(Debug, Serialize)]
pub struct DownloadPreflight {
    pub file_size: u64,
    pub available_space: u64,
    pub has_enough_space: bool,
    pub supports_resume: bool,
}
```

### 3.3 断点续传实现

```rust
// apps/desktop/src-tauri/src/updater/download.rs（续）

/// 支持断点续传的下载器
pub async fn download_with_resume(
    url: &str,
    dest: &PathBuf,
    app: &AppHandle,
) -> Result<(), anyhow::Error> {
    let client = reqwest::Client::new();

    // 检查是否有未完成的下载（.part 文件）
    let part_file = dest.with_extension("part");
    let existing_size = if part_file.exists() {
        tokio::fs::metadata(&part_file).await?.len()
    } else {
        0
    };

    let mut request = client.get(url);
    if existing_size > 0 {
        tracing::info!("从 {} 字节处续传下载", existing_size);
        request = request.header(RANGE, format!("bytes={}-", existing_size));
    }

    let resp = request.send().await?;
    let total_size = resp.content_length().unwrap_or(0) + existing_size;

    let mut file = tokio::fs::OpenOptions::new()
        .create(true)
        .append(true)
        .open(&part_file)
        .await?;

    let mut downloaded = existing_size;
    let mut stream = resp.bytes_stream();

    use futures_util::StreamExt;
    while let Some(chunk) = stream.next().await {
        let chunk = chunk?;
        file.write_all(&chunk).await?;
        downloaded += chunk.len() as u64;

        let progress = if total_size > 0 {
            downloaded as f32 / total_size as f32 * 100.0
        } else {
            0.0
        };

        app.emit("update-state-changed", UpdateState::Downloading {
            version: String::new(), // 由调用方填充
            progress,
        })?;
    }

    file.flush().await?;

    // 下载完成，重命名 .part → 最终文件
    tokio::fs::rename(&part_file, dest).await?;
    Ok(())
}
```

### 3.4 进度追踪

前端通过 Tauri 事件监听下载进度，展示进度条和预计剩余时间：

```typescript
// apps/desktop/src/hooks/useUpdateProgress.ts

import { listen } from "@tauri-apps/api/event";
import { useState, useEffect, useRef } from "react";

interface DownloadProgress {
  percent: number;
  estimatedRemaining: string; // "约 2 分钟"
}

export function useUpdateProgress(): DownloadProgress | null {
  const [progress, setProgress] = useState<DownloadProgress | null>(null);
  const startTime = useRef<number>(Date.now());

  useEffect(() => {
    const unlisten = listen<{ progress: number }>("update-state-changed", (e) => {
      const payload = e.payload as any;
      if (payload.kind !== "Downloading") return;

      const percent = payload.data.progress;
      const elapsed = (Date.now() - startTime.current) / 1000;
      const rate = percent / elapsed; // %/秒
      const remaining = rate > 0 ? (100 - percent) / rate : 0;

      setProgress({
        percent,
        estimatedRemaining: formatDuration(remaining),
      });
    });

    return () => { unlisten.then((fn) => fn()); };
  }, []);

  return progress;
}

function formatDuration(seconds: number): string {
  if (seconds < 60) return `约 ${Math.ceil(seconds)} 秒`;
  return `约 ${Math.ceil(seconds / 60)} 分钟`;
}
```

## 4. 用户通知与交互

### 4.1 UpdateNotification 组件

更新通知组件根据 `UpdateState` 状态机展示三种视图：发现更新、下载中、准备安装。

```typescript
// apps/desktop/src/components/shared/UpdateNotification.tsx

import { invoke } from "@tauri-apps/api/core";
import { listen } from "@tauri-apps/api/event";
import { useState, useEffect } from "react";
import { useUpdateProgress } from "@/hooks/useUpdateProgress";

type UpdateState =
  | { kind: "Idle" }
  | { kind: "Checking" }
  | { kind: "Available"; data: UpdateInfo }
  | { kind: "Downloading"; data: { version: string; progress: number } }
  | { kind: "Ready"; data: { version: string } }
  | { kind: "Error"; data: { message: string } };

interface UpdateInfo {
  version: string;
  notes: string;
  pub_date: string | null;
  is_critical: boolean;
  is_downgrade: boolean;
}

export function UpdateNotification() {
  const [state, setState] = useState<UpdateState>({ kind: "Idle" });
  const progress = useUpdateProgress();

  useEffect(() => {
    const unlisten = listen<UpdateState>("update-state-changed", (e) => {
      setState(e.payload);
    });
    return () => { unlisten.then((fn) => fn()); };
  }, []);

  if (state.kind === "Idle" || state.kind === "Checking") return null;

  return (
    <div className="fixed bottom-4 right-4 w-96 rounded-lg border bg-card p-4 shadow-lg">
      {state.kind === "Available" && (
        <AvailableView info={state.data} />
      )}
      {state.kind === "Downloading" && (
        <DownloadingView version={state.data.version} progress={progress} />
      )}
      {state.kind === "Ready" && (
        <ReadyView version={state.data.version} />
      )}
      {state.kind === "Error" && (
        <ErrorView message={state.data.message} />
      )}
    </div>
  );
}
```

### 4.3 版本跳过持久化

用户选择"跳过此版本"后，将该版本号写入本地配置，后续检查时自动忽略：

```rust
// apps/desktop/src-tauri/src/updater/skip.rs

use std::collections::HashSet;
use std::path::PathBuf;

const SKIP_FILE: &str = "skipped_versions.json";

pub fn skipped_versions(data_dir: &PathBuf) -> HashSet<String> {
    let path = data_dir.join(SKIP_FILE);
    std::fs::read_to_string(&path)
        .ok()
        .and_then(|s| serde_json::from_str(&s).ok())
        .unwrap_or_default()
}

pub fn add_skipped_version(data_dir: &PathBuf, version: &str) -> anyhow::Result<()> {
    let mut set = skipped_versions(data_dir);
    set.insert(version.to_string());
    let json = serde_json::to_string_pretty(&set)?;
    std::fs::write(data_dir.join(SKIP_FILE), json)?;
    Ok(())
}

/// 关键安全更新不可跳过 — 即使版本在跳过列表中也会提示
pub fn should_notify(version: &str, is_critical: bool, data_dir: &PathBuf) -> bool {
    if is_critical {
        return true;
    }
    !skipped_versions(data_dir).contains(version)
}
```

## 5. 后台安装

### 5.1 下载与暂存流程

更新包在后台线程中下载，不阻塞用户操作。下载完成后进入暂存状态，等待用户触发安装：

```rust
// apps/desktop/src-tauri/src/updater/commands.rs

use tauri_plugin_updater::UpdaterExt;

#[tauri::command]
pub async fn download_update(app: AppHandle) -> Result<(), String> {
    let updater = app.updater().map_err(|e| e.to_string())?;

    let update = updater.check().await
        .map_err(|e| e.to_string())?
        .ok_or("没有可用更新")?;

    let version = update.version.clone();
    let app_clone = app.clone();

    // 后台下载，通过事件推送进度
    update.download_and_install(
        move |downloaded, total| {
            let progress = total.map(|t| downloaded as f32 / t as f32 * 100.0).unwrap_or(0.0);
            app_clone.emit("update-state-changed", UpdateState::Downloading {
                version: version.clone(),
                progress,
            }).ok();
        },
        || {
            // 下载完成，Tauri 已验证签名
            tracing::info!("更新下载完成，签名验证通过");
        },
    )
    .await
    .map_err(|e| e.to_string())?;

    // 标记 Ready 状态（Tauri 会在下次重启时应用）
    app.emit("update-state-changed", UpdateState::Ready {
        version: update.version.clone(),
    }).map_err(|e| e.to_string())?;

    Ok(())
}
```

### 5.2 签名验证

Tauri Updater 使用 Ed25519 算法验证安装包签名。公钥编译进客户端，私钥仅存在于 CI/CD 环境的 GitHub Secrets 中：

```json
// apps/desktop/src-tauri/tauri.conf.json（摘要）
{
  "plugins": {
    "updater": {
      "pubkey": "dW50cnVzdGVkIGNvbW1lbnQ6...",
      "endpoints": ["https://releases.astro-agent.dev/latest.json"],
      "dialog": false
    }
  }
}
```

验证流程由 Tauri 内部完成：下载文件后，从 `latest.json` 中读取对应平台的 `signature` 字段，使用内置公钥校验。校验失败时抛出错误，前端捕获后展示 `Error` 状态。

### 5.3 安装与重启

用户确认后触发安装。Tauri 在各平台的行为：

| 平台 | 安装行为 | 重启方式 |
|------|---------|---------|
| macOS | 替换 `.app` bundle | `tauri::process::restart` |
| Windows | 运行 NSIS/MSI 安装器 | 安装器自动重启 |
| Linux | 替换 AppImage / 运行 deb 安装 | `tauri::process::restart` |

```rust
#[tauri::command]

        .map_err(|e| e.to_string())?;

    tauri::process::restart(&app.env());
}
```

```text
            │
```

### 6.2 兼容性检查逻辑

```rust
// crates/agent-core/src/plugins/compatibility.rs

use semver::{Version, VersionReq};

pub struct CompatibilityChecker {
    target_version: Version,
}

#[derive(Debug, Serialize)]
pub struct CompatReport {
    pub compatible: Vec<PluginStatus>,
    pub incompatible: Vec<PluginStatus>,
    pub unknown: Vec<PluginStatus>,
}

#[derive(Debug, Serialize)]
pub struct PluginStatus {
    pub name: String,
    pub current_version: String,
    pub required_agent_version: String,
    pub migration_hint: Option<String>,
}

impl CompatibilityChecker {
    pub fn new(target_version: Version) -> Self {
        Self { target_version }
    }

    pub fn check_all(&self, plugins: &[InstalledPlugin]) -> CompatReport {
        let mut report = CompatReport {
            compatible: Vec::new(),
            incompatible: Vec::new(),
            unknown: Vec::new(),
        };

        for plugin in plugins {
            let status = PluginStatus {
                name: plugin.manifest.name.clone(),
                current_version: plugin.manifest.version.clone(),
                required_agent_version: plugin.manifest.compatibility
                    .min_agent_version.clone(),
                migration_hint: plugin.manifest.compatibility
                    .migration_hint.clone(),
            };

            match VersionReq::parse(&plugin.manifest.compatibility.min_agent_version) {
                Ok(req) if req.matches(&self.target_version) => {
                    report.compatible.push(status);
                }
                Ok(_) => {
                    report.incompatible.push(status);
                }
                Err(_) => {
                    report.unknown.push(status);
                }
            }
        }

        report
    }
}
```

## 7. 回滚支持

### 7.1 版本备份策略

每次成功安装新版本前，将当前版本的关键信息备份到本地数据目录，以支持回滚：

```rust
// apps/desktop/src-tauri/src/updater/rollback.rs

use std::path::PathBuf;

const ROLLBACK_DIR: &str = "rollback";
const CRASH_COUNTER_FILE: &str = "crash_counter.json";
const MAX_CRASH_COUNT: u32 = 3;

#[derive(Debug, Serialize, Deserialize)]
pub struct RollbackMeta {
    pub previous_version: String,
    pub backup_path: PathBuf,
    pub backed_up_at: String,
}

/// 更新前备份当前版本信息
pub fn backup_current_version(app: &AppHandle) -> Result<(), anyhow::Error> {
    let data_dir = app.path().app_data_dir()?;
    let rollback_dir = data_dir.join(ROLLBACK_DIR);
    std::fs::create_dir_all(&rollback_dir)?;

    let current_version = env!("CARGO_PKG_VERSION");

    let meta = RollbackMeta {
        previous_version: current_version.to_string(),
        backup_path: rollback_dir.clone(),
        backed_up_at: chrono::Utc::now().to_rfc3339(),
    };

    let meta_path = rollback_dir.join("rollback_meta.json");
    std::fs::write(&meta_path, serde_json::to_string_pretty(&meta)?)?;

    // 重置崩溃计数器
    reset_crash_counter(&data_dir)?;

    tracing::info!("已备份当前版本 v{} 用于回滚", current_version);
    Ok(())
}
```

### 7.2 启动崩溃检测

应用启动时记录一次启动计数，正常运行超过 60 秒后清零。若连续 3 次启动在 60 秒内崩溃，判定新版本不稳定，自动触发回滚：

```rust
// apps/desktop/src-tauri/src/updater/rollback.rs（续）

#[derive(Debug, Serialize, Deserialize, Default)]
pub struct CrashCounter {
    pub count: u32,
    pub last_start: String,
}

/// 启动时调用：递增崩溃计数器
pub fn record_startup(data_dir: &PathBuf) -> Result<CrashAction, anyhow::Error> {
    let counter_path = data_dir.join(CRASH_COUNTER_FILE);
    let mut counter: CrashCounter = std::fs::read_to_string(&counter_path)
        .ok()
        .and_then(|s| serde_json::from_str(&s).ok())
        .unwrap_or_default();

    counter.count += 1;
    counter.last_start = chrono::Utc::now().to_rfc3339();
    std::fs::write(&counter_path, serde_json::to_string(&counter)?)?;

    if counter.count >= MAX_CRASH_COUNT {
        tracing::error!("连续 {} 次启动崩溃，触发自动回滚", counter.count);
        return Ok(CrashAction::Rollback);
    }

    Ok(CrashAction::Continue)
}

/// 稳定运行 60 秒后调用：清零崩溃计数器
pub fn mark_stable(data_dir: &PathBuf) -> Result<(), anyhow::Error> {
    reset_crash_counter(data_dir)
}

fn reset_crash_counter(data_dir: &PathBuf) -> Result<(), anyhow::Error> {
    let counter = CrashCounter { count: 0, last_start: String::new() };
    let path = data_dir.join(CRASH_COUNTER_FILE);
    std::fs::write(&path, serde_json::to_string(&counter)?)?;
    Ok(())
}

pub enum CrashAction {
    Continue,
    Rollback,
}
```

### 7.3 自动回滚执行

```rust
// apps/desktop/src-tauri/src/updater/rollback.rs（续）

/// 执行回滚：通知用户并引导至前一版本
pub fn execute_rollback(app: &AppHandle) -> Result<(), anyhow::Error> {
    let data_dir = app.path().app_data_dir()?;
    let rollback_dir = data_dir.join(ROLLBACK_DIR);
    let meta_path = rollback_dir.join("rollback_meta.json");

    let meta: RollbackMeta = serde_json::from_str(
        &std::fs::read_to_string(&meta_path)?
    )?;

    tracing::warn!(
        "正在回滚到 v{} (从 {})",
        meta.previous_version,
        meta.backed_up_at
    );

    // 通知前端显示回滚提示
    app.emit("rollback-triggered", &meta)?;

    // 重置崩溃计数器，避免回滚后再次触发
    reset_crash_counter(&data_dir)?;

    // 平台相关的回滚操作由 Tauri Updater 清单驱动：
    // 将 latest.json 本地缓存指向前一版本，触发"降级更新"
    // 参见 05-CICD与发布详细设计.md 第 10.3 节

    Ok(())
}
```

### 7.4 启动时回滚检测集成

```rust
// apps/desktop/src-tauri/src/lib.rs（setup 钩子中）

.setup(|app| {
    let data_dir = app.path().app_data_dir()?;

    // 1. 检查是否需要自动回滚
    match rollback::record_startup(&data_dir)? {
        rollback::CrashAction::Rollback => {
            rollback::execute_rollback(&app.handle())?;
            return Ok(());
        }
        rollback::CrashAction::Continue => {}
    }

    // 2. 启动 60 秒后标记为稳定
    let dir = data_dir.clone();
    tauri::async_runtime::spawn(async move {
        tokio::time::sleep(std::time::Duration::from_secs(60)).await;
        rollback::mark_stable(&dir).ok();
    });

    // 3. 启动定期更新检查
    let handle = app.handle().clone();
    tauri::async_runtime::spawn(async move {
        tokio::time::sleep(std::time::Duration::from_secs(30)).await;
        updater::start_periodic_check(handle).await;
    });

    Ok(())
})
```

### 7.5 手动回滚

```typescript
// apps/desktop/src/pages/Settings/UpdateSettings.tsx（片段）

function RollbackSection() {

      </p>
      <button onClick={handleRollback} className="mt-2 btn-destructive text-sm">
```
