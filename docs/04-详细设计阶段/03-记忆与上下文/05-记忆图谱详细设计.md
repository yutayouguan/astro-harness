## 1. 记忆图谱概述

### 1.1 问题陈述

现有四层记忆架构以**扁平条目**为基本单元：L1 情节记忆存储对话消息序列，L2 语义记忆通过向量相似度检索关联片段，L3 持久记忆以 key-value 形式记录事实，L4 程序性记忆索引 Skill 文档。这套架构在"给定查询，找到相似内容"的场景下表现良好，但存在一个结构性盲区：**条目之间的关系不可见**。

具体表现：

- 用户问"谁参与了项目 X？"——向量检索只能找到包含"项目 X"关键词的记忆条目，无法遍历"参与"这一关系链。
- 用户问"技术 A 和技术 B 之间有什么联系？"——语义相似度无法捕捉"依赖"、"替代"、"组合使用"等结构化关系。
- Agent 需要理解"用户在项目 X 中使用了技术 A，技术 A 依赖库 B，库 B 最近有安全漏洞"这样的多跳推理链——扁平记忆无法表达。

### 1.2 设计定位

记忆图谱（Memory Knowledge Graph）是建立在现有四层记忆**之上**的增强层，而非替代层。它从对话消息和记忆条目中抽取结构化实体与关系，构建一张以用户为中心的知识图谱，使 Agent 具备**图结构推理**能力。

```text
┌─────────────────────────────────────────────────────────────────┐
│                    Agent 记忆与知识体系                           │
│                                                                 │
│  ┌──────────────────────────────────────────────┐              │
│  │          记忆图谱（本文档）                     │              │
│  │  实体 + 关系 → 图结构推理                      │              │
│  │  "谁做了什么"、"什么依赖什么"                   │              │
│  └──────────┬───────────────────────┬───────────┘              │
│             │ 实体抽取               │ 图增强检索               │
│             ▼                       ▼                          │
│  ┌──────────────┐  ┌──────────────┐  ┌────────────────────┐   │
│  │ L1 情节记忆   │  │ L2 语义记忆   │  │  知识库 RAG         │   │
│  │ 对话消息序列  │  │ 向量相似检索  │  │  文档分块检索       │   │
│  └──────────────┘  └──────────────┘  └────────────────────┘   │
│  ┌──────────────┐  ┌──────────────┐                           │
│  │ L3 持久记忆   │  │ L4 程序性记忆 │                           │
│  │ MEMORY/USER  │  │ Skills 索引  │                           │
│  └──────────────┘  └──────────────┘                           │
└─────────────────────────────────────────────────────────────────┘
```

### 1.3 与 L2 语义记忆的互补关系

| 维度 | L2 语义记忆（向量检索） | 记忆图谱（图检索） |
| ---- | ---------------------- | ------------------ |
| 检索方式 | 给定 query 的 embedding，找最近邻 | 给定实体，沿关系边遍历邻居 |
| 擅长场景 | "与 X 相似的内容" | "与 X 相关联的实体" |
| 数据粒度 | 文本片段（记忆条目原文） | 结构化三元组（实体-关系-实体） |
| 多跳推理 | 不支持 | 天然支持（路径查询） |
| 关系类型 | 隐式（距离远近） | 显式（typed edges） |

两者协同工作：图谱发现关联实体后，将实体名称作为额外查询词传递给向量检索，扩大召回范围；向量检索找到的记忆条目反过来作为图谱实体抽取的输入源。

use serde::{Deserialize, Serialize};

/// 实体类型枚举
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq, Hash)]
#[serde(rename_all = "snake_case")]
pub enum EntityType {
    Person,       // 人物：同事、用户自身、外部联系人
    Project,      // 项目：代码仓库、产品、业务项目
    Technology,   // 技术：编程语言、框架、工具链
    Concept,      // 概念：设计模式、架构原则、业务术语
    File,         // 文件：具体的代码文件、配置文件
    Tool,         // 工具：Agent 使用的工具、外部服务
    Organization, // 组织：公司、团队、部门
}

impl EntityType {
    pub fn as_str(&self) -> &'static str {
        match self {
            Self::Person => "person",
            Self::Project => "project",
            Self::Technology => "technology",
            Self::Concept => "concept",
            Self::File => "file",
            Self::Tool => "tool",
            Self::Organization => "organization",
        }
    }
}

/// 实体节点
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Entity {
    pub id: String,                          // UUID v4
    pub workspace_id: String,                // 所属工作区
    pub name: String,                        // 实体名称（规范化后）
    pub entity_type: EntityType,             // 实体类型
    pub aliases: Vec<String>,                // 别名列表（如 "React.js" / "ReactJS" / "React"）
    pub attributes: HashMap<String, String>, // 自由属性（如 role="前端工程师"）
    pub source_memory_ids: Vec<String>,      // 抽取来源的 memory_entry ID 列表
    pub source_conversation_ids: Vec<String>,// 抽取来源的 conversation ID 列表
    pub mention_count: u32,                  // 被提及总次数
    pub confidence: f32,                     // 实体置信度（0.0~1.0）
    pub first_seen_at: i64,                  // 首次出现时间
    pub last_seen_at: i64,                   // 最近出现时间
    pub created_at: i64,
    pub updated_at: i64,
}

/// 关系类型枚举
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq, Hash)]
#[serde(rename_all = "snake_case")]
pub enum RelationType {
    Uses,        // 使用：Person uses Technology
    CreatedBy,   // 创建：Project created_by Person
    RelatedTo,   // 相关：Concept related_to Concept
    DependsOn,   // 依赖：Technology depends_on Technology
    MentionedIn, // 提及：Entity mentioned_in Project/File
    WorksOn,     // 工作于：Person works_on Project
    PartOf,      // 属于：File part_of Project
    Manages,     // 管理：Person manages Project/Organization
    Prefers,     // 偏好：Person(用户) prefers Technology/Concept
    Replaces,    // 替代：Technology replaces Technology
}

impl RelationType {
    pub fn as_str(&self) -> &'static str {
        match self {
            Self::Uses => "uses",
            Self::CreatedBy => "created_by",
            Self::RelatedTo => "related_to",
            Self::DependsOn => "depends_on",
            Self::MentionedIn => "mentioned_in",
            Self::WorksOn => "works_on",
            Self::PartOf => "part_of",
            Self::Manages => "manages",
            Self::Prefers => "prefers",
            Self::Replaces => "replaces",
        }
    }
}

/// 关系边
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Relationship {
    pub id: String,                    // UUID v4
    pub workspace_id: String,          // 所属工作区
    pub from_entity_id: String,        // 起点实体 ID
    pub to_entity_id: String,          // 终点实体 ID
    pub relation_type: RelationType,   // 关系类型
    pub weight: f32,                   // 关系强度（0.0~1.0），多次出现则累加
    pub evidence: Vec<String>,         // 关系依据（原文摘录，最多 5 条）
    pub source_memory_ids: Vec<String>,// 抽取来源
    pub confidence: f32,               // 关系置信度（0.0~1.0）
    pub first_seen_at: i64,
    pub last_seen_at: i64,
    pub created_at: i64,
    pub updated_at: i64,
}

### 2.3 设计决策：为什么用 SQLite 而非专用图数据库

使用 SQLite `graph_entities` + `graph_relationships` 两张表而非引入 Neo4j、DGraph 等专用图数据库，原因如下：

- **部署简单**：Astro Agent 是本地桌面应用，不应要求用户安装额外数据库服务。SQLite 嵌入式运行，零依赖。
- **规模匹配**：单用户工作区的实体规模预估在千级（人名、项目名、技术栈），关系规模在万级，SQLite 的 recursive CTE 在此规模下遍历性能充足（< 50ms / 5 跳）。
- **事务一致性**：图谱数据与记忆条目（`memory_entries`）在同一 SQLite 数据库内，可在同一事务中原子更新，无需跨库分布式事务。
- **已有基础设施**：项目已建立完善的 SQLite 访问层（连接池、WAL 模式、加密），图谱模块直接复用。

当单工作区实体数超过 10,000 或关系数超过 100,000 时，可考虑引入 SQLite 的 R-tree 扩展或迁移到嵌入式图引擎（如 CozoDB），但当前阶段不做此优化。

### 3.2 LLM 抽取 Prompt

```rust
impl EntityExtractor {
    /// 从一段文本中抽取实体和关系
    pub async fn extract(&self, text: &str, context_hint: &str) -> anyhow::Result<ExtractionResult> {
        let prompt = format!(
            r#"你是知识图谱实体抽取专家。从以下文本中抽取结构化实体和关系。

文本类型：{context}
文本内容：
{text}

抽取规则：
1. 实体类型限定为：person, project, technology, concept, file, tool, organization
2. 关系类型限定为：uses, created_by, related_to, depends_on, mentioned_in, works_on, part_of, manages, prefers, replaces
3. 只抽取明确提及的实体，不要推测
4. 人名保留原始称呼（如"张工"、"小李"），同时给出可能的别名
5. 技术名称使用官方名称（如"React"而非"react.js"）
6. 每个关系必须有文本中的直接依据

以 JSON 格式返回：
{{
  "entities": [
    {{
      "name": "实体名",
      "entity_type": "类型",
      "aliases": ["别名1"],
      "attributes": {{"key": "value"}}
    }}
  ],
  "relations": [
    {{
      "from_entity": "起点实体名",
      "to_entity": "终点实体名",
      "relation_type": "关系类型",
      "evidence": "原文依据摘录"
    }}
  ]
}}"#,
            context = context_hint,
            text = truncate_text(text, 2000), // 截断过长文本
        );

        let response = self.llm.generate(&prompt).await?;
        let result: ExtractionResult = serde_json::from_str(&extract_json_block(&response))
            .unwrap_or_else(|_| ExtractionResult {
                entities: Vec::new(),
                relations: Vec::new(),
            });

        // 过滤低质量结果
        let filtered = ExtractionResult {
            entities: result.entities.into_iter()
                .filter(|e| !e.name.trim().is_empty())
                .take(self.config.max_entities_per_batch)
                .collect(),
            relations: result.relations,
        };

        Ok(filtered)
    }
}

/// 从 LLM 响应中提取 JSON 块
fn extract_json_block(text: &str) -> &str {
    // 尝试找 ```json ... ``` 包裹的块
    if let Some(start) = text.find("```json") {
        let content_start = start + 7;
        if let Some(end) = text[content_start..].find("```") {
            return &text[content_start..content_start + end];
        }
    }
    // 尝试找 { ... } 包裹的块
    if let Some(start) = text.find('{') {
        if let Some(end) = text.rfind('}') {
            return &text[start..=end];
        }
    }
    text
}

fn truncate_text(text: &str, max_chars: usize) -> &str {
    if text.len() <= max_chars {
        text
    } else {
        let boundary = text.char_indices()
            .take_while(|(i, _)| *i < max_chars)
            .last()
            .map(|(i, c)| i + c.len_utf8())
            .unwrap_or(max_chars);
        &text[..boundary]
    }
}

### 3.3 抽取来源与触发时机

实体抽取从两个数据源获取输入，均在后台异步执行：

```rust
impl EntityExtractor {
    /// 从对话消息批量抽取（session 结束时触发）
    pub async fn extract_from_conversation(
        &self,
        repo: &GraphRepo,
        workspace_id: &str,
        conversation_id: &str,
        messages: &[Message],
    ) -> anyhow::Result<ExtractionSummary> {
        // 检查是否已处理过
        if repo.is_extracted(workspace_id, "conversation", conversation_id).await? {
            return Ok(ExtractionSummary::skipped());
        }

        // 将多轮对话合并为单段文本，保留角色标记
        let combined = messages.iter()
            .filter(|m| m.role == "user" || m.role == "assistant")
            .map(|m| format!("[{}]: {}", m.role, m.text_content()))
            .collect::<Vec<_>>()
            .join("\n");

        let result = self.extract(&combined, "多轮对话记录").await?;
        let summary = self.persist_extraction(
            repo, workspace_id, "conversation", conversation_id, &result,
        ).await?;

        Ok(summary)
    }

    /// 从记忆条目批量抽取（新记忆写入后触发）
    pub async fn extract_from_memory(
        &self,
        repo: &GraphRepo,
        workspace_id: &str,
        memory_id: &str,
        key: &str,
        value: &str,
    ) -> anyhow::Result<ExtractionSummary> {
        if repo.is_extracted(workspace_id, "memory", memory_id).await? {
            return Ok(ExtractionSummary::skipped());
        }

        let text = format!("记忆标题：{}\n记忆内容：{}", key, value);
        let result = self.extract(&text, "Agent 记忆条目").await?;
        let summary = self.persist_extraction(
            repo, workspace_id, "memory", memory_id, &result,
        ).await?;

        Ok(summary)
    }

    /// 将抽取结果写入图谱（合并已有实体）
    async fn persist_extraction(
        &self,
        repo: &GraphRepo,
        workspace_id: &str,
        source_type: &str,
        source_id: &str,
        result: &ExtractionResult,
    ) -> anyhow::Result<ExtractionSummary> {
        let mut tx = repo.begin().await?;
        let now = now_ms();
        let mut entity_count = 0;
        let mut relation_count = 0;

        // 实体名 → 实体 ID 的映射（用于后续关系写入）
        let mut name_to_id: HashMap<String, String> = HashMap::new();

        for raw in &result.entities {
            let normalized_name = normalize_entity_name(&raw.name);

            // 尝试查找已有实体（精确匹配或别名匹配）
            let existing = repo.find_entity_by_name_or_alias_in_tx(
                &mut tx, workspace_id, &normalized_name,
            ).await?;

            let entity_id = match existing {
                Some(mut entity) => {
                    // 合并：增加提及次数，合并别名，更新 last_seen_at
                    entity.mention_count += 1;
                    entity.last_seen_at = now;
                    for alias in &raw.aliases {
                        let norm_alias = normalize_entity_name(alias);
                        if !entity.aliases.contains(&norm_alias) {
                            entity.aliases.push(norm_alias);
                        }
                    }
                    // 合并属性（新属性覆盖旧属性）
                    for (k, v) in &raw.attributes {
                        entity.attributes.insert(k.clone(), v.clone());
                    }
                    // 追加来源 ID
                    match source_type {
                        "memory" => {
                            if !entity.source_memory_ids.contains(&source_id.to_string()) {
                                entity.source_memory_ids.push(source_id.to_string());
                            }
                        }
                        "conversation" => {
                            if !entity.source_conversation_ids.contains(&source_id.to_string()) {
                                entity.source_conversation_ids.push(source_id.to_string());
                            }
                        }
                        _ => {}
                    }
                    repo.update_entity_in_tx(&mut tx, &entity).await?;
                    entity.id
                }
                None => {
                    // 新实体
                    let id = uuid::Uuid::new_v4().to_string();
                    let entity = Entity {
                        id: id.clone(),
                        workspace_id: workspace_id.to_string(),
                        name: normalized_name.clone(),
                        entity_type: raw.entity_type.clone(),
                        aliases: raw.aliases.iter()
                            .map(|a| normalize_entity_name(a))
                            .collect(),
                        attributes: raw.attributes.clone(),
                        source_memory_ids: if source_type == "memory" {
                            vec![source_id.to_string()]
                        } else { vec![] },
                        source_conversation_ids: if source_type == "conversation" {
                            vec![source_id.to_string()]
                        } else { vec![] },
                        mention_count: 1,
                        confidence: 0.5,
                        first_seen_at: now,
                        last_seen_at: now,
                        created_at: now,
                        updated_at: now,
                    };
                    repo.insert_entity_in_tx(&mut tx, &entity).await?;
                    entity_count += 1;
                    id
                }
            };

            name_to_id.insert(normalized_name, entity_id);
        }

        // 写入关系（在关系抽取结果中关联实体 ID）
        for raw_rel in &result.relations {
            let from_name = normalize_entity_name(&raw_rel.from_entity);
            let to_name = normalize_entity_name(&raw_rel.to_entity);

            let from_id = match name_to_id.get(&from_name) {
                Some(id) => id.clone(),
                None => continue, // 找不到实体则跳过此关系
            };
            let to_id = match name_to_id.get(&to_name) {
                Some(id) => id.clone(),
                None => continue,
            };

            // 尝试查找已有关系
            let existing_rel = repo.find_relationship_in_tx(
                &mut tx, workspace_id, &from_id, &to_id, &raw_rel.relation_type,
            ).await?;

            match existing_rel {
                Some(mut rel) => {
                    // 强化已有关系：增加权重，追加证据
                    rel.weight = (rel.weight + 0.1).min(1.0);
                    rel.last_seen_at = now;
                    if rel.evidence.len() < 5 {
                        rel.evidence.push(raw_rel.evidence.clone());
                    }
                    repo.update_relationship_in_tx(&mut tx, &rel).await?;
                }
                None => {
                    let rel = Relationship {
                        id: uuid::Uuid::new_v4().to_string(),
                        workspace_id: workspace_id.to_string(),
                        from_entity_id: from_id,
                        to_entity_id: to_id,
                        relation_type: raw_rel.relation_type.clone(),
                        weight: 0.5,
                        evidence: vec![raw_rel.evidence.clone()],
                        source_memory_ids: vec![source_id.to_string()],
                        confidence: 0.5,
                        first_seen_at: now,
                        last_seen_at: now,
                        created_at: now,
                        updated_at: now,
                    };
                    repo.insert_relationship_in_tx(&mut tx, &rel).await?;
                    relation_count += 1;
                }
            }
        }

        // 记录抽取日志
        repo.log_extraction_in_tx(
            &mut tx, workspace_id, source_type, source_id,
            entity_count, relation_count,
        ).await?;

        tx.commit().await?;

        Ok(ExtractionSummary {
            entities_created: entity_count,
            relations_created: relation_count,
            skipped: false,
        })
    }
}

/// 实体名称规范化：去除多余空格，统一大小写

        .collect::<Vec<_>>()
        .join(" ")

## 4. 关系抽取

### 4.1 双策略关系抽取

关系抽取采用两种互补策略：**共现分析**（低成本、高召回）和 **LLM 辅助抽取**（高精度、按需使用）。

```rust
// crates/agent-core/src/graph/relation.rs

use crate::graph::models::{RelationType, RawRelation};

/// 原始关系（LLM 或共现分析产出）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RawRelation {
    pub from_entity: String,
    pub to_entity: String,
    pub relation_type: RelationType,
    pub evidence: String,
    pub confidence: f32,
}

pub struct RelationExtractor {
    llm: Arc<dyn ChatCompletionModel>,
}

impl RelationExtractor {
    /// 策略一：共现分析
    /// 当两个实体在同一段文本（对话轮次或记忆条目）中共同出现时，
    /// 推断它们之间存在 related_to 关系。
    /// 优点：无需 LLM 调用，可批量处理。
    /// 缺点：只能得到泛化的 related_to，无法推断具体关系类型。
    pub fn extract_cooccurrence(
        &self,
        entities: &[RawEntity],
        text: &str,
    ) -> Vec<RawRelation> {
        let mut relations = Vec::new();

        // 两两组合检测共现
        for i in 0..entities.len() {
            for j in (i + 1)..entities.len() {
                let e1 = &entities[i];
                let e2 = &entities[j];

                let e1_present = text.contains(&e1.name)
                    || e1.aliases.iter().any(|a| text.contains(a.as_str()));
                let e2_present = text.contains(&e2.name)
                    || e2.aliases.iter().any(|a| text.contains(a.as_str()));

                if e1_present && e2_present {
                    // 计算文本距离：两个实体名在文本中的最近字符距离
                    let distance = min_text_distance(text, &e1.name, &e2.name);
                    // 距离越近，关系越强
                    let confidence = if distance < 50 { 0.7 }
                        else if distance < 200 { 0.5 }
                        else { 0.3 };

                    relations.push(RawRelation {
                        from_entity: e1.name.clone(),
                        to_entity: e2.name.clone(),
                        relation_type: RelationType::RelatedTo,
                        evidence: extract_surrounding_context(text, &e1.name, &e2.name, 100),
                        confidence,
                    });
                }
            }
        }

        relations
    }

    /// 策略二：LLM 辅助关系分类
    /// 对共现分析产出的 related_to 关系进行细化分类。
    /// 仅在共现关系数 > 0 时调用，避免无意义的 LLM 消耗。
    pub async fn refine_relations(
        &self,
        cooccurrence_relations: &[RawRelation],
        source_text: &str,
    ) -> anyhow::Result<Vec<RawRelation>> {
        if cooccurrence_relations.is_empty() {
            return Ok(Vec::new());
        }

        let pairs: Vec<String> = cooccurrence_relations.iter()
            .map(|r| format!("- {} <-> {} (上下文: {})", r.from_entity, r.to_entity, r.evidence))
            .collect();

        let prompt = format!(
            r#"以下实体对在同一段文本中共同出现，请判断它们之间的具体关系类型。

实体对列表：
{pairs}

可选关系类型：
- uses: A 使用 B（人使用技术）
- created_by: A 由 B 创建（项目由人创建）
- depends_on: A 依赖 B（技术依赖技术）
- works_on: A 工作于 B（人参与项目）
- part_of: A 属于 B（文件属于项目）
- manages: A 管理 B（人管理项目/组织）
- prefers: A 偏好 B（用户偏好某技术/风格）
- replaces: A 替代 B（新技术替代旧技术）
- related_to: 无法判断具体类型时使用

以 JSON 数组返回，每项包含 from_entity, to_entity, relation_type, evidence:
"#,
            pairs = pairs.join("\n"),
        );

        let response = self.llm.generate(&prompt).await?;
        let refined: Vec<RawRelation> = serde_json::from_str(&extract_json_block(&response))
            .unwrap_or_else(|_| cooccurrence_relations.to_vec()); // 解析失败则回退

        Ok(refined)
    }
}

/// 计算两个子串在文本中的最近字符距离
fn min_text_distance(text: &str, a: &str, b: &str) -> usize {
    let a_positions: Vec<usize> = text.match_indices(a).map(|(i, _)| i).collect();
    let b_positions: Vec<usize> = text.match_indices(b).map(|(i, _)| i).collect();

    let mut min_dist = usize::MAX;
    for &ap in &a_positions {
        for &bp in &b_positions {
            let dist = if ap > bp { ap - bp } else { bp - ap };
            min_dist = min_dist.min(dist);
        }
    }
    min_dist
}

/// 提取两个实体周围的上下文文本
fn extract_surrounding_context(text: &str, a: &str, b: &str, max_len: usize) -> String {
    let a_pos = text.find(a).unwrap_or(0);
    let b_pos = text.find(b).unwrap_or(0);
    let start = a_pos.min(b_pos).saturating_sub(20);
    let end = (a_pos.max(b_pos) + a.len().max(b.len()) + 20).min(text.len());
    let snippet = &text[start..end];
    if snippet.len() > max_len {
        snippet[..max_len].to_string()
    } else {
        snippet.to_string()
    }
}

### 5.2 邻域查询（N 跳以内的所有实体）

```rust
impl GraphQueryEngine {
    /// 获取某实体 N 跳以内的所有关联实体和关系
    ///
    /// 使用 SQLite recursive CTE 实现广度优先遍历
    pub async fn get_neighborhood(
        &self,
        workspace_id: &str,
        entity_id: &str,
        max_hops: u32,
        min_weight: f32,
    ) -> anyhow::Result<SubGraph> {
        // 递归 CTE：从起点出发，沿关系边向外扩展 max_hops 层
        let rows = sqlx::query!(
            r#"
            WITH RECURSIVE reachable(entity_id, depth) AS (
                -- 起点
                SELECT ?1, 0

                UNION

                -- 沿正向边扩展
                SELECT r.to_entity_id, re.depth + 1
                FROM graph_relationships r
                JOIN reachable re ON r.from_entity_id = re.entity_id
                WHERE r.workspace_id = ?2
                  AND r.weight >= ?4
                  AND re.depth < ?3

                UNION

                -- 沿反向边扩展（无向遍历）
                SELECT r.from_entity_id, re.depth + 1
                FROM graph_relationships r
                JOIN reachable re ON r.to_entity_id = re.entity_id
                WHERE r.workspace_id = ?2
                  AND r.weight >= ?4
                  AND re.depth < ?3
            )
            SELECT DISTINCT e.*
            FROM reachable re
            JOIN graph_entities e ON e.id = re.entity_id
            WHERE e.workspace_id = ?2
            "#,
            entity_id,
            workspace_id,
            max_hops as i64,
            min_weight,
        )
        .fetch_all(&self.pool)
        .await?;

        let entities: Vec<Entity> = rows.into_iter()
            .map(|r| row_to_entity(r))
            .collect();

        let entity_ids: Vec<&str> = entities.iter().map(|e| e.id.as_str()).collect();

        // 获取这些实体之间的所有关系
        let relationships = self.get_relationships_between(
            workspace_id, &entity_ids,
        ).await?;

        Ok(SubGraph { entities, relationships })
    }

    /// 获取一组实体之间的所有关系
    async fn get_relationships_between(
        &self,
        workspace_id: &str,
        entity_ids: &[&str],
    ) -> anyhow::Result<Vec<Relationship>> {
        if entity_ids.is_empty() {
            return Ok(Vec::new());
        }

        // 动态构建 IN 子句的占位符
        let placeholders: String = entity_ids.iter()
            .enumerate()
            .map(|(i, _)| format!("?{}", i + 2))
            .collect::<Vec<_>>()
            .join(",");

        let sql = format!(
            "SELECT * FROM graph_relationships
             WHERE workspace_id = ?1
               AND from_entity_id IN ({placeholders})
               AND to_entity_id IN ({placeholders})"
        );

        let mut query = sqlx::query(&sql).bind(workspace_id);
        for id in entity_ids {
            query = query.bind(id);
        }

        let rows = query.fetch_all(&self.pool).await?;
        Ok(rows.into_iter().map(|r| row_to_relationship(r)).collect())
    }
}

### 5.3 最短路径查询

```rust
impl GraphQueryEngine {
    /// 查找两个实体之间的最短路径
    ///
    /// 使用 recursive CTE 实现 BFS，找到第一条到达终点的路径
    /// 最大搜索深度限定为 6 跳，避免在大图上无限扩展
    pub async fn shortest_path(
        &self,
        workspace_id: &str,
        from_entity_id: &str,
        to_entity_id: &str,
        max_depth: u32,
    ) -> anyhow::Result<Option<GraphPath>> {
        let max_depth = max_depth.min(6); // 安全上限

        // BFS 路径记录：使用 path 列记录完整路径
        let rows = sqlx::query!(
            r#"
            WITH RECURSIVE path_search(
                current_id, depth, path, edge_path
            ) AS (
                SELECT ?1, 0, ?1, ''

                UNION ALL

                -- 正向遍历
                SELECT r.to_entity_id,
                       ps.depth + 1,
                       ps.path || ',' || r.to_entity_id,
                       ps.edge_path || CASE WHEN ps.edge_path = '' THEN '' ELSE ',' END || r.id
                FROM graph_relationships r
                JOIN path_search ps ON r.from_entity_id = ps.current_id
                WHERE r.workspace_id = ?3
                  AND ps.depth < ?4
                  AND INSTR(ps.path, r.to_entity_id) = 0  -- 防环

                UNION ALL

                -- 反向遍历
                SELECT r.from_entity_id,
                       ps.depth + 1,
                       ps.path || ',' || r.from_entity_id,
                       ps.edge_path || CASE WHEN ps.edge_path = '' THEN '' ELSE ',' END || r.id
                FROM graph_relationships r
                JOIN path_search ps ON r.to_entity_id = ps.current_id
                WHERE r.workspace_id = ?3
                  AND ps.depth < ?4
                  AND INSTR(ps.path, r.from_entity_id) = 0
            )
            SELECT path, edge_path, depth
            FROM path_search
            WHERE current_id = ?2
            ORDER BY depth ASC
            LIMIT 1
            "#,
            from_entity_id,
            to_entity_id,
            workspace_id,
            max_depth as i64,
        )
        .fetch_optional(&self.pool)
        .await?;

        match rows {
            Some(row) => {
                let node_ids: Vec<&str> = row.path.split(',').collect();
                let edge_ids: Vec<&str> = row.edge_path.split(',')
                    .filter(|s| !s.is_empty())
                    .collect();

                let nodes = self.get_entities_by_ids(workspace_id, &node_ids).await?;
                let edges = self.get_relationships_by_ids(&edge_ids).await?;
                let total_weight: f32 = edges.iter().map(|e| e.weight).sum();

                Ok(Some(GraphPath { nodes, edges, total_weight }))
            }
            None => Ok(None),
        }
    }
}

### 5.4 模式匹配查询

```rust
impl GraphQueryEngine {
    /// 按实体类型和关系类型查询匹配的三元组模式
    ///
    /// 示例：查找所有 (Person) -[works_on]-> (Project) 的三元组
    pub async fn pattern_match(
        &self,
        workspace_id: &str,
        from_type: Option<&EntityType>,
        relation_type: Option<&RelationType>,
        to_type: Option<&EntityType>,
        limit: usize,
    ) -> anyhow::Result<Vec<(Entity, Relationship, Entity)>> {
        let mut conditions = vec!["r.workspace_id = ?1".to_string()];
        let mut bind_index = 2;
        let mut binds: Vec<String> = vec![workspace_id.to_string()];

        if let Some(ft) = from_type {
            conditions.push(format!("e_from.entity_type = ?{bind_index}"));
            binds.push(ft.as_str().to_string());
            bind_index += 1;
        }
        if let Some(rt) = relation_type {
            conditions.push(format!("r.relation_type = ?{bind_index}"));
            binds.push(rt.as_str().to_string());
            bind_index += 1;
        }
        if let Some(tt) = to_type {
            conditions.push(format!("e_to.entity_type = ?{bind_index}"));
            binds.push(tt.as_str().to_string());
        }

        let where_clause = conditions.join(" AND ");
        let sql = format!(
            "SELECT e_from.*, r.*, e_to.*
             FROM graph_relationships r
             JOIN graph_entities e_from ON r.from_entity_id = e_from.id
             JOIN graph_entities e_to ON r.to_entity_id = e_to.id
             WHERE {where_clause}
             ORDER BY r.weight DESC
             LIMIT ?",
        );

        let mut query = sqlx::query(&sql);
        for b in &binds {
            query = query.bind(b);
        }
        query = query.bind(limit as i64);

        let rows = query.fetch_all(&self.pool).await?;

        Ok(rows.into_iter().map(|r| {
            let from = row_to_entity_prefixed(&r, "e_from");
            let rel = row_to_relationship_prefixed(&r, "r");
            let to = row_to_entity_prefixed(&r, "e_to");
            (from, rel, to)
        }).collect())
    }

    /// 搜索实体（FTS5 模糊匹配 + 类型过滤）
    pub async fn search_entities(
        &self,
        workspace_id: &str,
        query: &str,
        entity_type: Option<&EntityType>,
        limit: usize,
    ) -> anyhow::Result<Vec<Entity>> {
        let rows = if let Some(et) = entity_type {
            sqlx::query!(
                r#"
                SELECT e.*
                FROM entities_fts fts
                JOIN graph_entities e ON e.rowid = fts.rowid
                WHERE fts.entities_fts MATCH ?1
                  AND e.workspace_id = ?2
                  AND e.entity_type = ?3
                ORDER BY rank
                LIMIT ?4
                "#,
                query,
                workspace_id,
                et.as_str(),
                limit as i64,
            )
            .fetch_all(&self.pool)
            .await?
        } else {
            sqlx::query!(
                r#"
                SELECT e.*
                FROM entities_fts fts
                JOIN graph_entities e ON e.rowid = fts.rowid
                WHERE fts.entities_fts MATCH ?1
                  AND e.workspace_id = ?2
                ORDER BY rank
                LIMIT ?3
                "#,
                query,
                workspace_id,
                limit as i64,
            )
            .fetch_all(&self.pool)
            .await?
        };

        Ok(rows.into_iter().map(|r| row_to_entity(r)).collect())
    }

    /// 获取图谱统计信息
    pub async fn get_stats(
        &self,
        workspace_id: &str,
    ) -> anyhow::Result<GraphStats> {
        let entity_count: i64 = sqlx::query_scalar(
            "SELECT COUNT(*) FROM graph_entities WHERE workspace_id = ?",
        ).bind(workspace_id).fetch_one(&self.pool).await?;

        let relationship_count: i64 = sqlx::query_scalar(
            "SELECT COUNT(*) FROM graph_relationships WHERE workspace_id = ?",
        ).bind(workspace_id).fetch_one(&self.pool).await?;

        let type_distribution: Vec<(String, i64)> = sqlx::query_as(
            "SELECT entity_type, COUNT(*) as cnt FROM graph_entities
             WHERE workspace_id = ? GROUP BY entity_type ORDER BY cnt DESC",
        ).bind(workspace_id).fetch_all(&self.pool).await?;

        let relation_distribution: Vec<(String, i64)> = sqlx::query_as(
            "SELECT relation_type, COUNT(*) as cnt FROM graph_relationships
             WHERE workspace_id = ? GROUP BY relation_type ORDER BY cnt DESC",
        ).bind(workspace_id).fetch_all(&self.pool).await?;

        let avg_connections: f64 = if entity_count > 0 {
            (relationship_count as f64 * 2.0) / entity_count as f64
        } else { 0.0 };

        Ok(GraphStats {
            entity_count: entity_count as u32,
            relationship_count: relationship_count as u32,
            type_distribution: type_distribution.into_iter()
                .map(|(t, c)| (t, c as u32)).collect(),
            relation_distribution: relation_distribution.into_iter()
                .map(|(t, c)| (t, c as u32)).collect(),
            avg_connections_per_entity: avg_connections,
        })
    }
}

## 6. 图谱增强检索

### 6.1 设计思路

当用户提问涉及实体时，仅靠向量相似度检索可能遗漏关联信息。`GraphEnhancedRetriever` 在标准检索流程中插入图谱扩展步骤：先识别用户查询中的实体，通过图谱获取其邻居实体，将邻居实体名称作为额外查询词，扩大向量检索的召回范围。

```text
用户查询："项目 Apollo 用了哪些技术？"
    │
    ▼
① 实体识别：在图谱中匹配 "Apollo" → entity_id = "abc"
    │
    ▼
② 图谱邻域查询：get_neighborhood("abc", hops=1)
    │
    ├── Apollo -[uses]-> React
    ├── Apollo -[uses]-> Rust
    ├── Apollo -[created_by]-> 张工
    └── Apollo -[depends_on]-> SQLite
    │
    ▼
③ 扩展查询词：["项目 Apollo 用了哪些技术", "React", "Rust", "SQLite"]
    │
    ▼
④ 向量检索：对扩展后的查询执行 KNN，召回更多相关记忆条目
    │
    ▼
⑤ 结果合并：图谱上下文 + 向量检索结果 → 注入 prompt
```

### 6.2 GraphEnhancedRetriever 实现

```rust
// crates/agent-core/src/graph/enhanced_retriever.rs

use crate::graph::query::GraphQueryEngine;
use crate::graph::models::Entity;
use crate::knowledge::retriever::RetrievalResult;

/// 图谱增强检索器
pub struct GraphEnhancedRetriever {
    graph_engine: GraphQueryEngine,
    graph_repo: GraphRepo,
    /// 图谱扩展的最大邻居数量
    max_neighbor_expansion: usize,
    /// 邻域查询跳数
    neighborhood_hops: u32,
}

impl GraphEnhancedRetriever {
    pub fn new(graph_engine: GraphQueryEngine, graph_repo: GraphRepo) -> Self {
        Self {
            graph_engine,
            graph_repo,
            max_neighbor_expansion: 5,
            neighborhood_hops: 1,
        }
    }

    /// 从用户查询中识别已知实体
    pub async fn identify_entities(
        &self,
        workspace_id: &str,
        query: &str,
    ) -> anyhow::Result<Vec<Entity>> {
        // 策略：将查询文本中的每个词/短语与图谱实体名和别名做匹配
        // 优先精确匹配，然后 FTS5 模糊匹配
        let mut matched = Vec::new();

        // 1. FTS5 匹配：将整个查询作为搜索词
        let fts_results = self.graph_engine
            .search_entities(workspace_id, query, None, 10)
            .await?;

        // 2. 过滤：只保留名称确实出现在查询中的实体（防止 FTS 误匹配）
        for entity in fts_results {
            let query_lower = query.to_lowercase();
            let name_lower = entity.name.to_lowercase();
            let is_present = query_lower.contains(&name_lower)
                || entity.aliases.iter().any(|a| query_lower.contains(&a.to_lowercase()));

            if is_present {
                matched.push(entity);
            }
        }

        Ok(matched)
    }

    /// 图谱增强检索：扩展查询词 + 生成图谱上下文
    pub async fn enhance_query(
        &self,
        workspace_id: &str,
        original_query: &str,
    ) -> anyhow::Result<GraphEnhancement> {
        let entities = self.identify_entities(workspace_id, original_query).await?;

        if entities.is_empty() {
            return Ok(GraphEnhancement::empty());
        }

        let mut expanded_terms: Vec<String> = Vec::new();
        let mut graph_context_parts: Vec<String> = Vec::new();

        for entity in &entities {
            // 获取 1 跳邻居
            let subgraph = self.graph_engine.get_neighborhood(
                workspace_id, &entity.id,
                self.neighborhood_hops, 0.3, // 权重下限 0.3
            ).await?;

            // 收集邻居实体名作为扩展查询词
            for neighbor in &subgraph.entities {
                if neighbor.id != entity.id && expanded_terms.len() < self.max_neighbor_expansion {
                    expanded_terms.push(neighbor.name.clone());
                }
            }

            // 生成结构化图谱上下文
            let context = format_entity_context(entity, &subgraph);
            graph_context_parts.push(context);
        }

        Ok(GraphEnhancement {
            matched_entities: entities,
            expanded_terms,
            graph_context: if graph_context_parts.is_empty() {
                None
            } else {
                Some(graph_context_parts.join("\n"))
            },
        })
    }
}

/// 图谱增强结果
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct GraphEnhancement {
    pub matched_entities: Vec<Entity>,
    pub expanded_terms: Vec<String>,
    pub graph_context: Option<String>,
}

impl GraphEnhancement {
    fn empty() -> Self {
        Self {
            matched_entities: Vec::new(),
            expanded_terms: Vec::new(),
            graph_context: None,
        }
    }

    pub fn has_content(&self) -> bool {
        !self.matched_entities.is_empty()
    }
}

/// 将实体及其邻域格式化为 LLM 可读的上下文
fn format_entity_context(entity: &Entity, subgraph: &SubGraph) -> String {
    let mut lines = vec![
        format!("实体「{}」(类型: {:?}):", entity.name, entity.entity_type),
    ];

    for rel in &subgraph.relationships {
        let other_id = if rel.from_entity_id == entity.id {
            &rel.to_entity_id
        } else {
            &rel.from_entity_id
        };

        if let Some(other) = subgraph.entities.iter().find(|e| e.id == *other_id) {
            let direction = if rel.from_entity_id == entity.id {
                format!("{} -[{}]-> {}", entity.name, rel.relation_type.as_str(), other.name)
            } else {
                format!("{} <-[{}]- {}", entity.name, rel.relation_type.as_str(), other.name)
            };
            lines.push(format!("  - {}", direction));
        }
    }

    lines.join("\n")
}

## 7. 图谱维护

### 7.1 实体去重

随着对话积累，同一实体可能以不同名称被多次创建（如"React"和"ReactJS"、"张三"和"张工"）。去重分两阶段：写入时实时匹配（已在 `persist_extraction` 中实现）和定期批量扫描。

```rust
// crates/agent-core/src/graph/maintenance.rs

pub struct GraphMaintenance {
    repo: GraphRepo,
    llm: Arc<dyn ChatCompletionModel>,
}

impl GraphMaintenance {
    /// 批量实体去重扫描
    ///
    /// 对同一类型的实体做模糊名称匹配，找出潜在重复对，
    /// 交给 LLM 确认后合并。
    pub async fn deduplicate_entities(
        &self,
        workspace_id: &str,
    ) -> anyhow::Result<DeduplicationReport> {
        let mut merged_count = 0;

        // 按实体类型分组处理
        let entity_types = [
            EntityType::Person, EntityType::Project, EntityType::Technology,
            EntityType::Concept, EntityType::Tool, EntityType::Organization,
        ];

        for entity_type in &entity_types {
            let entities = self.repo
                .list_entities_by_type(workspace_id, entity_type)
                .await?;

            if entities.len() < 2 { continue; }

            // 两两比较名称相似度
            let mut candidates: Vec<(String, String, f32)> = Vec::new();
            for i in 0..entities.len() {
                for j in (i + 1)..entities.len() {
                    let similarity = fuzzy_name_similarity(
                        &entities[i].name, &entities[j].name,
                        &entities[i].aliases, &entities[j].aliases,
                    );
                    if similarity > 0.7 {
                        candidates.push((
                            entities[i].id.clone(),
                            entities[j].id.clone(),
                            similarity,
                        ));
                    }
                }
            }

            if candidates.is_empty() { continue; }

            // LLM 确认（批量）
            let confirmed = self.confirm_duplicates(workspace_id, &candidates).await?;

            for (keep_id, merge_id) in &confirmed {
                self.merge_entities(workspace_id, keep_id, merge_id).await?;
                merged_count += 1;
            }
        }

        Ok(DeduplicationReport { merged_count })
    }

    /// LLM 确认两个实体是否为同一实体
    async fn confirm_duplicates(
        &self,
        workspace_id: &str,
        candidates: &[(String, String, f32)],
    ) -> anyhow::Result<Vec<(String, String)>> {
        if candidates.is_empty() {
            return Ok(Vec::new());
        }

        let mut pairs_desc = Vec::new();
        for (id_a, id_b, sim) in candidates {
            let a = self.repo.get_entity(id_a).await?;
            let b = self.repo.get_entity(id_b).await?;
            pairs_desc.push(format!(
                "- A: \"{}\" (类型:{:?}, 别名:{:?}) vs B: \"{}\" (类型:{:?}, 别名:{:?}) [相似度:{:.2}]",
                a.name, a.entity_type, a.aliases,
                b.name, b.entity_type, b.aliases, sim,
            ));
        }

        let prompt = format!(
            r#"以下实体对可能是同一实体的不同写法。请判断哪些确实是同一实体。

{pairs}

对每对返回 "same" 或 "different"，JSON 数组格式：
[{{"pair_index": 0, "verdict": "same"}}, ...]"#,
            pairs = pairs_desc.join("\n"),
        );

        let response = self.llm.generate(&prompt).await?;
        let verdicts: Vec<PairVerdict> = serde_json::from_str(&extract_json_block(&response))
            .unwrap_or_default();

        let confirmed: Vec<(String, String)> = verdicts.iter()
            .filter(|v| v.verdict == "same")
            .filter_map(|v| {
                candidates.get(v.pair_index).map(|(a, b, _)| (a.clone(), b.clone()))
            })
            .collect();

        Ok(confirmed)
    }

    /// 合并两个实体：将 merge_id 的所有关系迁移到 keep_id，然后删除 merge_id
    async fn merge_entities(
        &self,
        workspace_id: &str,
        keep_id: &str,
        merge_id: &str,
    ) -> anyhow::Result<()> {
        let mut tx = self.repo.begin().await?;

        let keep = self.repo.get_entity_in_tx(&mut tx, keep_id).await?;
        let merge = self.repo.get_entity_in_tx(&mut tx, merge_id).await?;

        // 合并别名
        let mut new_aliases = keep.aliases.clone();
        new_aliases.push(merge.name.clone());
        for alias in &merge.aliases {
            if !new_aliases.contains(alias) {
                new_aliases.push(alias.clone());
            }
        }

        // 合并提及次数和来源
        let mut new_source_memory = keep.source_memory_ids.clone();
        for id in &merge.source_memory_ids {
            if !new_source_memory.contains(id) {
                new_source_memory.push(id.clone());
            }
        }
        let mut new_source_conv = keep.source_conversation_ids.clone();
        for id in &merge.source_conversation_ids {
            if !new_source_conv.contains(id) {
                new_source_conv.push(id.clone());
            }
        }

        // 更新保留实体
        sqlx::query(
            "UPDATE graph_entities
             SET aliases = ?1, mention_count = ?2,
                 source_memory_ids = ?3, source_conversation_ids = ?4,
                 updated_at = ?5
             WHERE id = ?6"
        )
        .bind(serde_json::to_string(&new_aliases)?)
        .bind(keep.mention_count + merge.mention_count)
        .bind(serde_json::to_string(&new_source_memory)?)
        .bind(serde_json::to_string(&new_source_conv)?)
        .bind(now_ms())
        .bind(keep_id)
        .execute(&mut *tx).await?;

        // 迁移关系：将 merge_id 的所有关系指向 keep_id
        sqlx::query(
            "UPDATE graph_relationships SET from_entity_id = ?1, updated_at = ?3
             WHERE from_entity_id = ?2"
        ).bind(keep_id).bind(merge_id).bind(now_ms())
        .execute(&mut *tx).await?;

        sqlx::query(
            "UPDATE graph_relationships SET to_entity_id = ?1, updated_at = ?3
             WHERE to_entity_id = ?2"
        ).bind(keep_id).bind(merge_id).bind(now_ms())
        .execute(&mut *tx).await?;

        // 删除合并的重复关系（同一对实体同类型关系可能出现两条）
        sqlx::query(
            "DELETE FROM graph_relationships
             WHERE rowid NOT IN (
                 SELECT MIN(rowid) FROM graph_relationships
                 GROUP BY workspace_id, from_entity_id, to_entity_id, relation_type
             )"
        ).execute(&mut *tx).await?;

        // 删除被合并的实体
        sqlx::query("DELETE FROM graph_entities WHERE id = ?")
            .bind(merge_id)
            .execute(&mut *tx).await?;

        tx.commit().await?;

        tracing::info!(
            keep = keep_id, merge = merge_id,
            "entities merged: '{}' absorbed '{}'", keep.name, merge.name,
        );

        Ok(())
    }
}

### 7.2 关系权重衰减

与记忆系统的 Weibull 衰减类似，图谱关系的 weight 随时间递减。长期未被强化（即未再次出现在新对话中）的关系逐渐弱化：

```rust
impl GraphMaintenance {
    /// 关系权重衰减
    ///
    /// 每次 Session 启动时执行，对所有关系按 last_seen_at 的时间差衰减 weight。
    /// 半衰期 90 天：90 天未强化的关系 weight 衰减为原来的一半。
    pub async fn decay_relationships(
        &self,
        workspace_id: &str,
    ) -> anyhow::Result<u32> {
        let now = now_ms();
        let half_life_ms: f64 = 90.0 * 24.0 * 3600.0 * 1000.0; // 90 天

        let relationships = self.repo
            .list_all_relationships(workspace_id)
            .await?;

        let mut decayed_count = 0u32;
        let mut tx = self.repo.begin().await?;

        for rel in &relationships {
            let age_ms = (now - rel.last_seen_at) as f64;
            if age_ms <= 0.0 { continue; }

            // 指数衰减：weight_new = weight * 2^(-age/half_life)
            let decay_factor = (2.0f64).powf(-age_ms / half_life_ms);
            let new_weight = (rel.weight as f64 * decay_factor) as f32;

            if (rel.weight - new_weight).abs() > 0.01 {
                sqlx::query(
                    "UPDATE graph_relationships SET weight = ?1, updated_at = ?2 WHERE id = ?3"
                )
                .bind(new_weight)
                .bind(now)
                .bind(&rel.id)
                .execute(&mut *tx).await?;
                decayed_count += 1;
            }
        }

        tx.commit().await?;
        Ok(decayed_count)
    }

    /// 图谱剪枝：移除低置信度、低权重的关系和孤立实体
    pub async fn prune(
        &self,
        workspace_id: &str,
    ) -> anyhow::Result<PruneReport> {
        let mut tx = self.repo.begin().await?;

        // 1. 删除权重低于 0.05 的关系（已衰减至几乎无效）
        let pruned_relations = sqlx::query(
            "DELETE FROM graph_relationships
             WHERE workspace_id = ?1 AND weight < 0.05"
        ).bind(workspace_id).execute(&mut *tx).await?.rows_affected();

        // 2. 删除孤立实体（没有任何关系连接且 mention_count <= 1）
        let pruned_entities = sqlx::query(
            "DELETE FROM graph_entities
             WHERE workspace_id = ?1
               AND mention_count <= 1
               AND id NOT IN (
                   SELECT from_entity_id FROM graph_relationships WHERE workspace_id = ?1
                   UNION
                   SELECT to_entity_id FROM graph_relationships WHERE workspace_id = ?1
               )"
        ).bind(workspace_id).execute(&mut *tx).await?.rows_affected();

        tx.commit().await?;

        Ok(PruneReport {
            pruned_relationships: pruned_relations as u32,
            pruned_entities: pruned_entities as u32,
        })
    }
}

#[derive(Debug)]
pub struct PruneReport {
    pub pruned_relationships: u32,
    pub pruned_entities: u32,
}
```

### 7.3 增量更新

新对话产生后，图谱通过 `extract_from_conversation` 增量更新。已有实体的 `mention_count` 递增，已有关系的 `weight` 递增（最高 1.0），`last_seen_at` 刷新。这种设计确保频繁出现的实体和关系自然保持高权重，而过时的关系逐渐衰减，无需全量重建。

```text
维护任务调度：

Session 启动：
  └── decay_relationships()  — 关系权重衰减

Session 结束：
  └── extract_from_conversation()  — 增量抽取

每日定时（EvolutionScheduler）：
  ├── deduplicate_entities()  — 实体去重
  └── prune()  — 图谱剪枝
```

  tool:         { background: "#06b6d4", border: "#0891b2" }, // cyan
  organization: { background: "#ec4899", border: "#db2777" }, // pink
};

// ── 组件 ─────────────────────────────────────────────────

interface EntityGraphViewerProps {
  workspaceId: string;
}

export function EntityGraphViewer({ workspaceId }: EntityGraphViewerProps) {
  const containerRef = useRef<HTMLDivElement>(null);
  const networkRef = useRef<Network | null>(null);

  const [searchQuery, setSearchQuery] = useState("");
  const [selectedEntity, setSelectedEntity] = useState<GraphEntity | null>(null);
  const [stats, setStats] = useState<GraphStats | null>(null);
  const [currentSubgraph, setCurrentSubgraph] = useState<SubGraph | null>(null);

  // 加载图谱统计
  useEffect(() => {
    invoke<GraphStats>("get_graph_stats", { workspaceId }).then(setStats);
  }, [workspaceId]);

  // 渲染图谱
  const renderGraph = useCallback((subgraph: SubGraph) => {
    if (!containerRef.current) return;

    const nodes = new DataSet(
      subgraph.entities.map((e) => ({
        id: e.id,
        label: e.name,
        color: TYPE_COLORS[e.entity_type] || TYPE_COLORS.concept,
        size: 10 + Math.min(e.mention_count * 3, 30), // 节点大小随提及次数增大
        font: { color: "#e2e8f0", size: 12 },
        title: `${e.name}\n类型: ${e.entity_type}\n提及: ${e.mention_count} 次`,
      }))
    );

    const edges = new DataSet(
      subgraph.relationships.map((r) => ({
        id: r.id,
        from: r.from_entity_id,
        to: r.to_entity_id,
        label: r.relation_type,
        width: Math.max(r.weight * 4, 1), // 边宽度随权重增大
        font: { color: "#94a3b8", size: 10, align: "middle" },
        arrows: { to: { enabled: true, scaleFactor: 0.6 } },
        color: { color: "#475569", opacity: 0.4 + r.weight * 0.6 },
      }))
    );

    const options: Options = {
      layout: {
        improvedLayout: true,
        hierarchical: false,
      },
      physics: {
        forceAtlas2Based: {
          gravitationalConstant: -30,
          centralGravity: 0.005,
          springLength: 150,
          springConstant: 0.08,
        },
        solver: "forceAtlas2Based",
        stabilization: { iterations: 100 },
      },
      interaction: {
        hover: true,
        tooltipDelay: 200,
        zoomView: true,
        dragView: true,
      },
      nodes: {
        shape: "dot",
        borderWidth: 2,
      },
      edges: {
        smooth: { type: "continuous" },
      },
    };

    if (networkRef.current) {
      networkRef.current.destroy();
    }

    const network = new Network(containerRef.current, { nodes, edges }, options);

    network.on("click", (params) => {
      if (params.nodes.length > 0) {
        const entityId = params.nodes[0] as string;
        const entity = subgraph.entities.find((e) => e.id === entityId);
        if (entity) {
          setSelectedEntity(entity);
        }
      } else {
        setSelectedEntity(null);
      }
    });

    // 双击节点：以该节点为中心重新加载邻域
    network.on("doubleClick", async (params) => {
      if (params.nodes.length > 0) {
        const entityId = params.nodes[0] as string;
        const newSubgraph = await invoke<SubGraph>("get_entity_neighbors", {
          workspaceId,
          entityId,
          maxHops: 2,
        });
        setCurrentSubgraph(newSubgraph);
        renderGraph(newSubgraph);
      }
    });

    networkRef.current = network;
  }, [workspaceId]);

  // 当子图数据变化时重新渲染
  useEffect(() => {
    if (currentSubgraph) {
      renderGraph(currentSubgraph);
    }
  }, [currentSubgraph, renderGraph]);

  // 搜索实体并展示其邻域
  const handleSearch = async () => {
    if (!searchQuery.trim()) return;

    const entities = await invoke<GraphEntity[]>("search_entities", {
      workspaceId,
      query: searchQuery,
      limit: 5,
    });

    if (entities.length > 0) {
      const subgraph = await invoke<SubGraph>("get_entity_neighbors", {
        workspaceId,
        entityId: entities[0].id,
        maxHops: 2,
      });
      setCurrentSubgraph(subgraph);
      setSelectedEntity(entities[0]);
    }
  };

  // 加载全图概览（实体数量 < 100 时可用）
  const handleLoadOverview = async () => {
    const subgraph = await invoke<SubGraph>("query_entity_graph", {
      workspaceId,
      limit: 100,
    });
    setCurrentSubgraph(subgraph);
  };

  return (
    <div className="flex flex-col h-full">
      {/* 工具栏 */}
      <div className="flex items-center gap-2 p-3 border-b">
        <Input
          placeholder="搜索实体..."
          value={searchQuery}
          onChange={(e) => setSearchQuery(e.target.value)}
          onKeyDown={(e) => e.key === "Enter" && handleSearch()}
          className="max-w-xs"
        />
        <Button onClick={handleSearch} variant="ghost" size="icon">
          <Search size={16} />
        </Button>
        <div className="flex-1" />
        <Button onClick={handleLoadOverview} variant="outline" size="sm">
          <Maximize2 size={14} className="mr-1" /> 全局概览
        </Button>
        {stats && (
          <span className="text-xs text-muted-foreground">
            {stats.entity_count} 实体 / {stats.relationship_count} 关系
          </span>
        )}
      </div>

      {/* 图谱画布 */}
      <div className="flex-1 relative">
        <div ref={containerRef} className="w-full h-full bg-background" />

        {/* 图例 */}
        <div className="absolute bottom-3 left-3 flex flex-wrap gap-1.5">
          {Object.entries(TYPE_COLORS).map(([type, color]) => (
            <Badge
              key={type}
              variant="outline"
              className="text-xs"
              style={{ borderColor: color.border, color: color.background }}
            >
              {type}
            </Badge>
          ))}
        </div>
      </div>

      {/* 实体详情面板 */}
      {selectedEntity && (
        <div className="border-t p-3 space-y-2">
          <div className="flex items-center gap-2">
            <Badge style={{
              backgroundColor: TYPE_COLORS[selectedEntity.entity_type]?.background,
            }}>
              {selectedEntity.entity_type}
            </Badge>
            <span className="font-medium">{selectedEntity.name}</span>
            <span className="text-xs text-muted-foreground">
              (提及 {selectedEntity.mention_count} 次)
            </span>
          </div>
          {selectedEntity.aliases.length > 0 && (
            <p className="text-xs text-muted-foreground">
              别名: {selectedEntity.aliases.join(", ")}
            </p>
          )}
          {Object.entries(selectedEntity.attributes).length > 0 && (
            <div className="text-xs space-y-0.5">
              {Object.entries(selectedEntity.attributes).map(([k, v]) => (
                <p key={k}><span className="text-muted-foreground">{k}:</span> {v}</p>
              ))}
            </div>
          )}
        </div>
      )}
    </div>
  );
}

// apps/desktop/src-tauri/src/commands/graph.rs

use tauri::State;
use crate::AppState;

/// 查询实体图谱概览（返回权重最高的 N 个实体及其关系）
#[tauri::command]
pub async fn query_entity_graph(
    workspace_id: String,
    limit: Option<usize>,
    state: State<'_, AppState>,
) -> Result<SubGraph, String> {
    let limit = limit.unwrap_or(100);

    // 获取 mention_count 最高的实体
    let entities = state.graph_repo
        .list_top_entities(&workspace_id, limit)
        .await
        .map_err(|e| e.to_string())?;

    let entity_ids: Vec<&str> = entities.iter().map(|e| e.id.as_str()).collect();
    let relationships = state.graph_engine
        .get_relationships_between(&workspace_id, &entity_ids)
        .await
        .map_err(|e| e.to_string())?;

    Ok(SubGraph { entities, relationships })
}

/// 获取指定实体的邻域子图
#[tauri::command]
pub async fn get_entity_neighbors(
    workspace_id: String,
    entity_id: String,
    max_hops: Option<u32>,
    state: State<'_, AppState>,
) -> Result<SubGraph, String> {
    state.graph_engine
        .get_neighborhood(
            &workspace_id,
            &entity_id,
            max_hops.unwrap_or(2),
            0.1, // 最低权重阈值
        )
        .await
        .map_err(|e| e.to_string())
}

/// 搜索实体（FTS5 模糊匹配）
#[tauri::command]
pub async fn search_entities(
    workspace_id: String,
    query: String,
    entity_type: Option<String>,
    limit: Option<usize>,
    state: State<'_, AppState>,
) -> Result<Vec<Entity>, String> {
    if query.trim().is_empty() {
        return Ok(Vec::new());
    }

    let et = entity_type.as_deref().and_then(|s| match s {
        "person" => Some(EntityType::Person),
        "project" => Some(EntityType::Project),
        "technology" => Some(EntityType::Technology),
        "concept" => Some(EntityType::Concept),
        "file" => Some(EntityType::File),
        "tool" => Some(EntityType::Tool),
        "organization" => Some(EntityType::Organization),
        _ => None,
    });

    state.graph_engine
        .search_entities(
            &workspace_id,
            &query,
            et.as_ref(),
            limit.unwrap_or(10),
        )
        .await
        .map_err(|e| e.to_string())
}

/// 获取图谱统计信息
#[tauri::command]
pub async fn get_graph_stats(
    workspace_id: String,
    state: State<'_, AppState>,
) -> Result<GraphStats, String> {
    state.graph_engine
        .get_stats(&workspace_id)
        .await
        .map_err(|e| e.to_string())
}

/// 手动触发实体抽取（对指定对话重新执行抽取）
#[tauri::command]
pub async fn trigger_extraction(
    workspace_id: String,
    conversation_id: String,
    state: State<'_, AppState>,
) -> Result<ExtractionSummary, String> {
    // 加载对话消息
    let messages = state.conversation_repo
        .get_messages(&conversation_id)
        .await
        .map_err(|e| e.to_string())?;

    // 清除之前的抽取日志（允许重新抽取）
    state.graph_repo
        .clear_extraction_log(&workspace_id, "conversation", &conversation_id)
        .await
        .map_err(|e| e.to_string())?;

    // 执行抽取
    state.entity_extractor
        .extract_from_conversation(
            &state.graph_repo,
            &workspace_id,
            &conversation_id,
            &messages,
        )
        .await
        .map_err(|e| e.to_string())
}
