## 1. 隐私架构概述

### 1.1 Local-First 隐私原则

Astro Agent 是一个本地优先的桌面应用，隐私模型的核心假设是：**用户数据默认不离开设备**。只有在用户主动发起 LLM 调用时，对话内容才会经 HTTPS 发送到指定的 Provider API。除此之外，对话历史、记忆、Skill、知识库、设置等所有数据均存储在本地 SQLCipher 加密数据库中，不经过任何第三方服务器。

```text
用户数据流向

┌──────────────────────────────────────────────────────┐
│ 本地设备（永不离开，除非用户主动同步）                    │
│                                                      │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐           │
│  │ 对话历史  │  │ 记忆系统  │  │ 知识库    │           │
│  └──────────┘  └──────────┘  └──────────┘           │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐           │
│  │ Skill    │  │ 用户设置  │  │ 审计日志  │           │
│  └──────────┘  └──────────┘  └──────────┘           │
│       │                                              │
│       │ SQLCipher 加密存储（密钥由 OS Keychain 管理） │
└───────┼──────────────────────────────────────────────┘
        │
        │ 仅当用户发起 LLM 调用时
        │ 经 SensitiveFilter 过滤后
        ▼
┌──────────────────────┐
│ Provider API (HTTPS) │
│ Anthropic / OpenAI / │
│ Google / DeepSeek    │
└──────────────────────┘
```

### 1.2 数据分类

| 分类 | 存储位置 | 是否离开设备 | 加密方式 |
| --- | --- | --- | --- |
| 对话历史 | 本地 SQLite | 仅 LLM 调用时当次消息发出 | SQLCipher |
| 用户记忆 | 本地 SQLite | 仅作为上下文注入 LLM 调用 | SQLCipher |
| 知识库文档 | 本地 SQLite + 文件系统 | 仅 RAG 检索结果注入 LLM 调用 | SQLCipher |
| Skill 定义 | 本地文件系统 | 不离开 | 文件系统权限 |
| 用户设置 | 本地 SQLite | 不离开 | SQLCipher |
| 审计日志 | 本地 SQLite | 不离开 | SQLCipher |
| API Key | OS Keychain | 仅 HTTP Header 携带 | Keychain 加密 |
| E2E 同步数据 | 同步服务器（密文） | 密文形式 | XChaCha20-Poly1305 |

## 2. 敏感内容过滤

### 2.1 SensitiveFilter 核心结构

SensitiveFilter 在数据发送给外部 LLM Provider 之前自动检测并脱敏。用户可通过隐私设置启用/禁用过滤，也可自定义规则。

```rust
// crates/agent-core/src/privacy/filter.rs

use regex::Regex;

/// 敏感内容过滤器
pub struct SensitiveFilter {
    /// 过滤规则列表（内置 + 用户自定义，按优先级排序）
    rules: Vec<CompiledFilterRule>,
    /// 是否启用（用户可在设置中关闭）
    enabled: bool,
}

/// 编译后的过滤规则（正则已预编译，避免重复编译开销）
struct CompiledFilterRule {
    pub name: String,
    pub pattern: CompiledPattern,
    pub action: FilterAction,
    /// 是否为内置规则（内置规则不可删除，只能禁用）
    pub builtin: bool,
    /// 是否启用
    pub enabled: bool,
}

/// 预编译的匹配模式
enum CompiledPattern {
    Regex(Regex),
    Keyword { words: Vec<String>, case_sensitive: bool },
}

/// 用户可配置的过滤规则（序列化/反序列化用）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct FilterRule {
    pub name: String,
    pub pattern: FilterPattern,
    pub action: FilterAction,
    #[serde(default = "default_true")]
    pub enabled: bool,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum FilterPattern {
    /// 自定义正则表达式
    Regex { pattern: String },
    /// 关键词列表匹配
    Keyword { words: Vec<String>, case_sensitive: bool },
    /// 内置规则：信用卡号（Luhn 校验 + 正则）
    CreditCard,
    /// 内置规则：手机号（中国大陆 + 国际格式）
    PhoneNumber,
    /// 内置规则：电子邮箱
    Email,
    /// 内置规则：中国身份证号（18 位 + 校验码验证）
    IdNumber,
    /// 内置规则：常见 API Key 格式（sk-xxx, AKIA, ghp_ 等）
    ApiKey,
    /// 内置规则：银行卡号
    BankCard,
    /// 内置规则：IPv4 地址
    IpAddress,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum FilterAction {
    /// 阻断：命中时整个请求不发送，向用户报告原因
    Block,
    /// 脱敏替换：将匹配内容替换为占位符
    Redact { placeholder: String },
    /// 仅警告：允许发送但在 UI 显示黄色警示
    Warn,
}
```

### 2.2 内置正则模式

内置模式硬编码在 `patterns.rs` 中，确保常见 PII 的检测不依赖用户配置：

### 2.3 身份证号校验码验证

仅靠正则会产生误报（18 位数字组合很常见），因此对身份证号增加校验码验证：

```rust
// crates/agent-core/src/privacy/patterns.rs

/// 验证中国身份证号校验码（GB 11643-1999）
pub fn verify_id_number_checksum(id: &str) -> bool {
    if id.len() != 18 { return false; }

    let weights: [u32; 17] = [7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2];
    let check_chars: [char; 11] = ['1', '0', 'X', '9', '8', '7', '6', '5', '4', '3', '2'];

    let chars: Vec<char> = id.chars().collect();
    let sum: u32 = chars[..17]
        .iter()
        .zip(weights.iter())
        .filter_map(|(c, w)| c.to_digit(10).map(|d| d * w))
        .sum();

    if chars[..17].len() != 17 { return false; }

    let expected = check_chars[(sum % 11) as usize];
    chars[17].to_ascii_uppercase() == expected
}

/// 信用卡 Luhn 校验算法
pub fn verify_luhn(number: &str) -> bool {
    let digits: Vec<u32> = number
        .chars()
        .filter(|c| c.is_ascii_digit())
        .filter_map(|c| c.to_digit(10))
        .collect();

    if digits.len() < 13 || digits.len() > 19 { return false; }

    let checksum: u32 = digits
        .iter()
        .rev()
        .enumerate()
        .map(|(i, &d)| {
            if i % 2 == 1 {
                let doubled = d * 2;
                if doubled > 9 { doubled - 9 } else { doubled }
            } else {
                d
            }
        })
        .sum();

    checksum % 10 == 0
}
```

### 2.4 过滤执行流程

```rust
// crates/agent-core/src/privacy/filter.rs

/// 单次匹配结果
#[derive(Debug, Clone, Serialize)]
pub struct FilterMatch {
    /// 命中的规则名称
    pub rule_name: String,
    /// 匹配到的原文（部分脱敏后的摘要，仅用于日志）
    pub matched_text: String,
    /// 匹配在原文中的字节偏移
    pub offset: usize,
    /// 匹配长度
    pub length: usize,
    /// 对应的处理动作
    pub action: FilterAction,
}

/// 过滤结果
#[derive(Debug)]
pub enum FilterResult {
    /// 包含 Block 规则命中，整个请求被阻断
    Blocked {
        matches: Vec<FilterMatch>,
    },
    /// 允许发送（可能已脱敏或仅警告）
    Allowed {
        /// 脱敏后的内容
        content: String,
        /// 警告列表（Warn 规则命中时非空）
        warnings: Vec<FilterMatch>,
        /// 脱敏统计
        redacted_count: usize,
    },
}

impl SensitiveFilter {
    /// 从配置加载过滤规则（内置 + 用户自定义）
    pub fn from_config(config: &PrivacyConfig) -> anyhow::Result<Self> {
        let mut rules = Self::builtin_rules();

        // 加载用户自定义规则
        for rule in &config.custom_filter_rules {
            let compiled = Self::compile_rule(rule, false)?;
            rules.push(compiled);
        }

        Ok(Self {
            rules,
            enabled: config.filter_enabled,
        })
    }

    /// 扫描内容，返回所有匹配
    pub fn scan(&self, content: &str) -> Vec<FilterMatch> {
        if !self.enabled { return vec![]; }

        self.rules.iter()
            .filter(|r| r.enabled)
            .flat_map(|rule| self.apply_rule(rule, content))
            .collect()
    }

    /// 执行过滤：扫描 + 脱敏/阻断
    pub fn apply(&self, content: &str) -> FilterResult {
        if !self.enabled {
            return FilterResult::Allowed {
                content: content.to_string(),
                warnings: vec![],
                redacted_count: 0,
            };
        }

        let matches = self.scan(content);

        // 有 Block 规则命中时，阻断整个请求
        if matches.iter().any(|m| matches!(m.action, FilterAction::Block)) {
            return FilterResult::Blocked { matches };
        }

        // 执行脱敏替换（从后向前替换，避免偏移量错位）
        let mut redacted = content.to_string();
        let mut redacted_count = 0;

        // 按偏移量从大到小排序
        let mut redact_matches: Vec<&FilterMatch> = matches.iter()
            .filter(|m| matches!(m.action, FilterAction::Redact { .. }))
            .collect();
        redact_matches.sort_by(|a, b| b.offset.cmp(&a.offset));

        for m in &redact_matches {
            if let FilterAction::Redact { ref placeholder } = m.action {
                let end = m.offset + m.length;
                if end <= redacted.len() {
                    redacted.replace_range(m.offset..end, placeholder);
                    redacted_count += 1;
                }
            }
        }

        let warnings: Vec<FilterMatch> = matches.into_iter()
            .filter(|m| matches!(m.action, FilterAction::Warn))
            .collect();

        FilterResult::Allowed {
            content: redacted,
            warnings,
            redacted_count,
        }
    }

    /// 对单条规则执行匹配
    fn apply_rule(&self, rule: &CompiledFilterRule, content: &str) -> Vec<FilterMatch> {
        match &rule.pattern {
            CompiledPattern::Regex(regex) => {
                regex.find_iter(content)
                    .filter(|m| self.post_validate(&rule.name, m.as_str()))
                    .map(|m| {
                        let matched_text = Self::partial_mask(m.as_str());
                        FilterMatch {
                            rule_name: rule.name.clone(),
                            matched_text,
                            offset: m.start(),
                            length: m.end() - m.start(),
                            action: rule.action.clone(),
                        }
                    })
                    .collect()
            }
            CompiledPattern::Keyword { words, case_sensitive } => {
                let mut matches = Vec::new();
                let content_lower = if *case_sensitive { content.to_string() } else { content.to_lowercase() };
                for word in words {
                    let search = if *case_sensitive { word.clone() } else { word.to_lowercase() };
                    let mut start = 0;
                    while let Some(pos) = content_lower[start..].find(&search) {
                        let abs_pos = start + pos;
                        matches.push(FilterMatch {
                            rule_name: rule.name.clone(),
                            matched_text: format!("{}***", &word[..word.len().min(3)]),
                            offset: abs_pos,
                            length: word.len(),
                            action: rule.action.clone(),
                        });
                        start = abs_pos + word.len();
                    }
                }
                matches
            }
        }
    }

    /// 后置验证：对正则匹配结果做额外校验（减少误报）
    fn post_validate(&self, rule_name: &str, matched: &str) -> bool {
        match rule_name {
            "身份证号" => verify_id_number_checksum(matched),
            "信用卡号" => {
                let digits: String = matched.chars().filter(|c| c.is_ascii_digit()).collect();
                verify_luhn(&digits)
            }
            _ => true,
        }
    }

    /// 对匹配内容做部分遮罩（用于日志记录，避免在日志中暴露完整 PII）
    fn partial_mask(text: &str) -> String {
        let chars: Vec<char> = text.chars().collect();
        if chars.len() <= 4 {
            "****".to_string()
        } else {
            let visible = chars.len().min(4);
            format!("{}***", chars[..visible].iter().collect::<String>())
        }
    }
}
```

### 2.6 在 Provider 调用前拦截

SensitiveFilter 作为 PrivacyMiddleware 集成到 Provider 调用链中，在请求发出前对所有文本内容执行过滤：

```rust
// crates/agent-providers/src/middleware/privacy.rs

use crate::types::{TextRequest, ContentPart};
use agent_core::privacy::{SensitiveFilter, FilterResult, FilterAction};

pub struct PrivacyMiddleware {
    filter: Arc<SensitiveFilter>,
}

impl PrivacyMiddleware {
    pub fn new(filter: Arc<SensitiveFilter>) -> Self {
        Self { filter }
    }

    /// 在请求发送前对所有文本内容执行过滤
    /// 返回 Ok(FilterReport) 表示允许发送（可能已脱敏）
    /// 返回 Err 表示请求被阻断
    pub fn apply_to_request(
        &self,
        req: &mut TextRequest,
    ) -> anyhow::Result<FilterReport> {
        let mut total_redacted = 0;
        let mut all_warnings = Vec::new();

        // 过滤用户消息（system prompt 不过滤，因为是应用自身生成的）
        for msg in &mut req.messages {
            if msg.role == "system" { continue; }

            for part in &mut msg.content {
                if let ContentPart::Text { text } = part {
                    match self.filter.apply(text) {
                        FilterResult::Blocked { matches } => {
                            let blocked_rules: Vec<String> = matches.iter()
                                .filter(|m| matches!(m.action, FilterAction::Block))
                                .map(|m| m.rule_name.clone())
                                .collect();
                            return Err(PrivacyError::Blocked {
                                rules: blocked_rules,
                                message: "消息包含敏感内容，已阻止发送".into(),
                            }.into());
                        }
                        FilterResult::Allowed { content, warnings, redacted_count } => {
                            *text = content;
                            total_redacted += redacted_count;
                            all_warnings.extend(warnings);
                        }
                    }
                }
            }
        }

        Ok(FilterReport {
            redacted_count: total_redacted,
            warnings: all_warnings,
        })
    }
}

/// 过滤报告：传递给前端展示脱敏统计
#[derive(Debug, Serialize)]
pub struct FilterReport {
    pub redacted_count: usize,
    pub warnings: Vec<FilterMatch>,
}

/// 隐私错误
#[derive(Debug, thiserror::Error)]
pub enum PrivacyError {
    #[error("敏感内容阻断: {message}")]
    Blocked {
        rules: Vec<String>,
        message: String,
    },
}
```

### 2.7 过滤结果通知

当 PrivacyMiddleware 执行了脱敏或发出警告时，通过 Tauri 事件通知前端，前端在消息气泡旁显示脱敏标记：

### 4.2 RetentionScheduler 自动清理

```rust
// crates/agent-core/src/privacy/retention.rs

use tokio::time::{interval, Duration};

/// 数据保留策略调度器
pub struct RetentionScheduler {
    pool: SqlitePool,
    policy: RetentionPolicy,
    cancel_token: CancellationToken,
}

impl RetentionScheduler {
    pub fn new(
        pool: SqlitePool,
        policy: RetentionPolicy,
        cancel_token: CancellationToken,
    ) -> Self {
        Self { pool, policy, cancel_token }
    }

    /// 启动后台清理任务
    pub fn start(self) -> tokio::task::JoinHandle<()> {
        tokio::spawn(async move {
            let mut tick = interval(Duration::from_secs(
                self.policy.cleanup_interval_hours as u64 * 3600
            ));

            loop {
                tokio::select! {
                    _ = tick.tick() => {
                        if self.policy.auto_cleanup_enabled {
                            if let Err(e) = self.run_cleanup().await {
                                tracing::error!("数据清理失败: {}", e);
                            }
                        }
                    }
                    _ = self.cancel_token.cancelled() => {
                        tracing::info!("数据清理调度器已停止");
                        break;
                    }
                }
            }
        })
    }

    /// 执行一次清理
    async fn run_cleanup(&self) -> anyhow::Result<CleanupReport> {
        let now_ms = now_ms();
        let mut report = CleanupReport::default();

        // 1. 清理过期对话
        if let Some(ttl) = self.policy.conversations_ttl_days {
            let cutoff = now_ms - (ttl as i64 * 86_400_000);
            let result = sqlx::query!(
                "DELETE FROM conversations WHERE updated_at < ? AND status != 'pinned'",
                cutoff
            )
            .execute(&self.pool)
            .await?;
            report.conversations_deleted = result.rows_affected();
            // 关联的 messages 通过 ON DELETE CASCADE 自动清理
        }

        // 2. 清理过期记忆（有明确 TTL 时生效，否则由 Weibull 遗忘管理）
        if let Some(ttl) = self.policy.memories_ttl_days {
            let cutoff = now_ms - (ttl as i64 * 86_400_000);
            let result = sqlx::query!(
                "DELETE FROM memory_entries WHERE created_at < ? AND valid_to IS NOT NULL",
                cutoff
            )
            .execute(&self.pool)
            .await?;
            report.memories_deleted = result.rows_affected();
        }

        // 3. 清理过期审计日志（归档而非删除）
        {
            let cutoff = now_ms - (self.policy.audit_logs_ttl_days as i64 * 86_400_000);
            let result = sqlx::query!(
                "DELETE FROM audit_logs WHERE created_at < ?",
                cutoff
            )
            .execute(&self.pool)
            .await?;
            report.audit_logs_deleted = result.rows_affected();
        }

        // 4. 清理过期媒体任务
        if let Some(ttl) = self.policy.media_tasks_ttl_days {
            let cutoff = now_ms - (ttl as i64 * 86_400_000);
            let result = sqlx::query!(
                "DELETE FROM media_tasks WHERE finished_at IS NOT NULL AND finished_at < ?",
                cutoff
            )
            .execute(&self.pool)
            .await?;
            report.media_tasks_deleted = result.rows_affected();
        }

        // 5. 硬删除过期的 tombstone 记录
        {
            let cutoff = now_ms - (self.policy.tombstone_retention_days as i64 * 86_400_000);
            let result = sqlx::query!(
                "DELETE FROM memory_entries WHERE valid_to IS NOT NULL AND valid_to < ?",
                cutoff
            )
            .execute(&self.pool)
            .await?;
            report.tombstones_purged = result.rows_affected();
        }

        tracing::info!(
            "数据清理完成: 对话 {} 条, 记忆 {} 条, 审计日志 {} 条, 媒体任务 {} 条, tombstone {} 条",
            report.conversations_deleted,
            report.memories_deleted,
            report.audit_logs_deleted,
            report.media_tasks_deleted,
            report.tombstones_purged,
        );

        Ok(report)
    }
}

#[derive(Debug, Default, Serialize)]
pub struct CleanupReport {
    pub conversations_deleted: u64,
    pub memories_deleted: u64,
    pub audit_logs_deleted: u64,
    pub media_tasks_deleted: u64,
    pub tombstones_purged: u64,
}
```

### 4.3 手动清除

用户可通过设置 UI 手动触发特定类型的数据清除，不受 TTL 限制：

```rust
/// 手动清除指定类型的数据
pub async fn manual_purge(
    pool: &SqlitePool,
    target: PurgeTarget,
) -> anyhow::Result<CleanupReport> {
    let mut report = CleanupReport::default();

    match target {
        PurgeTarget::AllConversations => {
            let result = sqlx::query!("DELETE FROM conversations")
                .execute(pool).await?;
            report.conversations_deleted = result.rows_affected();
        }
        PurgeTarget::AllMemories => {
            let result = sqlx::query!("DELETE FROM memory_entries")
                .execute(pool).await?;
            report.memories_deleted = result.rows_affected();
        }
        PurgeTarget::ConversationsBefore { timestamp_ms } => {
            let result = sqlx::query!(
                "DELETE FROM conversations WHERE updated_at < ?",
                timestamp_ms
            ).execute(pool).await?;
            report.conversations_deleted = result.rows_affected();
        }
        PurgeTarget::WorkspaceData { workspace_id } => {
            // 清除指定工作区的所有数据
            sqlx::query!("DELETE FROM conversations WHERE workspace_id = ?", workspace_id)
                .execute(pool).await?;
            sqlx::query!("DELETE FROM memory_entries WHERE workspace_id = ?", workspace_id)
                .execute(pool).await?;
        }
    }

    Ok(report)
}
```

```rust
        if options.include_conversations {
            let conversations = self.export_conversations().await?;
            total += conversations.len() as u64;
            archive.conversations = Some(conversations);
        }

        // 导出记忆
        if options.include_memories {
            let memories = self.export_memories().await?;
            total += memories.len() as u64;
            archive.memories = Some(memories);
        }

        // 导出设置
        if options.include_settings {
            let settings = self.export_settings().await?;
            archive.settings = Some(settings);
            total += 1;
        }

        // 导出成本统计
        if options.include_cost_stats {
            let costs = self.export_costs().await?;
            total += costs.len() as u64;
            archive.cost_stats = Some(costs);
        }

        archive.metadata.total_records = total;

        let json = serde_json::to_vec_pretty(&archive)?;
        let filename = format!(
            "astro-agent-export-{}.json",
            chrono::Utc::now().format("%Y%m%d-%H%M%S")
        );

        Ok(ExportResult { data: json, filename })
    }

    async fn export_conversations(&self) -> anyhow::Result<Vec<ExportedConversation>> {
        let conversations = sqlx::query!(
            "SELECT id, workspace_id, title, model, created_at, updated_at
             FROM conversations ORDER BY created_at ASC"
        ).fetch_all(&self.pool).await?;

        let mut result = Vec::with_capacity(conversations.len());

        for conv in conversations {
            let messages = sqlx::query!(
                "SELECT id, role, content, tool_name, token_count, created_at
                 FROM messages WHERE conversation_id = ? ORDER BY created_at ASC",
                conv.id
            ).fetch_all(&self.pool).await?;

            result.push(ExportedConversation {
                id:           conv.id,
                workspace_id: conv.workspace_id,
                title:        conv.title,
                model:        conv.model,
                created_at:   conv.created_at,
                updated_at:   conv.updated_at,
                messages: messages.into_iter().map(|m| ExportedMessage {
                    id:          m.id,
                    role:        m.role,
                    content:     m.content.unwrap_or_default(),
                    tool_name:   m.tool_name,
                    token_count: m.token_count,
                    created_at:  m.created_at,
                }).collect(),
            });
        }

        Ok(result)
    }

    async fn export_memories(&self) -> anyhow::Result<Vec<ExportedMemory>> {
        let rows = sqlx::query!(
            "SELECT id, workspace_id, category, key, value, importance, created_at, valid_to
             FROM memory_entries ORDER BY created_at ASC"
        ).fetch_all(&self.pool).await?;

        Ok(rows.into_iter().map(|r| ExportedMemory {
            id:           r.id,
            workspace_id: r.workspace_id,
            category:     r.category,
            key:          r.key,
            value:        r.value,
            importance:   r.importance,
            created_at:   r.created_at,
            valid_to:     r.valid_to,
        }).collect())
    }

    async fn export_settings(&self) -> anyhow::Result<serde_json::Value> {
        // 导出用户设置（排除敏感信息如 API Key）
        let rows = sqlx::query!(
            "SELECT key, value FROM user_settings WHERE key NOT LIKE '%api_key%'"
        ).fetch_all(&self.pool).await?;

        let mut settings = serde_json::Map::new();
        for row in rows {
            if let Ok(val) = serde_json::from_str::<serde_json::Value>(&row.value) {
                settings.insert(row.key, val);
            }
        }
        Ok(serde_json::Value::Object(settings))
    }

    async fn export_costs(&self) -> anyhow::Result<Vec<ExportedCostRecord>> {
        let rows = sqlx::query!(
            "SELECT date, provider, model, input_tokens, output_tokens, cost_usd
             FROM cost_daily ORDER BY date ASC"
        ).fetch_all(&self.pool).await?;

        Ok(rows.into_iter().map(|r| ExportedCostRecord {
            date:          r.date,
            provider:      r.provider,
            model:         r.model,
            input_tokens:  r.input_tokens,
            output_tokens: r.output_tokens,
            cost_usd:      r.cost_usd,
        }).collect())
    }
}

pub struct ExportResult {
    pub data: Vec<u8>,
    pub filename: String,
}
```

### 5.4 导出安全考量

- **API Key 排除**：导出时严格排除 API Key、密码、密钥等敏感凭据字段
- **大文件保护**：知识库文档仅导出元数据（文件名、大小），不导出文件内容本身（用户可通过文件系统直接复制）
- **内存限制**：对话量超过 10,000 条时自动切换为 JSON Lines 流式导出，避免内存溢出
- **写入位置**：导出文件写入用户选择的目录（通过 Tauri file dialog），不写入临时目录

## 6. 用户数据删除

### 6.1 DataEraser 结构

用户数据删除支持三种粒度：选择性删除、全量删除、密码学擦除（不可逆）。

```rust
// crates/agent-core/src/privacy/erasure.rs

/// 数据擦除器
pub struct DataEraser {
    pool: SqlitePool,
}

/// 删除目标
#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum ErasureTarget {
    /// 删除指定对话
    Conversation { id: String },
    /// 删除指定工作区的所有数据
    Workspace { workspace_id: String },
    /// 删除所有对话历史
    AllConversations,
    /// 删除所有记忆
    AllMemories,
    /// 删除所有数据（保留应用设置和 API Key）
    AllUserData,
    /// 完全重置：删除所有数据 + 重置设置 + 密码学擦除
    FactoryReset,
}

/// 删除结果
#[derive(Debug, Serialize)]
pub struct ErasureResult {
    /// 删除的记录数
    pub records_deleted: u64,
    /// 是否执行了密码学擦除
    pub crypto_erasure: bool,
    /// 删除操作的审计 ID
    pub audit_id: String,
}
```

### 6.2 删除执行

```rust
impl DataEraser {
    pub fn new(pool: SqlitePool) -> Self {
        Self { pool }
    }

    /// 执行数据删除
    pub async fn erase(
        &self,
        target: &ErasureTarget,
        audit_store: &AuditLogRepo,
    ) -> anyhow::Result<ErasureResult> {
        let audit_id = uuid();
        let mut total_deleted = 0u64;

        // 在删除前记录审计日志
        audit_store.insert(AuditLog {
            id: audit_id.clone(),
            action: format!("data_erasure:{:?}", target),
            detail_json: serde_json::to_string(target).ok(),
            ..AuditLog::system_action()
        }).await?;

        match target {
            ErasureTarget::Conversation { id } => {
                // messages 通过 ON DELETE CASCADE 自动删除
                let result = sqlx::query!("DELETE FROM conversations WHERE id = ?", id)
                    .execute(&self.pool).await?;
                total_deleted = result.rows_affected();
            }

            ErasureTarget::Workspace { workspace_id } => {
                let mut tx = self.pool.begin().await?;

                let r1 = sqlx::query!(
                    "DELETE FROM conversations WHERE workspace_id = ?", workspace_id
                ).execute(&mut *tx).await?;

                let r2 = sqlx::query!(
                    "DELETE FROM memory_entries WHERE workspace_id = ?", workspace_id
                ).execute(&mut *tx).await?;

                let r3 = sqlx::query!(
                    "DELETE FROM media_tasks WHERE workspace_id = ?", workspace_id
                ).execute(&mut *tx).await?;

                // embeddings 通过 source_id 关联，cascade 或手动删除
                sqlx::query!(
                    "DELETE FROM embeddings WHERE workspace_id = ?", workspace_id
                ).execute(&mut *tx).await?;

                tx.commit().await?;
                total_deleted = r1.rows_affected() + r2.rows_affected() + r3.rows_affected();
            }

            ErasureTarget::AllConversations => {
                let result = sqlx::query!("DELETE FROM conversations")
                    .execute(&self.pool).await?;
                total_deleted = result.rows_affected();
            }

            ErasureTarget::AllMemories => {
                let result = sqlx::query!("DELETE FROM memory_entries")
                    .execute(&self.pool).await?;
                total_deleted = result.rows_affected();
                // 同步清除向量索引
                sqlx::query!("DELETE FROM embeddings WHERE source_type = 'memory'")
                    .execute(&self.pool).await?;
            }

            ErasureTarget::AllUserData => {
                let mut tx = self.pool.begin().await?;

                sqlx::query!("DELETE FROM conversations").execute(&mut *tx).await?;
                sqlx::query!("DELETE FROM memory_entries").execute(&mut *tx).await?;
                sqlx::query!("DELETE FROM media_tasks").execute(&mut *tx).await?;
                sqlx::query!("DELETE FROM embeddings").execute(&mut *tx).await?;
                sqlx::query!("DELETE FROM cost_daily").execute(&mut *tx).await?;
                sqlx::query!("DELETE FROM task_traces").execute(&mut *tx).await?;
                // 保留 audit_logs（删除操作本身需要审计追踪）
                // 保留 user_settings（API Key、主题等配置）

                tx.commit().await?;
                total_deleted = u64::MAX; // 全量删除不逐表计数
            }

            ErasureTarget::FactoryReset => {
                // 全量删除 + 密码学擦除（见 6.3 节）
                return self.factory_reset(audit_store).await;
            }
        }

        // 删除后执行 VACUUM 回收磁盘空间
        sqlx::query("VACUUM").execute(&self.pool).await?;

        Ok(ErasureResult {
            records_deleted: total_deleted,
            crypto_erasure: false,
            audit_id,
        })
    }
}
```

### 6.3 密码学擦除（Factory Reset）

密码学擦除通过轮换 SQLCipher 密钥实现。旧密钥销毁后，即使磁盘上残留旧的 WAL 文件或未被 VACUUM 覆盖的页面，也无法被解密。这是不可逆操作。

```rust
impl DataEraser {
    /// 工厂重置：删除所有数据 + 轮换加密密钥（密码学擦除）
    async fn factory_reset(
        &self,
        audit_store: &AuditLogRepo,
    ) -> anyhow::Result<ErasureResult> {
        let audit_id = uuid();

        // 1. 记录审计日志（这条日志会在重置后丢失，但操作记录已提交）
        audit_store.insert(AuditLog {
            id: audit_id.clone(),
            action: "data_erasure:FactoryReset".into(),
            detail_json: Some(r#"{"type":"factory_reset","crypto_erasure":true}"#.into()),
            ..AuditLog::system_action()
        }).await.ok(); // 允许失败（即将被擦除）

        // 2. 删除所有表数据
        let mut tx = self.pool.begin().await?;
        sqlx::query!("DELETE FROM conversations").execute(&mut *tx).await?;
        sqlx::query!("DELETE FROM messages").execute(&mut *tx).await?;
        sqlx::query!("DELETE FROM memory_entries").execute(&mut *tx).await?;
        sqlx::query!("DELETE FROM media_tasks").execute(&mut *tx).await?;
        sqlx::query!("DELETE FROM embeddings").execute(&mut *tx).await?;
        sqlx::query!("DELETE FROM cost_daily").execute(&mut *tx).await?;
        sqlx::query!("DELETE FROM task_traces").execute(&mut *tx).await?;
        sqlx::query!("DELETE FROM audit_logs").execute(&mut *tx).await?;
        sqlx::query!("DELETE FROM user_settings").execute(&mut *tx).await?;
        sqlx::query!("DELETE FROM crypto_keys").execute(&mut *tx).await?;
        tx.commit().await?;

        // 3. 密码学擦除：生成新密钥并用 PRAGMA rekey 轮换
        let new_passphrase = generate_random_passphrase(32);

        sqlx::query(&format!("PRAGMA rekey = \"x'{}'\"", hex::encode(&new_passphrase)))
            .execute(&self.pool)
            .await?;

        // 4. VACUUM 确保旧数据页面被覆盖
        sqlx::query("VACUUM").execute(&self.pool).await?;

        // 5. 将新密钥存入系统密钥链（覆盖旧密钥）
        // 此操作在 Tauri 层完成，见 §9 Tauri Commands

        Ok(ErasureResult {
            records_deleted: u64::MAX,
            crypto_erasure: true,
            audit_id,
        })
    }
}

/// 生成加密安全的随机密码
fn generate_random_passphrase(len: usize) -> Vec<u8> {
    let mut buf = vec![0u8; len];
    rand::thread_rng().fill_bytes(&mut buf);
    buf
}
```

### 7.2 密钥链集成

SQLCipher 密钥存储在操作系统密钥链中（macOS Keychain / Windows Credential Manager / Linux Secret Service），用户无感知：

```rust
// apps/desktop/src-tauri/src/security/keychain.rs

use keyring::Entry;

const SERVICE_NAME: &str = "com.astro-agent.desktop";
const DB_KEY_ACCOUNT: &str = "db_encryption_key";

/// 从系统密钥链获取或创建数据库加密密钥
pub fn get_or_create_db_key() -> anyhow::Result<String> {
    let entry = Entry::new(SERVICE_NAME, DB_KEY_ACCOUNT)?;

    // 尝试读取已有密钥
    match entry.get_password() {
        Ok(key) => Ok(key),
        Err(keyring::Error::NoEntry) => {
            // 首次启动：生成随机密钥并存入密钥链
            let key = generate_hex_key(32); // 256-bit, hex 编码
            entry.set_password(&key)?;
            tracing::info!("已生成并存储数据库加密密钥");
            Ok(key)
        }
        Err(e) => Err(anyhow::anyhow!("密钥链访问失败: {}", e)),
    }
}

/// 轮换数据库加密密钥（密码学擦除时使用）
pub fn rotate_db_key() -> anyhow::Result<String> {
    let entry = Entry::new(SERVICE_NAME, DB_KEY_ACCOUNT)?;
    let new_key = generate_hex_key(32);
    entry.set_password(&new_key)?;
    tracing::info!("数据库加密密钥已轮换");
    Ok(new_key)
}

/// 删除密钥链中的密钥（卸载时可选调用）
pub fn delete_db_key() -> anyhow::Result<()> {
    let entry = Entry::new(SERVICE_NAME, DB_KEY_ACCOUNT)?;
    entry.delete_credential()?;
    Ok(())
}

fn generate_hex_key(bytes: usize) -> String {
    let mut buf = vec![0u8; bytes];
    rand::thread_rng().fill_bytes(&mut buf);
    hex::encode(&buf)
}
```

### 7.3 内存中敏感数据保护

使用 `zeroize` crate 确保密钥、密码等敏感数据在离开作用域时被清零，防止内存残留：

```rust
use zeroize::{Zeroize, ZeroizeOnDrop};

/// 敏感字符串包装器：离开作用域时自动清零内存
#[derive(Zeroize, ZeroizeOnDrop)]
pub struct SensitiveString(String);

impl SensitiveString {
    pub fn new(s: String) -> Self {
        Self(s)
    }

    pub fn as_str(&self) -> &str {
        &self.0
    }
}

/// 敏感字节数组包装器
#[derive(Zeroize, ZeroizeOnDrop)]
pub struct SensitiveBytes(Vec<u8>);

impl SensitiveBytes {
    pub fn new(b: Vec<u8>) -> Self {
        Self(b)
    }

    pub fn as_slice(&self) -> &[u8] {
        &self.0
    }
}

// 使用示例：密钥在函数结束时自动清零
pub fn open_database(path: &Path) -> anyhow::Result<SqlitePool> {
    let key = SensitiveString::new(get_or_create_db_key()?);
    let pool = open_encrypted(path, key.as_str())?;
    // key 在此处离开作用域，内存自动被清零
    Ok(pool)
}
```

### 9.2 更新隐私设置

```rust
/// 更新隐私设置
#[tauri::command]
pub async fn update_privacy_settings(
    state: State<'_, AppState>,
    updates: PrivacySettingsUpdate,
) -> Result<(), AppError> {
    let mut config = state.config.write().await;

    // 更新过滤开关
    if let Some(enabled) = updates.filter_enabled {
        config.privacy.filter_enabled = enabled;
    }

    // 添加自定义过滤规则
    if let Some(rules) = &updates.add_filter_rules {
        for rule in rules {
            // 验证正则表达式语法
            if let FilterPattern::Regex { ref pattern } = rule.pattern {
                regex::Regex::new(pattern)
                    .map_err(|e| AppError::Validation(format!("无效正则: {}", e)))?;
            }
            config.privacy.custom_filter_rules.push(rule.clone());
        }
    }

    // 删除自定义过滤规则
    if let Some(names) = &updates.remove_filter_rules {
        config.privacy.custom_filter_rules
            .retain(|r| !names.contains(&r.name));
    }

    // 更新保留策略
    if let Some(retention) = &updates.retention_policy {
        // 审计日志保留天数最小 30 天
        if retention.audit_logs_ttl_days < 30 {
            return Err(AppError::Validation(
                "审计日志保留天数不得少于 30 天".into()
            ));
        }
        config.privacy.retention_policy = retention.clone();

        // 重新启动清理调度器
        state.retention_scheduler.restart(retention.clone()).await;
    }

    // 更新匿名统计
    if let Some(enabled) = updates.analytics_enabled {
        config.privacy.analytics_enabled = enabled;
    }
    if let Some(enabled) = updates.crash_report_enabled {
        config.privacy.crash_report_enabled = enabled;
    }

    // 持久化配置
    config.save().map_err(|e| AppError::Internal(e.to_string()))?;

    // 重建 SensitiveFilter（配置变更后需要重新编译规则）
    let filter = SensitiveFilter::from_config(&config.privacy)
        .map_err(|e| AppError::Internal(e.to_string()))?;
    state.sensitive_filter.swap(Arc::new(filter));

    Ok(())
}
```

```rust
/// 导出用户数据
/// 返回导出文件的路径（用户通过 file dialog 选择保存位置）
#[tauri::command]
pub async fn export_user_data(
    state: State<'_, AppState>,
    app_handle: AppHandle,
    options: ExportOptions,
) -> Result<String, AppError> {
    // 1. 弹出文件保存对话框
    let save_path = app_handle
        .dialog()
        .file()
        .add_filter("JSON", &["json"])
        .set_file_name(&format!(
            "astro-agent-export-{}.json",
            chrono::Utc::now().format("%Y%m%d-%H%M%S")
        ))
        .blocking_save_file()
        .ok_or(AppError::Cancelled)?;

    // 2. 执行导出
    let exporter = DataExporter::new(state.pool.clone());
    let result = exporter.export(&options).await
        .map_err(|e| AppError::Internal(e.to_string()))?;

    // 3. 写入文件
    tokio::fs::write(&save_path, &result.data).await
        .map_err(|e| AppError::Internal(format!("写入导出文件失败: {}", e)))?;

    // 4. 审计记录
    state.audit_store.insert(AuditLog {
        id: uuid(),
        action: "data_export".into(),
        detail_json: Some(serde_json::json!({
            "format": "json",
            "records": result.filename,
        }).to_string()),
        ..AuditLog::system_action()
    }).await.ok();

    Ok(save_path.to_string_lossy().to_string())
}
```

### 9.4 删除所有数据

```rust
/// 删除所有用户数据
/// confirmation 参数必须为 "DELETE" 字符串，防止误操作
#[tauri::command]
pub async fn delete_all_data(
    state: State<'_, AppState>,
    target: ErasureTarget,
    confirmation: String,
) -> Result<ErasureResult, AppError> {
    // 强制二次确认
    match &target {
        ErasureTarget::AllUserData | ErasureTarget::FactoryReset => {
            if confirmation != "DELETE" {
                return Err(AppError::Validation(
                    "请输入 DELETE 确认删除操作".into()
                ));
            }
        }
        _ => {} // 单条删除不需要文字确认
    }

    let eraser = DataEraser::new(state.pool.clone());
    let result = eraser.erase(&target, &state.audit_store).await
        .map_err(|e| AppError::Internal(e.to_string()))?;

    // Factory Reset 时轮换密钥链中的密钥
    if matches!(target, ErasureTarget::FactoryReset) {
        if let Ok(new_key) = rotate_db_key() {
            // 新密钥已存入密钥链，下次启动时自动使用
            tracing::info!("密钥链密钥已轮换（密码学擦除）");
        }
    }

    // 通知前端刷新状态
    state.emitter.emit("data_erased", serde_json::json!({
        "target": format!("{:?}", target),
        "crypto_erasure": result.crypto_erasure,
    })).await.ok();

    Ok(result)
}
```

## 10. 合规检查清单

### 10.1 GDPR 自评清单

以下清单用于自我评估 Astro Agent 对 GDPR 核心条款的合规情况。由于 Astro Agent 是本地优先的桌面应用，多数条款天然满足：

| 条款 | 要求 | 满足方式 | 状态 |
| --- | --- | --- | --- |
| Art. 5(1)(a) 合法、公正、透明 | 用户知情数据如何处理 | Provider 数据声明面板，明确展示每个 Provider 的数据政策 | ✅ |
| Art. 5(1)(b) 目的限制 | 数据仅用于声明目的 | 本地存储，仅用于 AI 对话；不收集非必要数据 | ✅ |
| Art. 5(1)(c) 数据最小化 | 仅收集必要数据 | 本地优先，仅在 LLM 调用时发送必要上下文；SensitiveFilter 自动脱敏 | ✅ |
| Art. 5(1)(d) 准确性 | 数据应准确且及时更新 | 用户可随时编辑/删除记忆和对话 | ✅ |
| Art. 5(1)(e) 存储限制 | 不超过必要期限保存 | RetentionPolicy 可配置 TTL，自动清理过期数据 | ✅ |
| Art. 5(1)(f) 完整性与保密性 | 适当的安全措施 | SQLCipher 加密、OS Keychain 密钥管理、zeroize 内存保护 | ✅ |
| Art. 15 访问权 | 用户可查看所有个人数据 | 所有数据本地存储，用户可直接查看 | ✅ |
| Art. 17 删除权 | 用户可要求删除数据 | DataEraser 支持选择性删除和完全擦除 | ✅ |
| Art. 20 数据可携权 | 用户可导出结构化数据 | DataExporter 导出 JSON 归档 | ✅ |
| Art. 25 隐私设计 | 设计阶段考虑隐私保护 | Local-First 架构、默认启用过滤和加密 | ✅ |
| Art. 32 安全措施 | 适当的技术保护 | E2E 加密、SQLCipher、安全边界（见 06 号文档） | ✅ |
| Art. 33 泄露通知 | 数据泄露后 72 小时内通知 | 本地应用无集中式数据存储，泄露风险由设备安全管理 | N/A |
| Art. 35 DPIA | 高风险处理需做影响评估 | 本地处理，不涉及大规模个人数据的系统化处理 | N/A |

### 10.2 数据最小化实践

以下设计决策体现了数据最小化原则：

| 实践 | 说明 |
| --- | --- |
| 上下文窗口裁剪 | LLM 调用时仅发送必要的上下文窗口，不发送完整对话历史 |
| 记忆摘要 | 注入 LLM 的记忆是摘要而非原始内容 |
| PII 脱敏 | SensitiveFilter 在发送前自动替换 PII |
| 匿名统计可选 | 使用统计和崩溃报告默认关闭，需用户主动开启 |
| API Key 不持久化到配置文件 | API Key 存储在 OS Keychain，不写入 TOML/YAML |
| 审计日志参数摘要 | 审计日志记录参数的 SHA-256 hash，不记录原始参数 |

### 10.3 Provider 使用的合规指引

| 场景 | 建议 |
| --- | --- |
| 处理包含个人信息的对话 | 启用 SensitiveFilter（默认启用），优先使用 GDPR 合规的 Provider |
| 处理公司机密内容 | 添加公司关键词到 Block 规则；考虑使用 Ollama 本地模型 |
| 使用高风险 Provider (DeepSeek) | 系统自动显示警告；建议仅用于非敏感任务 |
| 数据跨境传输 | Provider 数据声明中标注了数据存储地区；用户可据此选择 |
