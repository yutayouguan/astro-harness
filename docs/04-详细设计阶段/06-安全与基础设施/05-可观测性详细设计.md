# 可观测性详细设计

> **Harness 当前基线（2026-08-29）**：执行追踪以 submission/turn/item/tool-call identity 串联 `EventMsg/TurnItem`、rollout、usage DB、tool audit、approval 和 sandbox/network decision。前端 activity 是投影；要求可复现时必须回到 rollout 和原始 tool result。

> 版本：v1.0 | 日期：2026-08-09 | 状态：草稿
> 对应需求：F-13 可观测性（结构化日志、请求追踪、Token/费用追踪、开发者面板）
> 系统设计：[02-可观测性.md](../../03-系统设计阶段/03-基础设施/02-可观测性.md)

本系统是 Tauri 桌面应用，不部署 Prometheus/Grafana 等服务端基础设施。可观测性三大支柱全部落地为本地方案：结构化 JSON 日志文件、基于 SQLite 的 Span 树与指标存储、应用内开发者面板。

## 1. 可观测性架构

### 1.1 三支柱适配

```text
可观测性（桌面端适配）
├── Logs   → 结构化 JSON 文件（tracing-appender 轮转）
├── Traces → per-conversation Span 树（SQLite spans 表）
└── Metrics → 聚合指标（SQLite usage_metrics 表 + 内存滚动窗口）
```

与服务端方案的核心差异：

| 维度 | 服务端（系统设计原文） | 桌面端（本文） |
|------|----------------------|---------------|
| 日志 | JSON stdout → ELK / Loki | JSON 文件 → 本地轮转 + 应用内 LogViewer |
| 追踪 | OpenTelemetry → Jaeger | 内嵌 Span 树 → SQLite `spans` 表 |
| 指标 | Prometheus metrics | SQLite `usage_metrics` 表 + 内存 `MetricsCollector` |
| 查询 | Grafana Dashboard | 应用内 MetricsPanel / LogViewer 组件 |

> OpenTelemetry 依赖在桌面端保留为可选（`feature = "otlp"`），开发者调试时可通过 `telemetry.otlp_endpoint` 配置项启用，导出到本地 Jaeger。生产构建不打包 OTLP。

## 2. 结构化日志

### 2.1 LogEvent 结构

所有日志事件通过 `tracing` crate 的结构化字段输出，最终序列化为 JSON 行。

```rust
// crates/agent-core/src/telemetry/logger.rs

use tracing_appender::rolling::{RollingFileAppender, Rotation};
use tracing_subscriber::{fmt, layer::SubscriberExt, util::SubscriberInitExt, EnvFilter, Layer};

/// 日志事件的逻辑结构（由 tracing 字段自动组成，非显式构造）
/// 序列化后的 JSON 格式示例：
/// {
///   "timestamp": "2026-08-09T14:30:00.123Z",
///   "level": "INFO",
///   "module": "agent_runtime::executor",
///   "span_id": "a1b2c3d4",
///   "conversation_id": "conv_xxx",
///   "workspace_id": "ws_yyy",
///   "target": "tool_call_complete",
///   "fields": { "tool": "web_search", "duration_ms": 342 }
/// }
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LogEvent {
    pub timestamp: String,          // ISO 8601
    pub level: String,              // ERROR / WARN / INFO / DEBUG / TRACE
    pub module: String,             // Rust module path
    pub span_id: Option<String>,    // 当前 span 的短 ID
    pub conversation_id: Option<String>,
    pub workspace_id: Option<String>,
    pub agent_id: Option<String>,
    pub agent_depth: Option<u8>,    // 0 = 主 Agent，1+ = 子 Agent
    pub target: String,             // 事件名称（如 "tool_call_complete"）
    pub fields: serde_json::Value,  // 附加结构化字段
}
```

### 2.2 关键事件类型与日志级别

| 事件 | 级别 | 典型字段 |
|------|------|---------|
| 任务开始 | INFO | `conversation_id`, `user_message_preview`(前 50 字符) |
| 任务结束 | INFO | `conversation_id`, `total_turns`, `total_cost_usd` |
| LLM 请求 | DEBUG | `model`, `prompt_tokens`, `completion_tokens`, `ttft_ms` |
| LLM 流式完成 | DEBUG | `model`, `total_latency_ms`, `tokens_per_sec` |
| 工具调用开始 | DEBUG | `tool_name`, `risk_level` |
| 工具调用完成 | DEBUG | `tool_name`, `duration_ms`, `success` |
| 子 Agent 派生 | INFO | `child_agent_id`, `role`, `depth` |
| 记忆检索 | DEBUG | `query_preview`, `result_count`, `duration_ms` |
| Provider 降级 | WARN | `from_provider`, `to_provider`, `reason` |
| HumanGuard 拦截 | INFO | `tool_name`, `risk_level`, `decision` |
| 预算警告 | WARN | `current_usd`, `limit_usd`, `pct` |
| 任务失败 | ERROR | `error_type`, `error_message`, `stack` |

### 2.3 tracing 初始化与日志轮转

```rust
// crates/agent-core/src/telemetry/logger.rs

pub struct LoggerConfig {
    pub log_dir: PathBuf,           // 默认 $APP_DATA/logs/
    pub rotation: Rotation,         // Daily
    pub max_files: usize,           // 7（保留 7 天）
    pub compress_old: bool,         // true → gzip 压缩历史日志
    pub level: String,              // "info"（可通过设置页面调整）
    pub format: LogFormat,          // Json / Pretty
}

pub enum LogFormat {
    Json,       // 生产 / 文件日志
    Pretty,     // 开发时 stdout
}

pub fn init_logger(config: &LoggerConfig) -> anyhow::Result<()> {
    let file_appender = RollingFileAppender::builder()
        .rotation(Rotation::DAILY)
        .filename_prefix("astro-agent")
        .filename_suffix("log")
        .max_log_files(config.max_files)
        .build(&config.log_dir)?;

    let (file_writer, _guard) = tracing_appender::non_blocking(file_appender);

    // JSON 文件 Layer
    let json_layer = fmt::layer()
        .json()
        .with_writer(file_writer)
        .with_target(true)
        .with_span_list(true)
        .with_current_span(true)
        .with_filter(EnvFilter::new(&config.level));

    // 可选：stdout Pretty Layer（开发模式）
    let stdout_layer = if matches!(config.format, LogFormat::Pretty) {
        Some(fmt::layer().pretty().with_filter(EnvFilter::new("debug")))
    } else {
        None
    };

    tracing_subscriber::registry()
        .with(json_layer)
        .with(stdout_layer)
        .init();

    // 后台压缩历史日志文件（>1天前的 .log 文件 gzip 压缩）
    if config.compress_old {
        tokio::spawn(compress_old_logs(config.log_dir.clone()));
    }

    Ok(())
}

/// 压缩超过 1 天的日志文件为 .log.gz
async fn compress_old_logs(log_dir: PathBuf) {
    use flate2::write::GzEncoder;
    use flate2::Compression;

    let threshold = chrono::Utc::now() - chrono::Duration::days(1);
    let entries = std::fs::read_dir(&log_dir).ok();

    if let Some(entries) = entries {
        for entry in entries.flatten() {
            let path = entry.path();
            if path.extension().map(|e| e == "log").unwrap_or(false) {
                if let Ok(meta) = entry.metadata() {
                    if let Ok(modified) = meta.modified() {
                        let modified: chrono::DateTime<chrono::Utc> = modified.into();
                        if modified < threshold {
                            // 读取 → gzip → 写入 .gz → 删除原文件
                            if let Ok(content) = tokio::fs::read(&path).await {
                                let gz_path = path.with_extension("log.gz");
                                let gz_file = std::fs::File::create(&gz_path).ok();
                                if let Some(gz_file) = gz_file {
                                    let mut encoder = GzEncoder::new(gz_file, Compression::default());
                                    std::io::Write::write_all(&mut encoder, &content).ok();
                                    encoder.finish().ok();
                                    tokio::fs::remove_file(&path).await.ok();
                                }
                            }
                        }
                    }
                }
            }
        }
    }
}
```

## 3. 请求追踪（Span 树）

### 3.1 设计思路

每个对话轮次（`round_loop` 的一次完整迭代）生成一棵 Span 树，记录从用户输入到 Agent 响应的完整执行链路。Span 树取代 OpenTelemetry 远程追踪，直接持久化到本地 SQLite，支持应用内 SpanViewer 查看。

### 3.2 SpanRecord 结构

```rust
// crates/agent-core/src/telemetry/tracer.rs

use std::time::Instant;

/// 单个 Span 记录
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SpanRecord {
    pub span_id: String,
    pub parent_span_id: Option<String>,
    pub conversation_id: String,
    pub turn_index: u32,            // 对话内的轮次序号
    pub name: String,               // "round_loop" / "llm_call" / "tool_execution" / ...
    pub kind: SpanKind,
    pub start_time: i64,            // Unix ms
    pub end_time: Option<i64>,      // None = 尚未关闭
    pub duration_ms: Option<u64>,
    pub status: SpanStatus,
    pub attributes: serde_json::Value,  // 各 span 类型的专属字段
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum SpanKind {
    RoundLoop,          // 根 span：一个完整轮次
    LlmCall,            // LLM 调用
    ToolExecution,      // 工具执行
    MemoryRetrieval,    // 记忆检索
    PlanConfirmation,   // 计划确认等待
    ChildAgent,         // 子 Agent 执行
    ContextBuild,       // 上下文构建
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum SpanStatus {
    Ok,
    Error(String),
    Cancelled,
}
```

### 3.4 SpanCollector（内存态 Span 树构建）

```rust
// crates/agent-core/src/telemetry/tracer.rs

use dashmap::DashMap;
use tokio::sync::mpsc;

/// 进程内 Span 收集器，在轮次执行期间累积 SpanRecord，轮次结束后一次性持久化
pub struct SpanCollector {
    /// 当前活跃的 span（span_id → SpanRecord）
    active_spans: DashMap<String, SpanRecord>,
    /// 已关闭的 span，等待持久化
    completed_spans: parking_lot::Mutex<Vec<SpanRecord>>,
}

impl SpanCollector {
    pub fn new() -> Self {
        Self {
            active_spans: DashMap::new(),
            completed_spans: parking_lot::Mutex::new(Vec::new()),
        }
    }

    /// 开始一个新 Span
    pub fn start_span(
        &self,
        name: &str,
        kind: SpanKind,
        conversation_id: &str,
        turn_index: u32,
        parent_span_id: Option<&str>,
    ) -> String {
        let span_id = nanoid::nanoid!(12);
        let record = SpanRecord {
            span_id: span_id.clone(),
            parent_span_id: parent_span_id.map(String::from),
            conversation_id: conversation_id.to_string(),
            turn_index,
            name: name.to_string(),
            kind,
            start_time: now_ms(),
            end_time: None,
            duration_ms: None,
            status: SpanStatus::Ok,
            attributes: serde_json::Value::Object(Default::default()),
        };
        self.active_spans.insert(span_id.clone(), record);
        span_id
    }

    /// 结束一个 Span
    pub fn end_span(&self, span_id: &str, status: SpanStatus) {
        if let Some((_, mut span)) = self.active_spans.remove(span_id) {
            let end = now_ms();
            span.end_time = Some(end);
            span.duration_ms = Some((end - span.start_time) as u64);
            span.status = status;
            self.completed_spans.lock().push(span);
        }
    }

    /// 为活跃 Span 追加属性
    pub fn set_attribute(&self, span_id: &str, key: &str, value: serde_json::Value) {
        if let Some(mut span) = self.active_spans.get_mut(span_id) {
            if let serde_json::Value::Object(ref mut map) = span.attributes {
                map.insert(key.to_string(), value);
            }
        }
    }

    /// 轮次结束，收割所有已完成 Span，返回完整树
    pub fn drain(&self) -> Vec<SpanRecord> {
        let mut spans = self.completed_spans.lock();
        std::mem::take(&mut *spans)
    }
}
```

### 3.6 SpanRepo

```rust
// crates/agent-core/src/storage/repos/span_repo.rs

pub struct SpanRepo {
    pool: SqlitePool,
}

impl SpanRepo {
    pub fn new(pool: &SqlitePool) -> Self {
        Self { pool: pool.clone() }
    }

    /// 批量写入一个轮次的所有 Span
    pub async fn save_tree(&self, spans: &[SpanRecord]) -> anyhow::Result<()> {
        let mut tx = self.pool.begin().await?;
        for span in spans {
            sqlx::query(
                "INSERT INTO spans (span_id, parent_span_id, conversation_id, turn_index,
                    name, kind, start_time, end_time, duration_ms, status, error_message, attributes)
                 VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)"
            )
            .bind(&span.span_id)
            .bind(&span.parent_span_id)
            .bind(&span.conversation_id)
            .bind(span.turn_index)
            .bind(&span.name)
            .bind(serde_json::to_string(&span.kind)?)
            .bind(span.start_time)
            .bind(span.end_time)
            .bind(span.duration_ms.map(|d| d as i64))
            .bind(serde_json::to_string(&span.status)?)
            .bind(match &span.status {
                SpanStatus::Error(msg) => Some(msg.as_str()),
                _ => None,
            })
            .bind(serde_json::to_string(&span.attributes)?)
            .execute(&mut *tx)
            .await?;
        }
        tx.commit().await?;
        Ok(())
    }

    /// 查询某个对话某轮的完整 Span 树
    pub async fn get_tree(
        &self,
        conversation_id: &str,
        turn_index: u32,
    ) -> anyhow::Result<Vec<SpanRecord>> {
        let rows = sqlx::query_as::<_, SpanRecord>(
            "SELECT * FROM spans
             WHERE conversation_id = ? AND turn_index = ?
             ORDER BY start_time ASC"
        )
        .bind(conversation_id)
        .bind(turn_index)
        .fetch_all(&self.pool)
        .await?;
        Ok(rows)
    }

    /// 查询某个对话的所有轮次摘要（根 span 列表）
    pub async fn list_root_spans(
        &self,
        conversation_id: &str,
    ) -> anyhow::Result<Vec<SpanRecord>> {
        let rows = sqlx::query_as::<_, SpanRecord>(
            "SELECT * FROM spans
             WHERE conversation_id = ? AND parent_span_id IS NULL
             ORDER BY turn_index ASC"
        )
        .bind(conversation_id)
        .fetch_all(&self.pool)
        .await?;
        Ok(rows)
    }

    /// 清理超过保留期的 Span 数据
    pub async fn cleanup(&self, retention_days: u32) -> anyhow::Result<u64> {
        let threshold = now_ms() - (retention_days as i64 * 86_400_000);
        let result = sqlx::query("DELETE FROM spans WHERE created_at < ?")
            .bind(threshold)
            .execute(&self.pool)
            .await?;
        Ok(result.rows_affected())
    }
}
```

## 4. Token 与费用追踪

### 4.1 TokenUsage 结构

与系统设计阶段 `CostRecord`（02-可观测性 / Schema DDL `cost_records` 表）保持一致，`TokenUsage` 是 LLM 调用后即时构造的轻量结构，由 `UsageRepo` 负责聚合后写入 `usage_metrics` 与 `cost_records`。

```rust
// crates/agent-core/src/telemetry/cost.rs（扩展已有定义）

/// 单次 LLM 调用的 Token 使用量
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TokenUsage {
    pub model: String,
    pub provider: String,
    pub prompt_tokens: u64,
    pub completion_tokens: u64,
    pub cached_tokens: Option<u64>,       // 命中缓存的 token 数
    pub unit_price: ModelPrice,           // 已有：单位美元/百万 token
}

impl TokenUsage {
    /// 计算本次调用费用（美元）
    pub fn cost_usd(&self) -> f64 {
        let input_cost = self.prompt_tokens as f64 * self.unit_price.input / 1_000_000.0;
        let output_cost = self.completion_tokens as f64 * self.unit_price.output / 1_000_000.0;
        // 缓存 token 按输入价的 10% 计费（Anthropic prompt caching 策略）
        let cache_cost = self.cached_tokens.unwrap_or(0) as f64
            * self.unit_price.input * 0.1 / 1_000_000.0;
        input_cost + output_cost + cache_cost
    }
}

/// 单轮对话的聚合使用量
#[derive(Debug, Clone, Default, Serialize, Deserialize)]
pub struct TurnUsageSummary {
    pub conversation_id: String,
    pub turn_index: u32,
    pub total_prompt_tokens: u64,
    pub total_completion_tokens: u64,
    pub total_cost_usd: f64,
    pub llm_calls: u32,                   // 本轮 LLM 调用次数
    pub tool_calls: u32,                  // 本轮工具调用次数
    pub latency_ms: u64,                  // 本轮总耗时
    pub ttft_ms: Option<u64>,             // 首次 LLM 调用的 TTFT
    pub models_used: Vec<String>,         // 本轮使用的模型列表
}

impl TurnUsageSummary {
    /// 累加一次 LLM 调用的 token 使用量
    pub fn add_llm_usage(&mut self, usage: &TokenUsage) {
        self.total_prompt_tokens += usage.prompt_tokens;
        self.total_completion_tokens += usage.completion_tokens;
        self.total_cost_usd += usage.cost_usd();
        self.llm_calls += 1;
        if !self.models_used.contains(&usage.model) {
            self.models_used.push(usage.model.clone());
        }
    }
}

/// 整个对话的聚合使用量
#[derive(Debug, Clone, Default, Serialize, Deserialize)]
pub struct ConversationUsageSummary {
    pub conversation_id: String,
```

## 5. 性能指标收集（MetricsCollector）

内存态的滚动窗口指标收集器，用于实时计算 TTFT、延迟百分位数等性能指标。数据来源于每轮 `round_loop` 结束时的上报，不走 SQLite 查询，保证低延迟。

### 5.1 指标定义

| 指标 | 含义 | 采集点 |
|------|------|--------|
| `ttft_ms` | Time To First Token | LLM 流式调用首个 token 到达时间 |
| `total_latency_ms` | 单轮总延迟 | `round_loop` 从开始到结束的耗时 |
| `llm_latency_ms` | LLM 调用延迟 | 单次 `provider.chat_stream()` 总耗时 |
| `tool_exec_ms` | 工具执行延迟 | 单个工具调用耗时 |
| `memory_retrieval_ms` | 记忆检索延迟 | embedding 搜索 + 结果组装耗时 |
| `context_build_ms` | 上下文构建延迟 | ContextBuilder 组装完整 prompt 耗时 |
| `tokens_per_sec` | 输出速度 | `completion_tokens / (llm_latency_ms / 1000)` |

### 5.2 滚动窗口实现

```rust
// crates/agent-core/src/telemetry/metrics.rs

use std::collections::VecDeque;
use parking_lot::RwLock;

/// 滚动窗口聚合指标
pub struct MetricsCollector {
    /// 各指标的滚动窗口样本
    windows: RwLock<MetricWindows>,
}

struct MetricWindows {
    ttft: RollingWindow,
    total_latency: RollingWindow,
    llm_latency: RollingWindow,
    tool_exec: RollingWindow,
    memory_retrieval: RollingWindow,
    tokens_per_sec: RollingWindow,
}

/// 支持三个时间窗口的滚动样本集合
struct RollingWindow {
    samples: VecDeque<TimedSample>,
}

struct TimedSample {
    value: f64,
    timestamp: i64,  // Unix ms
}

impl RollingWindow {
    fn new() -> Self {
        Self { samples: VecDeque::new() }
    }

    fn push(&mut self, value: f64) {
        self.samples.push_back(TimedSample {
            value,
            timestamp: now_ms(),
        });
        // 只保留 7 天数据（最大窗口）
        let cutoff = now_ms() - 7 * 86_400_000;
        while self.samples.front().map(|s| s.timestamp < cutoff).unwrap_or(false) {
            self.samples.pop_front();
        }
    }

    /// 获取指定窗口内的聚合数据
    fn aggregate(&self, window: TimeWindow) -> WindowAggregate {
        let cutoff = now_ms() - window.duration_ms();
        let values: Vec<f64> = self.samples.iter()
            .filter(|s| s.timestamp >= cutoff)
            .map(|s| s.value)
            .collect();

        if values.is_empty() {
            return WindowAggregate::default();
        }

        let count = values.len();
        let sum: f64 = values.iter().sum();
        let avg = sum / count as f64;
        let mut sorted = values.clone();
        sorted.sort_by(|a, b| a.partial_cmp(b).unwrap());

        WindowAggregate {
            count: count as u64,
            avg,
            min: sorted[0],
            max: sorted[count - 1],
            p50: percentile(&sorted, 0.5),
            p95: percentile(&sorted, 0.95),
            p99: percentile(&sorted, 0.99),
        }
    }
}

#[derive(Debug, Clone, Copy)]
pub enum TimeWindow {
    OneHour,
    TwentyFourHours,
    SevenDays,
}

impl TimeWindow {
    fn duration_ms(&self) -> i64 {
        match self {
            TimeWindow::OneHour => 3_600_000,
            TimeWindow::TwentyFourHours => 86_400_000,
            TimeWindow::SevenDays => 604_800_000,
        }
    }
}

#[derive(Debug, Clone, Default, Serialize, Deserialize)]
pub struct WindowAggregate {
    pub count: u64,
    pub avg: f64,
    pub min: f64,
    pub max: f64,
    pub p50: f64,
    pub p95: f64,
    pub p99: f64,
}

fn percentile(sorted: &[f64], pct: f64) -> f64 {
    if sorted.is_empty() { return 0.0; }
    let idx = ((sorted.len() as f64 - 1.0) * pct).round() as usize;
    sorted[idx.min(sorted.len() - 1)]
}
```

```sql
    ON usage_metrics(conversation_id, turn_index);

CREATE INDEX IF NOT EXISTS idx_usage_created

    ON usage_metrics(model, created_at);
```

与 `cost_records` 表的关系：

| 表 | 粒度 | 用途 |
|----|------|------|
| `cost_records` | 单次 LLM 调用 | 精细化成本审计、预算管控（BudgetManager 消费） |
| `usage_metrics` | 单轮对话 | 性能分析、开发者面板、趋势展示 |

两张表数据互补但不冗余：`cost_records` 由 `agent-providers` 层在每次 LLM 调用完成时写入；`usage_metrics` 由 `agent-runtime` 层在每轮 `round_loop` 结束时聚合写入。

```typescript
import { invoke } from "@tauri-apps/api/core";

interface SpanRecord {

  parentSpanId: string | null;
  name: string;
  kind: string;

  status: string;
  attributes: Record<string, unknown>;

export function SpanViewer({

function SpanNodeView({ node, depth }: { node: SpanNode; depth: number }) {
  const [expanded, setExpanded] = useState(depth < 2);
  const indent = depth * 20;

  return (
    <div>
      <div
        className="flex items-center gap-2 py-1 hover:bg-muted/50 cursor-pointer"
        style={{ paddingLeft: `${indent}px` }}
        onClick={() => setExpanded(!expanded)}
      >
        <span className="text-muted-foreground">
          {node.children.length > 0 ? (expanded ? "▼" : "▶") : "─"}
        </span>
        <span className={`font-medium ${statusColor(node.status)}`}>
          {node.name}
        </span>
        {node.durationMs != null && (
          <span className="text-muted-foreground">{node.durationMs}ms</span>
        )}
        {/* LLM 调用显示 token 数 */}
        {node.kind === "llm_call" && node.attributes.prompt_tokens && (
          <span className="text-xs text-muted-foreground">
            ({node.attributes.prompt_tokens} in / {node.attributes.completion_tokens} out)
          </span>
        )}
      </div>
      {expanded &&
        node.children.map((child) => (
          <SpanNodeView key={child.spanId} node={child} depth={depth + 1} />
        ))}
    </div>
  );
}

function buildTree(spans: SpanRecord[]): SpanNode | null {
  const map = new Map<string, SpanNode>();
  spans.forEach((s) => map.set(s.spanId, { ...s, children: [] }));

  let root: SpanNode | null = null;
  map.forEach((node) => {
    if (node.parentSpanId && map.has(node.parentSpanId)) {
      map.get(node.parentSpanId)!.children.push(node);
    } else {
      root = node;
    }
  });
  return root;
}

function statusColor(status: string): string {
  if (status === "ok") return "text-green-600";
  if (status.startsWith("error")) return "text-red-600";
  if (status === "cancelled") return "text-yellow-600";
  return "";
}
```

```typescript
import { useState, useEffect, useRef } from "react";
import { invoke } from "@tauri-apps/api/core";
import { listen } from "@tauri-apps/api/event";

interface LogEntry {
  timestamp: string;
  level: string;
  module: string;
  target: string;
  conversationId: string | null;
  fields: Record<string, unknown>;
}

export function LogViewer() {
  const [logs, setLogs] = useState<LogEntry[]>([]);
  const [filter, setFilter] = useState({
    levels: new Set(["ERROR", "WARN", "INFO"]),
    conversationId: "",
    search: "",
  });
  const [autoScroll, setAutoScroll] = useState(true);
  const containerRef = useRef<HTMLDivElement>(null);

  // 加载历史日志
  useEffect(() => {
    invoke<LogEntry[]>("get_recent_logs", {
      limit: 500,
      levels: Array.from(filter.levels),
      conversationId: filter.conversationId || null,
    }).then(setLogs);
  }, [filter.levels, filter.conversationId]);

  // 实时监听新日志事件
  useEffect(() => {
    const unlisten = listen<LogEntry>("log_event", ({ payload }) => {
      if (!filter.levels.has(payload.level)) return;
      if (filter.conversationId && payload.conversationId !== filter.conversationId) return;

      setLogs((prev) => {
        const next = [...prev, payload];
        // 内存中最多保留 2000 条
        return next.length > 2000 ? next.slice(-2000) : next;
      });
    });
    return () => { unlisten.then((f) => f()); };
  }, [filter]);

  // 自动滚动
  useEffect(() => {
    if (autoScroll && containerRef.current) {
      containerRef.current.scrollTop = containerRef.current.scrollHeight;
    }
  }, [logs, autoScroll]);

  const filteredLogs = logs.filter((log) => {
    if (filter.search) {
      const searchLower = filter.search.toLowerCase();
      const text = `${log.target} ${JSON.stringify(log.fields)}`.toLowerCase();
      return text.includes(searchLower);
    }
    return true;
  });

  return (
    <div className="log-viewer flex flex-col h-full">
      {/* 过滤工具栏 */}
      <div className="flex items-center gap-3 p-3 border-b">
        {/* 级别过滤复选框 */}
        {["ERROR", "WARN", "INFO", "DEBUG"].map((level) => (
          <label key={level} className="flex items-center gap-1 text-sm">
            <input
              type="checkbox"
              checked={filter.levels.has(level)}
              onChange={(e) => {
                const next = new Set(filter.levels);
                e.target.checked ? next.add(level) : next.delete(level);
                setFilter({ ...filter, levels: next });
              }}
            />
            <span className={levelColor(level)}>{level}</span>
          </label>
        ))}

        <input
          placeholder="conversation_id 过滤..."
          className="px-2 py-1 border rounded text-sm w-48"
          value={filter.conversationId}
          onChange={(e) => setFilter({ ...filter, conversationId: e.target.value })}
        />

        <input
          placeholder="搜索..."
          className="px-2 py-1 border rounded text-sm flex-1"
          value={filter.search}
          onChange={(e) => setFilter({ ...filter, search: e.target.value })}
        />

        <button
          onClick={() => setAutoScroll(!autoScroll)}
          className={`text-sm px-2 py-1 rounded ${
            autoScroll ? "bg-blue-100 text-blue-700" : "bg-muted"
          }`}
        >
          {autoScroll ? "自动滚动: 开" : "自动滚动: 关"}
        </button>
      </div>

      {/* 日志内容 */}
      <div ref={containerRef} className="flex-1 overflow-y-auto font-mono text-xs p-2">
        {filteredLogs.map((log, i) => (
          <div key={i} className="flex gap-2 py-0.5 hover:bg-muted/30">
            <span className="text-muted-foreground shrink-0">
              {log.timestamp.slice(11, 23)}
            </span>
            <span className={`shrink-0 w-12 ${levelColor(log.level)}`}>
              {log.level.padEnd(5)}
            </span>
            <span className="text-muted-foreground shrink-0 w-40 truncate">
              {log.module}
            </span>
            <span>{log.target}</span>
            <span className="text-muted-foreground">
              {JSON.stringify(log.fields)}
            </span>
          </div>
        ))}
      </div>
    </div>
  );
}

  switch (level) {

    case "WARN": return "text-yellow-600";
    case "INFO": return "text-blue-600";
    case "DEBUG": return "text-muted-foreground";
    default: return "";
  }
}
```

```rust
// crates/agent-core/src/telemetry/logger.rs

use tracing::Subscriber;
use tracing_subscriber::Layer;

/// 将日志事件广播到前端的 tracing Layer
pub struct EventBroadcastLayer {
    emitter: Arc<dyn EventEmitter>,
}

impl<S: Subscriber> Layer<S> for EventBroadcastLayer {
    fn on_event(
        &self,
        event: &tracing::Event<'_>,
        ctx: tracing_subscriber::layer::Context<'_, S>,
    ) {
        // 仅广播 INFO 及以上级别（避免 DEBUG 洪水）
        if *event.metadata().level() > tracing::Level::INFO {
            return;
        }

        let mut visitor = JsonVisitor::default();
        event.record(&mut visitor);

        let log_entry = serde_json::json!({
            "timestamp": chrono::Utc::now().to_rfc3339_opts(chrono::SecondsFormat::Millis, true),
            "level": event.metadata().level().to_string(),
            "module": event.metadata().module_path().unwrap_or(""),
            "target": event.metadata().target(),
            "fields": visitor.fields,
        });

        // 非阻塞发送，丢弃失败不影响主逻辑
        let emitter = self.emitter.clone();
        tokio::spawn(async move {
            emitter.emit("log_event", log_entry).await.ok();
        });
    }
}
```

```rust
fn window_to_range(window: &str) -> (i64, i64) {
    let now = now_ms();
    let from = match window {
        "1h"  => now - 3_600_000,
        "24h" => now - 86_400_000,
        "7d"  => now - 604_800_000,
        _     => now - 86_400_000,
    };
    (from, now)
}

/// 从日志文件尾部读取条目（反向读取，性能优先）
fn read_log_file_tail(
    log_dir: &Path,
    limit: u32,
    levels: &[String],
    conversation_id: Option<&str>,
) -> anyhow::Result<Vec<LogEntry>> {
    // 找到最新的日志文件
    let today_file = log_dir.join(format!(
        "astro-agent.{}.log",
        chrono::Utc::now().format("%Y-%m-%d")
    ));

    if !today_file.exists() {
        return Ok(vec![]);
    }

    let content = std::fs::read_to_string(&today_file)?;
    let entries: Vec<LogEntry> = content
        .lines()
        .rev()
        .filter_map(|line| serde_json::from_str::<LogEntry>(line).ok())
        .filter(|e| levels.iter().any(|l| l == &e.level))
        .filter(|e| {
            conversation_id.map_or(true, |cid| {
                e.conversation_id.as_deref() == Some(cid)
            })
        })
        .take(limit as usize)
        .collect();

    Ok(entries.into_iter().rev().collect()) // 恢复时间正序
}
```

## 10. 与 round_loop 的集成

### 10.1 埋点位置总览

在 `AgentExecutor::round_loop()`（[02-agent-runtime详细设计.md](../01-核心引擎层/02-agent-runtime详细设计.md) 第 4 节）的各关键阶段植入 Span 和指标采集代码：

```text
round_loop()
  │
  ├─ [埋点 A] 创建 root span: "round_loop"
  │
  ├─ ① pending 注入
  │
  ├─ ② 上下文构建
  │    └─ [埋点 B] span: "context_build"
  │         └─ [埋点 C] span: "memory_retrieval"（如果触发记忆检索）
  │
  ├─ ③ LLM 调用
  │    └─ [埋点 D] span: "llm_call"
  │         ├─ 记录 TTFT（首个 token 到达时间）
  │         ├─ 记录 token 计数（流结束后）
  │         └─ 写入 cost_records（agent-providers 层）
  │
  ├─ ⑤ 工具执行
  │    └─ [埋点 E] span: "tool_execution"（每个工具一个 span）
  │
  ├─ 子 Agent 派生
  │    └─ [埋点 F] span: "child_agent"
  │
  └─ 轮次结束
       ├─ [埋点 G] 关闭 root span
       ├─ [埋点 H] SpanCollector::drain() → SpanRepo::save_tree()
       ├─ [埋点 I] TurnUsageSummary → UsageRepo::insert()
       └─ [埋点 J] MetricsCollector::record_round_latency()
```

### 10.2 埋点代码示例

```rust
// crates/agent-runtime/src/executor.rs（round_loop 扩展，与 §4 原有代码集成）

impl AgentExecutor {
    pub async fn round_loop(&self) -> Result<RoundOutcome> {
        let max_tool_rounds = self.context.max_tool_rounds;
        let mut round = 0;
        let collector = &self.span_collector;  // Arc<SpanCollector>
        let metrics = &self.metrics_collector;  // Arc<MetricsCollector>

        loop {
            round += 1;
            let round_start = Instant::now();

            // [埋点 A] 创建 root span
            let root_span_id = collector.start_span(
                "round_loop",
                SpanKind::RoundLoop,
                &self.context.conversation_id,
                round,
                None,
            );

            // ① pending 注入（无需单独 span，耗时可忽略）
            for msg in self.pending_queue.drain().await {
                self.context.add_message(Message::user(msg.content, ContextSlot::Regular));
            }

            // ② 上下文构建
            // [埋点 B]
            let ctx_span_id = collector.start_span(
                "context_build", SpanKind::ContextBuild,
                &self.context.conversation_id, round, Some(&root_span_id),
            );

            // [埋点 C] 记忆检索（如果 ContextBuilder 触发）
            let mem_start = Instant::now();
            // ... ContextBuilder 执行 ...
            if memory_retrieved {
                collector.set_attribute(&ctx_span_id, "memory_result_count",
                    serde_json::json!(result_count));
                metrics.record_memory_retrieval(mem_start.elapsed().as_millis() as f64);
            }
            collector.end_span(&ctx_span_id, SpanStatus::Ok);

            // ③ LLM 调用
            self.budget_manager.check_before_call(&self.context.workspace_id, 0.0).await?;

            // [埋点 D]
            let llm_span_id = collector.start_span(
                "llm_call", SpanKind::LlmCall,
                &self.context.conversation_id, round, Some(&root_span_id),
            );
            let llm_start = Instant::now();
            let mut first_token_time: Option<Instant> = None;

            let response = self.context.llm_call_stream_with_hooks(
                &self.emitter,
                |_token| {
                    // TTFT 记录：首个 token 回调
                    if first_token_time.is_none() {
                        first_token_time = Some(Instant::now());
                    }
                },
            ).await?;

            let llm_elapsed = llm_start.elapsed().as_millis() as f64;
            let ttft = first_token_time.map(|t| (t - llm_start).as_millis() as f64);
            let usage = response.usage(); // TokenUsage

            collector.set_attribute(&llm_span_id, "model", serde_json::json!(usage.model));
            collector.set_attribute(&llm_span_id, "prompt_tokens",
                serde_json::json!(usage.prompt_tokens));
            collector.set_attribute(&llm_span_id, "completion_tokens",
                serde_json::json!(usage.completion_tokens));
            if let Some(ttft_val) = ttft {
                collector.set_attribute(&llm_span_id, "ttft_ms", serde_json::json!(ttft_val));
            }
            collector.end_span(&llm_span_id, SpanStatus::Ok);

            // 记录到 MetricsCollector
            let tps = if llm_elapsed > 0.0 {
                usage.completion_tokens as f64 / (llm_elapsed / 1000.0)
            } else { 0.0 };
            metrics.record_llm_call(ttft.unwrap_or(0.0), llm_elapsed, tps);

            // ⑤ 工具执行
            let tool_calls = response.tool_calls();
            if tool_calls.is_empty() {
                // [埋点 G] 关闭 root span
                collector.end_span(&root_span_id, SpanStatus::Ok);
                // [埋点 H/I/J]
                self.finalize_round(collector, metrics, round, round_start, &usage).await;
                return Ok(RoundOutcome::Done);
            }

            for call in tool_calls {
                // [埋点 E]
                let tool_span_id = collector.start_span(
                    &format!("tool_execution:{}", call.tool_name),
                    SpanKind::ToolExecution,
                    &self.context.conversation_id, round, Some(&root_span_id),
                );
                let tool_start = Instant::now();

                let outcome = self.human_guard.check(&call.tool, &call.input).await?;
                // ... 执行工具 ...
                let result = self.context.tools.execute(&call.tool_name, call.input).await;

                let tool_elapsed = tool_start.elapsed().as_millis() as f64;
                collector.set_attribute(&tool_span_id, "tool", serde_json::json!(call.tool_name));
                collector.set_attribute(&tool_span_id, "success",
                    serde_json::json!(!result.is_error));
                collector.end_span(&tool_span_id,
                    if result.is_error { SpanStatus::Error(result.error_message()) }
                    else { SpanStatus::Ok });

                metrics.record_tool_exec(tool_elapsed);
            }
        }
    }

    /// 轮次结束后的统一收尾：持久化 Span 树、写入 usage_metrics、更新 MetricsCollector
    async fn finalize_round(
        &self,
        collector: &SpanCollector,
        metrics: &MetricsCollector,
        turn_index: u32,
        round_start: Instant,
        usage: &TokenUsage,
    ) {
        let round_latency = round_start.elapsed().as_millis() as f64;
        metrics.record_round_latency(round_latency);

        // [埋点 H] 持久化 Span 树
        let spans = collector.drain();
        if let Err(e) = SpanRepo::new(&self.pool).save_tree(&spans).await {
            tracing::warn!("Span 树持久化失败: {}", e);
        }

        // [埋点 I] 写入 usage_metrics
        let summary = TurnUsageSummary {
            conversation_id: self.context.conversation_id.clone(),
            turn_index,
            total_prompt_tokens: usage.prompt_tokens,
            total_completion_tokens: usage.completion_tokens,
            total_cost_usd: usage.cost_usd(),
            llm_calls: 1,
            tool_calls: 0, // 由上层统计
            latency_ms: round_latency as u64,
            ttft_ms: None,
            models_used: vec![usage.model.clone()],
        };
        if let Err(e) = UsageRepo::new(&self.pool).insert(&summary).await {
            tracing::warn!("usage_metrics 写入失败: {}", e);
        }
    }
}
```

```rust
// crates/agent-core/src/telemetry/privacy.rs

/// 日志字段脱敏处理器
pub struct LogSanitizer {
    verbose: bool,
    /// 需要始终脱敏的字段名
    always_redact: HashSet<String>,
    /// PII 正则检测（邮箱、手机号等）
    pii_patterns: Vec<regex::Regex>,
}

impl LogSanitizer {
    pub fn new(verbose: bool) -> Self {
        Self {
            verbose,
            always_redact: HashSet::from_iter([
                "api_key".into(), "secret".into(), "password".into(),
                "token".into(), "authorization".into(),
            ]),
            pii_patterns: vec![
                regex::Regex::new(r"\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b").unwrap(),
                regex::Regex::new(r"\b1[3-9]\d{9}\b").unwrap(),  // 中国手机号
            ],
        }
    }

    /// 清洗日志字段
    pub fn sanitize_fields(&self, fields: &mut serde_json::Map<String, serde_json::Value>) {
        for (key, value) in fields.iter_mut() {
            // 始终脱敏的字段
            if self.always_redact.contains(key) {
                *value = serde_json::Value::String("***".to_string());
                continue;
            }

            // 非 verbose 模式下，消息内容字段只保留预览
            if !self.verbose && (key == "message_content" || key == "response_content") {
                if let serde_json::Value::String(s) = value {
                    let preview: String = s.chars().take(50).collect();
                    *value = serde_json::Value::String(format!("{}...[truncated]", preview));
                }
            }

            // PII 检测与替换
            if let serde_json::Value::String(s) = value {
                let mut sanitized = s.clone();
                for pattern in &self.pii_patterns {
                    sanitized = pattern.replace_all(&sanitized, "[REDACTED]").to_string();
                }
                if sanitized != *s {
                    *value = serde_json::Value::String(sanitized);
                }
            }
        }
    }
}
```

### 11.3 日志导出安全

`export_metrics` 命令导出的 JSON 仅包含聚合统计数据（token 计数、费用、延迟），不包含任何消息内容或个人信息，可安全分享用于问题排查。

## 12. 设计约束

### 12.1 存储限制

| 资源 | 限制 | 清理策略 |
|------|------|---------|
| 日志文件 | 最多 7 个轮转文件 | `tracing-appender` 自动删除旧文件 |
| 单日志文件大小 | 约 10-50MB（取决于使用量） | 历史文件 gzip 压缩（压缩率约 90%） |
| `usage_metrics` 数据 | 保留 90 天 | 每日凌晨清理过期数据 |
| `spans` 数据 | 保留 30 天 | 每日凌晨清理过期数据 |
| `MetricsCollector` 内存 | 最多 7 天样本 × 6 指标 | 自动丢弃超窗口数据 |

### 12.2 性能开销预算

可观测性系统的总 CPU 开销必须控制在 2% 以内（基于 M1 MacBook Air 基准）。

| 组件 | 开销预算 | 实现保证 |
|------|---------|---------|
| tracing JSON 序列化 | < 0.5% | `tracing-appender` 异步写入，不阻塞主线程 |
| SpanCollector 内存操作 | < 0.3% | DashMap 无锁读、parking_lot Mutex 短临界区 |
| MetricsCollector 滚动窗口 | < 0.2% | 纯内存操作，无 I/O |
| SQLite 写入（spans + usage_metrics） | < 0.5% | 批量事务写入（每轮一次），异步执行 |
| EventBroadcast Layer | < 0.3% | 仅广播 INFO 及以上，tokio::spawn 异步 |
| 日志文件 gzip 压缩 | < 0.2% | 后台 tokio task，仅压缩隔天文件 |
| **合计** | **< 2.0%** | |

### 12.3 数据清理后台任务

```rust
// apps/desktop/src-tauri/src/tasks/telemetry_cleanup.rs

/// 每日凌晨 3:00 运行的清理任务
pub async fn run_telemetry_cleanup(pool: SqlitePool) {
    let mut interval = tokio::time::interval(Duration::from_secs(86_400));  // 24h
    loop {
        interval.tick().await;

        // 清理过期 usage_metrics（90 天）
        match UsageRepo::new(&pool).cleanup(90).await {
            Ok(n) => tracing::info!("清理 {} 条过期 usage_metrics", n),
            Err(e) => tracing::warn!("usage_metrics 清理失败: {}", e),
        }

        // 清理过期 spans（30 天）
        match SpanRepo::new(&pool).cleanup(30).await {
            Ok(n) => tracing::info!("清理 {} 条过期 spans", n),
            Err(e) => tracing::warn!("spans 清理失败: {}", e),
        }
    }
}
```
