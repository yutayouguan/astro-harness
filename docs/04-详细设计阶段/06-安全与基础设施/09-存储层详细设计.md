# 存储层详细设计

> **Harness 当前基线（2026-08-29）**：`~/.astro` 分离 Agent 文件、Session 投影、rollout、artifacts/knowledge、subagents、cron/workflow 和 usage 数据。Harness 恢复优先使用 rollout 事实源，不把 blob/cache/临时文件或 UI 投影库当作权威执行日志。

> 版本：v1.0 | 日期：2026-08-11 | 状态：草稿
> 对应需求：F-01 多工作区管理、F-05 知识库管理、F-19 备份与同步
> 补充文档：[01-数据库访问层详细设计](./01-数据库访问层详细设计.md)（SQLite 结构化数据层）

本文档覆盖存储层中**文件系统**部分的完整设计：目录结构规范、StorageManager、Blob 存储、缓存管理、临时文件管理、存储配额与监控、存储清理策略、跨设备同步适配以及 Tauri Commands。SQLite 结构化数据存储已在 01-数据库访问层详细设计中完整覆盖，本文档不再重复。

## 1. 存储架构概述

Astro Agent 的持久化层由两个存储引擎组成，各自承担不同职责：

```text
┌─────────────────────────────────────────────────────────────────┐
│                       Astro Agent 持久化层                       │
│                                                                 │
│  ┌───────────────────────┐     ┌───────────────────────────┐   │
│  │   SQLite 结构化存储    │     │   文件系统 Blob 存储       │   │
│  │   (数据库访问层)       │     │   (本文档)                 │   │
│  │                       │     │                           │   │
│  │  · 对话/消息           │     │  · 媒体文件（图片/音频）   │   │
│  │  · 记忆条目            │     │  · 知识库源文件            │   │
│  │  · 向量嵌入            │     │  · AI 生成文档             │   │
│  │  · 任务追踪            │     │  · Skill 定义文件          │   │
│  │  · 审计日志            │     │  · 配置文件（JSON/TOML）   │   │
│  │  · 媒体任务元数据       │     │  · 缓存（模型/Embedding） │   │
│  │  · 成本统计            │     │  · 日志（7 日轮转）        │   │
│  │                       │     │  · 临时文件                │   │
│  │  WAL + SQLCipher       │     │  · 数据库备份快照          │   │
│  │  sqlite-vec + FTS5     │     │                           │   │
│  └───────────────────────┘     └───────────────────────────┘   │
│         ▲                               ▲                       │
│         │      StorageManager           │                       │
│         └───────── 统一协调 ─────────────┘                       │
└─────────────────────────────────────────────────────────────────┘
```

### 1.1 职责边界

| 维度 | SQLite（01-数据库访问层） | 文件系统（本文档） |
| ---- | ------------------------ | ------------------ |
| 数据特征 | 结构化、可查询、关系型 | 非结构化、二进制、大文件 |
| 典型内容 | 消息文本、记忆条目、向量 | 图片、PDF、音频、缓存 |
| 访问模式 | CRUD + 全文检索 + KNN | 读写整文件、流式读取 |
| 事务保障 | SQLite ACID | write-rename 原子写 |
| 加密 | SQLCipher 整库加密 | 单文件不加密（依赖 OS 磁盘加密） |
| 同步粒度 | 记录级（见 03-E2E 加密同步） | 文件级（选择性同步） |

### 1.2 引用关系

SQLite 中的元数据记录通过路径或 Blob ID 引用文件系统中的实际文件。例如：

- `media_tasks.file_paths` 存储媒体文件在 `workspaces/{id}/media/` 下的相对路径
- `knowledge_sources.uri` 存储知识库源文件在 `workspaces/{id}/knowledge/` 下的路径
- `messages.content` 中的 `![](media://blob_id)` 引用 Blob 存储中的内容寻址文件

StorageManager 负责管理这些路径的解析、验证和生命周期。

### 2.2 路径规范

- 所有路径使用正斜杠 `/` 分隔（跨平台一致性）
- `workspace_id` 为 UUID v4，保证目录名唯一性
- Blob 文件名为完整 SHA-256 哈希 + `.bin` 后缀
- 媒体文件保留原始扩展名（`.png`、`.mp3`、`.mp4`）
- 知识库源文件以 `source_id` 重命名，保留原始扩展名
- 临时文件使用 `.partial` 后缀标识未完成状态

### 2.3 平台差异

| 平台 | 基础路径 | 说明 |
| ---- | -------- | ---- |
| macOS | `~/Library/Application Support/com.astro.agent/` | 遵循 macOS 应用数据规范 |
| Windows | `%APPDATA%\com.astro.agent\` | APPDATA 目录 |
| Linux | `~/.local/share/com.astro.agent/` | XDG 规范 |

在文档中统一使用 `~/.astro/` 指代实际基础路径。运行时通过 Tauri 的 `app_data_dir()` 获取：

```rust
use tauri::api::path::app_data_dir;

fn resolve_base_dir(app: &AppHandle) -> PathBuf {
    app_data_dir(&app.config())
        .expect("failed to resolve app data dir")
}
```

## 3. StorageManager

### 3.1 核心职责

StorageManager 是文件系统存储层的统一入口，负责：

- 工作区作用域的路径解析（所有路径操作必须经过 StorageManager）
- 路径验证与 jail 强制执行（防止路径穿越攻击）
- 原子写操作（write-rename 模式）
- 目录结构初始化与懒创建

### 3.2 数据结构

```rust
// crates/agent-core/src/storage/fs.rs

use std::path::{Path, PathBuf};
use tokio::fs;
use anyhow::Result;

/// 文件系统存储管理器
pub struct StorageManager {
    /// 应用数据根目录（~/.astro/）
    base_dir: PathBuf,
    /// 已规范化的根目录绝对路径（用于 jail 校验）
    base_canonical: PathBuf,
}

/// 存储子目录类型
#[derive(Debug, Clone, Copy)]
pub enum StorageDir {
    /// 工作区配置文件
    Config,
    /// 用户文件
    Files,
    /// AI 生成文档
    AiDocs,
    /// 知识库源文件
    Knowledge,
    /// 媒体文件
    Media,
    /// 内容寻址 Blob
    Blobs,
    /// 工作区级 Skills
    Skills,
    /// 工作区级插件
    Plugins,
}

/// 媒体子目录类型
#[derive(Debug, Clone, Copy)]
pub enum MediaType {
    Image,
    Audio,
    Video,
}
```

### 3.3 实现

```rust
impl StorageManager {
    /// 创建 StorageManager 并初始化全局目录结构
    pub async fn new(base_dir: PathBuf) -> Result<Self> {
        let base_canonical = base_dir.canonicalize()
            .unwrap_or_else(|_| base_dir.clone());

        let manager = Self { base_dir, base_canonical };
        manager.init_global_dirs().await?;
        Ok(manager)
    }

    /// 初始化全局目录（首次启动时创建）
    async fn init_global_dirs(&self) -> Result<()> {
        let dirs = [
            self.base_dir.join("skills"),
            self.base_dir.join("logs"),
            self.base_dir.join("cache/models"),
            self.base_dir.join("cache/embeddings"),
            self.base_dir.join("cache/skill_index"),
            self.base_dir.join("tmp/tool_exec"),
            self.base_dir.join("tmp/exports"),
            self.base_dir.join("tmp/downloads"),
            self.base_dir.join("backups"),
            self.base_dir.join("workspaces"),
        ];
        for dir in &dirs {
            fs::create_dir_all(dir).await?;
        }
        Ok(())
    }

    /// 初始化工作区目录结构（创建工作区时调用）
    pub async fn init_workspace(&self, workspace_id: &str) -> Result<()> {
        let ws_root = self.workspace_root(workspace_id);
        let subdirs = [
            "files/documents", "files/images",
            "ai-docs/reports", "ai-docs/summaries",
            "knowledge", "media/images", "media/audio", "media/video",
            "blobs", "plugins", "skills",
        ];
        for sub in &subdirs {
            fs::create_dir_all(ws_root.join(sub)).await?;
        }
        Ok(())
    }

    // ── 路径解析 ──────────────────────────────────────────────

    /// 应用数据根目录
    pub fn base_dir(&self) -> &Path {
        &self.base_dir
    }

    /// 工作区根目录
    pub fn workspace_root(&self, workspace_id: &str) -> PathBuf {
        self.base_dir.join("workspaces").join(workspace_id)
    }

    /// 解析工作区下某个存储子目录的路径
    pub fn workspace_dir(&self, workspace_id: &str, dir: StorageDir) -> PathBuf {
        let root = self.workspace_root(workspace_id);
        match dir {
            StorageDir::Config    => root.clone(),
            StorageDir::Files     => root.join("files"),
            StorageDir::AiDocs    => root.join("ai-docs"),
            StorageDir::Knowledge => root.join("knowledge"),
            StorageDir::Media     => root.join("media"),
            StorageDir::Blobs     => root.join("blobs"),
            StorageDir::Skills    => root.join("skills"),
            StorageDir::Plugins   => root.join("plugins"),
        }
    }

    /// 解析媒体文件路径
    pub fn media_path(
        &self,
        workspace_id: &str,
        media_type: MediaType,
        filename: &str,
    ) -> Result<PathBuf> {
        let subdir = match media_type {
            MediaType::Image => "images",
            MediaType::Audio => "audio",
            MediaType::Video => "video",
        };
        let path = self.workspace_root(workspace_id)
            .join("media")
            .join(subdir)
            .join(filename);
        self.validate_path(&path)?;
        Ok(path)
    }

    /// 全局缓存目录
    pub fn cache_dir(&self) -> PathBuf {
        self.base_dir.join("cache")
    }

    /// 全局临时文件目录
    pub fn tmp_dir(&self) -> PathBuf {
        self.base_dir.join("tmp")
    }

    /// 日志目录
    pub fn logs_dir(&self) -> PathBuf {
        self.base_dir.join("logs")
    }

    /// 备份目录
    pub fn backups_dir(&self) -> PathBuf {
        self.base_dir.join("backups")
    }

    // ── 路径安全 ──────────────────────────────────────────────

    /// Jail 校验：确保路径不会逃逸出应用数据目录
    ///
    /// 防止路径穿越攻击（如 ../../etc/passwd）
    pub fn validate_path(&self, path: &Path) -> Result<PathBuf> {
        // 先规范化路径（解析 ..、符号链接等）
        let canonical = if path.exists() {
            path.canonicalize()?
        } else {
            // 文件不存在时，规范化父目录 + 文件名
            let parent = path.parent()
                .ok_or_else(|| anyhow::anyhow!("无效路径：无父目录"))?;
            fs::create_dir_all(parent).now_or_never()
                .unwrap_or(Ok(()))?;
            let parent_canonical = parent.canonicalize()
                .unwrap_or_else(|_| parent.to_path_buf());
            parent_canonical.join(
                path.file_name()
                    .ok_or_else(|| anyhow::anyhow!("无效路径：无文件名"))?
            )
        };

        // 检查规范化后的路径是否在 base_dir 内
        if !canonical.starts_with(&self.base_canonical) {
            anyhow::bail!(
                "路径安全校验失败：{} 不在 {} 内",
                canonical.display(),
                self.base_canonical.display()
            );
        }

        Ok(canonical)
    }

    // ── 原子写操作 ────────────────────────────────────────────

    /// 原子写入文件（write-rename 模式）
    ///
    /// 先写入 .tmp 临时文件，成功后 rename 到目标路径。
    /// 即使进程崩溃，也不会产生半写入的损坏文件。
    pub async fn atomic_write(&self, path: &Path, content: &[u8]) -> Result<()> {
        self.validate_path(path)?;

        // 确保父目录存在
        if let Some(parent) = path.parent() {
            fs::create_dir_all(parent).await?;
        }

        // 写入临时文件
        let tmp_path = path.with_extension(
            format!("{}.tmp", path.extension().unwrap_or_default().to_string_lossy())
        );
        fs::write(&tmp_path, content).await?;

        // 原子 rename
        fs::rename(&tmp_path, path).await.map_err(|e| {
            // rename 失败时清理临时文件
            let _ = std::fs::remove_file(&tmp_path);
            anyhow::anyhow!("原子写入 rename 失败: {}", e)
        })?;

        Ok(())
    }

    /// 原子写入文本文件（UTF-8）
    pub async fn atomic_write_text(&self, path: &Path, content: &str) -> Result<()> {
        self.atomic_write(path, content.as_bytes()).await
    }

    // ── 文件操作辅助 ─────────────────────────────────────────

    /// 安全读取文件（经过 jail 校验）
    pub async fn read_file(&self, path: &Path) -> Result<Vec<u8>> {
        self.validate_path(path)?;
        Ok(fs::read(path).await?)
    }

    /// 安全删除文件
    pub async fn remove_file(&self, path: &Path) -> Result<()> {
        self.validate_path(path)?;
        if path.exists() {
            fs::remove_file(path).await?;
        }
        Ok(())
    }

    /// 安全递归删除目录
    pub async fn remove_dir_all(&self, path: &Path) -> Result<()> {
        self.validate_path(path)?;
        if path.exists() {
            fs::remove_dir_all(path).await?;
        }
        Ok(())
    }

    /// 删除工作区所有文件（工作区删除时调用）
    pub async fn delete_workspace_files(&self, workspace_id: &str) -> Result<()> {
        let ws_root = self.workspace_root(workspace_id);
        self.remove_dir_all(&ws_root).await
    }

    /// 计算目录总大小（字节）
    pub async fn dir_size(&self, path: &Path) -> Result<u64> {
        self.validate_path(path)?;
        calculate_dir_size(path).await
    }
}

/// 递归计算目录大小
async fn calculate_dir_size(path: &Path) -> Result<u64> {
    let mut total: u64 = 0;
    let mut entries = fs::read_dir(path).await?;
    while let Some(entry) = entries.next_entry().await? {
        let metadata = entry.metadata().await?;
        if metadata.is_dir() {
            total += Box::pin(calculate_dir_size(&entry.path())).await?;
        } else {
            total += metadata.len();
        }
    }
    Ok(total)
}
```

## 4. Blob 存储

Blob 存储管理媒体文件、大型工具输出、导出归档等二进制数据。采用内容寻址存储（Content-Addressed Storage），以 SHA-256 哈希为文件名，自动实现跨对话/跨消息的文件去重。

### 4.1 存储结构

```text
workspaces/{workspace_id}/blobs/
├── ab/                          # SHA-256 前两位分桶（256 个桶）
│   └── ab3f7c...a1.bin          # 完整 SHA-256 哈希 + .bin
├── cf/
│   └── cf92d1...b2.bin
└── ...
```

分桶设计避免单目录下文件数过多导致的文件系统性能问题（ext4 单目录超过 10000 个文件时 `readdir` 明显变慢）。

### 4.2 BlobStore 实现

```rust
// crates/agent-core/src/storage/blob.rs

use sha2::{Sha256, Digest};
use std::path::{Path, PathBuf};
use tokio::fs;
use anyhow::Result;

/// 内容寻址 Blob 存储
pub struct BlobStore {
    storage: Arc<StorageManager>,
}

/// Blob 元信息
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct BlobMeta {
    pub blob_id: String,          // SHA-256 哈希（十六进制）
    pub size: u64,                // 文件大小（字节）
    pub mime_type: Option<String>,// MIME 类型
    pub created_at: i64,          // 创建时间戳
}

impl BlobStore {
    pub fn new(storage: Arc<StorageManager>) -> Self {
        Self { storage }
    }

    /// 存储 Blob，返回 blob_id（SHA-256 哈希）
    ///
    /// 若相同内容已存在，直接返回已有 blob_id（去重）
    pub async fn put(
        &self,
        workspace_id: &str,
        content: &[u8],
        mime_type: Option<&str>,
    ) -> Result<BlobMeta> {
        let hash = sha256_hex(content);
        let blob_path = self.blob_path(workspace_id, &hash);

        // 去重：内容相同的 Blob 不重复写入
        if !blob_path.exists() {
            self.storage.atomic_write(&blob_path, content).await?;
        }

        Ok(BlobMeta {
            blob_id: hash,
            size: content.len() as u64,
            mime_type: mime_type.map(String::from),
            created_at: now_ms(),
        })
    }

    /// 从流式数据存储 Blob（大文件场景）
    pub async fn put_stream(
        &self,
        workspace_id: &str,
        reader: &mut (impl tokio::io::AsyncRead + Unpin),
        mime_type: Option<&str>,
    ) -> Result<BlobMeta> {
        use tokio::io::AsyncReadExt;

        // 先写到临时文件，同时计算哈希
        let tmp_dir = self.storage.tmp_dir().join("blob_upload");
        fs::create_dir_all(&tmp_dir).await?;
        let tmp_path = tmp_dir.join(format!("{}.partial", uuid::Uuid::new_v4()));

        let mut hasher = Sha256::new();
        let mut file = fs::File::create(&tmp_path).await?;
        let mut total_size: u64 = 0;
        let mut buf = vec![0u8; 64 * 1024]; // 64KB 缓冲区

        loop {
            let n = reader.read(&mut buf).await?;
            if n == 0 { break; }
            hasher.update(&buf[..n]);
            tokio::io::AsyncWriteExt::write_all(&mut file, &buf[..n]).await?;
            total_size += n as u64;
        }
        drop(file);

        let hash = format!("{:x}", hasher.finalize());
        let blob_path = self.blob_path(workspace_id, &hash);

        if blob_path.exists() {
            // 已存在相同内容，删除临时文件
            let _ = fs::remove_file(&tmp_path).await;
        } else {
            // rename 到目标路径
            if let Some(parent) = blob_path.parent() {
                fs::create_dir_all(parent).await?;
            }
            fs::rename(&tmp_path, &blob_path).await?;
        }

        Ok(BlobMeta {
            blob_id: hash,
            size: total_size,
            mime_type: mime_type.map(String::from),
            created_at: now_ms(),
        })
    }

    /// 读取 Blob 内容
    pub async fn get(
        &self,
        workspace_id: &str,
        blob_id: &str,
    ) -> Result<Vec<u8>> {
        let path = self.blob_path(workspace_id, blob_id);
        self.storage.read_file(&path).await
    }

    /// 检查 Blob 是否存在
    pub async fn exists(
        &self,
        workspace_id: &str,
        blob_id: &str,
    ) -> bool {
        self.blob_path(workspace_id, blob_id).exists()
    }

    /// 删除 Blob（仅在引用计数归零时调用）
    pub async fn delete(
        &self,
        workspace_id: &str,
        blob_id: &str,
    ) -> Result<()> {
        let path = self.blob_path(workspace_id, blob_id);
        self.storage.remove_file(&path).await
    }

    /// 列出工作区下所有 Blob ID
    pub async fn list_blobs(&self, workspace_id: &str) -> Result<Vec<String>> {
        let blobs_dir = self.storage.workspace_dir(workspace_id, StorageDir::Blobs);
        let mut blob_ids = Vec::new();

        if !blobs_dir.exists() {
            return Ok(blob_ids);
        }

        let mut buckets = fs::read_dir(&blobs_dir).await?;
        while let Some(bucket) = buckets.next_entry().await? {
            if !bucket.metadata().await?.is_dir() { continue; }
            let mut files = fs::read_dir(bucket.path()).await?;
            while let Some(file) = files.next_entry().await? {
                if let Some(name) = file.file_name().to_str() {
                    if let Some(id) = name.strip_suffix(".bin") {
                        blob_ids.push(id.to_string());
                    }
                }
            }
        }

        Ok(blob_ids)
    }

    /// 计算 Blob 存储总大小
    pub async fn total_size(&self, workspace_id: &str) -> Result<u64> {
        let blobs_dir = self.storage.workspace_dir(workspace_id, StorageDir::Blobs);
        self.storage.dir_size(&blobs_dir).await
    }

    // ── 内部方法 ──────────────────────────────────────────────

    /// 根据 blob_id 计算文件路径（分桶）
    fn blob_path(&self, workspace_id: &str, blob_id: &str) -> PathBuf {
        let bucket = &blob_id[..2]; // SHA-256 前两位
        self.storage.workspace_dir(workspace_id, StorageDir::Blobs)
            .join(bucket)
            .join(format!("{}.bin", blob_id))
    }
}

fn sha256_hex(data: &[u8]) -> String {
    let mut hasher = Sha256::new();
    hasher.update(data);
    format!("{:x}", hasher.finalize())
}
```

## 5. 缓存管理

### 5.1 CacheManager 概述

CacheManager 管理所有非持久性缓存数据，包括 Provider 模型目录、Embedding 向量、Skill 索引等。所有缓存数据丢失后可重建，不影响核心功能。

```rust
// crates/agent-core/src/storage/cache.rs

use std::path::PathBuf;
use tokio::fs;
use anyhow::Result;

/// 缓存管理器
pub struct CacheManager {
    cache_dir: PathBuf,
    /// Embedding 缓存 LRU 最大大小（字节）
    embedding_max_bytes: u64,
}

/// 缓存条目元信息
#[derive(Debug, Serialize, Deserialize)]
struct CacheMeta {
    created_at: i64,
    ttl_secs: u64,           // 生存时间（秒）
    size_bytes: u64,
}

impl CacheManager {
    pub fn new(cache_dir: PathBuf) -> Self {
        Self {
            cache_dir,
            embedding_max_bytes: 100 * 1024 * 1024, // 100MB
        }
    }

    // ── 模型目录缓存（24h TTL）──────────────────────────────

    /// 读取 Provider 的模型列表缓存
    pub async fn get_model_catalog(
        &self,
        provider: &str,
    ) -> Result<Option<String>> {
        let path = self.cache_dir.join("models").join(format!("{}.json", provider));
        let meta_path = path.with_extension("meta.json");

        if !path.exists() || !meta_path.exists() {
            return Ok(None);
        }

        // 检查 TTL
        let meta_bytes = fs::read(&meta_path).await?;
        let meta: CacheMeta = serde_json::from_slice(&meta_bytes)?;
        let age_secs = (now_ms() - meta.created_at) / 1000;
        if age_secs as u64 > meta.ttl_secs {
            // 已过期，删除
            let _ = fs::remove_file(&path).await;
            let _ = fs::remove_file(&meta_path).await;
            return Ok(None);
        }

        let content = fs::read_to_string(&path).await?;
        Ok(Some(content))
    }

    /// 写入 Provider 模型列表缓存
    pub async fn set_model_catalog(
        &self,
        provider: &str,
        content: &str,
    ) -> Result<()> {
        let dir = self.cache_dir.join("models");
        fs::create_dir_all(&dir).await?;

        let path = dir.join(format!("{}.json", provider));
        let meta_path = path.with_extension("meta.json");

        fs::write(&path, content).await?;
        let meta = CacheMeta {
            created_at: now_ms(),
            ttl_secs: 24 * 3600, // 24 小时
            size_bytes: content.len() as u64,
        };
        fs::write(&meta_path, serde_json::to_vec(&meta)?).await?;

        Ok(())
    }

    // ── Embedding 缓存（LRU，100MB 上限）─────────────────────

    /// 获取文本的缓存 Embedding 向量
    pub async fn get_embedding(
        &self,
        text_hash: &str,
    ) -> Result<Option<Vec<f32>>> {
        let path = self.cache_dir
            .join("embeddings")
            .join(format!("{}.emb", text_hash));

        if !path.exists() {
            return Ok(None);
        }

        let bytes = fs::read(&path).await?;
        let embedding: Vec<f32> = bytes
            .chunks_exact(4)
            .map(|b| f32::from_le_bytes([b[0], b[1], b[2], b[3]]))
            .collect();

        // 更新访问时间（LRU 排序依据）
        let _ = filetime::set_file_atime(&path, filetime::FileTime::now());

        Ok(Some(embedding))
    }

    /// 缓存 Embedding 向量
    pub async fn set_embedding(
        &self,
        text_hash: &str,
        embedding: &[f32],
    ) -> Result<()> {
        let dir = self.cache_dir.join("embeddings");
        fs::create_dir_all(&dir).await?;

        // 写入前检查缓存总大小，超出上限时触发 LRU 淘汰
        self.evict_embeddings_if_needed().await?;

        let path = dir.join(format!("{}.emb", text_hash));
        let bytes: Vec<u8> = embedding.iter()
            .flat_map(|f| f.to_le_bytes())
            .collect();
        fs::write(&path, bytes).await?;

        Ok(())
    }

    /// LRU 淘汰：当 Embedding 缓存超过上限时，删除最久未访问的文件
    async fn evict_embeddings_if_needed(&self) -> Result<()> {
        let dir = self.cache_dir.join("embeddings");
        if !dir.exists() { return Ok(()); }

        let total = calculate_dir_size(&dir).await.unwrap_or(0);
        if total <= self.embedding_max_bytes {
            return Ok(());
        }

        // 收集所有缓存文件及其访问时间
        let mut files: Vec<(PathBuf, std::time::SystemTime)> = Vec::new();
        let mut entries = fs::read_dir(&dir).await?;
        while let Some(entry) = entries.next_entry().await? {
            if let Ok(meta) = entry.metadata().await {
                let atime = meta.accessed().unwrap_or(meta.modified().unwrap_or(std::time::UNIX_EPOCH));
                files.push((entry.path(), atime));
            }
        }

        // 按访问时间排序（最旧的在前）
        files.sort_by_key(|(_, t)| *t);

        // 删除最旧的文件，直到低于阈值的 80%
        let target = self.embedding_max_bytes * 80 / 100;
        let mut current = total;
        for (path, _) in &files {
            if current <= target { break; }
            if let Ok(meta) = fs::metadata(&path).await {
                current -= meta.len();
                let _ = fs::remove_file(&path).await;
            }
        }

        Ok(())
    }

    // ── Skill BM25 索引缓存 ──────────────────────────────────

    /// 读取 Skill 索引缓存
    pub async fn get_skill_index(&self) -> Result<Option<Vec<u8>>> {
        let path = self.cache_dir.join("skill_index").join("index.bin");
        if path.exists() {
            Ok(Some(fs::read(&path).await?))
        } else {
            Ok(None)
        }
    }

    /// 写入 Skill 索引缓存
    pub async fn set_skill_index(&self, data: &[u8]) -> Result<()> {
        let dir = self.cache_dir.join("skill_index");
        fs::create_dir_all(&dir).await?;
        fs::write(dir.join("index.bin"), data).await?;
        Ok(())
    }

    // ── 全局操作 ──────────────────────────────────────────────

    /// 清空所有缓存
    pub async fn clear_all(&self) -> Result<u64> {
        let size = calculate_dir_size(&self.cache_dir).await.unwrap_or(0);
        if self.cache_dir.exists() {
            fs::remove_dir_all(&self.cache_dir).await?;
            fs::create_dir_all(&self.cache_dir).await?;
            // 重建子目录
            fs::create_dir_all(self.cache_dir.join("models")).await?;
            fs::create_dir_all(self.cache_dir.join("embeddings")).await?;
            fs::create_dir_all(self.cache_dir.join("skill_index")).await?;
        }
        Ok(size)
    }

    /// 获取缓存总大小
    pub async fn total_size(&self) -> Result<u64> {
        calculate_dir_size(&self.cache_dir).await
    }
}
```

## 6. 临时文件管理

### 6.1 TempFileManager

管理工具执行、导出操作、下载过程中产生的临时文件。所有临时文件受 24 小时 TTL 约束，会话结束时也触发清理。

```rust
// crates/agent-core/src/storage/temp.rs

use tokio::fs;
use std::path::{Path, PathBuf};
use anyhow::Result;

/// 临时文件类型
#[derive(Debug, Clone, Copy)]
pub enum TempCategory {
    /// 工具执行产生的临时文件
    ToolExec,
    /// 导出中间产物（PDF 渲染等）
    Export,
    /// 下载中的文件
    Download,
}

/// 临时文件管理器
pub struct TempFileManager {
    tmp_dir: PathBuf,
    /// 临时文件最大生存时间（毫秒），默认 24 小时
    ttl_ms: i64,
}

impl TempFileManager {
    pub fn new(tmp_dir: PathBuf) -> Self {
        Self {
            tmp_dir,
            ttl_ms: 24 * 3600 * 1000,
        }
    }

    /// 创建临时文件，返回文件路径
    ///
    /// 文件名格式：{timestamp}_{uuid}.{ext}
    pub async fn create_temp_file(
        &self,
        category: TempCategory,
        extension: &str,
    ) -> Result<PathBuf> {
        let dir = self.category_dir(category);
        fs::create_dir_all(&dir).await?;

        let filename = format!(
            "{}_{}.{}",
            now_ms(),
            uuid::Uuid::new_v4(),
            extension.trim_start_matches('.')
        );
        let path = dir.join(&filename);

        // 创建空文件占位
        fs::File::create(&path).await?;

        Ok(path)
    }

    /// 创建临时目录，返回目录路径
    pub async fn create_temp_dir(
        &self,
        category: TempCategory,
    ) -> Result<PathBuf> {
        let dir = self.category_dir(category)
            .join(format!("{}_{}", now_ms(), uuid::Uuid::new_v4()));
        fs::create_dir_all(&dir).await?;
        Ok(dir)
    }

    /// 清理所有过期临时文件（超过 TTL）
    pub async fn cleanup_expired(&self) -> Result<CleanupResult> {
        let now = now_ms();
        let mut result = CleanupResult::default();

        for category in &[TempCategory::ToolExec, TempCategory::Export, TempCategory::Download] {
            let dir = self.category_dir(*category);
            if !dir.exists() { continue; }

            let cleaned = self.cleanup_dir(&dir, now).await?;
            result.files_removed += cleaned.files_removed;
            result.bytes_freed += cleaned.bytes_freed;
        }

        Ok(result)
    }

    /// 清理特定目录中的过期文件
    async fn cleanup_dir(&self, dir: &Path, now: i64) -> Result<CleanupResult> {
        let mut result = CleanupResult::default();
        let mut entries = fs::read_dir(dir).await?;

        while let Some(entry) = entries.next_entry().await? {
            let metadata = entry.metadata().await?;

            if metadata.is_dir() {
                // 递归清理子目录
                let sub = Box::pin(self.cleanup_dir(&entry.path(), now)).await?;
                result.files_removed += sub.files_removed;
                result.bytes_freed += sub.bytes_freed;

                // 清理空目录
                if fs::read_dir(entry.path()).await?.next_entry().await?.is_none() {
                    let _ = fs::remove_dir(entry.path()).await;
                }
                continue;
            }

            // 从文件名中提取创建时间戳
            let created_at = self.extract_timestamp(entry.file_name().to_str().unwrap_or(""));
            let age = now - created_at;

            if age > self.ttl_ms {
                let size = metadata.len();
                if fs::remove_file(entry.path()).await.is_ok() {
                    result.files_removed += 1;
                    result.bytes_freed += size;
                }
            }
        }

        Ok(result)
    }

    /// 会话结束时清理该会话产生的临时文件
    pub async fn cleanup_session(&self, session_id: &str) -> Result<CleanupResult> {
        // 会话级清理：删除所有包含 session_id 的临时文件
        let mut result = CleanupResult::default();

        for category in &[TempCategory::ToolExec, TempCategory::Export] {
            let dir = self.category_dir(*category);
            if !dir.exists() { continue; }

            let mut entries = fs::read_dir(&dir).await?;
            while let Some(entry) = entries.next_entry().await? {
                let name = entry.file_name().to_string_lossy().to_string();
                if name.contains(session_id) {
                    let size = entry.metadata().await.map(|m| m.len()).unwrap_or(0);
                    if fs::remove_file(entry.path()).await.is_ok() {
                        result.files_removed += 1;
                        result.bytes_freed += size;
                    }
                }
            }
        }

        Ok(result)
    }

    /// 获取临时文件总大小
    pub async fn total_size(&self) -> Result<u64> {
        calculate_dir_size(&self.tmp_dir).await
    }

    // ── 内部方法 ──────────────────────────────────────────────

    fn category_dir(&self, category: TempCategory) -> PathBuf {
        match category {
            TempCategory::ToolExec => self.tmp_dir.join("tool_exec"),
            TempCategory::Export   => self.tmp_dir.join("exports"),
            TempCategory::Download => self.tmp_dir.join("downloads"),
        }
    }

    /// 从文件名前缀提取时间戳（格式：{timestamp}_{uuid}.ext）
    fn extract_timestamp(&self, filename: &str) -> i64 {
        filename.split('_')
            .next()
            .and_then(|s| s.parse::<i64>().ok())
            .unwrap_or(0)
    }
}

/// 清理结果
#[derive(Debug, Default, Serialize)]
pub struct CleanupResult {
    pub files_removed: usize,
    pub bytes_freed: u64,
}
```

```rust
pub struct StorageMonitor {

    /// 获取工作区存储使用统计

        quota: &StorageQuota,
    ) -> Result<StorageUsage> {

            .unwrap_or(0);

            .unwrap_or(0);

            .total_size(workspace_id)
            .await
            .unwrap_or(0);

        let total_bytes = files_bytes + media_bytes + knowledge_bytes + blobs_bytes;
        let total_max = quota.files_max_bytes + quota.media_max_bytes
            + quota.knowledge_max_bytes + quota.blobs_max_bytes;

        let files_pct = pct(files_bytes, quota.files_max_bytes);
        let media_pct = pct(media_bytes, quota.media_max_bytes);
        let knowledge_pct = pct(knowledge_bytes, quota.knowledge_max_bytes);
        let blobs_pct = pct(blobs_bytes, quota.blobs_max_bytes);
        let total_pct = pct(total_bytes, total_max);

        // 确定告警级别（任一类别达到 critical 即整体 critical）
        let alert_level = if [files_pct, media_pct, knowledge_pct, blobs_pct]
            .iter()
            .any(|&p| p >= quota.critical_threshold_pct as f32)
        {
            AlertLevel::Critical
        } else if [files_pct, media_pct, knowledge_pct, blobs_pct]
            .iter()
            .any(|&p| p >= quota.warn_threshold_pct as f32)
        {
            AlertLevel::Warning
        } else {
            AlertLevel::Normal
        };

        // 生成清理建议
        let suggestions = self.generate_suggestions(
            workspace_id, files_pct, media_pct, knowledge_pct, blobs_pct, quota,
        ).await;

        Ok(StorageUsage {
            workspace_id: workspace_id.to_string(),
            files_bytes,
            media_bytes,
            knowledge_bytes,
            blobs_bytes,
            total_bytes,
            quota: quota.clone(),
            files_pct,
            media_pct,
            knowledge_pct,
            blobs_pct,
            total_pct,
            alert_level,
            suggestions,
        })
    }

    /// 生成清理建议
    async fn generate_suggestions(
        &self,
        workspace_id: &str,
        files_pct: f32,
        media_pct: f32,
        knowledge_pct: f32,
        blobs_pct: f32,
        quota: &StorageQuota,
    ) -> Vec<CleanupSuggestion> {
        let mut suggestions = Vec::new();
        let warn = quota.warn_threshold_pct as f32;

        if blobs_pct >= warn {
            suggestions.push(CleanupSuggestion {
                category: "blobs".into(),
                description: "清理孤立 Blob 文件（未被任何消息或产物引用）".into(),
                estimated_bytes: 0, // 需要实际扫描
            });
        }

        if media_pct >= warn {
            suggestions.push(CleanupSuggestion {
                category: "media".into(),
                description: "删除超过 30 天未使用的媒体文件".into(),
                estimated_bytes: 0,
            });
        }

        if knowledge_pct >= warn {
            suggestions.push(CleanupSuggestion {
                category: "knowledge".into(),
                description: "移除不再需要的知识库源文件".into(),
                estimated_bytes: 0,
            });
        }

        if files_pct >= warn {
            suggestions.push(CleanupSuggestion {
                category: "files".into(),
                description: "清理用户文件目录中的大文件".into(),
                estimated_bytes: 0,
            });
        }

        suggestions
    }

    /// 配额检查：写入前调用，超出配额时拒绝写入
    pub async fn check_quota(
        &self,
        workspace_id: &str,
        dir: StorageDir,
        additional_bytes: u64,
        quota: &StorageQuota,
    ) -> Result<()> {
        let max_bytes = match dir {
            StorageDir::Files     => quota.files_max_bytes,
            StorageDir::Media     => quota.media_max_bytes,
            StorageDir::Knowledge => quota.knowledge_max_bytes,
            StorageDir::Blobs     => quota.blobs_max_bytes,
            _                     => return Ok(()), // 其他目录不限配额
        };

        let current = self.storage
            .dir_size(&self.storage.workspace_dir(workspace_id, dir))
            .await
            .unwrap_or(0);

        if current + additional_bytes > max_bytes {
            anyhow::bail!(
                "存储配额不足：当前 {:.1}MB / {:.1}MB，写入 {:.1}MB 将超出限制",
                current as f64 / 1_048_576.0,
                max_bytes as f64 / 1_048_576.0,
                additional_bytes as f64 / 1_048_576.0,
            );
        }

        Ok(())
    }
}

fn pct(used: u64, max: u64) -> f32 {
    if max == 0 { return 0.0; }
    (used as f32 / max as f32) * 100.0
}
```

## 8. 存储清理策略

### 8.1 CleanupScheduler

定时执行清理任务，也支持用户从设置 UI 手动触发。

```rust
// crates/agent-core/src/storage/cleanup.rs

use tokio::time::{interval, Duration};
use anyhow::Result;

/// 清理任务调度器
pub struct CleanupScheduler {
    storage: Arc<StorageManager>,
    blob_store: Arc<BlobStore>,
    blob_refs: Arc<BlobRefRepo>,
    cache_mgr: Arc<CacheManager>,
    temp_mgr: Arc<TempFileManager>,
}

/// 清理报告
#[derive(Debug, Default, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct CleanupReport {
    pub orphan_blobs_removed: usize,
    pub orphan_blobs_bytes: u64,
    pub expired_temp_files: usize,
    pub expired_temp_bytes: u64,
    pub old_logs_removed: usize,
    pub old_logs_bytes: u64,
    pub cache_evicted_bytes: u64,
    pub total_bytes_freed: u64,
}

impl CleanupScheduler {
    pub fn new(
        storage: Arc<StorageManager>,
        blob_store: Arc<BlobStore>,
        blob_refs: Arc<BlobRefRepo>,
        cache_mgr: Arc<CacheManager>,
        temp_mgr: Arc<TempFileManager>,
    ) -> Self {
        Self { storage, blob_store, blob_refs, cache_mgr, temp_mgr }
    }

    /// 启动定时清理任务（每 6 小时执行一次）
    pub fn start_periodic(self: Arc<Self>) {
        tokio::spawn(async move {
            let mut ticker = interval(Duration::from_secs(6 * 3600));
            loop {
                ticker.tick().await;
                match self.run_full_cleanup().await {
                    Ok(report) => {
                        tracing::info!(
                            "定时清理完成：释放 {:.1}MB",
                            report.total_bytes_freed as f64 / 1_048_576.0
                        );
                    }
                    Err(e) => {
                        tracing::warn!("定时清理失败: {e}");
                    }
                }
            }
        });
    }

    /// 执行完整清理流程
    pub async fn run_full_cleanup(&self) -> Result<CleanupReport> {
        let mut report = CleanupReport::default();

        // 1. 清理孤立 Blob
        let orphan_result = self.cleanup_orphan_blobs().await?;
        report.orphan_blobs_removed = orphan_result.0;
        report.orphan_blobs_bytes = orphan_result.1;

        // 2. 清理过期临时文件
        let temp_result = self.temp_mgr.cleanup_expired().await?;
        report.expired_temp_files = temp_result.files_removed;
        report.expired_temp_bytes = temp_result.bytes_freed;

        // 3. 日志轮转（保留 7 天）
        let log_result = self.rotate_logs(7).await?;
        report.old_logs_removed = log_result.0;
        report.old_logs_bytes = log_result.1;

        // 4. 缓存淘汰（触发各缓存的 eviction 策略）
        // CacheManager 内部 LRU 淘汰在写入时已经触发，这里只做过期检查
        // 主动清理 model catalog 过期缓存
        let cache_freed = self.cleanup_expired_cache().await?;
        report.cache_evicted_bytes = cache_freed;

        report.total_bytes_freed = report.orphan_blobs_bytes
            + report.expired_temp_bytes
            + report.old_logs_bytes
            + report.cache_evicted_bytes;

        Ok(report)
    }

    /// 清理孤立 Blob（未被任何记录引用的文件）
    async fn cleanup_orphan_blobs(&self) -> Result<(usize, u64)> {
        let mut total_removed = 0;
        let mut total_bytes = 0u64;

        // 遍历所有工作区
        let ws_dir = self.storage.base_dir().join("workspaces");
        if !ws_dir.exists() { return Ok((0, 0)); }

        let mut entries = tokio::fs::read_dir(&ws_dir).await?;
        while let Some(entry) = entries.next_entry().await? {
            if !entry.metadata().await?.is_dir() { continue; }

            let workspace_id = entry.file_name().to_string_lossy().to_string();
            let all_blobs = self.blob_store.list_blobs(&workspace_id).await?;

            for blob_id in &all_blobs {
                let ref_count = self.blob_refs.ref_count(blob_id).await?;
                if ref_count == 0 {
                    // 孤立 Blob，执行删除
                    let path = self.storage.workspace_dir(&workspace_id, StorageDir::Blobs)
                        .join(&blob_id[..2])
                        .join(format!("{}.bin", blob_id));

                    if let Ok(meta) = tokio::fs::metadata(&path).await {
                        total_bytes += meta.len();
                    }
                    if self.blob_store.delete(&workspace_id, blob_id).await.is_ok() {
                        total_removed += 1;
                    }
                }
            }
        }

        Ok((total_removed, total_bytes))
    }

    /// 日志轮转：删除超过 retention_days 天的日志文件
    async fn rotate_logs(&self, retention_days: u32) -> Result<(usize, u64)> {
        let log_dir = self.storage.logs_dir();
        if !log_dir.exists() { return Ok((0, 0)); }

        let cutoff = now_ms() - (retention_days as i64 * 24 * 3600 * 1000);
        let mut removed = 0;
        let mut bytes = 0u64;

        let mut entries = tokio::fs::read_dir(&log_dir).await?;
        while let Some(entry) = entries.next_entry().await? {
            let meta = entry.metadata().await?;
            let modified = meta.modified()
                .ok()
                .and_then(|t| t.duration_since(std::time::UNIX_EPOCH).ok())
                .map(|d| d.as_millis() as i64)
                .unwrap_or(0);

            if modified < cutoff {
                bytes += meta.len();
                if tokio::fs::remove_file(entry.path()).await.is_ok() {
                    removed += 1;
                }
            }
        }

        Ok((removed, bytes))
    }

    /// 清理过期的模型目录缓存
    async fn cleanup_expired_cache(&self) -> Result<u64> {
        let models_dir = self.cache_mgr.cache_dir.join("models");
        if !models_dir.exists() { return Ok(0); }

        let mut freed = 0u64;
        let mut entries = tokio::fs::read_dir(&models_dir).await?;

        while let Some(entry) = entries.next_entry().await? {
            let name = entry.file_name().to_string_lossy().to_string();
            if name.ends_with(".meta.json") {
                let meta_bytes = tokio::fs::read(entry.path()).await?;
                if let Ok(meta) = serde_json::from_slice::<CacheMeta>(&meta_bytes) {
                    let age_secs = (now_ms() - meta.created_at) / 1000;
                    if age_secs as u64 > meta.ttl_secs {
                        // 过期，删除缓存文件和元信息文件
                        let cache_file = entry.path()
                            .with_file_name(name.replace(".meta.json", ""));
                        if let Ok(m) = tokio::fs::metadata(&cache_file).await {
                            freed += m.len();
                        }
                        let _ = tokio::fs::remove_file(&cache_file).await;
                        let _ = tokio::fs::remove_file(entry.path()).await;
                    }
                }
            }
        }

        Ok(freed)
    }
}
```

### 8.2 清理策略汇总

| 清理目标 | 触发条件 | 策略 | 频率 |
| -------- | -------- | ---- | ---- |
| 孤立 Blob | 定时 / 手动 | 扫描 `blob_refs` 表，引用计数为 0 的文件删除 | 6h |
| 过期临时文件 | 定时 / 会话结束 | 文件名中时间戳超过 24h TTL | 6h + 会话结束 |
| 旧日志文件 | 定时 | 修改时间超过 7 天的日志删除 | 6h |
| 模型目录缓存 | 访问时 / 定时 | TTL 24h 过期删除 | 按需 + 6h |
| Embedding 缓存 | 写入时 | LRU 淘汰，超过 100MB 上限时删除最旧 20% | 按需 |

## 9. 跨设备同步适配

### 9.1 同步分类

文件系统中的文件按照是否需要跨设备同步分为三类。详细的同步协议见 [03-E2E加密同步详细设计](../_v0.3规划/03-E2E加密同步详细设计.md)，本节只定义文件层面的同步策略。

| 类别 | 文件 | 是否同步 | 理由 |
| ---- | ---- | -------- | ---- |
| **配置** | `settings.json` | 同步 | 用户偏好跨设备一致 |
| **配置** | `hooks.toml` | 同步 | 自定义 Hooks 跨设备可用 |
| **Persona** | `SOUL.md`, `MEMORY.md`, `USER.md` | 同步 | Agent 人格和记忆一致性 |
| **配置** | `workspaces/{id}/config.json` | 同步 | 工作区配置跨设备一致 |
| **Skill** | `skills/`, `workspaces/{id}/skills/` | 同步 | Skill 定义跨设备可用 |
| **知识源** | `workspaces/{id}/knowledge/` | 同步 | 知识库内容跨设备一致 |
| **缓存** | `cache/` | 不同步 | 可在本地重建 |
| **临时文件** | `tmp/` | 不同步 | 短期过渡数据 |
| **日志** | `logs/` | 不同步 | 设备本地诊断数据 |
| **备份** | `backups/` | 不同步 | 设备本地安全网 |
| **媒体** | `workspaces/{id}/media/` | 不同步 | 体积大，可按需重新生成 |
| **Blob** | `workspaces/{id}/blobs/` | 不同步 | 内容寻址，可按需拉取 |
| **AI 文档** | `workspaces/{id}/ai-docs/` | 可选同步 | 用户可选是否同步 Agent 产物 |
| **数据库** | `agent.db` | 记录级同步 | 由 E2E 同步协议处理 |

### 9.2 同步清单生成

StorageManager 提供方法生成文件系统层面的同步清单，供 E2E 同步模块使用：

```rust
// crates/agent-core/src/storage/sync_manifest.rs

use sha2::{Sha256, Digest};
use serde::{Serialize, Deserialize};
use std::collections::HashMap;

/// 文件同步条目
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct FileSyncEntry {
    /// 相对于 ~/.astro/ 的路径
    pub relative_path: String,
    /// SHA-256 内容哈希
    pub content_hash: String,
    /// 最后修改时间（毫秒时间戳）
    pub modified_at: i64,
    /// 文件大小（字节）
    pub size: u64,
    /// 是否已删除（tombstone）
    pub tombstone: bool,
}

/// 文件同步清单
#[derive(Debug, Serialize, Deserialize)]
pub struct FileSyncManifest {
    pub version: u64,
    pub generated_at: i64,
    pub entries: HashMap<String, FileSyncEntry>,
}

impl StorageManager {
    /// 生成需要同步的文件清单
    pub async fn generate_sync_manifest(&self) -> Result<FileSyncManifest> {
        let mut entries = HashMap::new();

        // 全局配置文件
        self.scan_file_for_sync(
            &self.base_dir.join("settings.json"),
            "settings.json",
            &mut entries,
        ).await;

        self.scan_file_for_sync(
            &self.base_dir.join("hooks.toml"),
            "hooks.toml",
            &mut entries,
        ).await;

        // 全局 Skills
        self.scan_dir_for_sync(
            &self.base_dir.join("skills"),
            "skills",
            &mut entries,
        ).await;

        // 工作区文件
        let ws_dir = self.base_dir.join("workspaces");
        if ws_dir.exists() {
            let mut ws_entries = tokio::fs::read_dir(&ws_dir).await?;
            while let Some(entry) = ws_entries.next_entry().await? {
                if !entry.metadata().await?.is_dir() { continue; }
                let ws_id = entry.file_name().to_string_lossy().to_string();
                let ws_root = entry.path();

                // 工作区配置和 Persona 文件
                let sync_files = [
                    "config.json", "SOUL.md", "MEMORY.md", "USER.md",
                ];
                for filename in &sync_files {
                    let rel = format!("workspaces/{}/{}", ws_id, filename);
                    self.scan_file_for_sync(&ws_root.join(filename), &rel, &mut entries).await;
                }

                // 工作区 Skills
                let skills_rel = format!("workspaces/{}/skills", ws_id);
                self.scan_dir_for_sync(&ws_root.join("skills"), &skills_rel, &mut entries).await;

                // 知识库源文件
                let knowledge_rel = format!("workspaces/{}/knowledge", ws_id);
                self.scan_dir_for_sync(
                    &ws_root.join("knowledge"),
                    &knowledge_rel,
                    &mut entries,
                ).await;
            }
        }

        Ok(FileSyncManifest {
            version: 1,
            generated_at: now_ms(),
            entries,
        })
    }

    /// 扫描单个文件加入同步清单
    async fn scan_file_for_sync(
        &self,
        path: &Path,
        relative_path: &str,
        entries: &mut HashMap<String, FileSyncEntry>,
    ) {
        if !path.exists() { return; }
        if let Ok(content) = tokio::fs::read(path).await {
            let meta = tokio::fs::metadata(path).await.ok();
            let modified = meta.as_ref()
                .and_then(|m| m.modified().ok())
                .and_then(|t| t.duration_since(std::time::UNIX_EPOCH).ok())
                .map(|d| d.as_millis() as i64)
                .unwrap_or(0);

            entries.insert(relative_path.to_string(), FileSyncEntry {
                relative_path: relative_path.to_string(),
                content_hash: sha256_hex(&content),
                modified_at: modified,
                size: content.len() as u64,
                tombstone: false,
            });
        }
    }

    /// 递归扫描目录中的文件加入同步清单
    async fn scan_dir_for_sync(
        &self,
        dir: &Path,
        relative_prefix: &str,
        entries: &mut HashMap<String, FileSyncEntry>,
    ) {
        if !dir.exists() { return; }
        if let Ok(mut dir_entries) = tokio::fs::read_dir(dir).await {
            while let Some(entry) = dir_entries.next_entry().await.ok().flatten() {
                let meta = entry.metadata().await.ok();
                let name = entry.file_name().to_string_lossy().to_string();
                let rel = format!("{}/{}", relative_prefix, name);

                if meta.as_ref().map_or(false, |m| m.is_dir()) {
                    Box::pin(self.scan_dir_for_sync(&entry.path(), &rel, entries)).await;
                } else {
                    self.scan_file_for_sync(&entry.path(), &rel, entries).await;
                }
            }
        }
    }
}
```

```rust
use crate::error::AppError;
use crate::state::AppState;

    workspace_id: String,

    filename: String,

        "image" => MediaType::Image,

        .media_path(&workspace_id, mt, &filename)
        .map_err(AppError::from)?;

    Ok(path.to_string_lossy().to_string())
}
```
