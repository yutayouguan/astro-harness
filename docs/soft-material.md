# 柔塑 Soft 材质

入口：设置 → 外观 → 主题与材质 → 界面材质 → 柔塑 Soft。

这是独立于明暗模式的可选材质，默认仍为玻璃。亮色采用乳白磨砂表面，暗色采用石墨磨砂；沿用已有强调色、字号、布局和界面缩放。自动模式继续遵循现有壁纸/系统主题解析规则。

## 全局轻毛玻璃（当前）

浮雕采用低抬升光影：卡片 2px 下落阴影、控件 2px 接触阴影、0.5px 内高光；浅色阴影透明度 8%，暗色 18%。输入内凹仅保留 1px 偏移与 2px 柔化，普通描边降低对比度。弹层仍比卡片稍高，但不铺大面积暗影；焦点、状态色及高对比边缘不随装饰光影减弱。

设置 → 外观 → 主题与材质中的「毛玻璃强度」滑块只调节卡片、按钮、输入框等界面材质的透明度与磨砂效果，范围 0–100，默认 50；不调节壁纸图片或整屏壁纸遮罩：

| 强度 | 主面板材质不透明度 | 材质层模糊 |
| --- | --- | --- |
| 0 | 100% | 0px |
| 50 | 79% | 32px |
| 100 | 72% | 64px |

参考乳白磨砂效果：大卡片透出柔和背景色，默认强度下按钮使用 94% 的较厚乳白，输入框使用 88% 的乳白填充。按钮与输入框透明度随同一强度变化，分别为 `100% - (100% - 主面板不透明度) × 2/7` 和 `100% - (100% - 主面板不透明度) × 4/7`；零强度及无障碍回退时全部恢复实心。卡片透明度使用 ease-out 曲线（`100 - 28 * (1 - (1 - intensity / 100)^2)`），模糊线性增加，每一步均有效。沿用已有细高光边和低阴影；聊天输入框取消凹槽感，内层控件不重复背景模糊。

全局背景不再被 Soft 的实灰底覆盖：氛围配色保留既有色彩并覆一层静态乳白/石墨薄罩。壁纸图片的模糊只由全局壁纸设置「柔化背景」控制；Soft 不向 `.shell-wallpaper-layer` 或其遮罩追加滤镜，也不修改原图、fit、shade、blur 或壁纸偏好。界面材质覆盖区域内的局部磨砂仍由卡片自己合成。没有额外动画。实际透色取决于当前背景，参考图的照片和品牌内容不会复制进应用。

只改变界面材质底层，不降低文字/图标的 opacity。`softFrostIntensity.ts` 使用独立偏好 `astro-soft-frost-intensity`，切回玻璃保留原玻璃强度；初始化、即时修改、重新断言均同步参数。滑块变化不重复触发原生窗口主题同步。

`--soft-material-background` / `--soft-material-backdrop` 是主面板配方入口，`--soft-control-background` / `--soft-input-background` 定义同色系的控件厚度，映射到既有全局表面契约，覆盖聊天、侧栏/dock、设置卡片、欢迎页、商店和浮层。环境依赖网格卡片与桌宠库/创建/通用设置已补入；桌宠控件不再自行从壁纸提取粉色底。嵌套控件沿用同色材质但不重复模糊，状态徽标、危险操作、开启的开关和照片/场景内容不去色。

支持标准及 WebKit 背景模糊；不支持模糊、减少透明度、高对比或强制颜色时回退实心。Soft 同时重绑通用 Glass 的无障碍表面别名，避免设置/菜单回退为半透明紫底。文字色板针对 72% 不透明度叠在纯黑/纯白上的最差情况验证 4.5:1 对比度。桌宠透明画布和任务伴随窗口不应用此主题。

`Design / Soft Settings Material / Playground` 使用真实外观设置、环境依赖、桌宠组件及只读模拟数据，不安装依赖、不调用模型、不修改真实宠物。原生 Tauri WebView 的背景合成仍需单独验收，Storybook 不等同于原生结果。

## 第一版范围（历史）

- 接入共享表面变量，让聊天卡片、标题栏工具组、菜单与设置面板使用同一实色材质。
- 侧栏保持平面，普通输入框浅凹，发送/模式/附件按钮提供轻浮雕与按下反馈。
- 不改变审批组合布局，不覆盖完全访问的橙色警示，不修改壁纸、强调色和玻璃强度偏好。
- 柔塑下玻璃强度滑块禁用并显示原因，切回玻璃恢复原值。
- 键盘焦点、原生单选键盘操作、减少动态效果、高对比边界均有独立处理。
- 桌宠与任务伴随窗口不在首帧应用该材质，避免污染透明画布。

第一版的视觉样板是聊天内容与外观设置；其他专业面板通过共享变量继承基础材质，但不代表全部页面已完成视觉验收。

## 第二轮：工作台与控件一致性

`materials/soft-controls.css` 补齐顶部工具选中态、文件/会话导航选中态、右侧 dock 外壳、常用设置输入、下拉选择和模型设置分组。大区域使用平整底色，普通控件保持轻微浮雕；选中态使用局部强调色浅填充与单条 0.5px 内边（高对比为 1px），不叠加玻璃渐变或外光晕。关闭状态的设置开关保持浅凹槽，开启状态的语义强调色不变。

设置材质契约通过可选 `--material-*` 变量接入柔塑；玻璃模式继续使用原有回退配方。焦点样式仍在控件样式之后加载，保持鼠标 1px / 键盘 2px 的独立契约。

验收样板 `Design / Soft Workbench` 复用已有生产组件与测试数据，覆盖侧栏、顶部工具/右侧抽屉、模型设置，不访问真实 Provider 凭证或发送模型请求。已检查亮暗材质与输入焦点切换；这不是所有功能页的逐页验收。当前原生自动化无法选中运行中的开发窗口，仅发现旧 QA 包，因此原生 Tauri 验收仍未完成。

## 浮层材质

`materials/soft-overlays.css` 统一确认/输入弹窗、通用浮层、下拉和右键菜单、Toast 的实色表面与柔和投影。模态遮罩只负责遮暗，不采样背景模糊；轻浮层的透明外部区域不改变。可搜索下拉的结果列表保持透明，不叠加第二个表面；搜索区沿圆角承载既有焦点边。

危险确认按钮和错误/警告通知继续使用语义色。焦点循环、关闭、输入、通知倒计时及层级定位不在这层 CSS 中修改。高对比模式移除投影并保留可辨识边界。

样板 `Design / Soft Overlays / Playground` 使用生产组件，只修改本地样板状态。覆盖亮暗菜单、危险操作与输入弹窗、透明轻浮层、侧栏菜单和通知；原生窗口验收状态不变。

## 内容型欢迎页

柔塑欢迎页采用中性底色、两个重点内容入口和静态卡片网格，提供全部 / 工作效率 / 创作 / 探索筛选。12 个原有入口复用 `ChatWelcome` 的同一份元数据和本地化提示词，重点入口不会在下方重复。图表与图像封面为装饰性 SVG 示意，不代表已生成的结果，也不加载远程图片。

欢迎页采用紧凑横向卡片：普通入口为 44px 图标区、最小高度 84px；重点入口为 120px 插图区、最小高度 104px，窄窗口缩为 96px 插图区与最小高度。正文仍为 14px 标题 / 12px 说明，长文本可换行增高，不使用固定高度裁切。此密度调整不影响商店卡片。

`ChatWelcome` 根据 `ThemeProvider` 的材质选择渲染 `SoftWelcome` 或原来的玻璃欢迎页；柔塑分支不挂载跑马灯、粒子场或动态 Logo。独立组件预览未提供主题上下文时仍显示默认玻璃布局。卡片只调用原有提示词选择回调，用户编辑后再发送；欢迎页不再提供重复的“开始对话”按钮，用户可直接使用下方输入框。

样板 `Design / Soft Welcome / Content Cards` 可验证分类、本地化模板与草稿、亮暗模式、窄窗口纵向滚动和材质切换。卡片和分类按钮统一复用共享材质表面、细高光边与柔和投影，预览区不再另铺渐变底色，颜色仅保留在图标和插图中。分类选中项使用清晰文字和短标记，不切换整块底色；高对比模式统一增强边缘并移除投影。

欢迎页动作表面现在复用全局轻毛玻璃配方，默认 79% 不透明度、32px 模糊与 1.12 倍饱和度，由柔塑强度滑块统一控制，不改变尺寸。纯色背景下效果克制；样板提供独立的纹理背景开关用于观察透射和模糊，不修改 APP 背景偏好。无障碍回退由全局材质负责。

## Skill 商店内容卡片

`materials/soft-skill-store.css` 只在柔塑模式下为在线市场的画廊卡片增加封面区，复用原有图标和稳定的卡片色调，不生成虚构推荐或统计。卡片名称、用途、来源、分类、密钥要求和安装状态均使用原字段。排序采用中性反差胶囊，分类保持较轻的选中态；列表与详情布局不扩展为封面卡片。

画廊网格使用内容驱动行高，简介保留三行空间，防止长名称或窄窗口将操作栏挤出卡片。图标加载失败时显式隐藏失败图片并显示原备用图标；图标 URL 更新后重新挂载图片，避免沿用失败隐藏状态。

样板 `Design / Soft Skill Store / Gallery` 使用生产 `SkillsPanel` 和明确标记的示例数据。搜索、分类与 API Key 条件仅过滤样板数据，安装等未授权命令被模拟层拦截。已验证已安装状态、密钥提示、失败图标、列表切换和窄窗口；未进行真实安装或原生 APP 验收。

## 实现约定

`interfaceMaterial.ts` 通过现有 `preferenceStore` 保存本机外观偏好 `astro-interface-material`，值仅为 `glass | soft`；无效值回到玻璃。这与现有明暗/玻璃强度/缩放偏好的存储方式一致，不涉及 Provider、工具或 Agent 设置。

`main.tsx` 首帧预热，`ThemeProvider` 负责切换和重新断言，根节点用 `data-material` 与 `data-theme` 独立组合。CSS 在 `materials/soft.css` 的 overrides 层重映射现有 `--immersive-reference-*` 表面契约；不要向每个功能页追加独立的新拟态配方。

## 输入焦点

`ThemeProvider` 安装 `inputFocus.ts` 的捕获阶段监听器：指针操作采用 1px 细边，Tab/Shift+Tab 导航采用 2px 边；普通打字、光标移动、快捷键和 IME 不改变该模式。卸载时清理标记与监听器。

独立输入框自己承载焦点，聊天框、组合搜索框和数字步进控件由实际外壳承载。新的组合输入框可以用 `data-input-surface` 标明外壳。只有正在聚焦的输入框及其外壳获得标记；按钮、复选框、滑块等保留自身的键盘提示。

`materials/soft-focus.css` 仅作用于柔塑材质，并以未分层规则加载以覆盖未分层设置样式；桌宠材质归入 features 层，不能抢走全局焦点。内描边覆盖原边缘，不改变边框宽度或布局，不叠加外光晕。焦点色使用当前局部强调色的色相、固定低色度与亮暗明度；不支持相对 OKLCH 的环境使用灰蓝回退色。高对比模式使用 2px 高对比线，错误字段保留错误色。

`inputFocus.test.ts` 覆盖输入方式识别、组合控件归属、焦点转移、清理与重挂载。`Design / Composer Focus / Regression` 提供展开/胶囊聊天框、搜索、密码、数字、下拉和错误状态的交互验收样板。

本轮完成 Storybook 的亮暗切换、键盘切回玻璃、刷新恢复与窄窗口检查。原生 Tauri 窗口未完成视觉验收；仍需确认实际聊天、抽屉、壁纸背景和重启后的表现，再扩大逐页验收范围。
