# 柔塑 Soft 材质

入口：设置 → 外观 → 主题与材质 → 界面材质 → 柔塑 Soft。

这是独立于明暗模式的可选材质，默认仍为玻璃。亮色采用冷灰白瓷表面，暗色采用石墨灰；沿用已有强调色、字号、布局和界面缩放。自动模式继续遵循现有壁纸/系统主题解析规则。

## 第一版范围

- 接入共享表面变量，让聊天卡片、标题栏工具组、菜单与设置面板使用同一实色材质。
- 侧栏保持平面，普通输入框浅凹，发送/模式/附件按钮提供轻浮雕与按下反馈。
- 不改变审批组合布局，不覆盖完全访问的橙色警示，不修改壁纸、强调色和玻璃强度偏好。
- 柔塑下玻璃强度滑块禁用并显示原因，切回玻璃恢复原值。
- 键盘焦点、原生单选键盘操作、减少动态效果、高对比边界均有独立处理。
- 桌宠与任务伴随窗口不在首帧应用该材质，避免污染透明画布。

第一版的视觉样板是聊天内容与外观设置；其他专业面板通过共享变量继承基础材质，但不代表全部页面已完成视觉验收。

## 第二轮：工作台与控件一致性

`materials/soft-controls.css` 补齐顶部工具选中态、文件/会话导航选中态、右侧 dock 外壳、常用设置输入、下拉选择和模型设置分组。大区域使用平整底色，普通控件保持轻微浮雕；选中态使用局部强调色浅填充与单条 0.5px 内边（高对比为 1px），不叠加玻璃渐变或外光晕。关闭状态的设置开关保持浅凹槽，开启状态的语义强调色不变。

设置材质契约通过可选 `--material-*` 变量接入柔塑；玻璃模式继续使用原有回退配方。焦点样式仍在控件样式之后加载，保持鼠标 1px / 键盘 2px 的独立契约。

验收样板 `Design / Soft Workbench` 复用已有生产组件与测试数据，覆盖侧栏、顶部工具/右侧抽屉、模型设置，不访问真实 Provider 凭证或发送模型请求。已检查亮暗材质与输入焦点切换；这不是所有功能页的逐页验收。当前原生自动化无法选中运行中的开发窗口，仅发现旧 QA 包，因此原生 Tauri 验收仍未完成。

## 实现约定

`interfaceMaterial.ts` 通过现有 `preferenceStore` 保存本机外观偏好 `astro-interface-material`，值仅为 `glass | soft`；无效值回到玻璃。这与现有明暗/玻璃强度/缩放偏好的存储方式一致，不涉及 Provider、工具或 Agent 设置。

`main.tsx` 首帧预热，`ThemeProvider` 负责切换和重新断言，根节点用 `data-material` 与 `data-theme` 独立组合。CSS 在 `materials/soft.css` 的 overrides 层重映射现有 `--immersive-reference-*` 表面契约；不要向每个功能页追加独立的新拟态配方。

## 输入焦点

`ThemeProvider` 安装 `inputFocus.ts` 的捕获阶段监听器：指针操作采用 1px 细边，Tab/Shift+Tab 导航采用 2px 边；普通打字、光标移动、快捷键和 IME 不改变该模式。卸载时清理标记与监听器。

独立输入框自己承载焦点，聊天框、组合搜索框和数字步进控件由实际外壳承载。新的组合输入框可以用 `data-input-surface` 标明外壳。只有正在聚焦的输入框及其外壳获得标记；按钮、复选框、滑块等保留自身的键盘提示。

`materials/soft-focus.css` 仅作用于柔塑材质。内描边覆盖原边缘，不改变边框宽度或布局，不叠加外光晕。焦点色使用当前局部强调色的色相、固定低色度与亮暗明度；不支持相对 OKLCH 的环境使用灰蓝回退色。高对比模式使用 2px 高对比线，错误字段保留错误色。

## 验证

自动回归：`interfaceMaterial.test.ts` 与 `softMaterialContract.test.mjs`，覆盖持久化、默认值、失败存储、偏好隔离、亮暗正文/次要文字色板对比度、首帧入口和无障碍规则。

`inputFocus.test.ts` 覆盖输入方式识别、组合控件归属、焦点转移、清理与重挂载。`Design / Composer Focus / Regression` 提供展开/胶囊聊天框、搜索、密码、数字、下拉和错误状态的交互验收样板。

交互样板：在 `apps/desktop` 执行 `npm run storybook`，打开 `Design / Soft Material / Playground`。样板右侧使用真实外观设置组件，左侧为静态聊天材质展示，不发送消息或调用模型。

本轮完成 Storybook 的亮暗切换、键盘切回玻璃、刷新恢复与窄窗口检查。原生 Tauri 窗口未完成视觉验收；仍需确认实际聊天、抽屉、壁纸背景和重启后的表现，再扩大逐页验收范围。
