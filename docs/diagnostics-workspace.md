# 诊断工作区

诊断页复用既有 Tauri 查询、导出和存储确认链路，只调整展示与前端生命周期，不改变文件清理策略。

## 布局

- 页头：刷新状态、导出诊断包。
- 状态区：后端、模型服务、MCP、数据库各为独立磨砂卡片，间隔 12px；外层不再铺连续背景或描边。宽窗口四列、窄窗口两列，点击展开检查范围和详情。
- 默认页签为运行日志；存储与配置使用独立页签，两者保留自身视图状态。
- 日志筛选和搜索分行：范围、时间、来源、级别在第一行，搜索与高级筛选在第二行；窄容器下筛选改为两列。行数、会话 ID、回合 ID、自定义时间进入高级筛选，原有 50/100/200/500 行选项不变。
- 日志面板保持内容自然高度（阅读区下限 240px，展开窄屏详情时为 440px），日志列表不单独滚动；宿主高度不足时由工作区整体滚动，筛选与状态不被压缩。详情默认右侧显示，窄窗口改为上下排列。详情显示格式化消息和原始文本，复制原文不做格式化。
- 存储页展示检查摘要、已扫描大小、清理候选大小，下面分配置与路径、领域占用、清理与保留。部分扫描与候选样本的限制仍明确显示。

## 材质与受限空间

日志面板及状态区域使用现有 `--settings-panel-background` / `--settings-panel-backdrop`，不再使用单独的 94% 基础底色。减少透明度或高对比时仍回退实心；正常模式随全局材质和强度变化，内层日志行不重复模糊。

顶部控件不参与纵向压缩。日志区由控件、阅读区、页脚三行 Grid 组成，阅读区下限为 240px；展开窄屏详情时为 440px。父容器不够高时，工作区整体滚动，避免筛选和状态挤叠。布局依据容器宽度，不依赖浏览器窗口高度来判断嵌入面板空间。

`Settings / Diagnostics Workspace` 另提供 `Short Host`（620×440）与 `Narrow Host`（380×640）样板，用于在大浏览器窗口中验证受限宿主。

2026-09-15 用隔离样板重做了一轮视觉复测，覆盖 `Settings / Diagnostics Workspace` 的 Workbench 与两个受限宿主（Short Host 620×440、Narrow Host 380×640，暗色 + soft 材质），测量结果：状态区是 4 张独立卡片，工作台 4 列、两个受限宿主 2 列，卡片列/行间距都是 12px，每张卡片各自带 `backdrop-filter: blur(32px) saturate(1.12)`；三个宿主横向溢出都是 0px、控制台无报错；宿主高度不足时由 `.diagnostics-workspace` 整体滚动（Short Host 341/2542、Narrow Host 512/2551），筛选行没有被压缩。日志列表本身不滚动，高度随内容增长（样板里恒为 1929px）。

这轮复测只覆盖浏览器样板，不是原生验收；上面这些结论仍不代表真实 Tauri WebView 已通过。此前的旧版基线截图与验收记录同样不代表本次修复通过。

## 状态语义

| 状态 | 当前检查范围 |
| --- | --- |
| 后端正常 | 原有后端状态 RPC 可响应，不是完整健康测试 |
| 模型已启用 N/M | 配置数量；没有发起模型连通性请求 |
| MCP 已连接 N/M | 连接状态；未配置使用中性状态 |
| 数据库可读取 | 成功打开 SessionStore 并读取 schema 版本；不是完整性检查 |

WAL 与 schema 版本保留在详情，不再作为“健康状态”的大字结论。

## 交互与安全

- `DiagnosticsPanel` 负责布局和视图状态；`useDiagnosticsSettings` 继续管理查询、刷新、复制和导出。
- `active` 控制诊断状态读取，`logsActive` 控制日志查询与 1.5 秒轮询。切到存储页暂停日志轮询，返回后刷新。
- 离开诊断或切换会话后，旧日志请求的响应被代次标记忽略；状态检查同样有独立代次保护。
- 页签复用 `SegmentedTabs`，支持方向键。详情打开后聚焦关闭按钮，Escape 关闭并返回原日志行；行已离开列表时回到列表容器。
- 实时刷新通过日志时间、来源和原文匹配选中快照，不依赖对象引用保持高亮。
- 存储仅在对应页签激活时检查。清理继续使用 `prepare_storage_cleanup → 勾选核对 → execute_storage_cleanup`，不新增一键删除或自动执行。准备/执行期间禁用页签切换；离开诊断仍遵循原组件的 token 丢弃规则。
- `onBusyChange` 通过稳定回调传递，避免重新渲染使清理确认单失效。复制路径只写剪贴板，不修改配置或文件。
