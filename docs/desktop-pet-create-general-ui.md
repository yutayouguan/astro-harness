# 创建宠物与通用设置优化（2026-09-11）

范围：用户提供的两张设置页截图；只调整这两页的内容层级与交互呈现，保留顶部横幅、宠物库、请求/取消协议和已保存的配置。不是完整原生窗口审计。

## 截图检查与调整

| Before | After | Why |
| --- | --- | --- |
| 大面积上传占位，按钮贴在右下角 | 210px 上传区域，中心选择入口，完整显示所选照片 | 减少空白，不裁掉照片主体 |
| 长隐私说明在页头和卡片重复 | 页头简述两种创建方式，提交区保留发送范围说明 | 在决策处说明何时上传 |
| 生成按钮旁并列动画导入 | 照片生成主卡与动画导入独立卡 | 明确静态形象与动画包的区别 |
| 未勾选壁纸也有可展开选项 | 勾选后展示，取消勾选隐藏但不丢草稿 | 消除两个互不一致的开关 |
| 通用设置四个远距离小复选框 | 显示与联动 / 免打扰分组，复用 prefs-switch | 提高点击目标和状态辨识度 |
| 说明混在底部，恢复按钮游离 | 说明绑定对应开关，辅助操作归入找回桌宠 | 减少查找与误解 |
| 笼统声称切换不覆盖全部策略 | 明确仅应用宠物会关闭壁纸联动 | 与已有行为一致 |

## 实现边界

- `PetSettingSwitch` 使用原有开关材质；提供 `role=switch`、`aria-checked`、帮助文字关联和完整 label 点击目标。
- 输入名字和风格仍可选；首个场景保留原有自动命名机制。生成仍明确标为静态，不承诺生成动画。
- 导入不需要照片，不调用图片模型。取消生成和服务商发送说明保留。
- 调整不改变 Rust/Tauri 状态或图片生成实现；共享工作区其他任务的改动不包含在本提交中。
