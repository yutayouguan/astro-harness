# AI 动作图标

`AIActionIcon` 是应用内的 SVG 图标，不调用图像模型，也不依赖外部资源。参考风格为青蓝 → 蓝紫 → 粉色渐变、圆润描边与星芒圆点。

- `generate`：AI 生成、润色、助手与记忆整理。
- `search`：AI 诊断、进化搜索与优化，使用星芒放大镜。
- `size`：沿用入口原有尺寸；13–16px 的生成图标减少圆点与装饰线，避免糊成一团。
- `framed`：展示或较大的入口可用圆形底座；普通带文字按钮默认只显示图标。
- `ai-action-button`：独立图标按钮使用圆形轻底座，保留原有大小和选中态。

已接入壁纸生成、桌宠形象与场景壁纸、工作流 AI 助手/润色、上下文压缩入口、记忆整理、进化诊断/搜索和 DSPy 优化。加载时继续使用已有旋转图标；保存、取消、普通搜索、模型品牌与非 AI 装饰图标不替换。

每个实例用 React `useId` 生成独立渐变 ID，避免同页多个图标互相串色。亮暗模式使用不同色阶；填色主按钮上的小圆底座用于保持图标辨识度。高对比/强制颜色模式退化为系统前景色，图标本身为装饰性元素，由所属按钮提供可访问名称。

样板：`Design / AI Action Icons / Gallery`。自动测试覆盖实际 SVG 渲染、渐变引用与 ID 唯一性、小尺寸几何、无障碍退化、入口接入及加载状态保留。本轮不触发真实生成请求。
