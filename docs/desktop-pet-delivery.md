## 阶段与门槛

- [ ] A. 播放基础：APNG主体循环、暂停续播、64MiB共享缓存、离屏/隐藏停止。
- [ ] B. 动作制作：逐项审查26个现有动作/注视文件；重做不合格动作，补齐入口/出口；先验收踩奶、舔爪、慢走。
- [ ] C. 漫游：默认关闭、底边活动、步态同步、交互抢占；不把漫游位置写入场景偏好。
- [ ] D. 内置升级：新版本资源目录、哈希校验、共享事务更新宠物及所有场景、可恢复且幂等。
- [ ] E. 最终验收：原速/慢放、白黑底、50/75/100%大小；原生焦点/拖动/穿透、锁定吸附、全屏与托盘、双屏/断屏、重启；全部通过后再应用。

## 动作规范

| 业务/行为 | 奶糖 | 布丁 |
| --- | --- | --- |
| 待机 | 轻呼吸、真实眼睑眨眼、耳尾小动作 | 轻呼吸、眨眼、耳尾小动作 |
| 左右移动 | 四足慢走，起步/完整周期/停步 | 四足慢走，起步/完整周期/停步 |
| 迎接/成功 | 抬头、耳尾反应，不做人立挥手 | 抬头与摇尾，不做人立挥手 |
| 忙碌/等待/观察/失败 | 专注观察、坐定、侧头、短暂低头 | 专注观察、坐定、侧头、短暂低头 |
| 特有动作 | 左右前爪交替踩奶；抬爪→舔爪→停顿→收爪 | 自然摇尾、歪头、伸展、趴卧呼吸与起身 |

动态段以24fps为制作基准，停顿按行为需要设置。单片不超过128帧，重复主体不重复编码。禁止全身缩放、重复帧充数、淡化重影掩盖缺姿态。支撑点不得无故漂移，但真实抬爪/低头不能被“包围盒恒高”误判。

图片沿用已授权Azure CLI：角色/补帧Sunburst，壁纸/普通图Flare。原始输出、提示词、抠图、归一化、接缝对照和失败原因都保留。缓存、编译或API成功不能替代视觉/实机验收。
