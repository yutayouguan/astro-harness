# 小风车 / 桌面氛围

2026-09-11，第一阶段：稳定的快捷入口，不调用图片模型。

## 第一阶段

- [x] 单击固定打开面板，场景 / 壁纸 / 配色三个Tab；不再根据模式直接随机换色或跳设置。
- [x] 场景按宠物分组，显示当前组合；无壁纸的场景不能应用。
- [x] 场景应用宠物和壁纸；普通壁纸保留宠物，只有显式勾选才联动绑定场景。
- [x] 跟随系统壁纸与纯色背景；上传、AI生成和库管理仍由设置页承担。
- [x] 壁纸取色、灵动配色、自定义颜色；灵动配色适配亮暗主题，手动颜色保留用户选择。
- [x] 改色保留背景、宠物和原样式非配色属性，生成临时活动样式，不改原场景；显示“已调整”。
- [x] 还原场景、另存为场景。另存保存当前颜色快照及宠物偏好，不覆盖原条目、不自动应用。
- [x] 一步撤销；服务端保存单个不透明token。外观/宠物在其他地方修改后拒绝旧撤销，库编辑和无关窗口状态不回滚。
- [x] 快速点击互斥，重复点当前场景不替换撤销记录；失败有反馈。
- [x] Escape关闭并恢复焦点，Tab焦点约束，方向键切Tab；减少动态效果时不旋转。
- [x] 亮暗主题与窄窗口截图检查；内容滚动，标题/操作区保留。
- [ ] 原生Tauri窗口实机验收：浏览器测试不替代真实焦点/窗口验证。本轮不主动中断运行任务重启App。

## 下一阶段（本轮不做自动随机切换）

- [ ] 明确范围的“换一个”：当前宠物场景 / 收藏壁纸 / 灵动配色；没有候选时禁用。
- [ ] 壁纸收藏与锁定；默认不跨宠物轮换。

## 实现与验证

`DesktopAmbienceButton`复用`PopoverSurface`、`SegmentedTabs`及原风车图标；没有第二套设置页。
`useDesktopAmbience`协调本地壁纸、Shell配色与原生事务，暂停并排空旧壁纸同步，再提交新状态；epoch丢弃迟到的样式/系统壁纸响应。
原生`desktop_ambience`复用`prepare_scene`与`update_desktop_pet_state`，主题应用及重置均使用可恢复outbox。
撤销仅恢复本次可见组合和场景相关偏好，不回写旧的完整宠物库。

审查修正：

| Before | After | Why |
| --- | --- | --- |
| 共享弹层260px上限裁切卡片 | 本面板独立高度限制，内容区滚动 | 让场景和撤销入口可见 |
