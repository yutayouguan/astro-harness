## 当前快捷面板（2026-09-12）

2026-09-14 实时反馈补齐：宠物缩放的忙碌状态与普通切换分开标记，图片卡片仍禁止冲突点击，但不再逐次变灰闪动。壁纸模糊与内容保护拖动时只写当前图片层的临时 CSS 预览值；松手后沿用事务保存，正式值渲染完成后才清除预览。取消、失败、切换图片或卸载控件会清理临时值，不改原壁纸文件或全局材质。

2026-09-14 桌宠大小改为实时缩放：移除 input 宿主指针捕获，拖动的 input 事件立即进入串行末值队列，通过现有 `set_desktop_pet_scale` 持续调整原生窗口。旧响应不会拉回正在拖动的滑钮；一次指针/键盘手势合并为一步撤销，外部大小修改或不同宠物会打断合并。停止拖动后保留最终尺寸，不再采用松手才应用的模式。无需新增原生命令。

2026-09-14 滑块修复：壁纸 range 不再在宿主 input 上强制捕获指针，拖动由 WebView 原生滑钮处理，窗口级 pointerup/pointercancel 收尾；拖动中失焦不提前保存。保存使用串行末值队列，当前控件保持可操作，不反复禁用变灰。壁纸参数更新跳过相同配色及无变化场景列表的重载；活动样式按差异更新 token，不在每次壁纸 revision 变化时清空整套主题。新增真实 mouse drag 慢保存回归用例，须分别在浏览器与原生 WebView 验收，点击/键盘测试不能替代拖拽。

- 图片壁纸下新增「显示调整」折叠区：填满/适应/拉伸、内容保护 0–55%、柔化背景 0–12px。沿用外观设置的参数校验，滑块松手或键盘完成后保存，可一步撤销。`wallpaper_display` 原生事务只更新活动样式的显示参数，不编辑原场景、不切换宠物，并拒绝已切换图片的过期请求；普通壁纸仍使用同一份本机偏好。此项需要新原生端构建。

- 三标签「材质 / 背景 / 宠物」，约 380–400px 宽，面板高度统一为 560px、受窗口 75% 高度约束，避免切标签时入口上下跳动。标题和摘要合并，标签等宽；中间内容滚动，随机操作与底部撤销/更多设置保持可见。窄于 390px 时图库改为两列。

- 背景分为氛围配色与图片壁纸。氛围配色复用统一/灵动/多彩策略及预设渐变；图片支持最近、收藏、系统壁纸、自动取色和显式宠物联动。上传/AI生成、自定义渐变仍进入外观设置。
- 宠物头像只筛选浏览，不立即改变桌面；场景卡带宠物缩略标记，点击后才应用场景。沿用真实桌宠显隐按钮，浏览器预览中保持禁用，不伪装原生窗口操作。
