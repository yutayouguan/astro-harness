## WASM 插件市场

### 为什么选 WASM

| 特性 | 说明 |
|------|------|
| 安全隔离 | 沙箱执行，无法访问宿主文件系统和网络（除非显式授权） |
| 跨平台 | 一次编译，Windows/macOS/Linux 全部支持 |
| 多语言 | 作者可用 Rust/Go/C/AssemblyScript 编写，编译为 `.wasm` |
| 热加载 | 运行时加载，不需要重启 Agent |
| 版本锁定 | 内容寻址（SHA256），安装后不会被篡改 |

### 插件包格式

```
my-skill.wasm-plugin/
├── plugin.toml         # 插件元数据
├── skill.wasm          # 编译好的 WASM 文件
├── icon.png            # 插件图标（可选）
└── README.md
```

`plugin.toml` 结构：

```toml
[plugin]
name        = "arxiv-researcher"
version     = "1.2.0"
description = "搜索和解析 arXiv 论文，生成结构化摘要"
author      = "username"
license     = "MIT"
homepage    = "https://github.com/username/arxiv-researcher"
entry       = "skill.wasm"
min_agent_version = "0.3.0"

[capabilities]
permissions = ["NetworkRead"]           # 声明所需权限
allowed_tools = ["web_search"]          # 可调用的内置工具
can_spawn_agents = false

[limits]
max_memory_mb = 256                     # WASM 内存上限
timeout_secs = 60                       # 执行超时
```

> **权限映射**：`plugin.toml` 中 `[capabilities]` 的 `allowed_tools` 白名单在运行时映射为 `PermissionSet` 子集。每个白名单条目对应一个 `Permission::UseTool(tool_name)` 权限。插件实际获得的权限为 manifest 声明与用户审批弹窗确认的交集，遵循 `06-安全边界.md` 的最小权限原则。详见术语统一规范。

### 插件注册表

本地维护一份注册表索引（JSON），定期从官方源同步：

```rust
// crates/agent-core/src/plugins/registry.rs

pub struct PluginRegistry {
    index: PluginIndex,             // 本地缓存的索引
    install_dir: PathBuf,           // 已安装插件目录
    wasm_runtime: Arc<WasmRuntime>,
}

pub struct PluginIndex {
    pub plugins: Vec<PluginEntry>,
    pub updated_at: DateTime<Utc>,
}

pub struct PluginEntry {
    pub name: String,
    pub version: String,
    pub description: String,
    pub author: String,
    pub downloads: u64,
    pub rating: f32,
    pub wasm_url: String,
    pub wasm_sha256: String,        // 完整性校验
    pub manifest_url: String,
    pub tags: Vec<String>,
}

impl PluginRegistry {
    // 搜索插件
    pub fn search(&self, query: &str) -> Vec<&PluginEntry>;

    // 安装插件（下载 → 校验 SHA256 → 加载到 WasmRuntime → 注册到 SkillRegistry）
    pub async fn install(&self, name: &str, version: Option<&str>) -> Result<()>;

    // 更新已安装插件
    pub async fn update(&self, name: &str) -> Result<()>;

    // 卸载插件
    pub async fn uninstall(&self, name: &str) -> Result<()>;

    // 列出已安装插件
    pub fn installed(&self) -> Vec<InstalledPlugin>;
}
```

### 安装流程

```
用户点击安装
    │
    ▼
下载 .wasm 文件
    │
    ▼
SHA256 校验（与注册表中 wasm_sha256 比对）
    │ 不匹配 → 拒绝安装 + 告警
    ▼ 匹配
解析 plugin.toml
    │
    ▼
权限审批弹窗（显示插件申请的权限，用户确认）
    │ 拒绝 → 取消安装
    ▼ 确认
写入 install_dir/
    │
    ▼
注册到 SkillRegistry（热加载，无需重启）
    │
    ▼
安装完成，插件立即可用
```

### 安全规则

- 所有插件在 `WasmRuntime` 沙箱中执行，无系统调用权限
- 插件申请 `NetworkRead` 权限时，用户安装时需明确确认
- 插件调用内置 Tool 受 `allowed_tools` 白名单限制
- 插件无法访问其他插件的数据或主 Agent 的内部状态
- 官方注册表只接受开源插件（需附 license + 源码链接）

### Tauri Command

```rust
// apps/desktop/src-tauri/src/commands/mcp.rs

#[command]
pub async fn list_mcp_catalog(state: State<'_, AppState>) -> Result<Vec<McpCatalogEntry>, String> {
    state.mcp_catalog.list().map_err(|e| e.to_string())
}

#[command]
pub async fn install_mcp_server(
    name: String,
    config: serde_json::Value,
    state: State<'_, AppState>,
) -> Result<(), String> {
    state.ctx.mcp_manager
        .install_from_template(&name, config)
        .await
        .map_err(|e| e.to_string())
}

#[command]
pub async fn test_mcp_connection(name: String, state: State<'_, AppState>) -> Result<bool, String> {
    state.ctx.mcp_manager
        .test_connection(&name)
        .await
        .map_err(|e| e.to_string())
}
```
