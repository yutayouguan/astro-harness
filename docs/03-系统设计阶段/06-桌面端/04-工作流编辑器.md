# Agent 工作流可视化编辑器

> 阶段：系统设计 | 状态：定稿 | 说明：React Flow 节点设计、编译为 Skill

可视化节点编辑器让用户以拖拽方式创建 Skill 工作流，编译输出为 SKILL.md 格式（YAML frontmatter + 自然语言步骤）。

---

## 核心概念

```
工作流 = 有向无环图（DAG）
节点类型（NodeType 枚举，定义在 crates/agent-workflow/src/model.rs）
43 种节点跨 6 大类 + 1 自定义类：

├── Trigger（5）        → ManualTrigger, ScheduledTrigger, WebhookTrigger, EmailTrigger, FileWatchTrigger
├── AI（8）             → AiAgentTask, ParameterExtraction, QuestionClassification, KnowledgeRetrieval,
│                         Summarization, SentimentAnalysis, DocumentUnderstanding, VisionUnderstanding
├── Media（9）          → ImageGeneration, VideoGeneration, MusicGeneration, TextToSpeech,
│                         SubtitleGeneration, VoiceClone, SpeechToText, ImageEdit, Translation
├── FlowControl（6）    → Conditional, MultiBranch, Filter, Merge, Loop, HumanApproval
├── DataProcessing（7） → SetFields, FormatText, Json, Code, Sort, Slice, Aggregate
├── Action（7）         → HttpRequest, RunLoop, DelayWait, Output, AudioProcessing, SendNotification, FileIo
└── Custom              → CustomLoop（引用已保存的工作流）
```

## React Flow 集成

```typescript
// apps/desktop/src/components/workflow-editor/WorkflowEditor.tsx

import ReactFlow, {
  Node, Edge, addEdge, useNodesState, useEdgesState,
  Background, Controls, MiniMap,
} from "@xyflow/react";

import { StartNode } from "./nodes/StartNode";
import { EndNode } from "./nodes/EndNode";
import { ToolNode } from "./nodes/ToolNode";
import { LlmNode } from "./nodes/LlmNode";
import { ConditionNode } from "./nodes/ConditionNode";

const NODE_TYPES = {
  start:       StartNode,
  end:         EndNode,
  tool:        ToolNode,
  llm:         LlmNode,
  condition:   ConditionNode,
  loop:        LoopNode,
  parallel:    ParallelNode,
  subworkflow: SubWorkflowNode,
};

export function WorkflowEditor({ workflowId }: { workflowId?: string }) {
  const [nodes, setNodes, onNodesChange] = useNodesState(initialNodes);
  const [edges, setEdges, onEdgesChange] = useEdgesState(initialEdges);
  const [selectedNode, setSelectedNode] = useState<Node | null>(null);

  return (
    <div className="workflow-editor">
      <NodeLibrarySidebar onDrop={addNode} />

      <ReactFlow
        nodes={nodes}
        edges={edges}
        nodeTypes={NODE_TYPES}
        onNodesChange={onNodesChange}
        onEdgesChange={onEdgesChange}
        onConnect={(params) => setEdges(eds => addEdge(params, eds))}
        onNodeClick={(_, node) => setSelectedNode(node)}
        fitView
      >
        <Background />
        <Controls />
        <MiniMap />
      </ReactFlow>

      {selectedNode && (
        <NodeConfigPanel
          node={selectedNode}
          onChange={(data) => updateNodeData(selectedNode.id, data)}
        />
      )}

      <WorkflowToolbar
        onRun={() => runWorkflow(nodes, edges)}
        onSave={() => saveAsSkill(nodes, edges)}
      />
    </div>
  );
}
```

## 工作流 → Skill 编译

编辑器保存时，将 JSON 工作流编译为 SKILL.md 格式（YAML frontmatter + 自然语言步骤）：

```rust
// crates/agent-core/src/skills/workflow_compiler.rs

pub struct WorkflowCompiler;

impl WorkflowCompiler {
    /// 将可视化工作流编译为 SKILL.md 格式
    pub fn compile_to_skill(graph: &WorkflowGraph) -> String {
        // generates SKILL.md with YAML frontmatter
        let order = topological_sort(&graph.nodes, &graph.edges).unwrap();

        // 生成 YAML frontmatter
        let mut frontmatter = format!(
            "---\nname: {}\ndescription: {}\n",
            graph.id, graph.description
        );
        frontmatter.push_str(&Self::generate_frontmatter_fields(graph));
        frontmatter.push_str("---\n\n");

        // 生成自然语言步骤
        let mut body = String::new();
        for (i, node_id) in order.iter().enumerate() {
            let node = graph.node(node_id).unwrap();
            body.push_str(&Self::node_to_step(i + 1, node, graph));
            body.push('\n');
        }

        format!("{}{}", frontmatter, body)
    }

    fn node_to_step(&self, step: usize, node: &Node, graph: &WorkflowGraph) -> String {
        match node.node_type.as_str() {
            "tool" => format!(
                "{}. 调用工具 `{}`，参数：{}\n",
                step,
                node.data["tool"].as_str().unwrap(),
                self.format_input_mapping(&node.data["inputMapping"]),
            ),
            "llm" => format!(
                "{}. 使用 LLM 处理：{}\n",
                step,
                self.resolve_template(&node.data["prompt"], graph),
            ),
            "condition" => format!(
                "{}. 条件判断：如果 {} 则执行下一步，否则跳转\n",
                step,
                node.data["expression"].as_str().unwrap(),
            ),
            _ => format!("{}. {}\n", step, node.node_type),
        }
    }
}
```

## 单步调试

```typescript
// 调试模式：单步执行，在每个节点暂停
export function useWorkflowDebugger(nodes: Node[], edges: Edge[]) {
  const [currentNode, setCurrentNode] = useState<string | null>(null);
  const [nodeOutputs, setNodeOutputs] = useState<Record<string, unknown>>({});

  const stepForward = async () => {
    const next = getNextNode(currentNode, edges);
    if (!next) return;

    // 执行节点
    const output = await invoke("execute_workflow_node", {
      nodeId: next,
      inputs: collectInputs(next, edges, nodeOutputs),
    });

    setNodeOutputs(prev => ({ ...prev, [next]: output }));
    setCurrentNode(next);
  };

  return { currentNode, nodeOutputs, stepForward };
}
```
