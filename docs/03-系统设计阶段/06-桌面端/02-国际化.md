# 国际化（i18n）

> 阶段：系统设计 | 状态：定稿 | 说明：react-i18next、Prompt 多语言、locale

桌面端面向多语言用户，需要在架构层面提前规划，避免后期大规模重构。

---

## 技术选型

| 层次 | 方案 |
|------|------|
| 前端文本 | react-i18next + i18next |
| 日期/数字/货币 | Intl API（浏览器原生） |
| Prompt 模板 | 多语言模板文件，运行时按 locale 加载 |
| Rust 后端 | fluent-rs（Mozilla 的 i18n 库） |

### 初始化

```typescript
// apps/desktop/src/i18n/index.ts

import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import resourcesToBackend from "i18next-resources-to-backend";

i18n
  .use(initReactI18next)
  .use(resourcesToBackend((lang: string, ns: string) =>
    import(`./locales/${lang}/${ns}.json`)
  ))
  .init({
    lng: "zh-CN",           // 默认语言
    fallbackLng: "en-US",   // 找不到翻译时回退
    defaultNS: "common",
    interpolation: { escapeValue: false },
  });

export default i18n;
```

### 使用方式

```typescript
import { useTranslation } from "react-i18next";

export function InputBar() {
  const { t } = useTranslation("chat");
  return <input placeholder={t("inputPlaceholder")} />;
}

// 日期格式化（Intl API）
const formatter = new Intl.DateTimeFormat(i18n.language, {
  dateStyle: "medium",
  timeStyle: "short",
});
formatter.format(new Date(trace.timestamp));

// 货币格式化
const cost = new Intl.NumberFormat(i18n.language, {
  style: "currency",
  currency: "USD",
  minimumFractionDigits: 4,
}).format(0.0023);
```

## Prompt 模板多语言

Agent 的 Prompt 模板按 locale 分目录存放：

```text
prompts/
├── zh-CN/
│   ├── system.md
│   ├── planner.md
│   └── skills/
│       └── research.md
├── en-US/
│   ├── system.md
│   └── ...
└── ja-JP/
    └── ...
```

```rust
// crates/agent-core/src/prompts/mod.rs

pub struct PromptStore {
    base_dir: PathBuf,
    locale: String,         // "zh-CN" / "en-US"
    fallback: String,       // "en-US"
}

impl PromptStore {
    pub fn load(&self, name: &str) -> anyhow::Result<String> {
        // 优先加载当前 locale，找不到则回退
        let locale_path = self.base_dir.join(&self.locale).join(name);
        let fallback_path = self.base_dir.join(&self.fallback).join(name);

        if locale_path.exists() {
            fs::read_to_string(locale_path)
        } else {
            fs::read_to_string(fallback_path)
        }
        .map_err(Into::into)
    }
}
```

## 语言检测与切换

```rust
// apps/desktop/src-tauri/src/commands/config.rs

#[command]
pub fn get_system_locale() -> String {
    // 读取系统语言设置
    sys_locale::get_locale().unwrap_or_else(|| "en-US".to_string())
}

#[command]
pub async fn set_locale(locale: String, state: State<'_, AppState>) -> Result<(), String> {
    state.config.write().await.locale = locale.clone();
    state.config.write().await.save().map_err(|e| e.to_string())
}
```

```typescript
// 前端切换语言
const changeLanguage = async (locale: string) => {
  await invoke("set_locale", { locale });
  await i18n.changeLanguage(locale);
};
```
