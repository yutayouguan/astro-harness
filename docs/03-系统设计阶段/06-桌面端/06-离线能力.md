# 离线能力

> 阶段：系统设计 | 状态：定稿 | 说明：Ollama sidecar、网络检测、优雅降级

当前架构强依赖云端 LLM API，网络断开时完全不可用。通过集成本地模型实现优雅降级。

---

## 架构

```
网络可用
    └── 云端 Provider（Claude / OpenAI / Gemini 等）

网络不可用（自动降级）
    └── 本地模型（Ollama sidecar）

恢复网络
    └── 自动切回云端（可配置）
```

---

## 本地模型方案

使用 **Ollama** 作为本地模型运行时，通过 Tauri sidecar 机制随应用启动：

- 零配置：打包进应用，用户无需单独安装
- 兼容 OpenAI API 格式：复用已有 `TextClient` 实现
- 支持主流本地模型：Llama 3、Qwen2.5、Mistral、Phi-4 等

---

## Tauri Sidecar 配置

```json
// apps/desktop/src-tauri/tauri.conf.json
{
  "bundle": {
    "externalBin": ["bin/ollama"]   // 打包 ollama 可执行文件
  },
  "plugins": {
    "shell": {
      "sidecar": true
    }
  }
}
```

```rust
// apps/desktop/src-tauri/src/sidecar.rs

use tauri_plugin_shell::ShellExt;

pub async fn start_ollama(app: &AppHandle) -> anyhow::Result<()> {
    let sidecar = app.shell()
        .sidecar("ollama")?
        .args(["serve"]);

    let (_, child) = sidecar.spawn()?;

    // 等待 Ollama 启动（轮询健康检查）
    for _ in 0..30 {
        if reqwest::get("http://localhost:11434/api/tags").await.is_ok() {
            tracing::info!("Ollama sidecar 启动完成");
            return Ok(());
        }
        tokio::time::sleep(Duration::from_secs(1)).await;
    }

    Err(anyhow::anyhow!("Ollama 启动超时"))
}
```

## Ollama Provider 实现

Ollama 兼容 OpenAI API，直接复用 OpenAI provider，只需切换 base_url：

```rust
// crates/agent-providers/src/providers/ollama/mod.rs

pub fn create_ollama_client(model: &str) -> Arc<dyn TextClient> {
    // 复用 OpenAI provider 实现，指向本地 Ollama
    Arc::new(OpenAiTextClient::new(OpenAiConfig {
        api_key: "ollama".to_string(),      // Ollama 不校验 key
        base_url: "http://localhost:11434/v1".to_string(),
        model: model.to_string(),
    }))
}
```

配置支持的本地模型：

```toml
# configs/providers.toml

[providers.ollama]
base_url = "http://localhost:11434/v1"
models.text = [
    "qwen2.5:7b",       # 中文支持好，7B 适合 16GB 内存
    "llama3.2:3b",      # 轻量，适合 8GB 内存
    "phi4:14b",         # 推理能力强
    "mistral:7b",
]
```

## 网络状态检测

```rust
// crates/agent-core/src/network/monitor.rs

pub struct NetworkMonitor {
    state: Arc<RwLock<NetworkState>>,
    check_interval: Duration,
}

#[derive(Debug, Clone, PartialEq)]
pub enum NetworkState {
    Online,
    Offline,
    Degraded { latency_ms: u64 },   // 网络质量差
}

impl NetworkMonitor {
    pub async fn start(&self, app: AppHandle) {
        let mut interval = tokio::time::interval(self.check_interval);

        loop {
            interval.tick().await;

            let new_state = self.probe().await;
            let old_state = self.state.read().await.clone();

            if new_state != old_state {
                *self.state.write().await = new_state.clone();
                // 通知前端网络状态变化
                app.emit("network-state-changed", &new_state).ok();
            }
        }
    }

    async fn probe(&self) -> NetworkState {
        let start = tokio::time::Instant::now();
        match reqwest::get("https://api.anthropic.com/health").await {
            Ok(_) => {
                let ms = start.elapsed().as_millis() as u64;
                if ms > 2000 {
                    NetworkState::Degraded { latency_ms: ms }
                } else {
                    NetworkState::Online
                }
            }
            Err(_) => NetworkState::Offline,
        }
    }
}
```

## ProviderRegistry 降级路由

```rust
// crates/agent-providers/src/registry.rs

impl ProviderRegistry {
    pub fn text_with_fallback(
        &self,
        preferred: &str,
        network: &NetworkState,
    ) -> Result<Arc<dyn TextClient>> {

        match network {
            NetworkState::Online => {
                // 优先使用首选云端模型
                self.text(preferred)
            }
            NetworkState::Offline | NetworkState::Degraded { .. } => {
                // 降级到本地模型
                tracing::warn!("网络不可用，降级到本地模型");
                self.text(&self.config.offline_fallback_model)
                    .or_else(|_| self.text("qwen2.5:7b"))
            }
        }
    }
}
```

配置降级策略：

```toml
# configs/providers.toml

[routing]
default_text           = "claude-sonnet-5"
offline_fallback_model = "qwen2.5:7b"      # 网络不可用时使用
auto_switch_back       = true               # 网络恢复后自动切回云端
degraded_threshold_ms  = 3000              # 超过此延迟视为 Degraded
```

## 本地模型管理

```rust
// apps/desktop/src-tauri/src/commands/ollama.rs

#[command]
pub async fn list_local_models() -> Result<Vec<OllamaModel>, String> {
    let resp = reqwest::get("http://localhost:11434/api/tags")
        .await.map_err(|e| e.to_string())?
        .json::<serde_json::Value>()
        .await.map_err(|e| e.to_string())?;

    Ok(parse_models(resp))
}

#[command]
pub async fn pull_model(name: String, app: AppHandle) -> Result<(), String> {
    // 流式拉取模型，推送下载进度给前端
    let client = reqwest::Client::new();
    let mut stream = client
        .post("http://localhost:11434/api/pull")
        .json(&json!({ "name": name }))
        .send().await.map_err(|e| e.to_string())?
        .bytes_stream();

    while let Some(chunk) = stream.next().await {
        let chunk = chunk.map_err(|e| e.to_string())?;
        if let Ok(progress) = serde_json::from_slice::<OllamaPullProgress>(&chunk) {
            app.emit("model-pull-progress", &progress).ok();
        }
    }
    Ok(())
}

#[command]
pub async fn delete_model(name: String) -> Result<(), String> {
    reqwest::Client::new()
        .delete("http://localhost:11434/api/delete")
        .json(&json!({ "name": name }))
        .send().await.map_err(|e| e.to_string())?;
    Ok(())
}
```

| 功能 | 离线状态 |

| 查看/管理 Skill | ✓ |
| 查看进化日志 | ✓ |
| 查看本地备份 | ✓ |
| 使用本地模型对话 | ✓（需提前下载模型） |
| 调用联网工具（web_search 等） | ✗ |
| 云端 LLM Provider | ✗ |
| Model Insights 更新 | ✗（展示缓存数据） |
| 插件市场 | ✗ |

## 前端网络状态指示

```typescript
// apps/desktop/src/hooks/useNetworkState.ts

export function useNetworkState() {
  const [state, setState] = useState<NetworkState>("online");

  useEffect(() => {
    const unlisten = listen<NetworkState>("network-state-changed", (e) => {
      setState(e.payload);
    });
    return () => { unlisten.then(fn => fn()); };
  }, []);

  return state;
}

// 在标题栏显示网络状态
export function NetworkIndicator() {
  const state = useNetworkState();
  if (state === "online") return null;

  return (
    <Badge variant={state === "offline" ? "destructive" : "warning"}>
      {state === "offline" ? "离线模式（本地模型）" : "网络质量差"}
    </Badge>
  );
}
```
