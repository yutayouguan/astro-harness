# Model Insights 界面设计

> 阶段：系统设计 | 状态：定稿 | 说明：多维排行榜、筛选器、模型对比

桌面端独立页面，实时从 OpenRouter API 拉取数据，按多个维度展示模型排行榜，帮助用户选择最合适的模型。

## 排行榜维度

### 1. 价格最低

调用：`?sort=pricing-low-to-high&output_modalities=text`

展示字段：排名、模型名、提供商、输入价格、输出价格、上下文长度

```
#1  deepseek/deepseek-v4-flash   DeepSeek    $0.09 / $0.18    1M
#2  qwen/qwen3.7-flash           Alibaba     $0.03 / $0.13    1M
#3  nex-agi/nex-n2-mini          Nex AGI     $0.03 / $0.10    256K
```

### 2. 速度最快（吞吐量）

调用：`?sort=throughput-high-to-low`

展示字段：排名、模型名、tokens/s（p50）、首字延迟（TTFT p50）

### 3. 延迟最低

调用：`?sort=latency-low-to-high`

展示字段：排名、模型名、TTFT p50、吞吐量

### 4. 上下文最长

调用：`?sort=context-high-to-low`

展示字段：排名、模型名、上下文长度、输入价格

### 5. 最受欢迎

调用：`?sort=most-popular`

展示字段：排名、模型名、过去一周 token 量（相对柱状图）

### 6. 最新上线

调用：`?sort=newest`

展示字段：排名、模型名、上线时间（相对，如"3 天前"）

### 7. 性价比

前端计算维度：`quality_score / price_per_1m_token`

quality_score 来源：
- 有 ELO 数据：使用 `benchmarks.design_arena[0].elo` 归一化
- 无 ELO：用 `context_length` + `supported_parameters.length` 启发式估算

### 8. 基准测试（Design Arena）

过滤：`jq '.data[] | select(.benchmarks)'`

展示字段：排名、模型名、ELO、胜率、Arena 类别

## 筛选器

| 筛选项 | API 参数 | 说明 |
| ------ | -------- | ---- |
| 输出模态 | `output_modalities=text\|image\|audio\|embeddings\|all` | 多选 |
| Tool Use | `supported_parameters=tools` | 开关 |
| 推理模式 | `supported_parameters=reasoning` | 开关 |
| 结构化输出 | `supported_parameters=structured_outputs` | 开关 |
| 联网搜索 | `supported_parameters=web_search_options` | 开关 |
| 仅免费 | 前端过滤 `pricing.prompt === "0"` | 开关 |
| 视频输入 | 前端过滤 `architecture.input_modalities.includes("video")` | 开关 |
| 图像输出 | 前端过滤 `architecture.output_modalities.includes("image")` | 开关 |
| 提供商 | 前端过滤 `id.startsWith(provider)` | 多选下拉 |

## 数据层设计

```typescript
// apps/desktop/src/store/modelInsights.ts

interface ModelInsightsStore {
  models: OpenRouterModel[];
  loading: boolean;
  lastFetched: number | null;

  // 筛选 & 排序状态
  sortDimension: SortDimension;
  filters: ModelFilters;

  // 动作
  fetch: () => Promise<void>;
  setSort: (dim: SortDimension) => void;
  setFilter: (key: keyof ModelFilters, value: unknown) => void;

  // 计算属性
  filtered: () => OpenRouterModel[];
  ranked: () => RankedModel[];
}

type SortDimension =
  | "pricing-low-to-high"
  | "throughput-high-to-low"
  | "latency-low-to-high"
  | "context-high-to-low"
  | "most-popular"
  | "newest"
  | "value-score"     // 前端计算
  | "benchmark-elo";  // 前端计算

interface ModelFilters {
  outputModalities: string[];
  supportedParams: string[];
  freeOnly: boolean;
  videoInput: boolean;
  imageOutput: boolean;
  providers: string[];
}
```

## Tauri Command

```rust
// apps/desktop/src-tauri/src/commands/providers.rs

#[command]
pub async fn fetch_openrouter_models(
    sort: Option<String>,
    output_modalities: Option<String>,
    supported_parameters: Option<String>,
) -> Result<serde_json::Value, String> {
    let mut url = "https://openrouter.ai/api/v1/models".to_string();
    let mut params = vec!["output_modalities=all".to_string()];

    if let Some(s) = sort {
        params.push(format!("sort={s}"));
    }
    if let Some(p) = supported_parameters {
        params.push(format!("supported_parameters={p}"));
    }

    url = format!("{}?{}", url, params.join("&"));

    let resp = reqwest::get(&url)
        .await
        .map_err(|e| e.to_string())?
        .json::<serde_json::Value>()
        .await
        .map_err(|e| e.to_string())?;

    Ok(resp)
}

// 单模型详情（含别名解析）
#[command]
pub async fn fetch_model_detail(model_id: String) -> Result<serde_json::Value, String> {
    let url = format!("https://openrouter.ai/api/v1/model/{model_id}");
    let resp = reqwest::get(&url)
        .await
        .map_err(|e| e.to_string())?
        .json::<serde_json::Value>()
        .await
        .map_err(|e| e.to_string())?;
    Ok(resp)
}
```

## 缓存策略

- 首次打开页面：立即发起请求
- 数据缓存 **15 分钟**（OpenRouter 文档说明有 CDN 缓存）
- 后台静默刷新：切换到该页面时若超过 15 分钟则刷新
- 离线时展示上次缓存数据 + 时间戳提示

```typescript
const CACHE_TTL_MS = 15 * 60 * 1000;

async function fetchWithCache() {
  const age = Date.now() - (store.lastFetched ?? 0);
  if (age < CACHE_TTL_MS && store.models.length > 0) return;
  await store.fetch();
}
```
