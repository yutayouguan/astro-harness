# 隐私与合规

> 阶段：系统设计 | 状态：定稿 | 说明：敏感词过滤、数据声明、SQLCipher

Agent 处理的内容可能包含个人信息、公司机密等敏感数据，需要在架构层面提供隐私保护能力。

---

## 三个核心机制

```
隐私保护
├── 敏感词过滤      → 防止把内部数据发给外部 API
├── Provider 数据声明 → 告知用户哪些 Provider 不存储请求数据
└── 本地加密存储    → SQLite 使用 SQLCipher 加密
```

## 敏感词过滤

在数据发送给外部 API 之前，自动检测并脱敏。

```rust
// crates/agent-core/src/privacy/filter.rs

pub struct SensitiveFilter {
    rules: Vec<FilterRule>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct FilterRule {
    pub name: String,
    pub pattern: FilterPattern,
    pub action: FilterAction,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum FilterPattern {
    Regex { pattern: String },
    Keyword { words: Vec<String>, case_sensitive: bool },
    // 内置规则
    CreditCard,
    PhoneNumber,
    Email,
    IdNumber,            // 中国身份证号
    ApiKey,              // 常见 API Key 格式
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum FilterAction {
    Block,                      // 阻断，不发送
    Redact { placeholder: String }, // 替换为占位符
    Warn,                       // 警告但允许发送
}

impl SensitiveFilter {
    pub fn scan(&self, content: &str) -> Vec<FilterMatch> {
        self.rules.iter()
            .flat_map(|rule| self.apply_rule(rule, content))
            .collect()
    }

    pub fn apply(&self, content: &str) -> FilterResult {
        let matches = self.scan(content);

        // 有 Block 规则命中时，阻断整个请求
        if matches.iter().any(|m| matches!(m.action, FilterAction::Block)) {
            return FilterResult::Blocked { matches };
        }

        // 执行脱敏替换
        let mut redacted = content.to_string();
        for m in &matches {
            if let FilterAction::Redact { placeholder } = &m.action {
                redacted = redacted.replace(&m.matched_text, placeholder);
            }
        }

        FilterResult::Allowed { content: redacted, warnings: matches }
    }
}
```


### 在 Provider 调用前拦截

```rust
// crates/agent-providers/src/middleware/privacy.rs

pub struct PrivacyMiddleware {
    filter: Arc<SensitiveFilter>,
}

impl PrivacyMiddleware {
    pub fn apply_to_request(&self, req: &mut TextRequest) -> anyhow::Result<()> {
        for msg in &mut req.messages {
            for part in &mut msg.content {
                if let ContentPart::Text { text } = part {
                    match self.filter.apply(text) {
                        FilterResult::Blocked { matches } => {
                            return Err(PrivacyError::Blocked { matches }.into());
                        }
                        FilterResult::Allowed { content, .. } => {
                            *text = content;
                        }
                    }
                }
            }
        }
        Ok(())
    }
}
```

## Provider 数据留存声明

```rust
// crates/agent-providers/src/types/capabilities.rs

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct DataPrivacyPolicy {
    pub stores_prompts: bool,           // 是否存储用户请求
    pub trains_on_data: bool,           // 是否用于模型训练
    pub retention_days: Option<u32>,    // 数据保留天数（None = 不保留）
    pub gdpr_compliant: bool,
    pub policy_url: String,
    pub zero_data_retention: bool,      // ZDR 选项（企业版）
}

// 各 Provider 的声明（根据官方文档整理）
pub fn provider_privacy_policy(provider: &str) -> DataPrivacyPolicy {
    match provider {
        "anthropic" => DataPrivacyPolicy {
            stores_prompts:      false, // API 调用默认不存储
            trains_on_data:      false,
            retention_days:      Some(30), // 日志保留 30 天
            gdpr_compliant:      true,
            zero_data_retention: true,     // 企业版支持
            policy_url: "https://anthropic.com/privacy".into(),
        },
        "openai" => DataPrivacyPolicy {
            stores_prompts:      false, // API 默认不用于训练
            trains_on_data:      false,
            retention_days:      Some(30),
            gdpr_compliant:      true,
            zero_data_retention: true,
            policy_url: "https://openai.com/privacy".into(),
        },
        "google" => DataPrivacyPolicy {
            stores_prompts:      false,
            trains_on_data:      false,
            retention_days:      Some(30),
            gdpr_compliant:      true,
            zero_data_retention: true,
            policy_url: "https://policies.google.com/privacy".into(),
        },
        "deepseek" => DataPrivacyPolicy {
            stores_prompts:      true,  // 注意：DeepSeek 存储请求用于改进
            trains_on_data:      true,
            retention_days:      None,
            gdpr_compliant:      false,
            zero_data_retention: false,
            policy_url: "https://www.deepseek.com/privacy".into(),
        },
        _ => DataPrivacyPolicy::unknown(),
    }
}
```

## 本地加密存储（SQLCipher）

使用 SQLCipher 对整个 SQLite 数据库文件加密，密钥由用户密码派生。

```toml
# workspace Cargo.toml 新增
sqlx = { version = "0.8", features = ["sqlite", "runtime-tokio"] }
libsqlite3-sys = { version = "0.27", features = ["sqlcipher"] }
```

```rust
// crates/agent-core/src/storage/mod.rs

impl Store {
    pub async fn open_encrypted(
        path: &Path,
        passphrase: &str,
    ) -> anyhow::Result<Self> {
        // SQLCipher 内置 PBKDF2 密钥派生，直接传入 passphrase 即可
        // 无需应用层 Argon2 KDF
        let options = SqliteConnectOptions::new()
            .filename(path)
            .create_if_missing(true)
            .pragma("key", passphrase)
            .pragma("cipher_page_size", "4096")
            .journal_mode(SqliteJournalMode::Wal);

        let pool = SqlitePoolOptions::new()
            .connect_with(options)
            .await?;

        sqlx::migrate!("./migrations").run(&pool).await?;
        Ok(Self { pool })
    }
}
```

### 系统密钥链集成

```rust
// apps/desktop/src-tauri/src/security/keychain.rs

use keyring::Entry;

pub fn get_or_create_db_password() -> anyhow::Result<String> {
    let entry = Entry::new("astro-agent", "db_password")?;

    // 尝试从系统密钥链读取已有密码
    if let Ok(password) = entry.get_password() {
        return Ok(password);
    }

    // 首次启动：生成随机密码并存入密钥链
    let password = generate_random_password(32);
    entry.set_password(&password)?;
    Ok(password)
}
```
