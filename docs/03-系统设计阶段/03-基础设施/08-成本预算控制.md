# 成本预算控制

> **Harness 定位（2026-09-07）**：预算是 turn 停止条件之一。当前实现以 `TurnState`（轮次工具深度）、`IterationBudget`（per-thread 迭代预算）、Provider usage 覆盖式累加和 `usage.db`（`crates/agent-usage`）归因为准。V2 Agent Threads 使用每线程独立预算。

> 阶段：系统设计 | 状态：定稿 | 说明：三级预算、超支告警、费用仪表板

## 概述

调用 LLM API 会产生实际费用。Astro Agent 提供四个维度的预算控制体系，防止意外超支，同时在超出预算时给出合理的降级策略和告警通知。

---

## 1. 预算维度

| 维度 | 说明 | 典型上限 |
| ---- | ---- | ---- |
| **全局预算** | 整个应用的每日 / 每月总花费上限 | $10/日，$100/月 |
| **工作区预算** | 每个工作区独立配额，防止单个项目耗尽全局预算 | $2/日 |
| **任务预算** | 单次 Agent 运行的花费上限 | $0.50/次 |
| **进化引擎预算** | 自我进化引擎（Eval + Prompt 优化）专项配额 | $5/月 |

## 2. BudgetManager 实现

```rust
// crates/agent-core/src/budget/manager.rs

use anyhow::Result;
use chrono::{Datelike, Utc};
use sqlx::SqlitePool;

/// 成本记录（来自 Provider 的用量报告，字段与 Schema DDL cost_records 表对齐）
#[derive(Debug, Clone)]
pub struct CostRecord {
    pub workspace_id: String,              // NOT NULL，关联工作区
    pub session_id: Option<String>,        // 关联会话 session
    pub conversation_id: Option<String>,   // 关联会话（可为空）
    pub task_id: Option<String>,           // 关联任务（可为空）
    pub provider: String,
    pub model: String,
    pub input_tokens: u64,
    pub output_tokens: u64,
    pub cached_tokens: Option<u64>,        // 缓存命中 token 数
    /// 美元金额
    pub cost_usd: f64,
    pub recorded_at: i64,                  // Unix ms
}

/// 超出预算时的处理策略
#[derive(Debug, Clone, serde::Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum OverflowPolicy {
    /// 拒绝调用，返回错误
    Block,
    /// 记录警告，允许继续
    Warn,
    /// 切换到更便宜的模型后继续
    Downgrade { fallback_model: String },
}

pub struct BudgetManager {
    db: SqlitePool,
    config: BudgetConfig,
    /// 费用超限时强制关闭 YOLO；Option 允许在非 Tauri 环境（测试/CLI）中省略
    human_guard: Option<Arc<HumanGuard>>,
    emitter: Arc<dyn EventEmitter>,
}

impl BudgetManager {
    pub fn new(db: SqlitePool, config: BudgetConfig) -> Self {
        Self { db, config }
    }

    /// 调用前检查：返回是否允许继续（以及可能的降级模型）
    /// 检查顺序：session → workspace daily → global daily → global monthly
    pub async fn check_before_call(
        &self,
        workspace_id: &str,
        session_id: &str,
        estimated_cost: f64,
    ) -> Result<PreCallDecision> {
        let today = Utc::now().date_naive();
        let month_start = format!("{}-{:02}-01", today.year(), today.month());

        // 1. 检查 session 预算（单次任务上限）
        if let Some(session_limit) = self.config.session_limit_usd {
            let session_cost: f64 = sqlx::query_scalar!(
                "SELECT COALESCE(SUM(cost_usd), 0.0) FROM cost_records
                 WHERE session_id = ?",
                session_id
            )
            .fetch_one(&self.db)
            .await?;

            if session_cost + estimated_cost > session_limit {
                return Ok(self.apply_policy(&self.config.overflow_policy, "会话预算"));
            }
        }

        // 2. 检查工作区每日上限
        if let Some(ws_config) = self.config.workspace_limits.get(workspace_id) {
            let daily_workspace: f64 = sqlx::query_scalar!(
                "SELECT COALESCE(SUM(cost_usd), 0.0) FROM cost_records
                 WHERE workspace_id = ? AND date(recorded_at / 1000, 'unixepoch') = date('now')",
                workspace_id
            )
            .fetch_one(&self.db)
            .await?;

            if daily_workspace + estimated_cost > ws_config.daily_limit_usd {
                return Ok(self.apply_policy(&ws_config.overflow_policy, "工作区每日预算"));
            }
        }

        // 3. 检查全局每日上限
        let daily_global: f64 = sqlx::query_scalar!(
            "SELECT COALESCE(SUM(cost_usd), 0.0) FROM cost_records
             WHERE date(recorded_at / 1000, 'unixepoch') = date('now')"
        )
        .fetch_one(&self.db)
        .await?;

        if daily_global + estimated_cost > self.config.global_daily_limit_usd {
            return Ok(self.apply_policy(&self.config.overflow_policy, "全局每日预算"));
        }

        // 4. 检查全局每月上限
        let monthly_global: f64 = sqlx::query_scalar!(
            "SELECT COALESCE(SUM(cost_usd), 0.0) FROM cost_records
             WHERE recorded_at >= ?",
            month_start
        )
        .fetch_one(&self.db)
        .await?;

        if monthly_global + estimated_cost > self.config.global_monthly_limit_usd {
            return Ok(self.apply_policy(&self.config.overflow_policy, "全局每月预算"));
        }

        Ok(PreCallDecision::Allow)
    }

    fn apply_policy(&self, policy: &OverflowPolicy, budget_name: &str) -> PreCallDecision {
        // 任何超限策略触发时均强制关闭 YOLO，防止后续调用无声绕过弹窗
        self.enforce_yolo_shutdown(budget_name);

        match policy {
            OverflowPolicy::Block => PreCallDecision::Block {
                reason: format!("已超出{}上限", budget_name),
            },
            OverflowPolicy::Warn => PreCallDecision::Warn {
                message: format!("警告：已超出{}上限，继续执行", budget_name),
            },
            OverflowPolicy::Downgrade { fallback_model } => PreCallDecision::Downgrade {
                model: fallback_model.clone(),
                reason: format!("已超出{}，切换至 {}", budget_name, fallback_model),
            },
        }
    }

    /// 记录实际消耗
    pub async fn record_cost(&self, record: &CostRecord) -> Result<()> {
        sqlx::query!(
            r#"
            INSERT INTO cost_records (
                id, workspace_id, task_id, provider, model,
                input_tokens, output_tokens, cost_usd, recorded_at
            ) VALUES (
                lower(hex(randomblob(16))), ?, ?, ?, ?,
                ?, ?, ?, unixepoch('now','subsec')*1000
            )
            "#,
            record.workspace_id,
            record.task_id,
            record.provider,
            record.model,
            record.input_tokens as i64,
            record.output_tokens as i64,
            record.cost_usd,
        )
        .execute(&self.db)
        .await?;

        // 更新日汇总缓存
        self.upsert_daily_summary(&record).await?;
        Ok(())
    }

    /// 费用超限时强制关闭 YOLO 开关（防止无弹窗继续消耗）
    fn enforce_yolo_shutdown(&self, budget_name: &str) {
        if let Some(guard) = &self.human_guard {
            if guard.yolo_mode.load(Ordering::Relaxed) {
                guard.set_yolo(false);
                let _ = self.emitter.emit("yolo_force_disabled", serde_json::json!({
                    "reason": format!("{}超限，YOLO 模式已自动关闭", budget_name)
                }));
            }
        }
    }

    /// 获取费用摘要
    pub async fn get_summary(&self, workspace_id: Option<&str>) -> Result<CostSummary> {
        let today_cost: f64 = sqlx::query_scalar!(
            "SELECT COALESCE(SUM(cost_usd), 0.0) FROM cost_records
             WHERE date(recorded_at / 1000, 'unixepoch') = date('now')
               AND (? IS NULL OR workspace_id = ?)",
            workspace_id, workspace_id
        )
        .fetch_one(&self.db)
        .await?;

        let month_cost: f64 = sqlx::query_scalar!(
            "SELECT COALESCE(SUM(cost_usd), 0.0) FROM cost_records
             WHERE strftime('%Y-%m', recorded_at / 1000, 'unixepoch') = strftime('%Y-%m', 'now')
               AND (? IS NULL OR workspace_id = ?)",
            workspace_id, workspace_id
        )
        .fetch_one(&self.db)
        .await?;

        Ok(CostSummary {
            today_usd: today_cost,
            this_month_usd: month_cost,
            daily_limit_usd: self.config.global_daily_limit_usd,
            monthly_limit_usd: self.config.global_monthly_limit_usd,
        })
    }

    async fn upsert_daily_summary(&self, record: &CostRecord) -> Result<()> {
        let date = Utc::now().format("%Y-%m-%d").to_string();
        sqlx::query!(
            r#"
            INSERT INTO daily_cost_summary (date, workspace_id, provider, model, total_cost_usd, call_count)
            VALUES (?, ?, ?, ?, ?, 1)
            ON CONFLICT(date, workspace_id, provider, model) DO UPDATE SET
                total_cost_usd = total_cost_usd + excluded.total_cost_usd,
                call_count = call_count + 1
            "#,
            date, record.workspace_id, record.provider, record.model, record.cost_usd
        )
        .execute(&self.db)
        .await?;
        Ok(())
    }
}

#[derive(Debug)]
pub enum PreCallDecision {
    Allow,
    Warn { message: String },
    Block { reason: String },
    Downgrade { model: String, reason: String },
}

#[derive(Debug, serde::Serialize)]
pub struct CostSummary {
    pub today_usd: f64,
    pub this_month_usd: f64,
    pub daily_limit_usd: f64,
    pub monthly_limit_usd: f64,
}
```

## 5. Tauri Commands

```rust
// src-tauri/src/commands/budget.rs

use tauri::State;
use crate::AppState;

#[tauri::command]
pub async fn get_cost_summary(
    workspace_id: Option<String>,
    state: State<'_, AppState>,
) -> Result<CostSummary, String> {
    state.budget_manager
        .get_summary(workspace_id.as_deref())
        .await
        .map_err(|e| e.to_string())
}

#[tauri::command]
pub async fn set_budget(
    config: BudgetConfigInput,
    state: State<'_, AppState>,
) -> Result<(), String> {
    sqlx::query!(
        "INSERT OR REPLACE INTO budget_configs
         (id, global_daily_usd, global_monthly_usd, evolution_monthly_usd, overflow_policy, updated_at)
         VALUES ('global', ?, ?, ?, ?, datetime('now'))",
        config.global_daily_usd,
        config.global_monthly_usd,
        config.evolution_monthly_usd,
        serde_json::to_string(&config.overflow_policy).unwrap(),
    )
    .execute(&state.db)
    .await
    .map_err(|e| e.to_string())?;

    // 重新加载配置
    state.budget_manager.reload_config().await.map_err(|e| e.to_string())
}

#[tauri::command]
pub async fn get_budget_alerts(
    state: State<'_, AppState>,
) -> Result<Vec<BudgetAlert>, String> {
    let summary = state.budget_manager.get_summary(None).await.map_err(|e| e.to_string())?;
    let mut alerts = vec![];

    let daily_ratio = summary.today_usd / summary.daily_limit_usd;
    if daily_ratio >= 0.9 {
        alerts.push(BudgetAlert {
            level: if daily_ratio >= 1.0 { "error" } else { "warning" }.to_string(),
            message: format!(
                "今日花费 ${:.2}，已达每日限额的 {:.0}%",
                summary.today_usd,
                daily_ratio * 100.0
            ),
        });
    }

    Ok(alerts)
}
```

```tsx
// src/pages/CostDashboard.tsx

import { useEffect, useState } from "react";
import { invoke } from "@tauri-apps/api/core";
import { Progress } from "@/components/ui/progress";
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card";
import {
  BarChart,
  Bar,
  XAxis,
  YAxis,
  Tooltip,
  ResponsiveContainer,
  Cell,
} from "recharts";

interface CostSummary {
  today_usd: number;
  this_month_usd: number;
  daily_limit_usd: number;
  monthly_limit_usd: number;
}

interface ProviderCost {
  provider: string;
  total_cost_usd: number;
}

const PROVIDER_COLORS: Record<string, string> = {
  anthropic: "#d97706",
  openai: "#10b981",
  google: "#3b82f6",
  openrouter: "#8b5cf6",
};

export function CostDashboard() {
  const [summary, setSummary] = useState<CostSummary | null>(null);
  const [providerBreakdown, setProviderBreakdown] = useState<ProviderCost[]>([]);

  useEffect(() => {
    invoke<CostSummary>("get_cost_summary").then(setSummary);
    // 按 Provider 查询本月明细
    invoke<ProviderCost[]>("get_cost_by_provider").then(setProviderBreakdown);
  }, []);

  if (!summary) return <div className="p-6">加载中...</div>;

  const dailyRatio = summary.today_usd / summary.daily_limit_usd;
  const monthlyRatio = summary.this_month_usd / summary.monthly_limit_usd;

  return (
    <div className="p-6 space-y-6">
      <h1 className="text-2xl font-bold">费用仪表板</h1>

      {/* 今日 / 本月费用卡片 */}
      <div className="grid grid-cols-2 gap-4">
        <Card>
          <CardHeader>
            <CardTitle className="text-sm text-muted-foreground">今日费用</CardTitle>
          </CardHeader>
          <CardContent>
            <p className="text-3xl font-bold">${summary.today_usd.toFixed(3)}</p>
            <Progress value={dailyRatio * 100} className="mt-2" />
            <p className="text-xs text-muted-foreground mt-1">
              每日限额 ${summary.daily_limit_usd.toFixed(2)}（已用 {(dailyRatio * 100).toFixed(1)}%）
            </p>
          </CardContent>
        </Card>

        <Card>
          <CardHeader>
            <CardTitle className="text-sm text-muted-foreground">本月费用</CardTitle>
          </CardHeader>
          <CardContent>
            <p className="text-3xl font-bold">${summary.this_month_usd.toFixed(2)}</p>
            <Progress value={monthlyRatio * 100} className="mt-2" />
            <p className="text-xs text-muted-foreground mt-1">
              每月限额 ${summary.monthly_limit_usd.toFixed(2)}（已用 {(monthlyRatio * 100).toFixed(1)}%）
            </p>
          </CardContent>
        </Card>
      </div>

      {/* 各 Provider 占比柱状图 */}
      <Card>
        <CardHeader>
          <CardTitle className="text-sm">本月各 Provider 费用</CardTitle>
        </CardHeader>
        <CardContent>
          <ResponsiveContainer width="100%" height={200}>
```

```rust
use tauri::{AppHandle, Manager};

pub async fn send_budget_alert(app: &AppHandle, message: &str, level: &str) {
    // 发送 Tauri 系统通知
```

## 8. 成本归因系统

每次 LLM 调用后记录 `CostItem`，形成完整的任务成本明细，帮助用户理解"钱花在哪了"。

```rust
pub struct CostAttribution {
    pub task_id: Uuid,
    pub conversation_id: String,
    pub total_cost_usd: f64,
    pub breakdown: Vec<CostItem>,
}

pub struct CostItem {
    pub step_index: u32,
    pub description: String,              // "调用 web_search 后处理结果"
    pub agent_id: Uuid,                   // 主 Agent 或子 Agent
    pub agent_depth: u8,                  // 0=主 Agent, 1+=子 Agent
    pub model: String,                    // 使用的模型
    pub input_tokens: u64,
    pub output_tokens: u64,
    pub cost_usd: f64,
    pub timestamp: i64,
}
```

**数据采集流程**：

1. 每轮 LLM 调用后，从 Provider 响应中提取 `usage` 字段（覆盖式累加，兼容 Google 累计式 usageMetadata）
2. 计算本轮成本并记录到 `usage.db`（`crates/agent-usage`），含路由感知成本估算（官方定价快照 + OpenRouter API）
3. 每个 V2 Agent Thread 独立记录用量，通过 per-agent 统计实现归因
4. `usage.db` 支持 trace insights 和 eval JSONL 导出

**前端展示**：

- 对话底部展示本次任务总费用
- 点击展开：按步骤时间线展示每个 `CostItem`（模型、token 数、费用）
- 子 Agent 的成本通过 `usage.db` per-agent 统计独立追踪
- 费用仪表板增加"按任务类型"和"按模型"两个维度的成本分布图
