# 持久化层

> **Harness 基线（2026-08-29）**：持久化不是单一 SQLite 库。`agent-rollout` 是执行事件事实源；`state.db` 是会话、消息、billing 和 FTS 投影；`subagents-v2.db`、`usage.db`、`cron_v1.db`、`artifacts.db`、`knowledge.db` 各有独立责任。六个职责库均位于 `{base}/data/`，路径由 `agent-home` 统一生成。

> 阶段：系统设计 | 状态：定稿 | 说明：SQLite 运行时访问、数据目录结构

桌面端本地优先，所有持久化使用 SQLite（零配置、单文件、支持 WAL 模式高并发读）。

## 数据分层

```text
持久化层
├── rollout JSONL（权威执行事件历史）
│   └── agent-rollout append-only 时间线 → 会话恢复的事实源
├── state.db（会话 SessionStore，WAL SQLite，schema v24）
│   ├── 消息、会话、billing → 用户可浏览历史对话
│   ├── FTS5 召回 → 全文检索
│   └── rollout 投影重建 → 可从 rollout 重建
├── subagents-v2.db → Agent 线程图、邮箱、状态事件
├── usage.db → 用量事件、per-agent 统计、成本估算
├── artifacts.db → 文件空间索引
├── knowledge.db → 知识内容 FTS
├── cron.db → Cron job 运行记录
└── 向量存储 (sqlite-vec 扩展)
    └── 长期语义记忆 → 嵌入向量，用于相似检索
```

六个职责库均位于 `{base}/data/`，路径由 `agent-home` 统一生成。SessionStore 为可重建投影；rollout JSONL 为权威历史。

## 存储层实现

```rust
// crates/agent-core/src/storage/mod.rs

pub struct Store {
    pool: SqlitePool,
}

impl Store {
    pub async fn open(path: &Path) -> anyhow::Result<Self> {
        let options = SqliteConnectOptions::new()
            .filename(path)
            .create_if_missing(true)
            .journal_mode(SqliteJournalMode::Wal)   // WAL 模式：读写不互斥
            .foreign_keys(true);

        let pool = SqlitePoolOptions::new()
            .max_connections(5)
            .connect_with(options)
            .await?;

        // 自动运行迁移
        sqlx::migrate!("./migrations").run(&pool).await?;

        Ok(Self { pool })
    }
}
```

```rust
// crates/agent-core/src/storage/traces.rs

impl Store {
    pub async fn save_trace(&self, trace: &TaskTrace) -> anyhow::Result<()> {
        sqlx::query!(
            r#"INSERT INTO task_traces
               (id, task, agent_id, depth, steps, outcome, metrics, created_at)
               VALUES (?, ?, ?, ?, ?, ?, ?, ?)"#,
            trace.trace_id.to_string(),
            trace.task,
            trace.agent_id.to_string(),
            trace.depth,
            serde_json::to_string(&trace.steps)?,
            trace.outcome.to_string(),
            serde_json::to_string(&trace.metrics)?,
            trace.timestamp.to_rfc3339(),
        )
        .execute(&self.pool)
        .await?;
        Ok(())
    }

    // 查询最近 N 小时的轨迹（进化引擎批量分析用）
    pub async fn recent_traces(&self, window: Duration) -> anyhow::Result<Vec<TaskTrace>> {
        let since = (Utc::now() - window).to_rfc3339();
        let rows = sqlx::query!(
            "SELECT * FROM task_traces WHERE created_at >= ? ORDER BY created_at DESC",
            since
        )
        .fetch_all(&self.pool)
        .await?;

        rows.into_iter().map(|r| TaskTrace::from_row(r)).collect()
    }
}
```

## Skill/Prompt 版本管理

内容寻址存储——相同内容不重复保存，支持任意版本回滚：

```rust
// crates/agent-core/src/storage/versions.rs

impl Store {
    pub async fn save_skill(&self, name: &str, content: &str) -> anyhow::Result<String> {
        let hash = sha256(content);

        // 内容未变化则跳过
        if self.skill_hash_exists(&hash).await? {
            return Ok(hash);
        }

        let version = self.next_skill_version(name).await?;
        let parent  = self.active_skill_id(name).await?;

        // 旧版本设为 inactive
        sqlx::query!("UPDATE skills SET status='retired' WHERE name=? AND status='active'", name)
            .execute(&self.pool).await?;

        sqlx::query!(
            r#"INSERT INTO skills (id, name, version, content, content_hash, origin, parent_id, created_at)
               VALUES (?, ?, ?, ?, ?, 'synthesized', ?, ?)"#,
            Uuid::new_v4().to_string(), name, version, content, hash,
            parent, Utc::now().to_rfc3339(),
        )
        .execute(&self.pool).await?;

        Ok(hash)
    }

    // 回滚到指定版本
    pub async fn rollback_skill(&self, name: &str, version: i64) -> anyhow::Result<()> {
        sqlx::query!("UPDATE skills SET status='retired' WHERE name=? AND status='active'", name)
            .execute(&self.pool).await?;
        sqlx::query!(
            "UPDATE skills SET status='active' WHERE name=? AND version=?",
            name, version
        )
        .execute(&self.pool).await?;
        Ok(())
    }
}
```

## 向量存储（sqlite-vec）

使用 sqlite-vec 扩展，无需独立部署向量数据库：

```rust
// crates/agent-core/src/storage/vectors.rs

impl Store {
    pub async fn init_vec_table(&self) -> anyhow::Result<()> {
        sqlx::query(
            "CREATE VIRTUAL TABLE IF NOT EXISTS memory_vectors
             USING vec0(content TEXT, embedding FLOAT[1536])"
        )
        .execute(&self.pool).await?;
        Ok(())
    }

    pub async fn store_knowledge(
        &self,
        content: &str,
        vector: &[f32],
    ) -> anyhow::Result<()> {
        sqlx::query(
            "INSERT INTO memory_vectors(content, embedding) VALUES (?, ?)"
        )
        .bind(content)
        .bind(vector)
        .execute(&self.pool).await?;
        Ok(())
    }

    // KNN 相似检索
    pub async fn search(
        &self,
        query_vector: &[f32],
        top_k: usize,
    ) -> anyhow::Result<Vec<(String, f32)>> {
        let rows = sqlx::query(
            r#"SELECT content, distance
               FROM memory_vectors
               WHERE embedding MATCH ?
               ORDER BY distance LIMIT ?"#
        )
        .bind(query_vector)
        .bind(top_k as i64)
        .fetch_all(&self.pool).await?;

        Ok(rows.iter().map(|r| (r.get(0), r.get(1))).collect())
    }
}
```

## 非持久化状态（内存 only）

以下运行时状态故意不写入数据库，仅存活于进程内存：

| 状态 | 存储位置 | 崩溃后行为 | 设计理由 |
| ---- | -------- | ---------- | -------- |
| **Pending 消息队列** | `PendingQueue`（`Arc<Mutex<Vec>>>`） | 队列丢失，用户需重新输入 | 实现简洁；崩溃概率低；用户可从 UI 感知 Agent 异常终止 |
| **YOLO 开关** | `HumanGuard.yolo_mode`（`AtomicBool`） | 重置为 OFF（安全默认） | 跨会话持久化 YOLO=ON 存在安全隐患，每次启动强制重新授权 |
| **会话 Token 预算** | `TokenBudget`（`AtomicU64`） | 重置为 0 | Token 预算按任务计，崩溃即任务终止，不需恢复 |
