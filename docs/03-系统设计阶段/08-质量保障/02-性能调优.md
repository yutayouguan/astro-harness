> 阶段：系统设计 | 状态：定稿 | 说明：冷启动、虚拟滚动、SQLite、LRU

## 启动性能

### 目标：冷启动 < 2 秒

#### 启动时序图

```
T=0ms    Tauri 主进程启动
T=50ms   SQLite 连接池初始化（并行预热 5 个连接）
T=80ms   加载用户配置（工作区列表、全局设置）
T=120ms  Webview 创建，注入 HTML
T=200ms  React 应用初始化，加载当前工作区数据
T=400ms  首屏渲染完成，用户可交互
T=600ms  （后台）预加载最近会话的消息列表
T=1500ms （后台）懒连接 MCP Servers
T=3000ms （后台）Ollama sidecar 启动（仅离线模式）
```

#### SQLite 连接池预热

启动时并行初始化连接，避免首次查询的连接建立延迟：

```rust
// crates/db/src/pool.rs

use sqlx::{SqlitePool, sqlite::SqlitePoolOptions};

pub async fn create_pool(db_path: &str) -> anyhow::Result<SqlitePool> {
    let pool = SqlitePoolOptions::new()
        .max_connections(5)
        .min_connections(2)         // 预热 2 个连接
        .acquire_timeout(std::time::Duration::from_secs(5))
        .connect(&format!("sqlite:{}", db_path))
        .await?;

    // 并行执行 PRAGMA 初始化，避免串行等待
    let (r1, r2, r3) = tokio::join!(
        sqlx::query("PRAGMA journal_mode=WAL").execute(&pool),
        sqlx::query("PRAGMA cache_size=-65536").execute(&pool), // 64 MB
        sqlx::query("PRAGMA mmap_size=268435456").execute(&pool), // 256 MB
    );
    r1?; r2?; r3?;

    Ok(pool)
}
```

### 冷启动分级加载策略

将应用启动拆分为三个阶段，确保用户在 500ms 内看到 UI：

| 阶段 | 时间目标 | 加载内容 | 实现方式 |
| ---- | ---- | ---- | ---- |
| Phase 1 | < 500ms | UI 渲染 + 基础配置 + SQLite 连接池 | Tauri WebView 预热 + `config.toml` 解析 |
| Phase 2 | < 2s | 内置工具注册 + 记忆快照注入 + 上次会话恢复 | 同步加载，阻塞首次对话 |
| Phase 3 | 后台异步 | Tantivy 索引恢复 + MCP 懒连接 + WASM AOT 缓存 | `tokio::spawn` 后台任务 |

**关键优化技术**：

1. **Tantivy 索引持久化**：索引文件存储在 `~/.astro/cache/tantivy/`，启动时直接 mmap 加载，仅对上次启动后变更的 Skill 做增量更新。首次启动才全量构建。
2. **MCP 懒连接**：MCP Server 在首次被工具调用引用时才建立连接，而非启动时全部连接。工具 Schema 缓存到 SQLite（TTL 1 小时），避免每次启动都查询 `tools/list`。
3. **WASM AOT 预编译**：wasmtime 支持 AOT 编译，将 `.wasm` 预编译为 `.cwasm`（平台特定），存储在 `~/.astro/cache/wasm/`。启动时直接 mmap 加载，省去 JIT 编译。
4. **MCP 连接池回收**：超过 5 分钟未使用的 MCP 连接自动关闭 STDIO 子进程或断开 Streamable HTTP transport，按需重建。

**启动时间预算**：

```text
Phase 1: config.toml 解析 (~10ms) + SQLite 连接池 (~50ms) + UI 渲染 (~200ms) = ~260ms
Phase 2: 工具注册 (~20ms) + 记忆快照读取 (~30ms) + 会话恢复 (~50ms) = ~100ms
Phase 3 (后台): Tantivy 增量 (~200ms) + MCP 按需 + WASM 缓存命中 (~5ms/plugin)
```

#### 懒加载非关键模块

```rust
// crates/agent-core/src/mcp/lazy_client.rs

use std::sync::OnceLock;
use tokio::sync::Mutex;

/// MCP Client 仅在首次使用时建立连接
pub struct LazyMcpClient {
    inner: OnceLock<Mutex<McpClient>>,
    config: McpServerConfig,
}

impl LazyMcpClient {
    pub fn new(config: McpServerConfig) -> Self {
        Self { inner: OnceLock::new(), config }
    }

    pub async fn get(&self) -> anyhow::Result<&Mutex<McpClient>> {
        if self.inner.get().is_none() {
            let client = McpClient::connect(&self.config).await?;
            let _ = self.inner.set(Mutex::new(client));
        }
        Ok(self.inner.get().unwrap())
    }
}
```

## 前端渲染性能

### 虚拟滚动（长对话）

长对话可能有数百条消息。使用 `@tanstack/react-virtual` 只渲染可见区域：

```tsx
// src/components/MessageList.tsx

import React, { useRef } from 'react'
import { useVirtualizer } from '@tanstack/react-virtual'
import { Message } from '../types'
import { MessageItem } from './MessageItem'

interface MessageListProps {
  messages: Message[]
}

export function MessageList({ messages }: MessageListProps) {
  const parentRef = useRef<HTMLDivElement>(null)

  const virtualizer = useVirtualizer({
    count: messages.length,
    getScrollElement: () => parentRef.current,
    estimateSize: (index) => {
      // 根据消息类型估算高度，减少布局抖动
      const msg = messages[index]
      if (msg.role === 'user') return 80
      if (msg.content.length > 500) return 400
      return 200
    },
    overscan: 5, // 可见区域外额外渲染 5 条，避免快速滚动时白屏
  })

  return (
    <div
      ref={parentRef}
      className="h-full overflow-auto"
    >
      {/* 撑开滚动容器 */}
      <div style={{ height: `${virtualizer.getTotalSize()}px`, position: 'relative' }}>
        {virtualizer.getVirtualItems().map((virtualItem) => (
          <div
            key={virtualItem.key}
            style={{
              position: 'absolute',
              top: 0,
              left: 0,
              width: '100%',
              transform: `translateY(${virtualItem.start}px)`,
            }}
          >
            <MessageItem
              message={messages[virtualItem.index]}
              ref={(el) => virtualizer.measureElement(el)}
            />
          </div>
        ))}
      </div>
    </div>
  )
}
```

### 流式文本渲染优化（Delta Batching）

每个 token 到达时直接触发重渲染会导致高频 re-render（每秒可能 30-50 次）。改为每 50ms 合并一次更新：

```tsx
// src/hooks/useStreamingText.ts

import { useState, useRef, useCallback, useEffect } from 'react'

export function useStreamingText() {
  const [displayText, setDisplayText] = useState('')
  const bufferRef = useRef('')
  const timerRef = useRef<ReturnType<typeof setInterval> | null>(null)

  // 启动批量更新定时器
  useEffect(() => {
    timerRef.current = setInterval(() => {
      if (bufferRef.current) {
        setDisplayText(prev => prev + bufferRef.current)
        bufferRef.current = ''
      }
    }, 50) // 每 50ms 合并一次

    return () => {
      if (timerRef.current) clearInterval(timerRef.current)
    }
  }, [])

  // Token 到达时只写入 buffer，不触发重渲染
  const appendDelta = useCallback((delta: string) => {
    bufferRef.current += delta
  }, [])

  const reset = useCallback(() => {
    bufferRef.current = ''
    setDisplayText('')
  }, [])

  return { displayText, appendDelta, reset }
}
```

### 媒体内容懒加载

```tsx
// src/components/LazyImage.tsx

import React, { useRef, useState, useEffect } from 'react'

interface LazyImageProps {
  src: string
  alt: string
  className?: string
}

export function LazyImage({ src, alt, className }: LazyImageProps) {
  const ref = useRef<HTMLImageElement>(null)
  const [loaded, setLoaded] = useState(false)

  useEffect(() => {
    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting && ref.current) {
          ref.current.src = src
          observer.disconnect()
        }
      },
      { rootMargin: '200px' } // 提前 200px 开始加载
    )

    if (ref.current) observer.observe(ref.current)
    return () => observer.disconnect()
  }, [src])

  return (
    <img
      ref={ref}
      alt={alt}
      className={className}
      onLoad={() => setLoaded(true)}
      style={{ opacity: loaded ? 1 : 0, transition: 'opacity 0.2s' }}
    />
  )
}
```

### 关键索引策略

```sql
-- task_traces 按时间查询（工作区历史列表）
CREATE INDEX IF NOT EXISTS idx_task_traces_workspace_created

  ON messages (conversation_id, created_at ASC);

CREATE INDEX IF NOT EXISTS idx_skills_workspace_usage
```

### PRAGMA 优化配置

```sql
-- 启用 WAL 模式：读写不互相阻塞
PRAGMA journal_mode = WAL;

-- 同步模式：NORMAL 在 WAL 下足够安全，性能优于 FULL
PRAGMA synchronous = NORMAL;

-- 页缓存：-65536 表示 64 MB（负数为 KiB 单位）
PRAGMA cache_size = -65536;

-- 内存映射大小：256 MB
PRAGMA mmap_size = 268435456;

-- WAL 自动 checkpoint 阈值：1000 页
PRAGMA wal_autocheckpoint = 1000;
```

### 连接池配置

```rust
// 读多写少：读连接池 4 个，写连接池 1 个（避免并发写锁冲突）
```

## 内存占用控制

### AgentContext LRU 缓存

多工作区同时打开时，不为所有工作区保持 AgentContext 在内存中。使用 LRU 策略最多缓存 3 个：

```rust
// crates/agent-core/src/context/cache.rs

use lru::LruCache;
use std::num::NonZeroUsize;
use tokio::sync::RwLock;

pub struct ContextCache {
    inner: RwLock<LruCache<String, AgentContext>>,
}

impl ContextCache {
    pub fn new() -> Self {
        Self {
            inner: RwLock::new(LruCache::new(NonZeroUsize::new(3).unwrap())),
        }
    }

    pub async fn get_or_load(
        &self,
        workspace_id: &str,
        loader: impl AsyncFnOnce() -> anyhow::Result<AgentContext>,
    ) -> anyhow::Result<AgentContext> {
        // 先尝试从缓存读
        {
            let mut cache = self.inner.write().await;
            if let Some(ctx) = cache.get(workspace_id) {
                return Ok(ctx.clone());
            }
        }

        // 缓存未命中，从磁盘加载
        let ctx = loader().await?;
        {
            let mut cache = self.inner.write().await;
            // LRU 自动淘汰最久未使用的条目（释放内存）
            cache.put(workspace_id.to_string(), ctx.clone());
        }

        Ok(ctx)
    }
}
```

### 向量存储分页加载

不一次性将所有向量加载到内存，按需分页：

```rust
// crates/vector-store/src/lib.rs

pub struct VectorStore {
    db: SqlitePool,
    page_size: usize, // 默认 1000
}

impl VectorStore {
    /// 分批加载向量，每次加载 page_size 条
    pub async fn iter_vectors(
        &self,
        workspace_id: &str,
    ) -> impl Stream<Item = anyhow::Result<VectorRecord>> + '_ {
        let page_size = self.page_size as i64;
        async_stream::stream! {
            let mut offset = 0i64;
            loop {
                let batch = sqlx::query_as!(
                    VectorRecord,
                    "SELECT * FROM vectors WHERE workspace_id = ? LIMIT ? OFFSET ?",
                    workspace_id, page_size, offset
                )
                .fetch_all(&self.db)
                .await;

                match batch {
                    Ok(records) if records.is_empty() => break,
                    Ok(records) => {
                        offset += records.len() as i64;
                        for r in records { yield Ok(r); }
                    }
                    Err(e) => { yield Err(e.into()); break; }
                }
            }
        }
    }
}
```
