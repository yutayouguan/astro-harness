# 更新机制

> 阶段：系统设计 | 状态：定稿 | 说明：Tauri Updater、迁移、插件兼容

---

## 三个核心问题

```
更新机制
├── 应用更新      → 检测新版本、下载、用户确认、安装
├── 数据库迁移    → 跨版本 SQLite schema 变更
└── 插件兼容检查  → 新版本 Agent 是否兼容已安装插件
```

### 更新流程实现

```rust
// apps/desktop/src-tauri/src/commands/updater.rs

use tauri_plugin_updater::UpdaterExt;

#[command]
pub async fn check_update(app: AppHandle) -> Result<Option<UpdateInfo>, String> {
    let updater = app.updater().map_err(|e| e.to_string())?;

    match updater.check().await.map_err(|e| e.to_string())? {
        Some(update) => Ok(Some(UpdateInfo {
            version: update.version.clone(),
            notes: update.body.clone().unwrap_or_default(),
            pub_date: update.date.map(|d| d.to_string()),
        })),
        None => Ok(None),
    }
}

#[command]
pub async fn download_and_install(app: AppHandle) -> Result<(), String> {
    let updater = app.updater().map_err(|e| e.to_string())?;

    if let Some(update) = updater.check().await.map_err(|e| e.to_string())? {
        // 下载时推送进度事件给前端
        let app_clone = app.clone();
        update.download_and_install(
            |downloaded, total| {
                let progress = total.map(|t| downloaded as f32 / t as f32 * 100.0);
                app_clone.emit("update-progress", progress).ok();
            },
            || {
                app_clone.emit("update-ready", ()).ok();
            },
        )
        .await
        .map_err(|e| e.to_string())?;
    }
    Ok(())
}
```

### 前端更新提示

```typescript
// apps/desktop/src/components/shared/UpdateBanner.tsx

export function UpdateBanner() {
  const [update, setUpdate] = useState<UpdateInfo | null>(null);
  const [progress, setProgress] = useState<number | null>(null);

  useEffect(() => {
    // 启动后 30 秒检查更新，不影响启动体验
    const timer = setTimeout(async () => {
      const info = await invoke<UpdateInfo | null>("check_update");
      setUpdate(info);
    }, 30_000);

    const unlisten = listen<number>("update-progress", (e) => {
      setProgress(e.payload);
    });

    return () => { clearTimeout(timer); unlisten.then(fn => fn()); };
  }, []);

  if (!update) return null;

  return (
    <div className="update-banner">
      <span>新版本 {update.version} 可用</span>
      {progress !== null
        ? <progress value={progress} max={100} />
        : <Button onClick={() => invoke("download_and_install")}>更新</Button>
      }
    </div>
  );
}
```

## 数据库 Schema 迁移

使用 sqlx 的内置迁移系统，每次版本发布对应一个迁移文件。

### 迁移文件命名规范

```text
migrations/
├── 0001_init.sql                 # 初始建表
├── 0002_vec_tables.sql           # 向量存储
├── 0003_media_artifacts.sql      # 多媒体与 AI 产物
├── 0004_memory_versioning.sql    # 记忆版本管理
└── 0005_fts.sql                  # 全文检索索引
```

### 迁移文件示例

```sql
-- migrations/0004_memory_versioning.sql

-- 为 skills 表添加权限字段（向后兼容，有默认值）
ALTER TABLE skills ADD COLUMN permissions TEXT NOT NULL DEFAULT '[]';
ALTER TABLE skills ADD COLUMN allowed_tools TEXT NOT NULL DEFAULT '[]';

-- 为已有数据设置默认权限
UPDATE skills SET
  permissions = '["ReadFile","NetworkRead"]',
  allowed_tools = '["web_search","read_file"]'
WHERE origin = 'builtin';
```

### 自动执行迁移

```rust
// crates/agent-core/src/storage/mod.rs

impl Store {
    pub async fn open(path: &Path) -> anyhow::Result<Self> {
        let pool = SqlitePoolOptions::new()
            .connect_with(
                SqliteConnectOptions::new()
                    .filename(path)
                    .create_if_missing(true)
                    .journal_mode(SqliteJournalMode::Wal)
            )
            .await?;

        // 每次启动自动运行待执行的迁移
        sqlx::migrate!("./migrations").run(&pool).await?;

        Ok(Self { pool })
    }
}
```

### 迁移失败处理

```rust
match sqlx::migrate!("./migrations").run(&pool).await {
    Ok(_) => tracing::info!("数据库迁移完成"),
    Err(e) => {
        tracing::error!("数据库迁移失败: {e}");
        // 迁移失败时不启动应用，弹出错误提示
        // 让用户选择：重试 / 重置数据库 / 联系支持
        return Err(e.into());
    }
}
```

## 插件兼容性检查

新版本 Agent 可能修改了 WASM 接口，导致旧插件不可用。

```rust
// crates/agent-core/src/plugins/compatibility.rs

pub struct CompatibilityChecker {
    current_agent_version: semver::Version,
}

impl CompatibilityChecker {
    pub fn check(&self, plugin: &InstalledPlugin) -> CompatibilityResult {
        let min_required = semver::VersionReq::parse(
            &plugin.manifest.compatibility.min_agent_version
        ).unwrap_or(semver::VersionReq::STAR);

        if min_required.matches(&self.current_agent_version) {
            CompatibilityResult::Compatible
        } else {
            CompatibilityResult::Incompatible {
                plugin_name: plugin.manifest.name.clone(),
                required: plugin.manifest.compatibility.min_agent_version.clone(),
                current: self.current_agent_version.to_string(),
            }
        }
    }

    // 更新前检查所有已安装插件
    pub fn pre_update_check(&self, plugins: &[InstalledPlugin]) -> Vec<CompatibilityResult> {
        plugins.iter().map(|p| self.check(p)).collect()
    }
}
```

更新前在 UI 展示不兼容插件列表，让用户决定是否继续：

```
┌─────────────────────────────────────────┐
│  更新到 v0.4.0                           │
│                                         │
│  ⚠️ 以下插件与新版本不兼容：              │
│  • arxiv-researcher (需要 ≥ 0.4.0)      │
│     → 更新后将被禁用，等待作者适配        │
│                                         │
│  [取消]              [仍然更新]           │
└─────────────────────────────────────────┘
```
