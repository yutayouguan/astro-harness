# 数据备份与同步

> 阶段：系统设计 | 状态：定稿 | 说明：本地备份、E2E 加密云同步

> **当前 Harness 基线（2026-08-29）**：备份对象是 rollout 事实源、各职责数据库、Agent 配置、记忆和产物文件的集合，不是单一 `agent.db`。E2E 云同步仍属目标设计；恢复验收必须验证 rollout 重放与 Session 投影边界。

本地 SQLite 单点存储有丢失风险，需要本地备份 + 可选云同步方案。

---

## 三层保护

```
数据安全
├── 本地定时备份    → zip 压缩，保留最近 N 份，零配置
├── 可选云同步      → iCloud / OneDrive / 自建 S3，端对端加密
└── 导入/导出       → 换设备迁移，标准格式
```

## 本地定时备份

### 备份策略

```toml
# configs/agent.toml

[backup]
enabled          = true
interval         = "6h"         # 备份间隔
keep_count       = 10           # 保留最近 N 份
compress         = true         # zip 压缩
backup_dir       = ""           # 空 = 使用默认路径（AppData/backups/）
include_media    = false        # 是否包含生成的图片/音频（体积大）
```

### 备份实现

```rust
// crates/agent-core/src/backup/local.rs

pub struct LocalBackup {
    config: BackupConfig,
    db_path: PathBuf,
    backup_dir: PathBuf,
}

impl LocalBackup {
    pub async fn run(&self) -> anyhow::Result<BackupResult> {
        let timestamp = Utc::now().format("%Y%m%d_%H%M%S").to_string();
        let filename = format!("astro-agent_{timestamp}.zip");
        let dest = self.backup_dir.join(&filename);

        // SQLite WAL checkpoint（确保数据已刷盘）
        self.checkpoint().await?;

        // 压缩 db 文件
        let zip_file = std::fs::File::create(&dest)?;
        let mut zip = zip::ZipWriter::new(zip_file);

        // 备份各职责数据库（state.db、artifacts.db、knowledge.db 等）
        for db_name in &["state.db", "artifacts.db", "knowledge.db", "usage.db", "cron.db", "subagents.db"] {
            let db_path = self.sessions_dir.join(db_name);
            if db_path.exists() {
                zip.start_file(format!("sessions/{}", db_name), zip::write::SimpleFileOptions::default())?;
                let db_bytes = tokio::fs::read(&db_path).await?;
                use std::io::Write;
                zip.write_all(&db_bytes)?;
            }
        }

        if self.config.include_media {
            // 追加 media/ 目录
            self.add_media_to_zip(&mut zip).await?;
        }

        zip.finish()?;

        // 清理旧备份，只保留最近 N 份
        self.prune_old_backups().await?;

        Ok(BackupResult {
            path: dest,
            size_bytes: tokio::fs::metadata(&dest).await?.len(),
            timestamp: Utc::now(),
        })
    }

    async fn prune_old_backups(&self) -> anyhow::Result<()> {
        let mut entries: Vec<_> = tokio::fs::read_dir(&self.backup_dir)
            .await?
            .collect::<Result<Vec<_>, _>>()
            .await?;

        // 按修改时间排序，删除多余的
        entries.sort_by_key(|e| e.metadata().unwrap().modified().unwrap());
        for entry in entries.iter().rev().skip(self.config.keep_count) {
            tokio::fs::remove_file(entry.path()).await?;
        }
        Ok(())
    }
}
```

### 后台调度

```rust
// 在 Tauri 启动时注册定时备份任务
pub async fn schedule_backup(state: Arc<AppState>) {
    let interval = state.config.backup.interval;

    tokio::spawn(async move {
        let mut ticker = tokio::time::interval(interval);
        loop {
            ticker.tick().await;
            if let Err(e) = state.backup.local.run().await {
                tracing::warn!("定时备份失败: {e}");
            }
        }
    });
}
```

## 云同步（可选）

端对端加密：数据在本地加密后再上传，云端无法读取明文。

### 加密方案

```rust
// crates/agent-core/src/backup/crypto.rs

use chacha20poly1305::{XChaCha20Poly1305, Key, XNonce, aead::{Aead, KeyInit}};

pub struct BackupCrypto {
    key: [u8; 32],  // 派生自用户密码（Argon2）
}

impl BackupCrypto {
    pub fn from_password(password: &str, salt: &[u8]) -> Self {
        let key = argon2::hash_raw(password.as_bytes(), salt, &argon2::Config::default())
            .expect("argon2 failed");
        Self { key: key.try_into().unwrap() }
    }

    pub fn encrypt(&self, data: &[u8]) -> anyhow::Result<Vec<u8>> {
        let cipher = XChaCha20Poly1305::new(Key::from_slice(&self.key));
        let nonce = XNonce::from_slice(&rand::random::<[u8; 24]>());
        let mut ciphertext = cipher.encrypt(nonce, data)?;
        // 把 24 字节 nonce 前置到密文中（解密时需要）
        let mut result = nonce.to_vec();
        result.append(&mut ciphertext);
        Ok(result)
    }

    pub fn decrypt(&self, data: &[u8]) -> anyhow::Result<Vec<u8>> {
        let (nonce, ciphertext) = data.split_at(24);
        let cipher = XChaCha20Poly1305::new(Key::from_slice(&self.key));
        Ok(cipher.decrypt(XNonce::from_slice(nonce), ciphertext)?)
    }
}
```

## 导入/导出

### 导出格式

```
astro-agent-export-20260805.zip
├── manifest.json       # 版本信息、导出时间
├── sessions/           # 各职责数据库（可选加密）
│   ├── state.db        # 消息、会话、FTS5
│   ├── artifacts.db    # 文件空间索引
│   ├── knowledge.db    # 知识内容 FTS
│   └── ...             # usage.db, cron.db, subagents.db 等
├── skills/             # 自定义 Skill 文件
├── prompts/            # 自定义 Prompt 文件
└── configs/            # 配置文件（不含 API Key）
```

`manifest.json`：

```json
{
  "version": "1.0",
  "agent_version": "0.4.0",
  "exported_at": "2026-08-05T10:00:00Z",
  "includes": ["conversations", "skills", "prompts", "evolution_log"],
  "encrypted": false
}
```

### Tauri Commands

```rust
// apps/desktop/src-tauri/src/commands/backup.rs

#[command]
pub async fn export_data(
    dest_path: String,
    options: ExportOptions,
    state: State<'_, AppState>,
) -> Result<(), String> {
    state.backup.export(&dest_path, options)
        .await
        .map_err(|e| e.to_string())
}

#[command]
pub async fn import_data(
    src_path: String,
    password: Option<String>,       // 若导出时加密
    state: State<'_, AppState>,
) -> Result<ImportReport, String> {
    state.backup.import(&src_path, password.as_deref())
        .await
        .map_err(|e| e.to_string())
}

#[command]
pub async fn list_local_backups(
    state: State<'_, AppState>,
) -> Result<Vec<BackupEntry>, String> {
    state.backup.local.list()
        .await
        .map_err(|e| e.to_string())
}

#[command]
pub async fn restore_backup(
    backup_path: String,
    state: State<'_, AppState>,
) -> Result<(), String> {
    // 恢复前先备份当前数据
    state.backup.local.run().await.map_err(|e| e.to_string())?;
    state.backup.restore(&backup_path)
        .await
        .map_err(|e| e.to_string())
}
```
