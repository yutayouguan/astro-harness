# 测试策略

> **Harness 回归基线（2026-08-29）**：测试必须覆盖 Thread submission、turn/step 快照、PromptContract、Provider stream/fallback、native tools/history、approval/sandbox/hooks、rollout reconstruction/projection、V2 Agent Threads 和 gRPC/Tauri 投影。旧 `delegate_task` 用例应迁移为六个 V2 Agent Thread 工具的契约测试。

> 阶段：系统设计 | 状态：定稿 | 说明：Mock、录制回放、Eval、前端 E2E

Agent 系统的测试难度远高于普通服务——LLM 输出不确定、外部工具有副作用、进化系统可能改变被测对象本身。需要分层测试策略。

---

## 测试分层

```
测试层级（从快到慢）
├── 单元测试       → 纯逻辑，Mock LLM，毫秒级
├── 集成测试       → 真实 Provider（可录制回放），秒级
├── 录制回放测试   → CI 中使用录制响应，无网络依赖
├── 进化回归测试   → Skill/Prompt 变更后自动跑基准集
└── Eval 套件      → 衡量 Agent 整体质量，非 pass/fail
```

## 单元测试 — Mock Provider

所有 Provider trait 均可 Mock，单元测试不依赖网络：

```rust
// crates/agent-providers/src/mock/mod.rs

pub struct MockTextClient {
    responses: VecDeque<TextResponse>,
    calls: Arc<Mutex<Vec<TextRequest>>>,
}

impl MockTextClient {
    pub fn with_responses(responses: Vec<TextResponse>) -> Self {
        Self {
            responses: responses.into(),
            calls: Default::default(),
        }
    }

    pub fn call_count(&self) -> usize {
        self.calls.blocking_lock().len()
    }

    pub fn last_request(&self) -> Option<TextRequest> {
        self.calls.blocking_lock().last().cloned()
    }
}

#[async_trait]
impl TextClient for MockTextClient {
    async fn complete(&self, req: TextRequest) -> Result<TextResponse> {
        self.calls.lock().await.push(req);
        self.responses
            .pop_front()
            .ok_or_else(|| anyhow::anyhow!("MockTextClient: no more responses"))
    }

    async fn stream(&self, req: TextRequest) -> Result<BoxStream<'static, Result<TextStreamEvent>>> {
        let resp = self.complete(req).await?;
        // 把完整响应拆成 delta 事件流
        let stream = futures::stream::iter(
            resp.content.chars()
                .map(|c| Ok(TextStreamEvent::Delta { text: c.to_string() }))
                .chain(std::iter::once(Ok(TextStreamEvent::Done)))
        );
        Ok(Box::pin(stream))
    }

    fn capabilities(&self) -> TextCapabilities {
        TextCapabilities::full()
    }
}
```

工具 Mock（验证调用行为）：

```rust
pub struct SpyTool {
    name: String,
    fixed_response: Value,
    calls: Arc<Mutex<Vec<Value>>>,
}

#[async_trait]
impl Tool for SpyTool {
    fn name(&self) -> &str { &self.name }
    fn description(&self) -> &str { "spy tool" }
    fn input_schema(&self) -> Value { json!({}) }
    fn risk_level(&self) -> RiskLevel { RiskLevel::Low }
    fn required_permissions(&self) -> Vec<Permission> { vec![] }
    fn is_readonly(&self) -> bool { true }
    fn timeout_ms(&self) -> u64 { 30_000 }

    async fn execute(&self, input: ToolInput) -> Result<ToolOutput, ToolError> {
        self.calls.lock().await.push(input);
        Ok(self.fixed_response.clone())
    }
}

// 测试示例
#[tokio::test]
async fn test_agent_calls_search_tool() {
    let search = Arc::new(SpyTool::new("web_search", json!({"results": []})));
    let llm = MockTextClient::with_tool_call("web_search", json!({"query": "Rust async"}));

    let ctx = AgentContext::test_builder()
        .with_tool(search.clone())
        .with_llm(llm)
        .build();

    let _ = AgentCore::new(ctx).run("搜索 Rust 异步编程").await;

    assert_eq!(search.call_count(), 1);
    assert_eq!(search.last_input()["query"], "Rust async");
}
```

## 录制回放测试

真实 LLM 调用录制一次，CI 中回放，无网络依赖，零 API 成本。

```rust
// crates/agent-providers/src/recording/mod.rs

pub struct RecordingTextClient {
    inner: Arc<dyn TextClient>,         // 真实 client（录制模式）
    cassette: Arc<Mutex<Cassette>>,     // 录制/回放数据
    mode: RecordingMode,
}

pub enum RecordingMode {
    Record { output_path: PathBuf },
    Replay { cassette_path: PathBuf },
    Passthrough,                        // 不录制，直接转发
}

pub struct Cassette {
    pub entries: Vec<CassetteEntry>,
}

pub struct CassetteEntry {
    pub request_hash: String,           // 请求内容的 SHA256，用于匹配
    pub response: TextResponse,
    pub recorded_at: DateTime<Utc>,
}

#[async_trait]
impl TextClient for RecordingTextClient {
    async fn complete(&self, req: TextRequest) -> Result<TextResponse> {
        match self.mode {
            RecordingMode::Replay { .. } => {
                // 按请求 hash 匹配，返回录制的响应
                let hash = hash_request(&req);
                self.cassette.lock().await
                    .find(&hash)
                    .ok_or_else(|| anyhow::anyhow!("cassette: no matching entry for {hash}"))
            }
            RecordingMode::Record { ref output_path } => {
                let resp = self.inner.complete(req.clone()).await?;
                // 追加到录制文件
                self.cassette.lock().await.append(CassetteEntry {
                    request_hash: hash_request(&req),
                    response: resp.clone(),
                    recorded_at: Utc::now(),
                });
                self.save(output_path).await?;
                Ok(resp)
            }
            RecordingMode::Passthrough => self.inner.complete(req).await,
        }
    }
}
```

录制文件存放位置：

```text
tests/cassettes/
├── agent_research_task.json
├── skill_synthesis.json
└── prompt_optimizer.json
```


## 进化回归测试

每次 Skill 或 Prompt 发生进化后自动运行，防止质量退化：

```rust
// crates/agent-evals/src/regression.rs

pub struct RegressionRunner {
    baseline: HashMap<String, f32>,     // skill/prompt → baseline 分数
    store: Arc<Store>,
}

impl RegressionRunner {
    // 进化调度器在应用变更后调用此函数
    pub async fn run_after_evolution(
        &self,
        target: &str,               // skill 名或 prompt_id
        benchmark: &Benchmark,
    ) -> RegressionReport {

        let score = benchmark.evaluate(target).await;
        let baseline = self.baseline.get(target).copied().unwrap_or(0.0);

        let regression = baseline - score;

        if regression > 0.05 {      // 5% 衰退触发自动回滚
            self.store.rollback_to_previous(target).await.ok();
        }

        RegressionReport {
            target: target.to_string(),
            baseline_score: baseline,
            new_score: score,
            regression,
            rolled_back: regression > 0.05,
        }
    }
}
```

## Eval 套件

衡量 Agent 整体质量，结果是分数而非 pass/fail：

```rust
// crates/agent-evals/src/runner.rs

pub struct EvalRunner {
    provider: Arc<ProviderRegistry>,
    cases: Vec<EvalCase>,
}

pub struct EvalCase {
    pub name: String,
    pub task: String,
    pub reference_answer: Option<String>,   // 参考答案（可选）
    pub metrics: Vec<EvalMetric>,
}

pub enum EvalMetric {
    Correctness,            // LLM-as-judge 评分
    Completeness,           // 关键信息覆盖率
    Conciseness,            // 冗余度
    ToolEfficiency,         // 工具调用步数 vs 最优步数
    CostUsd,                // 绝对成本
    LatencyMs,              // 延迟
}

pub struct EvalResult {
    pub case: String,
    pub scores: HashMap<EvalMetric, f32>,   // 0.0 ~ 1.0
    pub raw_output: String,
    pub trace: TaskTrace,
}

impl EvalRunner {
    pub async fn run_all(&self) -> EvalReport {
        let results = futures::future::join_all(
            self.cases.iter().map(|c| self.run_case(c))
        ).await;

        EvalReport {
            cases: results,
            aggregate: self.aggregate(&results),
        }
    }
}
```

运行评估：

```bash
# 完整评估套件
cargo run -p agent-evals -- --all

# 单项
cargo run -p agent-evals -- --case research_quality

# 与上次对比
cargo run -p agent-evals -- --compare-baseline
```

## 测试原则

- **录制文件提交 git** — 确保 CI 与本地行为一致，无随机性
- **单元测试不调用网络** — 所有 Provider 都可 Mock，速度快、稳定
- **进化回归自动触发** — 不依赖人工发现退化，5% 衰退自动回滚
- **Eval 分数趋势比绝对值更重要** — 关注版本间的相对变化，不追求完美分数
