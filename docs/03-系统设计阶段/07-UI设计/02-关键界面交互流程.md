# Astro Agent 关键界面交互流程

> 阶段：系统设计 | 状态：定稿 | 说明：发送消息、审批、Skills、工作区切换

---

## 1. 发送消息流程

**步骤说明：**

1. **输入阶段** — 用户在底部输入框键入内容，支持 `@` 触发技能引用、`/` 触发命令补全。输入框随内容自动扩展高度，最大占屏幕 40%。
2. **发送** — 点击发送按钮或按 `Enter`（默认，可在设置中切换为 `Cmd/Ctrl+Enter`），消息气泡立即出现在对话列表顶部（乐观渲染），输入框清空并禁用，底部出现「正在思考…」指示器（三点动画）。
3. **流式 Token 渲染** — 首个 token 到达后，「正在思考」替换为逐字追加的文字气泡；代码块在检测到三个反引号时即开始渲染语法高亮框架，代码内容持续填充。
4. **工具调用卡片展开** — 模型发出工具调用信号时，气泡下方插入一张折叠卡片，标题显示工具名称与图标（如「读取文件 · src/main.rs」），默认收起；用户可点击展开查看完整参数 JSON。工具执行期间卡片左侧显示旋转进度环；执行完成后进度环变为绿色对勾，卡片摘要行显示返回结果的前 80 字。
5. **完成** — 所有 token 与工具调用结束，底部指示器消失，发送按钮重新启用；对话顶部状态栏更新本轮 Token 用量与累计成本。

---

## 2. 人工介入审批流程

当工具被标记为高风险（如执行 Shell 命令、删除文件、写入生产配置）时触发审批弹窗：

- **弹窗结构**：半透明深色遮罩覆盖全屏，中央卡片分三区：① 风险等级徽章（红/橙/黄）+ 工具名称；② 完整参数展示（可滚动代码块）；③ 操作按钮行：「允许一次」「永久允许此工具」「拒绝」。
- **键盘支持**：`Y` 允许、`N` 拒绝、`Esc` 等同拒绝。
- **拒绝后**：弹窗关闭，对话流继续，工具调用卡片标记为「已拒绝」（红色叉号），模型收到拒绝通知后可选择替代方案。
- **永久允许**：将该工具加入当前工作区的白名单，后续同类调用静默通过，可在设置页撤销。

## 3. Skills 浏览器界面

通过顶部导航栏「Skills」图标或 `/skills` 命令进入：

- **搜索栏**：页面顶部全宽搜索框，支持关键词和标签过滤；右侧下拉菜单选择分类（内置 / 用户自定义 / 项目级）。
- **卡片列表**：每张卡片显示技能名、一行描述、触发关键词标签、最近使用时间。鼠标悬停卡片右侧出现「运行」按钮（三角形图标）。
- **详情面板**：点击卡片展开右侧抽屉，显示完整说明、参数列表（可选填写）、使用示例与历史调用记录。
- **手动触发**：在详情面板填写参数后点击「立即运行」，技能以当前对话上下文注入，返回结果插入到对话列表末尾，与普通消息外观一致但顶部带「Skill 输出」标签。

---

## 4. 工作区切换流程

- **入口**：左侧边栏顶部工作区选择器（显示当前工作区名称 + 箭头图标）。
- **切换确认**：点击后弹出工作区列表；选择不同工作区时，若当前工作区存在进行中的任务，弹出二次确认对话框：「当前任务将暂停，是否继续？」，提供「暂停并切换」「取消」两个选项。
- **切换动画**：确认后整个对话区域执行淡出（200 ms），左侧边栏工作区名称更新，对话区淡入新工作区的历史记录（200 ms）。
- **数据隔离提示**：切换完成后，顶部出现一条持续 3 秒的横幅提示：「已切换至「[工作区名]」，记忆与预算独立计算」，随后自动消失。

---

## 5. 记忆管理界面

通过侧边栏「记忆」图标或 `/memory` 命令进入：

- **列表视图**：按时间倒序排列记忆条目，每条显示内容摘要（前 60 字）、来源对话链接、创建时间。
- **编辑**：点击条目右侧铅笔图标，摘要行变为可编辑文本框，支持富文本；编辑完成按 `Enter` 或点击「保存」，条目顶部出现「已更新」绿色标签（2 秒后消失）。
- **删除**：点击条目右侧垃圾桶图标，出现行内确认提示「确认删除？」+「删除」红色按钮，避免误触；删除后条目向上滑出消失（150 ms 过渡动画）。
- **批量操作**：列表左上角「全选」复选框，选中多条后底部浮出操作栏，提供「批量删除」和「导出为 Markdown」。

---

## 6. 成本超支告警交互

当累计成本触达预算阈值（默认 80% 时预警、100% 时阻断）：

- **预警（80%）**：顶部状态栏预算数字变为橙色，轻微抖动一次，悬停显示「已用 $X / 预算 $Y」。
- **阻断弹窗（100%）**：全屏遮罩弹窗，中央显示当前用量与预算对比柱状图；操作区提供三个选项：「暂停任务」（推荐，按钮高亮）、「提高预算 +$10」（快捷调整）、「进入预算设置」（跳转详情页）。选择暂停后，正在进行的流式响应停止，对话列表末尾插入系统通知卡片「任务已因预算超支暂停」。选择提高预算后弹窗关闭，任务自动恢复，状态栏重置进度。

---

## 7. /personality 命令的 UI 反馈

用户在输入框键入 `/personality` 后：

1. **补全提示**：输入框上方浮出命令面板，显示「/personality — 切换 Agent 人格风格」及可用参数列表（如 `concise` `verbose` `formal` `casual`）。
2. **执行反馈**：发送后，对话列表插入一条系统卡片（区别于普通消息，灰色背景 + 斜体文字）：「人格已切换为「Concise」，后续回复将更简洁」。
3. **持久标识**：左侧边栏工作区名称下方出现小标签（如「Concise 模式」），提醒用户当前人格状态；再次执行 `/personality default` 标签消失。
