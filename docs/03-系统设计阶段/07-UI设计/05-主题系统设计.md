# 主题系统设计

> 文档状态：定稿 | 阶段：系统设计 | 设计风格：Glassmorphism 玻璃拟态

---

## 一、设计概述

Astro Agent 采用 **Glassmorphism（玻璃拟态）** 视觉风格，核心特征为半透明磨砂背景、微妙边框光、渐变或图片底色。主题系统支持三个正交维度的切换：

| 维度 | 选项 | 影响范围 |
| ---- | ---- | ---- |
| **外观主题** | 亮色 / 暗色 / 自动 | 全局色调、对比度、磨砂底色 |
| **背景来源** | 氛围配色 / 图片壁纸 | Shell 最底层使用渐变或用户图片 |
| **色彩风格** | 多彩 / 统一 / 灵动 | Shell 渐变底色、侧边栏 Tab 切换时的背景变化 |

三个维度相互独立。选择图片壁纸后，色彩风格仍负责强调色与原生窗口 underlay，壁纸覆盖 Shell 的可见渐变底层；切回氛围配色时立即恢复原有多彩 / 统一 / 灵动行为。

### 2.3 自动模式（Auto）

跟随系统外观设置，通过 `prefers-color-scheme` 媒体查询 + Tauri 系统主题检测双通道实现：

```typescript
// 系统主题检测（Tauri + CSS 双通道）
function detectSystemTheme(): 'light' | 'dark' {
  // 优先使用 Tauri API
  if (window.__TAURI__) {
    return window.__TAURI__.window.theme() === 'dark' ? 'dark' : 'light';
  }
  // 降级到 CSS 媒体查询
  return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
}

// 监听系统主题变化
window.matchMedia('(prefers-color-scheme: dark)')
  .addEventListener('change', (e) => {
    if (themeStore.mode === 'auto') {
      applyTheme(e.matches ? 'dark' : 'light');
    }
  });
```

## 三、色彩风格（Colorful / Unified / Dynamic）

色彩风格控制的是 **Shell 渐变底色** — 即整个应用窗口最底层的背景渐变。所有玻璃面板（侧边栏、对话区、设置页）都浮在这层渐变之上，通过磨砂半透明效果透出底色。

### 3.3 灵动模式（Dynamic）

每个页面独特配色，但刷新后保持不变（基于页面 ID 确定性生成）。

```typescript
// 基于页面标识生成确定性渐变（同一页面永远相同颜色）
function generateDynamicGradient(pageId: string, theme: 'light' | 'dark'): string {
  // 使用 pageId 的 hash 作为色相种子
  const hue = hashToHue(pageId);  // 0-360
  
  if (theme === 'light') {
    return `linear-gradient(135deg, 
      hsl(${hue}, 30%, 92%) 0%, 
      hsl(${hue + 15}, 25%, 88%) 50%, 
      hsl(${hue - 10}, 28%, 94%) 100%)`;
  } else {
    return `linear-gradient(135deg, 
      hsl(${hue}, 40%, 8%) 0%, 
      hsl(${hue + 15}, 35%, 12%) 50%, 
      hsl(${hue - 10}, 38%, 6%) 100%)`;
  }
}

function hashToHue(str: string): number {
  let hash = 0;
  for (const char of str) {
    hash = ((hash << 5) - hash) + char.charCodeAt(0);
    hash |= 0;
  }
  return Math.abs(hash) % 360;
}
```

### 3.4 图片壁纸（Wallpaper）

图片壁纸是 Shell 的独立背景来源，不扩充 `ShellColorStyle` 枚举。这样上传/生成图片、界面强调色和渐变回退不会互相耦合。

```text
设置 → 外观 → 全局背景
  ├─ 氛围配色：显示既有 Shell 渐变
  └─ 图片壁纸
      ├─ 上传图片 → 解码校验 → 复制到 ~/.astro/ui/wallpapers/
      └─ AI 生成 → 复用独立图片 Provider → 原子落盘 → 成功后应用
```

约束：

- 上传仅接受 PNG / JPEG / WebP，文件不超过 25 MB，最大边不超过 16384 px，解码内存上限 128 MB。
- 导入或生成时计算 64×64 缩略图的平均/中位感知亮度；外观主题为“自动”时优先采用壁纸建议的亮色或暗色，显式亮色/暗色始终尊重用户选择。旧壁纸首次加载时补做一次受限分析。
- “主题色跟随壁纸”默认开启：过滤近黑、近白与低饱和像素后按色块面积和饱和度选取主辅强调色，并校正到当前亮暗主题的安全明度；关闭后恢复用户原有的多彩 / 统一 / 灵动配色。
- 不持久化用户选择的外部原路径；图片校验通过后复制到 Astro 自有目录，并以 UUID 文件名保存。
- AI 生成复用 `active_image_provider_id` 与现有主备图片 Provider，不复制 API Key 到壁纸配置。
- 生成或导入完成前继续显示当前壁纸；失败时不替换，避免出现空白 Shell。
- 壁纸偏好保存填充方式、内容保护、柔化强度、当前资产与最近使用项；图片文件不可用时回退氛围配色。
- 聊天页右下角的小风车在壁纸模式下轮换最近壁纸；不足两张时进入外观设置。壁纸层不得覆盖原生标题栏拖拽区或侧栏折叠按钮。
- 终端 Dock 在壁纸模式下使用独立材质：Dock 自身提供厚玻璃，xterm 内容画布保持透明并以四角直角贴合 Dock，避免重复叠加浅色背景；降低透明度或高对比度模式才切换为实色。
- 终端 Dock 的显隐采用单一 `flex-basis` 曲线与向下位移，打开时从窗口底部抽出、关闭时原路收回；不同时动画 `height` / `min-height` / `max-height`，避免布局跳变。
- 窗口骨架层级使用 `primitive.css` 的语义 elevation token：壁纸、侧栏、拖拽区、标题栏与窗口控件保持固定关系，普通内容不得创建额外 stacking context；菜单、Popover、Dialog 才通过 `useDynamicOverlayLayer` 从 `1200` 基线动态置顶。
- `prefers-reduced-transparency` 与 `prefers-contrast` 下提高遮罩强度，优先保证内容可读。

### 3.5 AI 壁纸与主题链路

```text
用户自然语言请求
  → 内置 ui-style-designer Skill
  → image_gen（需要新壁纸时）
  → ui_style（status / apply / rollback / reset）
  → 校验图片、路径与颜色 token 白名单
  → ~/.astro/ui/style/themes/<id>/ + active.json
  → ui-style-changed 桌面事件
  → React 立即重读，应用壁纸、亮暗 token 与全局图标偏好
```

- `ui_style` 为 Deferred 工具，加载 `ui-style-designer` 后通过 `astro_tools` 按需开放；同时在“工具与技能”页中可见、可禁用。
- 主题不接受任意 CSS/JavaScript；清单只能覆盖受控语义颜色 token、壁纸展示参数与图标动效/线宽。
- 壁纸必须位于当前工作区或 Astro 受控目录，解码验证后复制到主题包；清单仅保存受控相对路径。
- 每次应用会将上一份有效清单存入 `history/`；`rollback` 恢复最近一版，`reset` 取消 AI 样式并回到手动/系统外观。
- Desktop 启动时主动读取当前清单，Agent 工具写入后通过进程内事件即时刷新，可见时轮询只作为外部改写的兜底。

### 3.6 全局沉浸光感材质

Astro 的玻璃系统以沉浸光感为主、少量清晰边缘为辅，不再采用固定蓝紫色或高折射 Apple 式配方：

- `--glass-intensity` 是唯一的 0–1 强度源；设置页以 0–100 连续滑块编辑，默认值为 64（均衡）。
- `immersive-light.css` 是唯一材质配方，直接映射通用 `--glass-*` 与各组件 surface token；旧 Liquid Glass 配方和中间映射层已删除。
- 环境主色优先取 `--wallpaper-tone` / `--wallpaper-accent-2`，否则取统一配色或当前 Tab 的 `--tone`；材质只混入低比例环境色，禁止固定偏紫。
- 普通内容卡片只有稳定通透填充、柔和边缘和低强度环境光；气态光场与极弱粒子只位于 Shell 背景，避免多层动态玻璃造成噪声。
- 顶层菜单与浮层使用同一算法的较厚平面，不创建第二套材质；功能色只用于图标、状态、选中和 hover。
- `prefers-reduced-motion` 停止粒子变化；`prefers-reduced-transparency` 与 `prefers-contrast` 移除光场和模糊，回退到实色语义表面。

## 四、侧边栏 Tab 切换与 Shell 渐变联动

### 4.1 交互流程

```text
用户点击侧边栏 Tab（如从 Chat 切换到 Knowledge）
    │
    ├─ 背景来源 = 图片壁纸
    │   └─ 壁纸保持不变；色彩风格仅继续驱动强调色与原生窗口底色
    │
    ├─ 色彩风格 = 多彩
    │   └─ Shell 背景渐变从 chat 色谱过渡到 knowledge 色谱（600ms）
    │
    ├─ 色彩风格 = 统一
    │   └─ Shell 背景不变（保持用户选择的固定渐变）
    │
    └─ 色彩风格 = 灵动
        └─ Shell 背景渐变到 knowledge 页面的确定性色谱（600ms）
```

### 4.2 实现架构

```typescript
// ThemeProvider.tsx — 顶层主题上下文
interface ThemeState {
  mode: 'light' | 'dark' | 'auto';
  colorStyle: 'colorful' | 'unified' | 'dynamic';
  unifiedPreset: string;       // 统一模式下的预设名或自定义渐变
  activeTab: string;           // 当前活跃的侧边栏 Tab
}

interface WallpaperPreferences {
  mode: 'color' | 'wallpaper';
  current: WallpaperAsset | null;
  recent: WallpaperAsset[];   // 最多 6 项
  fit: 'cover' | 'contain' | 'stretch';
  shade: number;              // 0–55
  blur: number;               // 0–12
}

const ThemeContext = createContext<ThemeState & ThemeActions>(null!);

function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [state, setState] = useState<ThemeState>(() => loadFromStorage());
  
  // 计算当前应该使用的 Shell 渐变
  const shellGradient = useMemo(() => {
    const resolvedMode = state.mode === 'auto' ? detectSystemTheme() : state.mode;
    
    switch (state.colorStyle) {
      case 'colorful':
        return TAB_GRADIENTS[resolvedMode][state.activeTab] ?? TAB_GRADIENTS[resolvedMode].chat;
      case 'unified':
        return state.unifiedPreset;
      case 'dynamic':
        return generateDynamicGradient(state.activeTab, resolvedMode);
    }
  }, [state.mode, state.colorStyle, state.activeTab, state.unifiedPreset]);
  
  // 应用到 DOM
  useEffect(() => {
    document.documentElement.style.setProperty('--shell-bg', shellGradient);
    document.documentElement.dataset.theme = 
      state.mode === 'auto' ? detectSystemTheme() : state.mode;
  }, [shellGradient, state.mode]);
  
  return (
    <ThemeContext.Provider value={{ ...state, setMode, setColorStyle, setActiveTab }}>
      {children}
    </ThemeContext.Provider>
  );
}
```

### 6.2 主题切换过渡（亮↔暗）

亮暗切换时，使用 View Transitions API（Chromium 111+）实现圆形扩散效果；不支持时降级为 200ms 淡入淡出。

```typescript
async function toggleTheme(newMode: 'light' | 'dark') {
  if (!document.startViewTransition) {
    // 降级：直接切换
    document.documentElement.dataset.theme = newMode;
    return;
  }
  
  const transition = document.startViewTransition(() => {
    document.documentElement.dataset.theme = newMode;
  });
  
  await transition.ready;
  
  // 从点击位置扩散
  document.documentElement.animate(
    { clipPath: [`circle(0px at center)`, `circle(150vmax at center)`] },
    { duration: 500, easing: 'ease-in-out', pseudoElement: '::view-transition-new(root)' }
  );
}
```

## 八、数据持久化

```typescript
// localStorage 存储
interface ThemePreferences {
  mode: 'light' | 'dark' | 'auto';
  colorStyle: 'colorful' | 'unified' | 'dynamic';
  unifiedGradient: string;     // CSS gradient 字符串
  customGradients: Record<string, string>;  // 用户自定义渐变
}

// 外观主题：'astro-theme-mode'
// 玻璃强度：'astro-glass-intensity'（0–100，默认 64）

// 壁纸视觉偏好：'astro-wallpaper-prefs.v1'
```

## 九、Tauri 窗口集成

### 9.1 标题栏适配

Tauri v2 自定义标题栏需与当前主题匹配：

```rust
// src-tauri/src/window.rs
fn update_title_bar_theme(window: &WebviewWindow, is_dark: bool) {
    #[cfg(target_os = "macos")]
    {
        use tauri::TitleBarStyle;
        window.set_title_bar_style(TitleBarStyle::Overlay).ok();
        // macOS 标题栏自动适配系统主题
    }
    
    #[cfg(target_os = "windows")]
    {
        // Windows: 通过 DWM 设置暗色标题栏
        use windows::Win32::Graphics::Dwm::*;
        let value = if is_dark { 1i32 } else { 0i32 };
        unsafe {
            DwmSetWindowAttribute(
                window.hwnd().unwrap(),
                DWMWA_USE_IMMERSIVE_DARK_MODE,
                &value as *const _ as _,
                std::mem::size_of_val(&value) as u32,
            );
        }
    }
}
```

### 9.2 系统托盘图标

亮色模式使用深色图标，暗色模式使用亮色图标：

```rust
fn update_tray_icon(tray: &SystemTray, is_dark: bool) {

}
```

## 十、性能考虑

| 项目 | 策略 |
| ---- | ---- |
| `backdrop-filter: blur()` | GPU 加速，但嵌套超过 3 层时性能下降。限制嵌套深度 |
| Shell 渐变过渡 | 使用 `will-change: background` 提示浏览器预分配 GPU 层 |
| 主题切换 | CSS 变量切换是零成本的（浏览器增量重绘），不触发全局重排 |
| View Transitions | 仅在手动切换亮暗时使用，Tab 切换用 CSS transition |
| 低端设备检测 | `navigator.hardwareConcurrency <= 2` 时自动关闭 blur 效果 |

```css
/* 低性能模式：关闭磨砂效果，使用纯色半透明 */
[data-perf="low"] .glass-panel {
  backdrop-filter: none;
  -webkit-backdrop-filter: none;
  background: var(--surface-0);  /* 不透明回退 */
}
```
