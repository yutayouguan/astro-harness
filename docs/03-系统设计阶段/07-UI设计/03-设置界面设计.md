# 设置界面设计文档

> 阶段：系统设计 | 状态：定稿 | 说明：Provider/预算/MCP/隐私配置

## 一、整体结构

设置页从主侧栏第 5 个导航项进入，采用左侧分组 icon 列表 + 右侧内容区的双栏布局。左栏宽 200px，按任务语义分为 4 组（basics / intelligence / extensions / system），每项带自定义 icon，选中项高亮（主题色 12% 背景），右侧自适应纵向滚动。

```
┌──────────────────────────────────────────────────────────┐
│  ⚙ 设置                                                 │
├──────────────┬───────────────────────────────────────────┤
│ ── 基础 ──   │                                           │
│ ⚙ 通用       │         右侧内容区（纵向滚动）              │
│ ✨ 外观      │                                           │
│ 💬 对话      │         当前选中项的设置面板                │
│ 🖥 终端       │                                           │
│ ── 智能 ──   │                                           │
│ 📚 上下文    │                                           │
│ 🔌 Provider  │                                           │
│ 🔧 工具      │                                           │
│ 🧠 记忆      │                                           │
│ ── 扩展 ──   │                                           │
│ 🌐 浏览器    │                                           │
│ 🏪 模型市场  │                                           │
│ 📊 洞察      │                                           │
│ ── 系统 ──   │                                           │
│ 📦 环境依赖  │                                           │
│ 📜 诊断      │                                           │
│ ℹ 关于       │                                           │
└──────────────┴───────────────────────────────────────────┘
```

左侧条目点击高亮，右侧内容区即时切换，无跳页。通用/外观/对话/上下文/诊断/关于 路由到 `PreferencesPanel` 的对应 section（`SettingsTabId` 前缀 `preferences:xxx`），其余路由到独立面板组件。另有 `evolution` tab 不在侧栏平铺列表中，仅可由跳转进入。定义在 `apps/desktop/src/lib/ui/settingsTabs.ts`。

### Tab 显示规则

| Tab | 显示条件 | 包含模型类型 |
| ---- | ---- | ---- |
| 对话模型 | 始终显示 | LLM 文本生成模型 |
| 多媒体模型 | Provider 支持图像/音频/视频生成或识别时显示 | 图像生成、图像识别、TTS、ASR、视频生成 |
| 嵌入模型 | Provider 支持 Embedding 时显示 | 向量嵌入模型（用于知识库） |
| 辅助模型 | 始终显示 | 重排序模型、分类模型、摘要专用轻量模型 |

### 各 Tab 内部布局

```
─── [当前 Tab 名称] ─────────────────────────── [刷新 ↺] ──
 模型列表（动态拉取，按子类型分组）
  子类型标签（图像生成 / TTS / ASR / …）
   ● model-name-a     ← 默认（点击单选设为该子类型默认）
   ○ model-name-b
   ○ model-name-c
```

- 每个子类型（对话 / 图像生成 / TTS / ASR / 嵌入 / 重排序等）分别维护一个默认模型，标注「← 默认」。
- 点击任意模型旁的单选按钮即将其设为该子类型的默认，立即保存。
- 模型列表由 API 动态拉取（`GET /v1/models`），支持手动刷新，离线时展示上次缓存列表。
- "测试连接"按钮发送最小 ping 请求，实时显示延迟与连接状态。
