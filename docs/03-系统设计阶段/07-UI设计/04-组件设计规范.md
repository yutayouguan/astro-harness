## 4. 布局组件

- **Sidebar**：可折叠（`collapsed` 态宽 56px，展开 240px），含 `WorkspaceItem` 列表与底部用户栏，过渡 200ms ease-out。
- **SplitPane**：水平/垂直分割，拖拽调整比例，`minSize`/`maxSize` 约束，记忆用户偏好至 localStorage。
- **CommandPalette**：⌘K 唤起，模糊搜索命令列表，键盘上下选中，Enter 执行，Esc 关闭，role="dialog" + aria-modal。
- **Modal**：焦点陷阱（focus-trap-react），Esc 关闭，背景点击可选关闭，动画 scale(0.95)→scale(1) 150ms。
- **Drawer**：从右/下滑入，`size` 支持 sm/md/lg/full，带遮罩层，支持嵌套堆叠。

## 5. 主题系统

所有设计 Token 挂载在 `:root` 与 `[data-theme="dark"]` 选择器上：

```css
:root { --bg-base: #ffffff; --text-primary: #0f172a; }
[data-theme="dark"] { --bg-base: #0f172a; --text-primary: #f8fafc; }
```

主题切换实现：`ThemeProvider` 通过 `document.documentElement.dataset.theme` 写入，配合 `prefers-color-scheme` 媒体查询设置默认值，状态持久化至 localStorage。组件内**只引用 CSS 变量**，禁止硬编码颜色值。

## 6. 动画规范

```ts
const duration = { instant: '80ms', fast: '150ms', base: '200ms', slow: '300ms', lazy: '500ms' };
const easing = {
  standard: 'cubic-bezier(0.4, 0, 0.2, 1)',   // 通用入出场
  decelerate: 'cubic-bezier(0, 0, 0.2, 1)',    // 元素入场
  accelerate: 'cubic-bezier(0.4, 0, 1, 1)',    // 元素退场
};
```

**流式 Token 打字动画**：消息内容通过 `ReadableStream` 逐字符追加，光标使用 CSS `@keyframes blink` 闪烁（500ms 周期），流式结束后光标淡出（opacity 0，200ms）。避免使用 `setInterval` 模拟，以实际 stream 事件驱动渲染。

## 7. 可访问性要求

- **ARIA 标签**：所有图标按钮必须提供 `aria-label`；状态变化区域（消息列表、CostBar）添加 `aria-live="polite"`；对话框使用 `role="dialog"` + `aria-labelledby`。
- **键盘导航**：所有交互元素可 Tab 聚焦，顺序符合视觉阅读顺序；CommandPalette、Modal、Drawer 实现焦点陷阱，关闭后焦点回归触发元素。
- **对比度标准**：正文文字对比度 ≥ 4.5:1（WCAG AA），大号标题 ≥ 3:1，禁止用纯色差传达信息（须配合图标或文字）。
- **减少动效**：检测 `prefers-reduced-motion`，命中时将所有过渡缩短至 `instant` 级别或直接跳过。
