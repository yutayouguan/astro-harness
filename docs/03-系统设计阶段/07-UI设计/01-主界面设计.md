## 二、左侧边栏

**工作区列表**（顶部固定区，h: 120px）：显示最近 3 个工作区图标 + 名称，当前选中高亮，右键可重命名/删除。底部有"+ 新建工作区"链接。

**对话历史**（中部滚动区，flex: 1）：按日期分组（今天 / 昨天 / 更早），每条显示首句摘要（最多 2 行），悬停显示删除图标。点击切换对话，当前对话左侧显示蓝色竖条指示。

**底部固定操作区**（h: 88px）：
- `[＋ 新建对话]` 主按钮，全宽，填充色
- `[⚙ 设置]` 次级按钮，镂空样式，图标在左

---

## 三、主对话区

**消息气泡**：用户消息右对齐，圆角矩形背景（主题色 10% 透明度），AI 消息左对齐无背景、宽度限 680px。每条消息底部显示时间戳和复制按钮（悬停出现）。

**流式输入动画**：最后一个字符后跟随闪烁光标 `▌`，打字机逐字渲染，动画帧率 60fps，避免布局抖动（预分配最小高度）。

**工具调用展示卡片**：内联于消息流中，折叠态显示工具名称 + 状态徽章（运行中 / 成功 / 失败），展开后显示输入参数（JSON 高亮）和输出结果，边框左侧有彩色竖条区分工具类型（文件操作=蓝，网络=橙，代码执行=紫）。

**代码块**：深色背景面板，顶部工具栏显示语言标签 + 复制按钮 + 运行按钮（可执行语言），内容使用等宽字体 `JetBrains Mono` 14px，超长行横向滚动不折行。

**输入框**：多行自动扩展（最大 6 行），支持 Shift+Enter 换行，Enter 发送，左侧附件按钮（图片/文件），右侧发送按钮在有内容时点亮。

---

## 四、右侧面板

顶部 `[◀ 收起]` 按钮，收起后变为浮动 `[▶]` 标签贴边，主区平滑过渡填充。

面板内从上至下分四个可折叠区块：

| 区块 | 默认状态 | 内容 |
|---|---|---|
| Agent 状态 | 展开 | 状态灯（空闲/思考/执行）+ 当前任务描述 |
| 思考过程 | 折叠 | `<thinking>` 内容流式展示，字体缩小为 13px 灰色 |
| 工具调用详情 | 展开 | 调用时间线，最近 5 条，可点击跳转到对话中对应位置 |
| Token 用量 | 展开 | 本次对话：输入/输出 Token 数，累计费用，进度条显示上下文窗口占用率 |

---

## 五、顶部栏

从左至右依次排列：
- **模型下拉**：当前模型名称 + `▾`，展开显示可用模型分组（Claude 4 / Claude 3.x），选中后即时切换
- **工作区名称**（居中）：可直接点击编辑，灰色细字
- **成本提示**（右侧）：显示当日累计费用，超过阈值变为橙色警告
- **主题切换**：☀/☾ 图标按钮，点击切换，无需重启
- **全局设置**：⚙ 图标，打开设置抽屉覆盖于界面上方

---

## 六、响应式收缩策略

| 窗口宽度 | 行为 |
|---|---|
| > 1200px | 三栏全展开，默认布局 |
| 900–1200px | 右侧面板自动折叠，可手动展开（悬浮于主区上方） |
| 600–900px | 左侧边栏折叠为图标栏（w: 56px），仅显示图标 |
| < 600px | 单栏模式：顶部标签栏切换"对话/历史/面板"，侧栏完全隐藏 |

| `--text-primary` | `#111827` | `#F2F2F7` | 主要文字 |
| `--text-secondary` | `#6B7280` | `#8E8E93` | 次要文字/时间戳 |
