## 二、左侧导航栏

**5 项主导航**（图标 + 文字，可收起为纯图标模式）：

| 导航项 | NavId | 图标 | 色调 |
|---|---|---|---|
| 对话 | `chat` | IconChat | blue |
| 定时 | `cron` | IconCron | cyan |
| 任务 | `loop` | IconLoop | pink |
| 扩展 | `skills` | IconPlugin | indigo |
| 设置 | `settings` | IconSettings | twilight |

导航切换动画：共享高亮指示器沿 Y 轴平滑滑动（220ms ease）。

**标题栏**：侧栏收起/展开按钮位于 macOS 交通灯右侧。

---

## 三、主对话区

**消息气泡**：用户消息右对齐，圆角矩形背景（主题色 10% 透明度），AI 消息左对齐无背景、宽度限 680px。每条消息底部显示时间戳和复制按钮（悬停出现）。

**流式输入动画**：最后一个字符后跟随闪烁光标 `▌`，打字机逐字渲染，动画帧率 60fps，避免布局抖动（预分配最小高度）。

**工具调用展示卡片**：内联于消息流中，折叠态显示工具名称 + 状态徽章（运行中 / 成功 / 失败），展开后显示输入参数（JSON 高亮）和输出结果，边框左侧有彩色竖条区分工具类型（文件操作=蓝，网络=橙，代码执行=紫）。

**代码块**：深色背景面板，顶部工具栏显示语言标签 + 复制按钮 + 运行按钮（可执行语言），内容使用等宽字体 `JetBrains Mono` 14px，超长行横向滚动不折行。

**输入框**：多行自动扩展（最大 6 行），支持 Shift+Enter 换行，Enter 发送，左侧附件按钮（图片/文件），右侧发送按钮在有内容时点亮。

## 四、右侧面板（ChatRightPanel）

3 个 tab 页签切换，关闭按钮在右上角：

| Tab | 图标 | 内容 |
|---|---|---|
| 总览 `summary` | LayoutDashboard | `ChatAgentInfo`（Agent 信息、上下文用量摘要）+ `SubagentActivityBar`（子 Agent 活动条）+ `TaskMonitorPanel`（任务监控、Todo 计划进度）；展开子 Agent 时显示 `SubagentsPanel` |
| 上下文 `context` | Layers | `ContextExplorer`（分层上下文占用可视化、token 计数）+ `ChatAgentInfo`（上下文模式） |
| 分支 `branches` | GitBranch | `BranchGraphPanel`（对话分支图，支持跳转/侧边打开/回填输入） |

---

## 五、顶部栏

从左至右依次排列：
- **模型下拉**：当前模型名称 + `▾`，展开显示可用模型分组（Claude 4 / Claude 3.x），选中后即时切换
- **工作区名称**（居中）：可直接点击编辑，灰色细字
- **成本提示**（右侧）：显示当日累计费用，超过阈值变为橙色警告
- **主题切换**：☀/☾ 图标按钮，点击切换，无需重启
- **全局设置**：⚙ 图标，打开设置抽屉覆盖于界面上方

## 六、响应式收缩策略

| 窗口宽度 | 行为 |
|---|---|
| > 1200px | 三栏全展开，默认布局 |
| 900–1200px | 右侧面板自动折叠，可手动展开（悬浮于主区上方） |
| 600–900px | 左侧边栏折叠为图标栏（w: 56px），仅显示图标 |
| < 600px | 单栏模式：顶部标签栏切换"对话/历史/面板"，侧栏完全隐藏 |
