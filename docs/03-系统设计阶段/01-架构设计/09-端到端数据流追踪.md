# 端到端数据流追踪

> **历史追踪图（2026-09-01，已过时）**：本文的大型逐步时序图保留用于需求追溯，其中 `AgentExecutor`、`HookPipeline`、`delegate_task`、`Supervisor`、`round_loop`、旧 8-slot prompt、`ProviderRouter`、`ToolDispatcher`、Chat 协议与 message-table 恢复均不是当前实现。当前架构使用 `AstroThread` → `Session::submission_loop` → `SessionTask::run_turn` → `EventMsg` → rollout JSONL → Core event queue → Server → clients 单一事件链。工具路由使用 `ToolRouter`，子 Agent 使用 Codex V2 Agent Threads（6 个模型工具），ToolExposure 五级暴露。现行端到端主链见 [Agent Harness 总体架构](11-Agent-Harness总体架构.md) 和 [Responses 原生 Agent 运行时架构](12-Responses原生Agent运行时架构.md)；不得用本文旧伪代码指导修改。

## 1. 概述

本文档是 Astro Agent 系统的"罗塞塔石碑"——它将分散在各详细设计文档中的模块设计串联为可追踪的端到端数据流。每个场景从用户操作出发，逐层穿透前端、Tauri Command、agent-runtime、agent-core、agent-providers 直至外部 API，标注每一步涉及的 **struct 名称、方法签名、源文件路径**，并用 ⚡ 标记 Hook 注入点。

### 覆盖场景

| 序号 | 场景 | 核心路径（当前实现） |
|------|------|----------|
| 1 | 核心对话流 | AstroThread::submit → submission_loop → SessionTask::run_turn → ProviderStreamer → EventMsg → rollout → clients |
| 2 | 工具执行流 | ResponseItem function_call → ToolRouter → StepContext 校验 → approval + sandbox + hooks → 执行 → matching output item |
| 3 | 记忆与上下文注入流 | PromptContract 组装 → MemoryManager 检索 → maintain_tool_context() 三阶段压缩 |
| 4 | 子 Agent 派生流 | spawn_agent → AgentControl → AgentGraphStore → 子 AstroThread → wait_agent/send_message 结果回传 |
| 5 | Skill 触发与执行流 | Skill soft-alias → skills(action=load) → BM25 召回 → SKILL.md 加载 → 上下文注入 |
| 6 | 工作流执行流 | 触发器 → DAG 拓扑排序 → 节点并行执行 → 检查点 |
| 7 | 错误传播流 | 工具错误 → 分类 → Provider Fallback 链 → EventMsg 错误事件 → 前端呈现 |

```rust
// ===== 前端 → Tauri =====
// React: src/components/InputBar.tsx
let conv_id = await invoke("send_message", { payload });

// ===== Tauri Command 层 =====
// apps/desktop/src-tauri/src/commands/message.rs
#[tauri::command]
async fn send_message(app: AppHandle, state: State<'_, AppState>, payload: SendMessagePayload)
    -> Result<String, AppError>
{
    let conv_id = payload.conversation_id.clone();
    let session_manager = state.session_manager.clone(); // Arc<AgentSessionManager>

    tokio::spawn(async move {
        // [2] 获取或创建 AgentInstance
        let instance = session_manager.get_by_workspace(&payload.workspace_id).await;
        let (event_tx, mut event_rx) = mpsc::channel::<AgentEvent>(128);

        // [3] 状态转移: Ready → Running
        instance.start_turn(conv_id.clone(), payload.message).await;

        // [4] 启动主执行循环
        let executor = AgentExecutor::new(instance.session.clone(), event_tx);
        tokio::spawn(async move { executor.round_loop(payload.message).await });

        // [10] 事件桥接: AgentEvent → Tauri Event → React
        while let Some(event) = event_rx.recv().await {
            match event {
                AgentEvent::TokenChunk(delta) =>
                    app.emit("token_chunk", TokenChunkEvent { conv_id: conv_id.clone(), delta }),
                AgentEvent::ToolCall(tc) => app.emit("tool_call", tc),
                AgentEvent::ToolResult(tr) => app.emit("tool_result", tr),
                AgentEvent::ApprovalRequest(req) => app.emit("approval_required", req),
                AgentEvent::Done => { app.emit("message_done", &conv_id); break; }
                AgentEvent::Error(msg) => { app.emit("message_error", ErrorEvent { .. }); break; }
            };
        }
    });
    Ok(conv_id)
}

// ===== agent-runtime 主循环 =====
// crates/agent-runtime/src/executor.rs
impl AgentExecutor {
    async fn round_loop(&self) -> Result<RoundOutcome> {
        let mut round = 0;
        loop {
            round += 1;

            // ⚡ Hook: OnTurnStart
            self.hook_pipeline.execute(HookEvent::OnTurnStart, &mut hook_ctx).await;

            // [4] pending 注入
            for msg in self.pending_queue.drain().await {
                self.context.add_message(Message::user(msg.content));
            }

            // [5] 上下文构建 (SystemPromptBuilder 8 slots)
            let turn_ctx = self.build_turn_context().await?;

            // [6] ⚡ Hook: BeforeLlmCall (BudgetCheck → PrivacyFilter → Observability)
            self.hook_pipeline.execute(HookEvent::BeforeLlmCall, &mut hook_ctx).await;

            // [7] 预算检查
            self.budget_manager.check_before_call(&workspace_id, estimated_cost).await?;

            // [8-9] LLM 流式调用 (通过 ProviderRouter → 具体 Provider)
            let response = tokio::select! {
                result = self.provider.chat_stream(&turn_ctx.messages, &mut self.emitter) => result?,
                _ = self.guard.paused() => return Ok(RoundOutcome::Paused),
                _ = self.cancel_token.cancelled() => return Ok(RoundOutcome::Cancelled),
            };

            // [11] ⚡ Hook: AfterLlmCall
            self.hook_pipeline.execute(HookEvent::AfterLlmCall, &mut hook_ctx).await;

            // [12] 工具调用检查
            let tool_calls = response.tool_calls();
            if tool_calls.is_empty() {
                self.emitter.emit("done", DoneMetrics::from(&response)).await;
                return Ok(RoundOutcome::Done); // → [13]
            }

            // 进入工具执行流 (详见 §3)
            for call in tool_calls { /* ... */ }
        }
    }
}
```

```rust
// crates/agent-runtime/src/executor.rs — round_loop 工具执行段

for call in tool_calls {
    // [2] 解析 ToolCall
    let tool_call = ToolCall {
        id: call.id.clone(),
        tool_name: call.name.clone(),
        arguments: serde_json::from_str(&call.arguments)?,
    };

    // [3] ⚡ BeforeToolExecute Hook 链
    //     SecurityCheckHook(100) → PromptGuardHook(110) → ...
    let mut hook_ctx = HookContext::new(HookEvent::BeforeToolExecute, HookPayload::ToolRequest {
        tool_name: tool_call.tool_name.clone(),
        arguments: tool_call.arguments.clone(),
        call_id: tool_call.id.clone(),
        risk_level: tool.risk_level(),
    });
    self.hook_pipeline.execute(HookEvent::BeforeToolExecute, &mut hook_ctx).await;

    if hook_ctx.is_aborted() {
        // 安全策略拒绝：注入错误 ToolResult
        self.context.add_tool_result(tool_call.id, ToolResult::error("安全策略拒绝"));
        continue;
    }

    // [4] HumanGuard 审批
    let outcome = self.human_guard.check(&tool_call.tool_name, &tool_call.arguments).await?;

    match outcome {
        ApprovalOutcome::Approved => { /* 继续 */ }
        ApprovalOutcome::Rejected => {
            // 拒绝反馈注入，避免 LLM 无限重试
            self.context.add_tool_result(tool_call.id, ToolResult {
                is_error: true,
                output: vec![ToolContent::Text("用户拒绝了此操作".into())],
            });
            continue;
        }
    }

    // [5] 工具执行
    let result = self.context.tools
        .execute(&tool_call.tool_name, ToolInput::from(tool_call.arguments))
        .await;

    // [6-7] ⚡ AfterToolExecute Hook 链
    //       PromptGuardHook(110) → AuditLogHook(250)
    self.hook_pipeline.execute(HookEvent::AfterToolExecute, &mut hook_ctx).await;

    // [8] 结果注入 + 事件推送
    self.emitter.emit("tool_result", &result).await;
```

```rust
impl AgentExecutor {
    async fn build_turn_context(&self) -> Result<TurnContext> {
        // [Step 1] 构建 SystemPrompt (8 slots)
        let system_prompt = SystemPromptBuilder::new()
            .slot_soul(&self.persona.soul_path)?                    // Slot[1]
            .slot_workspace_prompt(&self.persona.workspace_prompt)   // Slot[2]
            .slot_session_overlay(&self.persona.session_overlay)     // Slot[3]
            .slot_skills(&self.session.skills).await?                // Slot[4]
            .slot_memory(&self.workspace_id, &self.pool).await?     // Slot[5]
            .slot_knowledge(&self.knowledge_service).await?         // Slot[6]
            .slot_tools(&self.session.tools)                        // Slot[7]
            .slot_planning_instructions()                           // Slot[8]
            .build()?;

        // [Step 2] 消息历史：按 ContextSlot 优先级填充
        // Pinned（系统消息，永不驱逐）> Regular（正常对话）> Ephemeral（工具结果，可驱逐）
        let messages = ContextBuilder::new(self.token_budget.remaining())
            .add_system(system_prompt)                     // Pinned
            .add_history(self.context.message_history())   // Regular
            .add_tool_results(self.context.pending_tool_results()) // Ephemeral
            .compress_if_needed()                          // 超限时压缩早期消息
            .build();

        // [Step 3] 组装 TurnContext
        Ok(TurnContext {
            conversation_id: self.context.conversation_id.clone(),
            model: self.config.model.clone(),
            system_prompt,
            messages,
            available_tools: self.session.tools.definitions_for(&messages),
            permissions: self.session.permissions.clone(),
            max_tool_rounds: self.config.max_tool_rounds,
            depth: self.depth,
            round: self.round,
        })
    }
}
```

```rust
impl SkillContextInjector {
    /// 处理 SKILL.md 中的动态内容
    pub async fn inject(&self, skill: &SkillManifest, user_args: &str) -> String {
        let mut content = skill.guide_content.clone();

        // !cmd 预处理：执行嵌入的 shell 命令，替换为输出
        for cmd_block in extract_cmd_blocks(&content) {
            let output = exec_shell(&cmd_block.command).await;
            content = content.replace(&cmd_block.raw, &output);
        }

        // $ARGUMENTS 替换：将用户消息填入占位符
        content = content.replace("$ARGUMENTS", user_args);

        content
    }
}
```

```rust
// crates/agent-runtime/src/workflow/dag_engine.rs

impl WorkflowExecutor {
    pub async fn run(&self, workflow: &Workflow) -> Result<WorkflowResult> {
        // [3a] 拓扑排序
        let levels = topological_sort(&workflow.dag)?;
        let mut outputs: HashMap<NodeId, Value> = HashMap::new();

        for level in levels {
            // [4] 同一层级的节点并行执行
            let tasks: Vec<_> = level.nodes.iter().map(|node| {
                let input = self.resolve_inputs(node, &outputs);
                async move {
                    let result = NodeExecutor::execute(node, input).await;
                    // [5] 写入检查点
                    self.checkpoint(node.id, &result).await;
                    (node.id, result)
                }
            }).collect();

            let results = futures::future::join_all(tasks).await;

            // [6] 变量传递：本层输出 → 下层输入
            for (node_id, result) in results {
                outputs.insert(node_id, result.output);
            }
        }

        Ok(WorkflowResult { outputs, status: WorkflowStatus::Completed })
    }
}
```

```text
      │                     │ │                    │                     │                      │

      │                     │ │  ProviderRouter    │                     │                      │
      │                     │ │  ::failover()      │                     │                      │
      │                     │ │  Claude → DeepSeek │                     │                      │
      │                     │ │                    │                     │                      │
      │                     │ ├─ skip (工具失败)   │                     │                      │
      │                     │ │  注入 ToolResult   │                     │                      │

      │                     │ │  LLM 据此调整策略  │                     │                      │
      │                     │ │                    │                     │                      │
      │                     │ └─ abort (不可恢复)  │                     │                      │
      │                     │    RuntimeError 构造 │                     │                      │
      │                     │                      │                     │                      │
 [4]  │                     │ 所有重试耗尽:        │                     │                      │
      │                     │──RuntimeError───────►│                     │                      │
      │                     │  { category,         │                     │                      │
      │                     │    message,          │                     │                      │
      │                     │    recoverable,      │                     │                      │

 [5]  │                     │                      │ ErrorPresenter      │                      │
      │                     │                      │ ::to_user_message() │                      │
      │                     │                      │ 技术错误 → 用户     │                      │
      │                     │                      │ 友好提示文案        │                      │
      │                     │                      │                     │                      │
 [6]  │                     │                      │──emit("message_     │                      │
      │                     │                      │  error", {          │                      │
      │                     │                      │  conv_id,           │──Tauri Event────────►│
      │                     │                      │  code,              │                      │
      │                     │                      │  message,           │                      │
      │                     │                      │  recoverable })─────│                      │
      │                     │                      │                     │                      │
 [7]  │                     │                      │                     │                      │ 前端处理:
      │                     │                      │                     │                      │ ├─ recoverable
      │                     │                      │                     │                      │ │  = true
      │                     │                      │                     │                      │ │  → Toast 通知
```

### 8.2 错误分类表

| 错误来源 | 错误类型 | 可重试 | 可降级 | 用户提示 |
|---------|---------|--------|--------|---------|
| Provider | 429 Rate Limit | 是 (Retry-After) | 是 | "请求过于频繁，正在等待..." |
| Provider | 500 Server Error | 是 (指数退避) | 是 | "服务暂时不可用，正在重试..." |
| Provider | 401 Auth Error | 否 | 否 | "API 密钥无效，请在设置中更新" |
| Provider | Context Too Long | 否 | 是 (降级模型) | "对话过长，已自动压缩上下文" |
| Provider | Content Filter | 否 | 否 | "内容被安全策略过滤" |
| Tool | Timeout | 是 (1次) | N/A | "工具执行超时，已跳过" |
| Tool | Permission Denied | 否 | N/A | "权限不足，请检查配置" |
| Tool | Execution Error | 否 | N/A | "工具执行失败：{detail}" |
| Network | Connection Lost | 是 (等待恢复) | N/A | "网络连接已断开" |
| Budget | Quota Exceeded | 否 | 是 (关闭 YOLO) | "Token 预算已用尽" |
