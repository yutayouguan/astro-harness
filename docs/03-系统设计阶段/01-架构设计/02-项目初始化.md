# 项目初始化

> 阶段：系统设计 | 状态：定稿 | 说明：项目初始化步骤与模块开发顺序

## 前置依赖

```bash
# Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Node.js 包管理器
npm install -g pnpm

# Tauri CLI
cargo install tauri-cli --version "^2"

# 系统依赖（Linux）
# sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev
```

## 初始化步骤

### 1. 创建项目根

```bash
mkdir astro-agent && cd astro-agent
git init
```

### 2. 根 Cargo.toml（workspace）

```toml
[workspace]
members = [
    "crates/agent-core",
    "crates/agent-providers",
    "crates/agent-runtime",
    "crates/agent-mcp-server",
    "crates/agent-evals",
    "apps/desktop/src-tauri",
]
resolver = "2"

[workspace.dependencies]
tokio        = { version = "1", features = ["full"] }
serde        = { version = "1", features = ["derive"] }
serde_json   = "1"
anyhow       = "1"
thiserror    = "2"
async-trait  = "0.1"
tracing      = "0.1"
tracing-subscriber = { version = "0.3", features = ["env-filter", "json"] }
uuid         = { version = "1", features = ["v4", "serde"] }
chrono       = { version = "0.4", features = ["serde"] }
reqwest      = { version = "0.12", features = ["json", "stream", "multipart"] }
tokio-stream = "0.1"
bytes        = "1"
rhai         = "1"
```

### 3. 创建 Rust crate

```bash
cargo new --lib crates/agent-core
cargo new --lib crates/agent-providers
cargo new --lib crates/agent-runtime
cargo new --lib crates/agent-mcp-server
cargo new --lib crates/agent-evals
```

### 4. 创建 Tauri 应用

```bash
pnpm create tauri-app apps/desktop --template react-ts --manager pnpm
```

### 5. 前端依赖

```bash
cd apps/desktop

# UI & 样式
pnpm add tailwindcss @tailwindcss/vite
pnpm dlx shadcn@latest init

# 路由 & 状态
pnpm add @tanstack/react-router zustand

# Markdown & 代码高亮
pnpm add react-markdown remark-gfm rehype-raw shiki

# 动画 & 媒体
pnpm add motion wavesurfer.js

# Tauri API
pnpm add @tauri-apps/api @tauri-apps/plugin-shell
```

### 6. 根 package.json

```json
{
  "name": "astro-agent",
  "private": true,
  "scripts": {
    "dev":   "pnpm --filter desktop tauri dev",
    "build": "pnpm --filter desktop tauri build",
    "fe":    "pnpm --filter desktop dev"
  }
}
```

### 7. pnpm-workspace.yaml

```yaml
packages:
  - "apps/*"
```

### 8. 一键创建目录结构

```bash
mkdir -p \
  crates/agent-core/src/{agent,tools/{builtin,mcp/transport},skills/builtin,memory,evolution} \
  crates/agent-providers/src/{traits,types,providers/{anthropic,openai,deepseek,minimax}} \
  crates/agent-runtime/src \
  crates/agent-mcp-server/src \
  crates/agent-evals/src/benchmarks \
  apps/desktop/src-tauri/src/{commands,capabilities} \
  apps/desktop/src/{pages,components/{chat,evolution,shared},store,hooks,lib,types} \
  skills \
  prompts/skills \
  configs \
  mcp-servers \
  docs
```

### 9. 环境变量

```bash
cp .env.example .env
```

`.env.example`：

```bash
# LLM Providers
ANTHROPIC_API_KEY=
OPENAI_API_KEY=
GOOGLE_API_KEY=
DEEPSEEK_API_KEY=
MINIMAX_API_KEY=
MINIMAX_GROUP_ID=

# 默认路由（多媒体主力：Google + MiniMax）
DEFAULT_TEXT_MODEL=claude-sonnet-4-5
DEFAULT_EMBEDDING_MODEL=text-embedding-004   # Google
DEFAULT_TTS_PROVIDER=minimax                  # MiniMax speech-01-hailuo
DEFAULT_ASR_PROVIDER=google                  # Google Cloud STT
DEFAULT_IMAGE_PROVIDER=google                # Google Imagen 3
DEFAULT_VIDEO_PROVIDER=google                # Google Veo 3.1（含原生音频）
DEFAULT_MUSIC_PROVIDER=google                # Google Lyria 3 Pro
```


## 建议开发顺序

```text
Week 1  agent-providers  →  TextClient trait + Claude & OpenAI 实现
Week 2  agent-core       →  Agent 主循环 + Tool/Skill 注册表
Week 3  Tauri commands   →  run_agent + 事件流推送到前端
Week 4  前端 Chat 页面   →  流式渲染 + ToolCallCard + AgentTrace
Week 5  多模态           →  TTS/ASR/Image/Video provider 实现
Week 6  MCP client       →  McpToolBridge + transport 实现
Week 7  进化引擎         →  反思 + Skill 合成 + PromptOptimizer
Week 8  Evolution 页面   →  进化日志展示 + 人工审批 UI
```
