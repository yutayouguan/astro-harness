## 项目定位

Astro Agent 是一个 Rust 实现的 AI Agent 框架，支持：

- 多 Provider、多模态（文本、图像、音频、视频、音乐、嵌入）；支持 Anthropic、OpenAI（Chat Completions + Responses API）、Google Gemini（Interactions API + generateContent API）、DeepSeek（专属客户端，含 reasoning_content 回传）、MiniMax（专属客户端，含 reasoning_split / base_resp 处理）、以及月之暗面等 OpenAI 兼容厂商（配置即接入）
- MCP 协议（作为 client 接入外部 MCP server，也可暴露为 MCP server）
- Skills 系统（高层能力单元，可编排多个 Tool）
- 子 Agent 派生（树状/图状多 Agent 协作）
- 自我进化（反思、Skill 合成、Prompt 优化、工具生成、记忆蒸馏）
- **自适应规划**：LLM 自判断任务复杂度，预计超过 3 步工具调用或涉及不可逆操作时自动生成执行计划等待用户确认；简单任务直接执行
- **Pending 消息队列**：Agent 运行中用户追加的消息入队，当前轮次完成后注入下一轮 context
- **YOLO 开关**：临时跳过 L2/L3 审批弹窗；费用超限时强制关闭；三个机制正交（自适应规划 ⊥ L1/L2/L3 风险门控 ⊥ YOLO）
- Tauri v2 桌面端（React + TypeScript）

## Monorepo 结构

所有 Rust crate 扁平放置在 `crates/agent-*` 下（package name 保持短名），共 25 个 crate + 1 个桌面应用。

```text
astro/
├── crates/                         # 所有 Rust crate（扁平 agent-* 命名）
│   ├── agent-types/                # 共享类型（Message, ToolEntry, ToolExposure 等）
│   ├── agent-config/               # 分层配置原语
│   ├── agent-protocol/             # Core 领域事件协议（Event, EventMsg）
│   ├── agent-rollout/              # JSONL append-only 历史
│   ├── agent-home/                 # ~/.astro 路径约定
│   ├── agent-skills/               # Skill 管理
│   ├── agent-hooks/                # 三总线 Hook 系统
│   ├── agent-providers/            # 多厂商 LLM/图像 Provider
│   ├── agent-proto/                # Protobuf / gRPC 契约
│   ├── agent-session/              # 会话 SQLite 存储
│   ├── agent-artifacts/            # 文件空间 + 知识库索引
│   ├── agent-usage/                # 用量统计
│   ├── agent-mcp/                  # MCP 客户端
│   ├── agent-memory/               # 记忆管理
│   ├── agent-network-proxy/        # 受管网络代理
│   ├── agent-sandbox/              # 沙箱权限控制
│   ├── agent-delegate/             # 轻量级工具执行代理
│   ├── agent-subagents/            # V2 Agent Thread 系统
│   ├── agent-evolution/            # 自进化引擎
│   ├── agent-cron/                 # 定时任务
│   ├── agent-workflow/             # 可视化工作流引擎
│   ├── agent-a2ui/                 # AG-UI 声明式组件
│   ├── agent-tools/                # 工具实现 + ToolRegistry
│   ├── agent-core/                 # Agent 运行时核心
│   └── agent-server/               # gRPC 服务端
│
├── apps/
│   └── desktop/                    # Tauri 桌面应用
│       ├── src-tauri/              # Tauri Rust 层
│       └── src/                    # 前端 React + TypeScript
│
├── docs/                           # 设计文档
├── Cargo.toml                      # workspace root
└── package.json
```

## 核心能力层次

### 事件管线（单一事实链）

```text
AstroThread::submit(Op)
  → bounded(512) submission channel
  → Session::submission_loop — 有序 Op 分发
  → SessionTask::run_turn — 模型/工具循环
  → EventMsg — Core 单一事件格式
  → rollout policy + JSONL append（权威历史）
  → Core event queue（单 receiver）
  → Server ThreadListener → ThreadHistoryBuilder
  → per-connection bounded(128) queues
  → Tauri ThreadEventsBridge / external Thread clients
```

### 工具执行与延迟加载

```text
LLM 初始上下文
    │
    ▼  schemas_for_api() 仅含 Direct 工具
ToolRouter 工具路由
    │
    ├─ Direct 工具    → 直接可见，正常调用
    ├─ tool_search    → BM25 搜索 Deferred 工具
    │                   → activate_deferred() → 后续可见
    ├─ MCP 工具       → mcp__{server}__{tool} 前缀
    ├─ Skill soft-alias → 自动改写为 skills(action=load)
    └─ 子 Agent 工具   → spawn_agent / send_message 等 V2 工具
```

### 子 Agent 系统

```text
AgentControl（根级共享控制器）
    ├─ AgentGraphStore（subagents.db 线程图/邮箱/状态事件）
    ├─ AgentRegistry（RAII 预留/配额）
    └─ ActivityBus（事件等待）

状态：PendingInit → Running → Completed / Interrupted / Errored → Shutdown
```

## 已实现架构概览

- 25 个 Rust crate + 1 个 Tauri 桌面应用
- 15+ LLM 厂商支持（OpenAI、Claude、Google Interactions、DeepSeek、MiniMax、Ollama、Azure 等）
- ToolExposure 三级暴露（Direct/Deferred/Hidden）+ BM25 工具搜索
- V2 Agent Thread 子 Agent 系统（6 个模型工具）
- 三总线 Hook 系统（Plugin/Gateway/Shell）
- JSONL rollout 权威历史 + SessionStore 投影重建
- 沙箱权限控制（PermissionProfile）+ 受管网络代理
- 可视化工作流引擎（29 种节点、DAG 执行）
- AG-UI 声明式生成式 UI（22 种组件）
