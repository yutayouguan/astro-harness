# Hunyuan 眨眼研究：覆盖曲面方案未通过视觉验收

**状态：拒绝作为发布素材。没有制作眨眼 APNG，没有替换桌面宠物。**

工程与对照图：`output/hunyuan-eyelids-20260914-Ixwto3/`。
修改前状态保存在 `before-eyelids.blend`，独立实验工程为
`hunyuan-eyelid-study.blend`。最终保存时所有实验眼睑隐藏，模型恢复中立姿态。

## 已确认的结构

- 两只宠物均为一个高模对象、一个材质槽，没有原始眼睑 shape keys 或独立眼球对象。
- 直接按顶点索引统计，奶糖有 1,983 个连通分量，布丁有 6,220 个。
  这些数字不能当作可独立绑定的器官数量。
- 仅在内存中合并完全相同的顶点坐标（不改 Blender 网格）后，奶糖为
  749,996 个独立位置、布丁为 750,004 个；两者都只有 **1 个连通分量**。
  因而不能通过“分离松散部分”直接得到完整独立眼球或眼睑。
- 高光、眼圈、毛色与眼部几何相互叠加；新增薄片只遮住瞳孔并不等于自然闭眼。

## 本轮试验

在独立复制的第二轮骨骼场景中添加上下眼睑，源高模顶点、UV、图片像素不修改。
试验采用 BVH 射线投影、原图毛色采样、7 档闭合形态、跟随头骨的控制。
逐版保留近距离睁眼、半闭眼、闭眼截图。

1. v1：贴面曲面，半闭时穿透、全闭有眼圈残留。
2. v2：增加表面间距和平滑拟合，遮挡改善，但像硬质盖子。
3. v3：将 UV 取样转换为线性色彩顶点属性，去掉跨 UV 岛插值裂纹；
   上眼睑承担约 82.5% 的闭合距离。仍有明显独立壳体感。
4. v4：边缘颜色过渡与阴影调整，未解决结构问题。
5. v5：扩大到眼周皮肤过渡带，不再只在眼球范围内加盖；仍有皮肤接缝、
   拉伸和旧眼圈痕迹，未通过验收。

这轮没有用图片模型重新生成宠物，因问题在眼部结构与连续皮肤的过渡。
也没有通过压扁整块眼睛贴图来伪造眨眼。

## 防误发布与检查

`tools/desktop-pet/hunyuan_eyelid_study.py` 明确标记为 rejected experiment。
`build_lids()` 默认隐藏结果，只能用 `preview=True` 显式开启研究预览。
工具不提供打包、发布或应用到桌面的入口。

`verify_and_reject()` 检查独立网格与原顶点完全一致、形态键范围和相对基准、
眼睑绑定目标，随后复位并隐藏所有实验眼睑，写出拒绝原因和 QA JSON。
这些数值检查不替代视觉验收，数值通过不代表可以发布。

只读连通性分析可通过 `inspect_connectivity(pet)` 复现，底层纯 NumPy 工具为
`hunyuan_connectivity.py`。测试包括 UV 重复顶点、近邻不误合并、独立顶点、
非法边和长链连通性：

```sh
uv run --offline --no-project --with numpy python -m unittest discover \
  -s tools/desktop-pet -p test_hunyuan_connectivity.py -v
```
