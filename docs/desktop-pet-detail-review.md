# 宠物详情页局部优化（2026-09-11）

范围：用户提供的场景空状态、新增场景、动作与偏好三张截图。仅改详情相关组件和独立 `pet-detail.css`；不改创建页、通用设置、共享样式文件、真实配置或后台协议。

| Before | After | Why |
| --- | --- | --- |
| 详情头部介绍很长，应用操作悬在中间 | 精简身份与状态，操作区靠右 | 首屏优先展示管理内容 |
| Tab 背景横贯整个内容区 | Tab 背景随内容收紧 | 去掉无内容的长胶囊 |
| 新增表单插在 Tab 上方且占满宽度 | 场景区域内的紧凑表单 | 不再推动 Tab；草稿留在所属区域 |
| 巨大空状态重复说明 | 两行短说明，创建时隐藏 | 减少重复占位，读取完成后才确认空状态 |
| 动作预览与默认设置缺少界限 | 预览有独立标题，保存说明留在设置旁 | 不混淆预览、保存与应用 |
| 小复选框远离说明、保存状态模糊 | 标准开关与就近提示、未保存状态 | 更易理解影响范围，改回原值恢复已保存状态 |

验证记录：类型检查、局部 Stylelint、13 项聚焦回归测试通过；使用独立端口 6317 的 Storybook 测试数据，在 Codex 内置浏览器检查明暗主题、零场景、新增并保存场景、Escape 取消并恢复焦点、动作偏好、安静模式禁用动作间隔，以及改回原值后的保存状态。未调用图片模型，未操作正式宠物数据或重启正式应用。

这不是原生桌面窗口验收。详情页修复由主线程复核后与以下补修统一提交；不包含其他功能和连续眨眼实现的并行改动。

## 本轮补修与复核

- 修复应用默认配置或保存其他偏好时误清空新场景草稿的问题；仅成功保存名字/场景后关闭对应编辑器。
- 新场景保存与 Esc 取消后都把键盘焦点还给新增按钮。
- 移除头部更多菜单的自动左边距，窄窗口下两个操作保持相邻，不再被推到两端。
- 示例场景不再使用含多只猫和 UI 的宣传图作为壁纸；复用已有纯环境图 `stories/assets/pet-room.jpeg`。不修改真实壁纸，不调用图片模型。
- 通过 Codex 内置浏览器复核独立提交快照：760px/1232px、明暗主题、新增表单所属区域、36px 控件高度、应用默认配置后的草稿保留、保存、Esc、焦点恢复、安静模式和改回原值后的保存状态。
- 新增两项契约测试和一项浏览器回归用例；本轮交互检查由内置浏览器完成，没有运行 Playwright CLI 套件。
- 本轮独立快照：6 项详情/草稿聚焦测试、TypeScript/Vite 构建通过；前端全量 911/913，通过范围之外的两项仍为原有侧栏测试。正式 Astro Agent.app 已打包，未重启正式应用。
