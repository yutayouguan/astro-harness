# 用户故事与验收标准

> 文档状态：草稿 | 阶段：需求分析 | 属性：可选

---

## 一、用户角色定义

| 角色 | 简称 | 描述 |
| ---- | ---- | ---- |
| 开发者用户 | 开发者 | 使用 AI 辅助编码、调研、架构设计 |
| 内容创作者 | 创作者 | 使用 AI 生成文案、图像、音频 |
| 研究人员 | 研究者 | 使用 AI 整理文献、构建知识库 |
| 企业管理员 | 管理员 | 配置工作区、管理权限、监控费用 |

## 二、用户故事清单

### Epic 1：基础对话

#### US-001

> 作为**开发者**，我需要**与 AI 进行流式文本对话**，以便**实时看到回复内容而不是等待完整响应**。

验收标准：

- [ ] 发送消息后 500ms 内开始显示第一个字符
- [ ] 支持 Markdown 渲染（标题、列表、代码块、表格）
- [ ] 代码块显示语言标签和一键复制按钮
- [ ] 可按 Esc 中断正在生成的输出

---

#### US-002

> 作为**创作者**，我需要**将图片直接拖拽到对话框**，以便**询问 AI 关于图片内容的问题**。

验收标准：

- [ ] 支持拖拽图片文件（JPG/PNG/WebP/GIF）到对话框
- [ ] 支持从剪贴板粘贴图片（Cmd+V）
- [ ] 图片以缩略图形式展示在消息中
- [ ] 文件大小限制 20MB，超出时提示

---

#### US-003

> 作为**任意用户**，我需要**查看历史对话记录**，以便**找回之前的重要内容**。

验收标准：

- [ ] 对话列表按时间倒序排列，分组（今天/昨天/本周/更早）
- [ ] 支持对话标题搜索（全文搜索）
- [ ] 点击历史对话可恢复完整上下文
- [ ] 重启应用后历史记录仍然存在

---

### Epic 2：Skills 系统

#### US-010

> 作为**开发者**，我需要**在对话中输入 `/code-review` 快速触发代码审查 Skill**，以便**不用每次重新输入完整的 Prompt**。

验收标准：

- [ ] 输入 `/` 后立即弹出命令选择器浮层，展示所有可用命令（Skill / Tool / 系统命令）
- [ ] 继续输入字符实时模糊过滤，如 `/trans` 匹配"翻译"
- [ ] 每条命令显示名称、简短描述、来源类型标签（Skill / Tool / 系统）
- [ ] 键盘 `↑` `↓` 切换，`Enter` 确认执行，`Esc` 关闭浮层
- [ ] Skill 执行结果作为 AI 消息插入对话，执行时显示进度状态
- [ ] 系统命令（`/new-chat`、`/model`、`/clear` 等）直接执行对应操作

---

#### US-011

> 作为**开发者**，我需要**自定义一个 Skill 并保存**，以便**将我常用的 Prompt 组合复用**。

验收标准：

- [ ] 可通过 `SKILL.md` 目录结构定义 Skill（frontmatter 含 name、description、trigger_keywords）
- [ ] 自定义 Skill 出现在 / 命令选择器列表中
- [ ] 可编辑、删除、导出自定义 Skill

---

验收标准：

- [ ] 生成的图片内联显示在对话中
- [ ] 支持点击图片全屏预览

#### US-021

> 作为**创作者**，我需要**语音输入消息**，以便**在不方便打字时与 AI 交流**。

验收标准：

### Epic 3.1：视频能力

#### US-022

> 作为**创作者**，我需要**上传视频文件让 AI 理解内容**，以便**快速获取视频摘要、字幕或关键帧分析**。

验收标准：

- [ ] 支持上传 MP4 / MOV / AVI 格式视频（< 500MB）
- [ ] AI 可识别视频内容并给出文字描述和分段摘要
- [ ] 支持提取字幕（有声轨时自动 ASR 转写）
- [ ] 支持指定时间段进行分析（如"分析第 2 到第 5 分钟"）
- [ ] 视频缩略图内联展示在对话中

---

#### US-023

> 作为**创作者**，我需要**用文字描述生成一段视频**，以便**快速产出短视频素材**。

验收标准：

- [ ] 输入文字描述后调用视频生成 Provider（如 Sora、Kling）
- [ ] 生成进度实时展示（视频生成通常需要数十秒至数分钟）
- [ ] 生成完成后视频内联播放，支持下载保存
- [ ] 支持选择分辨率、时长、风格等参数

---

### Epic 3.2：音乐能力

#### US-024

> 作为**创作者**，我需要**上传音频文件让 AI 分析音乐内容**，以便**了解曲风、节拍、情绪和歌词**。

验收标准：

- [ ] 支持上传 MP3 / WAV / FLAC 格式音频（< 100MB）
- [ ] AI 可识别曲风（流行/古典/电子等）、BPM、情绪（欢快/悲伤等）
- [ ] 有人声时自动提取歌词并展示
- [ ] 音频内联波形播放器展示，可拖拽定位

---

#### US-025

> 作为**创作者**，我需要**用自然语言描述生成一段音乐**，以便**快速获取背景音乐或灵感素材**。

验收标准：

- [ ] 输入风格、情绪、时长等描述后调用音乐生成 Provider（如 MiniMax、Suno）
- [ ] 生成完成后音频内联播放，支持下载为 MP3
- [ ] 支持对生成结果进行续写或变奏

#### US-031

> 作为**任意用户**，我需要**实时看到当前对话消耗的 Token 数量和费用估算**，以便**控制使用成本**。

验收标准：

- [ ] 输入框下方显示当前对话累计 Token 数
- [ ] 发送消息后更新实际消耗 Token 和费用
- [ ] 费用精确到小数点后 4 位（单位：美元）
- [ ] 超出预算时弹窗提示，可选择继续或停止

验收标准：

- [ ] 支持拖拽上传 PDF、Markdown、TXT 文件

### Epic 5.1：工作空间文件管理

#### US-051

> 作为**研究者**，我需要**在工作区内管理我的文件和文件夹**，以便**将项目资料统一存放在 AI 工具内**。

验收标准：

- [ ] 支持三种视图切换：树形视图（展开/折叠文件夹）、列表视图（含元数据列）、网格视图（缩略图卡片）
- [ ] 支持新建、重命名、移动、删除文件和文件夹
- [ ] 支持拖拽本地文件导入工作区
- [ ] 支持内联预览：Markdown（渲染后展示）、图片、PDF、音频波形、视频播放
- [ ] 内置 Markdown 编辑器，左右分屏实时预览
- [ ] 视图偏好记忆，重启应用后保持上次所选视图

> 优先级提升说明：US-052（AI 文档归档）依赖文件管理基础设施，因此将本故事提升至 P0/v0.1。

---

#### US-052

> 作为**创作者**，我需要**将 AI 生成的文章或代码一键保存到工作区**，以便**方便后续查找和复用**。

验收标准：

- [ ] AI 回复中的文档/代码块显示「💾 保存」按钮，点击后弹出确认弹窗（可修改文件名和目标目录）
- [ ] 系统根据文件扩展名和内容自动推断类型，路由到 `ai-docs/code/`、`reports/`、`articles/`、`data/`、`other/` 对应子目录
- [ ] 默认命名格式为 `YYYY-MM-DD_<AI推断标题>.<ext>`，用户可在确认弹窗中修改
- [ ] 保存时数据库记录 `file_path + conversation_id + message_id`，文件管理页显示「来源对话」入口，点击可跳转回源消息
- [ ] `ai-docs/` 目录随工作区物理隔离，不同工作区的 AI 产物互不可见
- [ ] 工作区文件管理页支持按类型/日期/关键词搜索、重命名、删除 AI 生成文档
- [ ] 文档修改后保留版本历史，可查看差异和回溯（P2）

验收标准：

- [ ] 文件右键菜单有"与 AI 对话"入口
- [ ] 点击后自动开启新对话，文件内容作为系统上下文注入
- [ ] 对话框顶部显示当前引用的文件名，可点击移除
- [ ] 支持同时选中多个文件，作为联合上下文
- [ ] 对话中可输入 `@文件名` 随时引用工作区内任意文件

### Epic 6：多工作区

#### US-050

> 作为**开发者**，我需要**创建独立的"工作"和"个人"两个工作区**，以便**隔离不同场景的对话历史和配置**。

验收标准：

- [ ] 可创建、重命名、删除工作区
- [ ] 切换工作区后对话列表、知识库、Skills 配置独立切换
- [ ] 工作区之间的 Provider 配置可单独设置

---

#### US-050a：手动新建工作区

> 作为**用户**，我需要**通过侧边栏手动新建工作区并选择预设模板**，以便**快速建立适合当前场景的隔离环境**。

验收标准：

- [ ] 侧边栏底部有 `+` 按钮，点击弹出新建工作区对话框
- [ ] 新建时可输入工作区名称、选择图标颜色
- [ ] 提供内置模板供选择（通用助手 / 代码助手 / 写作助手 / 研究助手 / 空白），选后自动填入对应 System Prompt 和默认工具集
- [ ] 创建完成后自动切换到新工作区，3 秒内完成
- [ ] 每个用户最多创建 20 个工作区，超限时提示并引导删除旧工作区

#### US-050b：手动切换工作区

> 作为**用户**，我需要**在侧边栏点击切换工作区**，以便**在不同场景之间快速跳转且数据不相互干扰**。

验收标准：

- [ ] 侧边栏常驻展示所有工作区列表，当前激活工作区有高亮标识
- [ ] 点击切换后，对话列表、知识库、文件、Skills 激活状态、Agent Persona 全部独立切换
- [ ] 切换时若当前工作区有进行中的对话（流式输出未结束），提示用户确认或后台保持运行
- [ ] 切换耗时 < 500ms（无需重新加载模型，复用已有 AgentContext 缓存）
- [ ] 支持键盘快捷键（macOS `⌘ + 数字键`，Windows `Ctrl + 数字键`）快速跳转工作区

#### US-050c：Agent 主动提示切换工作区

> 作为**用户**，我需要**当对话主题明显偏离当前工作区定位时，Agent 提示我切换工作区**，以便**数据归档到正确的工作区，而无需我时刻关注当前所在工作区**。

设计原则：**Agent 只提示，不自动切换**。工作区承载记忆、文件、知识库等重状态，自动切换易导致数据归错位置，信任成本过高。

验收标准：

- [ ] Agent 在以下情形触发提示气泡（每个工作区每次会话最多提示 1 次，避免打扰）：
  - 当前工作区有明确定位（System Prompt 含明确领域描述），且连续 3 条消息的主题与定位偏差明显
  - 用户输入内容触发了另一个已有工作区的关键词匹配（如在"代码助手"区发送"帮我写一篇文章"）
- [ ] 提示气泡内容示例：`你目前在「代码助手」工作区，这个问题更适合「写作助手」工作区。要切换过去吗？[切换] [留在这里]`
- [ ] 点击「切换」执行工作区切换（等同 US-050b 手动切换流程），点击「留在这里」关闭提示且本轮会话不再提示
- [ ] 提示判断在本地完成（基于关键词规则或轻量分类），不额外消耗 LLM Token

### Epic 10：对话分支

#### US-081

> 作为**创作者**，我需要**从某条 AI 回复处分叉出多个方向继续探索**，以便**不破坏原对话的同时比较不同思路**。

验收标准：

- [ ] AI 回复的操作菜单中有"从此处分支"入口
- [ ] 分支后进入独立对话线，侧边栏显示分支树状结构
- [ ] 可在分支间自由切换，各分支独立保存
- [ ] 可将某个分支设为主线，其余分支归档

### Epic 11：多模型对比

#### US-082

> 作为**开发者**，我需要**把同一个问题同时发给 Claude 和 GPT-4o 并排查看结果**，以便**选出最适合当前任务的模型**。

验收标准：

- [ ] 消息发送时可选择"多模型对比模式"，勾选 2-4 个模型
- [ ] 各模型回复并排展示，顶部标注模型名称和费用
- [ ] 可点击"采用此回复"将某个回复作为后续对话的上下文
- [ ] 对比结果可保存，在模型洞察界面可查看历次对比记录

### Epic 12：上下文可视化

#### US-083

> 作为**任意用户**，我需要**直观看到当前对话占用了多少上下文空间，并能手动管理**，以便**精确控制 Token 消耗而不依赖自动压缩**。

验收标准：

- [ ] 对话侧边有 Token 占用进度条，接近上限时变红并提醒
- [ ] 点击进度条展开各条消息的 Token 占比列表
- [ ] 可右键某条消息选择"从上下文移除"
- [ ] 可将重要消息"钉住"，自动压缩时跳过钉住的消息

---

### Epic 13：异步任务与通知

#### US-084

> 作为**创作者**，我需要**提交视频生成任务后继续做其他事，完成时收到通知**，以便**不必盯着进度条等待**。

验收标准：

- [ ] 耗时任务（视频/音乐生成、大文档摄入）提交后立即返回，显示"任务已提交"
- [ ] 顶栏任务中心图标显示进行中任务数量
- [ ] 任务完成时推送桌面系统通知，点击可跳转到结果
- [ ] 应用内消息中心记录所有通知历史（任务完成、进化提案、费用预警）
- [ ] 可在任务中心手动取消运行中的任务

### Epic 14：Agent 调试模式

#### US-085

> 作为**开发者**，我需要**开启调试模式查看每次请求的完整 payload 和耗时分解**，以便**排查自定义 Skill 执行异常的原因**。

验收标准：

- [ ] 设置中可开启调试模式，对话界面出现可折叠的调试面板
- [ ] 调试面板展示：实际生效的 system prompt、请求 JSON body、响应总耗时、首 Token 延迟
- [ ] 工具调用以树状结构展示调用链，每个节点显示耗时和输入输出
- [ ] 调试信息可一键复制为 JSON，方便提交 issue

### Epic 15：全局搜索

#### US-086

> 作为**研究者**，我需要**用一个搜索框同时检索对话、文件、知识库、Skills**，以便**快速定位任何历史内容而不必逐个模块翻找**。

验收标准：

- [ ] `Cmd+Shift+F` 唤起全局搜索浮层
- [ ] 搜索结果按类型分组展示：对话消息 / 工作区文件 / 知识库 / Skills
- [ ] 结果列表右侧实时预览选中条目的上下文片段
- [ ] 点击结果直接跳转到对应对话、文件或 Skill 详情
- [ ] 支持过滤器（仅搜索某一类型），支持工作区范围限定

---

### Epic 16：对话标签与归档

#### US-087

> 作为**开发者**，我需要**给对话打标签并按标签筛选**，以便**在大量历史对话中快速找到特定项目的对话**。

验收标准：

- [ ] 对话右键菜单 / 侧边栏可添加、删除标签，支持自定义颜色
