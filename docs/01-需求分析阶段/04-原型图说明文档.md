### 2.2 输入框交互说明

- 默认高度 56px，内容超过 3 行时自动扩展，最大高度 200px
- 左侧图标区：📎 附件（图片/文件）、💬 Skills 选择、🎤 语音输入
- 右侧：Token 实时估算 + 发送按钮（`Cmd+Enter`）
- 输入 `/` 时弹出命令选择器浮层（Skills / Tool / 系统命令统一入口）
- 输入 `!` 时弹出 Prompt 片段库选择器（模糊搜索）
- 输入 `@` 时弹出知识库/文件引用选择器
- 输入 `#` 时弹出历史对话引用选择器
- 输入 `[[` 时触发工作区文档双链引用

### 2.5 消息气泡交互说明

**用户消息**
- 右对齐，蓝色背景
- Hover 时显示：编辑、复制、删除、🌿 创建分支图标

**AI 消息**
- 左对齐，卡片背景
- 流式输出时末尾显示光标动画，`Esc` 可中断
- Hover 时显示：复制、重新生成、👍 👎 评分、📖 专注阅读、🌿 创建分支
- 代码块内置语言标签 + 一键复制 + ▶ 运行（Python / JS / Shell）

**ToolCall 卡片**

- 折叠状态：🔧 工具名称 + 执行状态（运行中 / 完成 / 失败）
- 展开状态：参数 JSON + 返回结果（可滚动）

**代码块执行结果（内联）**

```text

─────────────────────────────────────────────
stdout:
Hello, world!
运行完成 (0.23s)
─────────────────────────────────────────────
```

- 点击「切换工作区」：立即执行切换，当前对话内容保留在原工作区
- 点击「留在这里」：关闭气泡，本轮会话不再提示
- 提示判断基于本地关键词规则，不消耗 LLM Token

### 14.4 工作区切换确认（流式输出中）
