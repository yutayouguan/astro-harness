# 创作媒体（creative-media）

用内置工具做**可交付的媒体草稿**，而不是只聊创意。本技能覆盖：`music_gen`、`image_gen`、`tts`，以及**单镜头** `video_gen`。连续分镜 / 短剧镜头请加载 **`storyboard-video`**。

## 总原则

1. **先对齐，再生成**：关键创意方向不明确时，用 `ask_user`（可多题 + 选项）；用户说「你定 / 随便 / 惊喜我」则自行拍板，不再追问。
2. **思考稿要进工具参数**：思考里写好的歌词、详细画面描述、镜头说明，**必须原样传入**对应字段；禁止缩成一两句摘要。
3. **每次生成都带可读 `title`**（短中文名）：落盘为 `{title}-{时间戳}-{短id}.ext`；不传则退化为「音乐 / 图片 / 视频 / 语音」。
4. **一次少出几条**：先交付可预览结果，再按反馈迭代；不要一口气盲打十版。

## 何时用 `ask_user`

在调用生成工具**之前**，若下列关键项缺失且无法从上下文合理推断，先 `ask_user`（优先给 3～5 个选项 + 允许自定义）：

| 类型 | 建议澄清项 |
|------|------------|
| 音乐 | 流派/情绪、有人声还是纯器乐、语言、时长取向（短 clip / 完整歌）、是否已有歌词 |
| 图片 | 主体、艺术风格/媒介、构图景别、光影氛围、画幅（→ `aspect_ratio`） |
| 语音 | 语气风格、单人/多人、用途（旁白/角色） |
| 单镜视频 | 主体动作、运镜、风格、画幅 |

**不要澄清**：用户已写清、上下文已定调、或明确授权自由发挥的部分。不要为细枝末节连问多轮。

`ask_user` 示例（多步）：

```json
{
  "title": "确认创作方向",
  "questions": [
    {
      "id": "style",
      "question": "更想要哪种风格？",
      "options": ["民谣清唱", "电子流行", "纯器乐氛围"]
    },
    {
      "id": "lyrics",
      "question": "歌词怎么处理？",
      "options": ["你来写完整歌词", "我稍后贴歌词", "只要哼唱/拟声"]
    }
  ]
}
```

## 工作流：音乐（`music_gen`）

1. **收集**：主题、情绪、流派、语言、clip vs pro、是否要固定歌词。
2. **作词（如需人声）**：在思考中写出带 `[Verse]` / `[Chorus]` / `[Bridge]` 等分段的歌词 → 调用时放入 **`lyrics`**；只写主题让模型自写则可不传 `lyrics`。
3. **`prompt`**：写风格、乐器、BPM/节奏、人声特质、结构；**不要**把整段歌词只塞进 `prompt` 而漏掉 `lyrics`。
4. **`title`**：短歌名，如「采菌子歌」。
5. **`model`**：试听/短片用 `clip`；完整歌用 `pro`；`wav` 仅 `pro`。
6. 交付：路径 +（若有）返回的 `lyrics:` 段；按用户意见改词后重生成。

## 工作流：图片（`image_gen`）

1. **收集 / ask_user**：主体、风格、构图、氛围；用户要的画幅/分辨率 → **`aspect_ratio` / `image_size` 字段**（勿只写进 prompt）。
2. **`prompt`**：充实描述——主体与动作、场景、构图景别、光影色彩、材质、风格/媒介、情绪。思考稿原样传入。
3. **`title`**：短中文名，如「雨后山菌」。
4. 参考图 / 多轮编辑：`reference_images`、`previous_interaction_id`。
5. 交付路径；若还要做视频，提示可作 `video_gen` 的 `image` / `last_frame`。

## 工作流：语音（`tts`）

1. 确认文稿与语气；Google 路径可用 `style`、可选 `speakers`。
2. **`title`**：如「旁白草稿」。
3. 交付 `generated/audio/…` 路径。

## 工作流：单镜头视频（`video_gen`）

- **一镜试拍**：详细 `prompt` + 建议先 `image_gen` 出首帧再 `image=`；设 `title`。
- **多镜连续短片**：停止本技能流程，**加载并遵循 `storyboard-video`**。

## 文件与交付

- 图 → `generated/images/`
- 视频 → `generated/videos/`
- 音频（音乐/语音）→ `generated/audio/`
- 向用户汇报时用**相对路径 + 中文 title**，不要只念一长串无意义的 id。

## 约束

- 无 Google Key：音乐 / Veo 视频会失败，提示去「模型提供商」配置；图片/TTS 可能仍有 OpenAI 回退。
- 版权与敏感内容：不主动生成明显侵权或违规题材；有疑虑时先问用户。
- 本技能不负责剪辑成片、封面设计流水线或发行投放。
