# Pet scene fixture

`pet-room.jpeg` is the inspected, environment-only image from
`output/imagegen/pet-scenes-20260911/generated/naitang-afternoon.jpeg`.
It is an existing Astro-generated asset, not a new image-model request.
It has no animal or UI chrome, so a scene-preview pet is not duplicated.

Used only by the isolated Storybook fixture. It does not replace a user's
saved wallpaper or alter any desktop state.
